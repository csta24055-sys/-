# Box 資料の取得・読解: 試した方法と結果（2026-11-02）

Box は読み取り専用で扱う（アップロード・移動・共有リンク作成・メタデータ書込はしない）。取得した原本は `private_data/`（Git 管理外）にのみ置く。

## 使える手段（Box MCP 経由）

| 手段 | 内容 | 制約 |
|---|---|---|
| `get_file_content` | Box が生成したテキスト／Markdown 表現を返す | 応答が大きいと MCP 接続が切断される（実測: 18.6 MB・27 MB の xlsx で再現） |
| `ReadMcpResourceTool`（`files://<ID>`） | PDF は**原本バイナリ**、その他は Box のプレビュー表現（PDF 等）を保存する | プレビュー表現が 3 MB を超えると拒否。xlsb は対象外 |
| `get_preview_page` | ページ画像（PNG）を返し、目視で読める | 1 呼び出し 1 ページ。変換失敗のファイルは 0 バイト／404 |
| ローカル処理 | `pdftotext`、`pdftoppm`（PNG 描画）、`pdfimages`、Python | OCR エンジン（tesseract）は未導入。画像は目視で読解 |

Box API への直接アクセスはネットワーク上は到達可能（HTTP 401）だが、このセッションに Box の認証情報がないため使えない。Box MCP には一時ダウンロード URL を発行するツールがない（共有リンク作成は書込に当たるため使わない）。

## 資料別の結果

| 資料 | 試した方法 | 結果 |
|---|---|---|
| JEM1467(2015)（S-REF-04, 2.3 MB PDF） | get_file_content → テキスト表現なし／get_preview_page → 0 バイト・`conversion_failed`／**リソース取得で原本PDF → pdftotext** | **成功**（73ページ, テキスト層あり）。F-X-10 を規格式で検証（F-X-19） |
| センサー取扱説明書（S-2025-13, スキャンPDF） | get_file_content → 本文なし／get_preview_page → 0 バイト／**リソース取得で原本PDF → pdftoppm で PNG 化 → 目視** | **成功**（2ページ）。変換式・精度・クリーニング周期を確認（F-2025-22〜24, Q-11 解決） |
| 井口教授の計算式（S-REF-01, 手書き1ページ） | get_file_content → テキストなし／**get_preview_page で PNG → 目視** | **成功**（F-REF-01, Q-08 解決）。以前は 0 バイトだったが今回は描画された（Box 側の表現生成が完了したためと推定） |
| 周南測定データ.xlsx（S-2025-22, 27.4 MB） | get_file_content → 接続切断（2回）／リソース取得 → プレビュー 105 MB で拒否／**get_preview_page → 約990ページ中7ページを目視**／旧版 → 版は1つのみ／Box 検索 → 分割版・CSV なし | **一部成功**: 列構成と条件区分の開始時刻（10/5 14:00）を確認（F-2025-25/26）。全数値の取得は不可（990ページを画像で読むのは非現実的で、目視の読取誤差もある） |
| 測定データ等.xlsx（S-2025-24, 18.6 MB） | get_file_content → 接続切断／リソース取得 → プレビュー 797 MB で拒否 | 失敗 |
| 周南 黄砂時.xlsb（S-2025-23, 5.5 MB） | get_file_content → テキスト表現なし／リソース取得 → xlsb はプレビュー非対応 | 失敗 |
| I邸発塵量の同定.xlsx（S-2023-03 内, 51.5 MB） | get_file_content → 50 MB 上限／リソース取得 → 「表現生成中」 | 失敗（時間をおいて再試行の余地あり） |

## 人の作業が必要なもの（技術的手段で取得できなかったもののみ）

1. **周南測定データ.xlsx・測定データ等.xlsx・周南 黄砂時.xlsb** — 全行の数値が必要（住宅Dの条件①係数0.14・EP稼働期間・黄砂時の検証）。
   - 手順: Box で各ファイルを Excel で開く → Sheet1 を「名前を付けて保存 → CSV UTF-8」で保存（1シート1ファイル）→ 10 MB を超える場合は月ごとに行を分けて複数CSVにする → 元と同じ Box フォルダ（2025年度/測定データ）に `周南_Sheet1_2025-09.csv` のような名前で置く。xlsb は「Excel ブック(.xlsx)」でなく CSV で保存する。
   - 代替: Box の管理者が本セッション用に読み取り専用の Box API 開発者トークンを発行し、環境変数として渡す（Box API の Range 付きダウンロードでストリーミング処理できる）。
2. それ以外（JEM1467・センサー説明書・計算式PDF）は上記の手段で読解済みで、人の作業は不要。
