### 375px 幅での横はみ出し（`scrollWidth <= clientWidth`）

全 6 画面で合格（最終: すべて 375/375）。ビューポートより右にはみ出す要素（表・タブ）は、どれも `overflow-x:auto` のコンテナの中で横スクロールするもので、ページ全体は横スクロールしない。

### Tab キーでのフォーカス移動

全画面で、スキップリンク → ロゴ → 使用量チップ → 検索 → ヘルプ → サイドナビ → 本文の順にフォーカスが移り、どれも `outline: 3px solid`（`:focus-visible`）で見えることを確認した（1440px で各画面 14 回 Tab）。concepts.html は目次リンクを最後までたどると `BODY` に戻る（本文にほかの操作要素はない。修正後は評価表の領域にもフォーカスできる）。

## 2. 実施した修正

### prototype.html（CSS のみ。HTML 構造と JS は変えていない）
1. `.check input` を 20px → **24px** にした（`flex:none; margin:0` も追加）。詳細表示チェックボックス、契約状態のラジオ、共有範囲のラジオが対象。2.5.8 の自動検出 4 件を解消した。
2. モバイル（≤768px）では、並べ替えボタンを含む `thead` を `display:none` にした。視覚的に隠すだけだとフォーカスが見えない場所に移ってしまうため。並べ替えはモバイル専用の `#mSort` セレクトでできる。各カードは `data-label` で列名を示すので、表示される情報は減らない。
3. モバイルのカード型表示で `table.responsive caption:not(.visually-hidden)` を `display:block; width:100%` にし、caption が縦に折り返さないようにした。
4. `fieldset > legend` を `float:left; width:100%` にし、続く要素で `clear` するようにした。legend が2行になっても枠線と重ならない。

### concepts.html
5. 評価表のラッパー `.tablewrap` に `role="region"`、`aria-label="評価基準・重み・採点の表（横にスクロールできます）"`、`tabindex="0"` を付けた。キーボードでフォーカスして矢印キーで横スクロールできる（2.1.1、axe `scrollable-region-focusable`）。

修正前のファイルはリポジトリ外のスクラッチパッドにバックアップした。

## 4. 残っている課題・次にやること

- #settings のタブ列（プランと請求 / アカウント / 計測とプライバシー）は 390px で最後のタブが途中で切れ、横スクロールしないと見えない。スクロールできることが分かりにくいので、折り返し表示や右端のフェードなどを検討する。
- スクリーンリーダー（VoiceOver iOS / NVDA）での読み上げと、ランドマーク移動の確認。
- 200% / 400% ズーム、テキスト間隔を上書きするブックマークレットでの確認（1.4.4 / 1.4.12）。
- 料金・解約まわりのフォームでエラーが起きたときの確認（3.3.1 / 3.3.3）。商用アプリでは解約フローの操作性を最優先で手動テストする。
- 非テキストのコントラスト（1.4.11）を、コントラスト計測ツールで実測する。
