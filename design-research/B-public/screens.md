# 画面一覧と操作説明（prototype.html）

ファイル: `design-research/B-public/prototype.html`（単一ファイル、外部依存なし、`lang="ja"`）。ブラウザで直接開くと動く。画面の切り替えは URL のハッシュで行う。データ・地名・数値はすべて架空で、出典は『環境データ公開基盤（ダミー）』。

確認レベル: ヘッドレス Chrome で 1440px と 375px（iframe 内）を描画し、全画面で横スクロールが無いことと、JS エラーが無いことを確認した。スクリーンショットは地域画面（1440px）と共通部品画面（375px）の 2 枚だけを目視した。スクリーンリーダー・実機での確認は未実施。

## 全画面に共通する要素

| 要素 | 内容 |
|---|---|
| スキップリンク | Tab キーを最初に押すと「本文へ移動」が出る |
| 識別帯（最上部） | 「架空大学 環境データ研究室（ダミー）が運営する研究用の試作。政府・自治体の公式サービスではない」と出典 |
| ヘッダー | 言語（日本語／English／やさしい）、文字サイズ（A／A／A）、詳しさ（一般向け／専門家向け）、災害時 軽量表示、ヘルプ。押した状態は `aria-pressed` と「✓」で示す |
| 緊急帯 | 【訓練用ダミー表示】光化学オキシダント注意報。対象地域と、対象外の地域（青葉市）を明記 |
| 出典ストリップ | 各画面の見出しの下に、出典・最終更新（速報値）・算出方法へのリンク |
| サイドバー | 画面一覧、データの状態（最終更新・次回更新・出典・算出方法）、区分の見方 |
| フッター | 運営主体、方法と出典、プライバシー、ヘルプ・問い合わせ（全画面で同じ位置） |
| 設定の保存 | 言語・文字サイズ・詳しさ・軽量表示・動きを減らす は端末のブラウザにだけ保存（保存できない環境でも動く） |

**詳しさの切替**: 一般向けでは第3層「根拠とデータ」が閉じた状態で始まる。専門家向けでは全層が開く。どちらも同じデータ・同じ URL。
**災害時 軽量表示**: グラフ・お知らせなど装飾的な部分を隠し、黒文字・白背景・黒罫線の高コントラストにする。結論・行動・表・ダウンロードは残る。
**JS が無い場合**: 全画面が縦に並び、全層が開いた状態で読める（表はすべて HTML。図だけが出ない）。

## 1. `#dashboard` トップ・全国概況

- **目的**: 初めての人が最初の数秒で「自分に関係する情報」にたどり着く。初期表示を空にしない（X4）。
- **主要操作**
  1. 4 つの市民タスクボタン: 今日の空気を知る／外出・換気を判断する（地域画面の第1層へ直接移動）／近くの公共建築物を調べる／注意報の通知を受け取る（設定画面の通知登録へ移動）。
  2. 地域から探す: 「青葉市」「あおば」「100-0000」で 1 件見つかる。他の語では空状態（理由・登録済みの地域・次の一手）を出す。空欄で送るとエラー文。
  3. 指標から探す: PM2.5／光化学オキシダント（地域画面を指標の条件付きで開く）／公共建築物。
  4. 全国概況: 区分別の自治体数を「グラフ｜地図｜表」のタブで切り替える。図の下に根拠ブロック（定義・単位・期間・出典・状態・次回更新・ライセンス・処理方法）。
- **デスクトップ / モバイル**: デスクトップはタスクボタン 4 列・検索 2 列。モバイルは 1 列、表はカードリスト、地図タイルは 2 列。
- **キーボード**: タブは ←→ / Home / End。検索欄は Enter で送信。

## 2. `#workspace` 主要機能の操作画面（青葉市の空気）

- **目的**: 一般市民は第1層だけで判断でき、専門家は同じページで比較・再現・取得まで行える。
- **構成**
  - 層ナビ（上部に追従）: ① いまの状況 ② くらべる ③ 根拠とデータ。現在の層を塗りと `aria-current` で示す。押すとその層へ移動して見出しにフォーカスし、閉じていれば開く（URL の条件は変えない）。
  - **第1層 いまの状況**（常に開いている）: 23 µg/m³、速報値、区分2 やや注意（▲・範囲）、結論文、行動の目安、影響を受けやすい人向けの注意、光化学オキシダント（注意報の対象外であることを明記）、やさしい日本語の要約。
  - **第2層 くらべる**: 比較の条件フォーム（指標／期間（日数）／比較先）。「PM2.5 の成分」は理由を書いたうえで選べない状態にしている。期間は −／＋ボタンでも変えられる（ドラッグ不要）。「この条件で表示」を押すとスケルトンが出てから、グラフ・地図・表がそろって更新され、URL（`#workspace?region=aoba&ind=…&days=…&cmp=…`）も更新される。
  - **第3層 根拠とデータ**: 定義・集計方法・測定局・状態区分・管理者・更新予定・ライセンス・引用文（コピー可）、この条件の URL（コピー可）、2 段階ダウンロード（表示中のデータ／全データ 90 日分の CSV）、API・Python・R のコード例（条件に連動）、詳細分析モード（準備中の理由とロードマップを併記）。
- **エラーの例**: 期間に「abc」「0」「120」を入れる、比較先で「（選んでください）」を選ぶ → 上部にエラー要約（リンクで該当欄へ）と、欄ごとの「✕ エラー:」と修正例が出る。全角数字（７）はそのまま受け付ける。
- **デスクトップ / モバイル**: デスクトップは第1層（左）と第2層（右）を 2 カラム、第3層は全幅。モバイルは 1 カラムで第1層が最上部。表はカードリストになり、並べ替えは「並べ替え」選択欄で行う。
- **キーボード**: 層の開閉は見出し行で Enter / Space。表の見出しボタンで並べ替え（もう一度押すと逆順）。タブは矢印キー。

## 3. `#detail` 詳細・結果表示画面（青葉市立中央図書館）

- **目的**: 公共建築物の LCA と省エネ性能を、結論・内訳・算定条件の 3 段で示す。
- **構成**
  - 第1層: ライフサイクル CO2 −22%（↓ 少ない・良い方向）、BEI 0.78（基準より 22% 少ないエネルギー）。中立性の注記（メーカー・製品名のランキングを作らない）。
  - 第2層: 段階別（製造 A1–A3／建設 A4–A5／運用 B6／解体 C1–C4）の積み上げ横棒と同内容の表。同用途の建物との比較表（並べ替え可能、速報値・確定値・推計値・未算定の状態列、データなしは常に最後）。
  - 第3層: 算定範囲・原単位 DB の版・評価期間 60 年・電力の排出係数・比較母集団・不確かさ、計算式（MathML と読み上げ用の文）、算定条件 JSON（コピー可）、内訳 CSV のダウンロード、再計算の接続先（リポジトリの `math_tools_v2/lca_ops.py` と Math IR パイプライン。この試作では計算しない）。
- **デスクトップ / モバイル**: 第1層のカード 2 枚は横並び → モバイルで縦積み。比較表はカードリスト＋並べ替え選択欄。
- **キーボード**: 地域画面と同じ。

## 4. `#methods` 方法と出典（追加画面）

- **目的**: 区分の判断基準、データの状態区分、運営主体・中立性・アクセシビリティの試験状況（未実施であることを正直に記載）、恒久 URL と終了時のデータ保存方針を公開する（P11）。
- 各画面の「算出方法」「方法と出典を見る」リンクと、緊急帯の「注意報の基準を見る」からここへ来る。

## 5. `#settings` 設定・管理画面

- **目的**: 表示の設定、通知の登録、データの公開範囲とプライバシーの説明、研究室スタッフ向けの管理。
- **構成**
  1. 表示の設定: ヘッダーと同じ設定をラジオボタンとチェックボックスで変更できる（言語・文字の大きさ・詳しさ・軽量表示・動きを減らす）。変更すると「✓ 設定を保存しました」と出る。
  2. 注意報の通知を受け取る（1画面1問・3 ステップ）: 地域 → 受け取る情報 → 確認 → 登録。地域は閲覧中の「青葉市」が初期値。確認画面から「変更」で戻れる。個人情報は求めない。未選択で進むとエラーと修正例。
  3. データの公開範囲とプライバシー: データ種別ごとの公開範囲・粒度・保存期間・ライセンスの表。解析・広告・追跡スクリプトを使わないこと、位置情報を使わないこと。「この端末の設定をすべて消す」（危険ボタン → 確認ダイアログ。初期フォーカスは「やめる」）。
  4. 管理（試作）: パスキー、またはメールのリンクでサインイン（認知機能テストなし。送信はしない）、データ取得状況の表（正常 ✓／停止 ／／遅延 ▲）、再取得ボタン、理由付きの無効ボタン。
- **デスクトップ / モバイル**: 表示設定と通知登録が 2 カラム → モバイルで 1 カラム。表はカードリスト。

## 6. `#components` 共通部品とトークン一覧

- ボタン（主・副・危険・無効＋理由）、フォーム（郵便番号の例。初期値「123-45」で確認するとエラーと修正例が出る）、ダイアログ、ナビゲーション・サイドバー・パンくず、タブ、成功・警告・エラー・情報（アイコン＋「成功:」などの文言）、空状態、スケルトン、カードと区分バッジ、テーブルとチャートの説明。
- トークン: カラー（画面上でコントラスト比を実測して ✓ を表示）、文字サイズ、余白、角丸・影・動き。

## キーボード操作のまとめ

| 操作 | キー |
|---|---|
| 本文へ移動 | ページ読み込み直後に Tab → Enter |
| タブ切替 | ← → で移動、Home / End で端へ |
| 層の開閉 | 層の見出し行で Enter / Space |
| 並べ替え | 列見出しのボタンで Enter（もう一度で逆順） |
| ダイアログ | Esc で閉じる。閉じると開いたボタンにフォーカスが戻る |
| ドロワー（1023px 以下） | 「メニュー」で開き、Esc・「閉じる」・背景で閉じる。開いている間は Tab がドロワーの中を循環 |
| 画面移動 | 画面が変わると、その画面の h1 にフォーカスが移り、タブのタイトルも変わる |

## 試作で動かない・省略したもの

- 通知・サインイン・API は実際には送信・接続しない（`api.example.invalid` は架空）。
- 「詳細分析モード」はロードマップ扱い（ボタンは理由付きで無効）。
- 英語・やさしい日本語は主要部分のみ。本文の一部は日本語のまま。
