# D-enterprise アクセシビリティ検証レポート

- 対象: `prototype.html`（#dashboard / #workspace / #detail / #settings / #components）、`concepts.html`
- 実施日: 2026-11-15（ダミーデータのみ、ローカル `file://` で実行。外部送信なし）
- 道具: Playwright（Chromium ヘッドレス）+ axe-core（`runOnly` タグ: wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa）
- スクリプト: スクラッチパッド `qa-D/audit.js`（各ルートの axe・375px リフロー・Tab 移動・スクリーンショット）、`qa-D/extra.js`（ダークテーマ・コマンドパレット表示時・フォーカス被り・小さいターゲットの確認）
- 確認レベル: 自動検査と、スクリプトでの Tab 移動・座標判定まで。スクリーンリーダー（NVDA / VoiceOver）での読み上げ、200% ズーム、実機タッチ操作は**未実施**。

## 1. 自動検査の結果（修正の前と後）

| 画面 | axe 違反（前） | axe 違反（後） | 375px 横スクロール（前 → 後） | axe「要確認」(incomplete) |
|---|---|---|---|---|
| #dashboard | 0 | 0 | なし → なし | なし |
| #workspace | 0 | 0 | なし → なし | なし |
| #detail | 0 | 0 | なし → なし | color-contrast 11 件 |
| #settings | 0 | 0 | なし → なし | なし |
| #components | 0 | 0 | なし → なし | color-contrast 6 件 |
| concepts.html | 0 | 0 | **あり（scrollWidth 594 / clientWidth 375）→ なし（375/375）** | 前: aria-prohibited-attr 1 件 + color-contrast 9 件 → 後: color-contrast 9 件 |

補足:
- ダークテーマ（`prefers-color-scheme: dark` をエミュレート）でも 6 画面すべて axe 違反 0 件。
- コマンドパレット（Ctrl+K）を開いた状態でも違反 0 件。
- axe の違反 0 件は「問題がない」という意味ではない。axe が自動で判定できるのは達成基準の一部だけ。「要確認」の color-contrast は、グラデーション・重なり・擬似要素の背景などで axe がコントラスト比を計算できなかった要素。目視で見る必要がある（下記チェックリストでは 1.4.3 を「未検証」寄りの扱いにしている）。
- `#settings` のタブは `role="tab"` で実装されていなかった（`[role=tab]` が 0 件）。そのため、タブを切り替えた後の各パネルは自動検査できていない。監査ログ・権限マトリクスのパネルは未検査。

## 3. 手動系の確認結果（スクリプト判定）

- **Tab 移動（1440px）**: 全ルートで最初の Tab 停止位置は「本文へスキップ」。続いて組織・プロジェクト・環境・ロールの選択、コマンド、テーマ、ヘルプ、レール展開、ナビの順に進む。12 回すべて、フォーカス先に outline または box-shadow があった（視認可能と判定）。concepts.html は スキップリンク → 目次 5 項目の順。
- **フォーカスの被り（#workspace、Tab 60 回）**: フォーカス中の要素の中心点を `elementFromPoint` で調べ、固定ヘッダーなどに隠れていないかを確認した。被りは 0 件。ただしモバイル幅（下部固定ナビがある状態）では未確認。
- **テーブル行のキーボード操作**: 行チェックボックスは `tabindex="-1"` だが、行要素にロービングタブインデックスがある。↑↓ / j k で移動、Space / x で選択、Enter で詳細を開く（`rowKeys` 関数をコードで確認）。1 文字ショートカットは行にフォーカスがあるときだけ効くため、2.1.4 の例外に当たる。
- **ターゲットサイズ**: #workspace のチェックボックスは 18×18px で、24px を下回る。axe の target-size ルールは合格（周囲 24px の余白による例外）。ただし表を高密度表示に切り替えたときは未確認。
