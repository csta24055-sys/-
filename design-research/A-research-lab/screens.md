# 分類A 研究支援アプリ 画面一覧と操作説明（試作 `prototype.html`）

採用案: 案C「Pipeline Ledger」（パイプライン＋台帳）。データは全てダミーである（室内空気質の測定 5,000 行、建材 LCA の条件、Math IR の計算ジョブ）。
画面はハッシュで切り替える: `#dashboard` / `#workspace` / `#detail` / `#settings` / `#components`。

## 確認レベル

- ヘッドレスの Chrome（Playwright）で、1440px と 375px の幅で5画面を表示した。JavaScript のエラーはなく、375px で横スクロールが出ないことを確かめた。次の操作も自動で確かめた: 失敗した段の修正 → Ctrl+Enter で実行 → 版が v6 になる、台帳の ↓ キーと 1 キーでのタグ付け、再実行のダイアログを Esc で閉じたときにフォーカスが戻ること、学部生の入力エラーの要約。
- スクリーンリーダーと実機のスマートフォンでは確認していない。
- 書き出しは端末内でファイルを生成するだけで、外部には送信しない。PDF は印刷ダイアログから保存する。

## 全画面で共通の要素

- **上部バー**: プロジェクト名、パイプラインの版、表示ロールの切替（教授 / 大学院生 / 学部生）、コマンドパレット（Ctrl+K）、配色の切替（自動 / ライト / ダーク）、ヘルプ（全画面で同じ位置）。
- **ナビゲーション**: デスクトップでは左のサイドバー、スマートフォンでは下部のナビゲーション（ホーム / 作業 / 結果 / 設定 / 部品）。
- **スキップリンク**「本文へスキップ」、トーストの通知、`aria-live` による読み上げ。

## 1. ダッシュボード `#dashboard`

**目的**: 研究室全体の状態（異常値・失敗・要再計算・承認待ち）をすぐに把握し、作業へ移る。

**主な内容と操作**
- 指標カード: 10月の異常値の数、失敗した段、要再計算の段、J-0412 の合計 CO2。カードを押すと該当の画面へ移る。
- パイプラインの状態: 6つの段を記号・色・文字で1行に並べる。「作業画面で開く」で移る。
- 異常値（直近5件）: ⚠ 異常の行と、その値・部屋・日時。
- 最近の計算ジョブ: 並べ替えできる表。ジョブの ID から詳細へ移る。
- ロールによる違い:
  - 教授: 「承認待ち」のカード（承認 / 差し戻し）。承認は任意の機能で、差し戻すときは確認ダイアログを出す。
  - 大学院生: 失敗した段と自分のジョブを先頭に見る。
  - 学部生: 先頭に「測定入力」のフォームが出る（既定の画面）。部屋と装置は前回の値を引き継ぐ。単位（µg/m³・mg/m³、ppm・%）を選ぶと換算して範囲を確かめ、ISO 14644-1 のクラスは自動で判定する。エラーは要約と各欄に表示する。

**デスクトップとスマートフォンの違い**: デスクトップでは 12 列のグリッドで、カードを横に並べる。スマートフォンでは1列にし、ジョブの表をカード一覧にする。

## 2. 作業（パイプライン） `#workspace`

**目的**: 段ごとに計算条件を入力・確認し、明示的に実行し、失敗した段を特定して直す。

**構成（デスクトップ 1440px）**
- 左「処理の段」: 1. データ取り込み → 2. 検証 → 3. Math IR 変換 → 4. ソルバー実行 → 5. LCA 演算 → 6. 図表・レポート。状態は ○ 未設定・◐ 準備完了・● 成功・✕ 失敗・↻ 要再計算のどれかで表示する。
- 中央「段」: 「条件」と「出力」のタブがある。
  - 条件: 項目・値と単位・許容範囲・既定と出典を1行にまとめた表。範囲外や数値でない値は、その場で赤枠と修正案を出す。変更した行には紫の線と「未適用」の文字を付ける。
  - 出力の例:
    - 検証: 測定台帳（5,000 行の仮想スクロール、集計行、異常の強調）
    - Math IR: 中間表現と、3エンジン（SymPy / SageMath / MATLAB）の照合表
    - ソルバー: 失敗時は理由と修正案、「最大反復回数を 200 にする」ボタンを出す
    - LCA: 横棒グラフ＋データ表、感度分析のスライダー（数値の入力欄つき、即時に試算）
    - レポート: 自動生成した根拠ページと書き出し
- 右「根拠」: 入力の来歴（元ファイルとハッシュ）、使った式、エンジンと版、係数の出典、変更履歴、コメント。既定では来歴だけを開く。
- 下「ジョブモニターと問題」: 実行中・失敗・注意の一覧。「段へ移動」でその段の出力を開く。折りたたむこともできる。
- 右上「未適用 n 項目 ▶ 実行」: 未適用の変更と、要再計算・失敗・準備完了の段をまとめて実行する。実行中は出力にスケルトンを出す。完了すると版が上がり（v5 → v6）、変更履歴に記録する。
- 「台帳」タブ: 全ジョブ共通の測定台帳を全幅で開く。検索、部屋、異常のみ、保存検索（今週の異常値 / C101）、CSV・Excel・PDF の書き出しがある。

**試せる流れ**: 4. ソルバー実行（✕ 失敗）→「出力」タブ →「最大反復回数を 200 にする」→ Ctrl+Enter → 全ての段が ● 成功になり、v6 になる。

**ロール**: 学部生は取り込みと検証の段だけを開ける。検証は閲覧のみで、ほかの段は「（院生以上）」と表示する。

**スマートフォン**: 段のリストを縦のタイムラインにし、その下に作業、根拠、ジョブを縦に並べる。条件の編集はできない（読み取り専用。測定入力はホームから）。台帳は 20 件ずつのカードで、ページを送って見る。

## 3. 結果の詳細 `#detail`

**目的**: 1つのジョブ（J-0412）の結果・計算根拠・版の差分を確かめ、同じ条件で再現し、書き出す。

**主な内容と操作**
- 条件の版の選択（v5 最新 / v4 / v3）。過去版を選ぶと、上部に全幅の「過去版を表示中」のバナーと「最新版に戻る」ボタンが出る。
- 指標カード: 合計 CO2、延床面積あたり、ISO クラス、異常値の数。
- PM2.5 の時系列グラフ: 閾値の線（△注意・⚠異常）と ✕ の異常点がある。図の下に入力（ジョブ・版・ハッシュ）を表示し、1時間ごとのデータ表を添える。
- 建材別の CO2 排出量: 横棒グラフ＋データ表（係数と出典つき）。
- 計算根拠と来歴: 入力データ、ハッシュ、Math IR、主エンジンと照合エンジン、LCA 演算子、係数表、乱数シード、実行者、日時。
- 変更履歴と版の差分の表、再現コマンド（GUI の操作を書き出したもの）。
- 「↻ 同条件で再実行」: ダイアログで条件を確かめてから実行し、元の結果と一致するかを通知する。
- 書き出し: CSV、Excel 用（UTF-8 BOM 付き CSV）、PDF（印刷）、再現コマンドのコピー。

**スマートフォン**: カードとグラフを1列にし、表をカード一覧にする。過去版のバナーは上部に固定する。

## 4. 設定・管理 `#settings`

タブ（←→ で切り替え）で5つに分ける。
1. **閾値テンプレート**: PM2.5 と CO2 の注意・異常の値を設定する。範囲外や「注意 ≥ 異常」はエラーの要約と各欄に修正案を出す。「初期値に戻す…」は危険ボタンで、確認ダイアログを出す。
2. **ロールと権限**: 教授・院生・学部生ごとの権限の表。
3. **表示**: 行の高さ（26 / 22px）、配色、台帳の列の並び順。並び順はドラッグでも、↑↓ ボタンでも変えられる。
4. **認証と保存先**: 学内シングルサインオンとパスキーにし、パスワード欄への貼り付けを許可する。認知テストは使わない。保存先は学内サーバーが既定で、外部クラウドは無効にしている。
5. **ショートカット**: キーの一覧。

## 5. 共通部品 `#components`

ボタン（主・副・危険・無効・文字）、フォーム（ラベル・ヘルプ・エラー）、ダイアログ、タブ、ナビゲーションとサイドバー、通知（成功・注意・エラー・情報）、状態の語彙、並べ替えできる表、チャートと代替表、カード、空状態、スケルトン、カラートークン（現在の配色の値を表示）、文字サイズ、余白と角丸の一覧。全て実際に動く。

## キーボード操作

| キー | 操作 |
|---|---|
| `?` | ショートカット一覧とヘルプ |
| `Ctrl`+`K` | コマンドパレット（画面の移動、実行、書き出し、配色） |
| `g` → `d` / `w` / `r` / `s` / `c` | ダッシュボード / 作業 / 結果 / 設定 / 部品へ移動 |
| `[` / `]` | 前の段 / 次の段（作業画面） |
| `Ctrl`+`Enter` | 未適用の変更を実行（作業画面） |
| `/` | 表示中の台帳の検索欄へ |
| `↑` `↓` `PageUp` `PageDown` `Home` `End` | 台帳の行を移動（台帳にフォーカスがあるとき） |
| `1`〜`3` / `0` | 選択行にタグ（要確認・除外候補・再測定）/ タグを消す |
| `Enter` | 選択行の判定理由と来歴を表示 |
| `←` `→` `Home` `End` | タブの切り替え |
| `F6` / `Shift`+`F6` | パネル（上部バー・ナビ・段・作業・根拠・ジョブ）の間を移動 |
| `Esc` | ダイアログを閉じる（開いたボタンへフォーカスが戻る） |

1文字のキーは、入力欄で文字を打っている間は動かない。

## 試作の範囲外（今後の実装）

- 実際の計算（SymPy / SageMath / MATLAB、`math_tools_v2/lca_ops.py`）との接続。試作の計算結果と照合結果はダミーである。
- 依存グラフの自動整列表示（ELK.js 等）、コマンドパレットのあいまい検索、スマートフォンでのコメントレビューの実体。
- 本物の .xlsx の生成（試作では Excel で開ける BOM 付き CSV にしている）。
