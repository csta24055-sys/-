# 3. 分野別総合分析 — 空気清浄技術の物理

本章の数値のうち【計算結果】は本アプリ（`backend/aqros/models.py`）による。式・単位・適用範囲は画面4「空気清浄シミュレーター」でも表示される。

## 3.1 個数濃度と質量濃度

- 【確認事実】研究室の測定は個数濃度（KC-52, 個/L・個/m³; 2018〜2023, 2026）と質量濃度（粉塵計 mg/m³, ワイヤレスセンサー μg/m³; 2024〜2025）が混在する。
- 【分析】WHO AQG（PM2.5 年5・日15 μg/m³）との比較には質量濃度が必要だが、個数→質量換算（式 Cm=4/3πr³Nρ, S-2023-01）は代表径の3乗に比例するため、粒径帯0.3〜0.5 μmで代表径を0.3/0.4/0.5 μmとすると質量は1 : 2.4 : 4.6 と変わる【計算結果】。2023年度の「基準未満」結論は**換算仮定込みの結論**である（F-2023-02）。
- 【分析】簡易センサー（光散乱）は内部で個数→質量換算をしており、粒子密度・屈折率・吸湿で系統誤差を持つ（H-07）。I/O比は同一センサー間比なので系統誤差が相殺されやすいが、絶対値（WHO値との比較）は相殺されない。

## 3.2 粒径別除去効率

- 【確認事実】EP（2026年度）: 粒径が小さく風量が大きいほど効率低下（0.3〜0.5 μm @750 m³/h で約82%）。
- 【分析】EPは荷電・捕集時間（滞留時間∝1/Q）に依存し、Deutsch-Anderson式 η=1−exp(−wA/Q) の定性挙動と整合する。本アプリでは端点間の線形補間を【仮定】し、範囲外は警告付きで外挿する。Deutsch型で外挿すると高風量の効率低下は線形より緩やかになり、最適開口率の評価が変わり得る（H-03b）。
- 【確認事実】外気フィルタ（2024年度表）: 「重量法10 μm以上80%」〜「2.0 μm以上約95%」と表記法が混在。PM2.5（主に<1 μm）に対する効率は記載なし。
- 【分析】2025年度条件②の係数0.55（=透過率）は「中性能フィルタ」の微小粒子透過率として妥当な範囲だが、逆解析（F-X-11）では沈着・換気量の仮定により0.55〜0.77と幅がある。

## 3.3 電気集塵機と機械式フィルタ

| 観点 | 電気集塵機（EP） | 機械式フィルタ（中性能〜HEPA） |
|---|---|---|
| 圧力損失 | 小（式(2): 750 m³/hで約15 Pa）【確認事実】 | 大、目詰まりで増加【一般知見】 |
| 効率の風量依存 | 大（95%→82%）【確認事実】 | 小〜中 |
| 電力 | 本体（2018年度仕様26 W）＋送風動力【確認事実】 | 送風動力のみ（ただし圧損大） |
| 保守 | 電極洗浄、効率低下は不可視【分析】 | 交換、圧損で劣化を検知可能【分析】 |
| 副生成物 | オゾン発生の可能性（機種依存、研究室資料に記載なし）【不明】 | なし |

【分析】EPの利点（低圧損）は全館空調のような大風量循環で顕在化する。一方、効率低下が差圧に現れないため、**長期性能劣化の監視手段がない**ことは研究室資料で扱われていない論点である（T-07）。

## 3.4 CADR と実効除塵風量

- 【確認事実】2026年度は CADR = η·Q_EP と定義（装置出口基準）。
- 【確認事実（外部）】ASHRAE 241 の Equivalent Clean Airflow も空気清浄機について「通過風量×1パス効率」と同型（E-02）。JEM1467は30分で1.25→0.15 mg/m³（12%）となる床面積で能力を表す（E-07）。
- 【計算結果】単室モデルで JEM 基準を検算すると、強5.1 m³/min の市販機は 38 m²（天井2.4 m）で29分となり表示と整合（F-X-10）。
- 【分析】住宅全体の濃度を決めるのは CADR の絶対値ではなく **CADR/V（等価換気回数）と外気負荷の比**である。中×5台のCADR約740 m³/hは気積240 m³の住宅で約3.1 回/h に相当し、換気0.5回/hの6倍の清浄空気を供給する【計算結果】。

## 3.5 空気循環経路・圧力損失・送風機特性・バイパス

- 【確認事実】送風機は風量一定制御で、限界静圧（70〜90 Pa）までは風量を維持し電力が3〜5倍に増加。
- 【分析】これは**ファン則（電力∝ΔP·Q）**と整合する。定風量下では電力はほぼ静圧に比例し、バイパスで静圧を下げることは直接の省エネになる。
- 【計算結果】式(2)全域適用時、中×20台で開口0%→100%の電力は約212 W→118 W（差約94 W、連続運転で約820 kWh/年）。電力単価31円/kWh（全国家庭電気製品公正取引協議会の目安単価）を仮定すると約2.5万円/年【予測】。ただし二乗則外挿では0%は定風量限界を超え、比較が成立しない。
- 【分析】バイパス空気は清浄されないため、CADR低下は室内濃度上昇として現れる。本アプリでは並列流路の結果（Q_EP, η）を単室モデルに渡し、**バイパス率→室内濃度→I/O比**まで連続して評価できる。

## 3.6 換気量と外気汚染

- 【確認事実】2025年度: 西日本4地点の2024年度PM2.5中央値 4.6〜8.6 μg/m³、季節平均は春が最大（10.7〜13.5）。黄砂時に外気約25 μg/m³。
- 【分析】定常I/O = Q_OA·(1−η_OA) / (Q_OA + CADR + βV)（侵入なし）。外気濃度が高い地域ほど、同じI/Oでも絶対濃度が上がるため、**地域別に必要CADRが異なる**。シミュレーターの外気プリセットに季節平均（S-2025-03）を実装した。
- 【分析】C値0.28〜0.38の範囲では隙間侵入の寄与は小さいと推定され（F-2025-05, H-06a）、外気の主経路は機械換気（全熱交換器）である。全熱交換器の漏気（RA→SA）は資料で評価されていない。

## 3.7 室内の発塵・沈着・再飛散

- 【確認事実】生活行動で1 μm超が3〜5倍に上昇し数時間で低下（2023）。全館空調では浮遊時間3〜40分（2024）。
- 【計算結果】重力沈降による β（天井2.4 m）は 1 μm 0.05 /h、2.5 μm 0.30 /h、5 μm 1.2 /h、10 μm 4.6 /h、30 μm 41 /h。
- 【分析】30〜45 μmの約98%が発生室に沈着（2022）は β≈40〜90 /h と整合。一方、線香（サブミクロン）のBOX β 1.3×10⁻⁴ 1/s（0.47 /h）は重力値の10〜100倍で、拡散・壁面付着・漏気の寄与を示す（F-X-09）。
- 【不明】再飛散（歩行・布団）は2021年度布団実験以外で扱われておらず、落下班（2021）の本論が未読。

## 3.8 温湿度・気流分布

- 【確認事実】研究室の他班（2018年度）に気流・温度分布、室間温度差、床下カビリスクの研究がある（住宅班2018フォルダの他梗概, 目録確認）。
- 【分析】粉塵研究と温湿度研究は同じ実験住宅を用いながら連携していない。相対湿度は簡易センサーの吸湿誤差（H-07b）とカビ胞子（生物粒子）の両面で粉塵研究に関係する。

## 3.9 消費電力・維持管理費・長期性能

- 【確認事実】2018年度: EP本体26 W。2026年度: 送風機4〜15 W/台。
- 【予測】EP本体＋送風機の年間電力は数百kWh規模（構成依存）。維持管理費（電極洗浄・フィルタ交換）の実測値は資料に無い【不明】。
- 【分析】長期性能低下はEP効率（不可視）とフィルタ圧損（可視）で検知性が異なる。EP効率の年度間矛盾（96% vs 82〜92%, F-X-07）は、劣化仮説（H-01c）を含む複数の説明があり、判別試験が必要。
