## 2. SPI英語（ENG）について：事実と推定

**事実（複数の解説サイトとリクルートの方式から）**
- テストセンターで約20分。問題数は人によって変わり、回答に応じて出題が変わる（適応型）。1問ごとに制限時間あり。
- 選択式。主な形式：同意語・反意語・英英定義（単語の意味）・空欄補充・誤文訂正・整序・和文英訳・長文読解。
- WEBテスティングでは行われない。

**推定（公式の公表なし）**
- INPEXの英語の足切り点は公表されていない。体験談では「SPI全体で正答率7〜8割程度の手応え」「英語はやや難しい」。
- エネルギー・総合職系で英語を課す企業なので、**英語が極端に低いと不利**と考えるのが安全。目標は「平均以上（7段階中4以上の目安）」、最低でも全問回答して大きく崩れないこと。
- 得点への寄与：語彙系（同意・反意・定義）は問題数が多く、1問あたりが短時間 → **4日間で最も伸びる**。長文は配点が大きいが短期では伸びにくい → 設問を先に読み、本文から根拠を探すやり方で失点を減らす。

## 4. 初回診断の結果（11/6）
- 正答 13/24（54%）、勘を除いた実力正答 10/24（42%）。時間は未記録。
- 中学レベルの語（borrow, decide, increase, big, expensive）は取れている。高校レベル（require, reluctant, abundant, diminish, temporary, treaty）から先はほぼ全滅。
- 自信を持って間違えた5問：accept の反意語に allow を選択／by と until の区別／Each of → has／look forward to ～ing／長文で import と export を取り違え。
- **結論：失点の大部分は語彙。** 長文の誤答も単語（importer）が原因。→ 4日間の時間の約7割を、SPIによく出る語の同意語・反意語ペアの暗記に使う。約2割を文法の頻出パターン（ルール暗記で即効性あり）、約1割を長文の解き方に使う。
