# STEP1 網羅性の監査（2026-11-07）

## 実施したこと
- 異なる検索クエリ：40件（`search_log.csv`）。対象は知恵袋・X・Reddit・note・みん就・ONE CAREER・就活会議・外資就活・SPI対策サイト・個人ブログ（はてな・アメブロ）・大学資料・公式資料・学術論文。表現・年度・企業名（JAL・ANA・三菱商事・住友商事・INPEX）を変えて検索した。
- 原文の取得：15ホストに直接接続を試した（`fetch_attempts.csv`）。**全ホストでプロキシが接続を拒否（HTTP 403）。** 前回は WebFetch でも全ホストでDNSの段階で失敗している。
- 環境の変更：対象ホストを許可する個人用の環境の作成を申請したが、サービス側で拒否された。

## 結果
| 区分 | 件数 |
|---|---|
| 採用レコード（SPI英語に関する、URLの特定できる外部報告） | 5件（全てINPEXまたはJAL。**長文の題数が分かるものは0件**） |
| 原文を確認できたもの | **0件**（全て検索結果の抜粋） |
| 存在だけ確認できた未解決の候補（URLを特定できない） | 3件（U1：長文3題・各3タブの報告、U2・U3：三菱商事の英語の手応え） |
| 対策サイトの主張 | 8件（独立した系統は多く見て4つ。K6の書籍だけが原文確認済み） |
| 目標 | 300〜500件 → **未達** |

## 未達の理由
1. 原文を確認する手段がない：主要10媒体の全てで、この環境からの接続が遮断されている。
2. 検索エンジン（WebSearch）は1クエリあたり約9件のURLと要約しか返さず、知恵袋・X・note・Redditの個別投稿は上位にほとんど出てこない。
3. ONE CAREER・外資就活・就活会議の体験談は、出題の詳細が会員限定部分にあることが多い。
4. 検索結果の大半は、同じ対策サイト群（reashu・noahs-ark・jo-katsu・kotora・キャリタス）の解説記事の繰り返しで、40クエリを追加しても新しい一次報告はほぼ出てこなかった（収穫逓減）。

## 判定
検索クエリ数と媒体の種類は基準を満たすが、原文確認率は0%（基準50%）で、件数も目標に遠く届かない。
主要媒体の原文取得が全て遮断されているため、**STEP1は BLOCKED**。検索を続けても、この環境では解消しない種類の制約である。
