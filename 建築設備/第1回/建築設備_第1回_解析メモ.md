## 2. 解析範囲と方法

- **解析範囲：0:00:00〜1:27:05（全編）**。音声は全区間を文字起こしし、映像は3秒間隔で全区間からフレームを抽出した。
- 動画・音声は**外部サービスへアップロードしていない**。処理はすべてこのコンテナ内で行った（外部と通信したのは、Dropbox からの取得と音声認識モデルのダウンロードのみ）。

| 工程 | 方法 | スクリプト |
|---|---|---|
| 音声抽出 | ffmpeg で 16kHz モノラル WAV に変換 | `scripts/run_all.sh` |
| 一次文字起こし | faster-whisper ＋ `kotoba-tech/kotoba-whisper-v2.0-faster`（日本語特化）、CPU int8、beam 5、VAD あり、全編（1043区間、処理時間約16分） | `scripts/transcribe.py` |
| 映像解析 | 3秒ごとにスライド領域を切り出し（1742枚）→ 前に採用したフレームとの差分でスライドの切替を検出（83枚）→ 2×2 の一覧画像にして全枚数を目視確認。細かい文字は拡大して読んだ（水質基準表・TOTO資料・水循環フロー図など） | `scripts/extract_slides.py` |
| 二次照合 | 重要な10区間（計約18分）を別のモデル `Systran/faster-whisper-large-v3` で再度文字起こしし、一次結果と突き合わせた | `scripts/verify_segments.py` |
| 統合 | 発言とスライドを時刻で対応づけ、誤変換を訂正したうえで要点を抽出 | （手作業） |
| PDF生成 | HTML（`scripts/print.html`）→ Playwright/Chromium で A4 PDF に変換。ページ数とはみ出しを自動で検査 | `scripts/build_pdf.js` |

> 文字起こし全文・スライド画像は、教員の著作物を含み、リポジトリが public であるため**コミットしていない**。`scripts/run_all.sh` を実行すれば再生成できる。

## 4. 重要事項の選定理由

- **教員が明示的に強調した箇所**：「何度も言ってますよ、常に飲用可の水質」[0:27:27, 0:38:42]、「これをよく知ってもらいたい」[0:27:27]、「要注意」（レジオネラ）[0:30:26]、「しっかり知っておいてもらえるといい」（責任分界点）[1:23:38]、「設備Ⅲで一番変わってくるのが安全・衛生」[0:14:09]。
- **スライドで赤字・下線・※印になっていた箇所**：常に飲用可の水質／加熱にエネルギー／トラップの封水を保護／※建築物の寿命60年・設備の寿命15年／いかなるときも飲料に適した水質／迅速に排除／2重化／上水使用量削減／被災時の下水利用は重要。
- **プリントの設問になっている箇所**：設問1＝構成、設問2＝原則 → 試験の出題源（毎回の授業から出題）と判断し、紙面を多めに割いた。
- **試験・評価の情報**：ユーザー指示に従い、最優先で冒頭に配置した。
- **数値**：200L、10℃、40℃、65℃（60〜65℃）、13L→4.8L/3.8L、6600V、100/200V、60年/15年、51項目、78%/19%、各年号。
