## 1. 建築設備Ⅲの位置づけ

### 建築の3つの分野（人体に例えると）`[0:06:21]`

| 分野 | 決めること | 人体なら |
|---|---|---|
| 設計・計画 | 実用的・美的要求を満たすため、建物の基本構成や形態を決定 | 体の構成・体型・容姿 |
| 構造・材料 | 安全に利用できるよう、力学的な面から構造形式・材料を決定 | 骨格 |
| **環境・設備** | 建物内の**快適性・利便性向上**のため、各種設備の形式や配置を決定 | **内臓や血管・神経** |

### 建築設備の種類と授業の分担 `[0:08:18–0:12:42]`

| 設備 | 内容・例 | 授業 |
|---|---|---|
| 空調設備 | 空気調和・暖冷房・換気（エアコン・天井扇・ダクト）。建物のエネルギーの3〜4割を使う「花形」 | 設備Ⅱ |
| **給排水衛生設備** | 給水・排水・給湯・衛生（ユニットバス・給排水配管） | **設備Ⅲ** |
| **消防（防災）設備** | 消火栓・スプリンクラー・火災報知器など（その他の設備として昇降機も） | **設備Ⅲ** |
| **電気設備** | 電気・通信・放送（照明・情報コンセント・分電盤、Wi-Fi・カメラ） | **設備Ⅲ** |

- 空調は**温熱環境・空気環境**（伝熱・湿気・換気）に直結するので、環境分野とのつながりが強い。給排水衛生・電気（屋内配線・照明・コンセント）は、部屋の水回りや電気を使う場所に直接関わる。

### ★考えるべき観点：空調 vs 給排水衛生・電気 `[0:12:54–0:16:50]`

| 観点 | 空調設備（設備Ⅱ） | 給排水衛生・電気（設備Ⅲ） |
|---|---|---|
| 物理を知る | 空気・水 | 共通 |
| テクノロジー | 機械・工学 | 共通 |
| エネルギー | エネルギー・コスト | 共通 |
| 実装 | 設備を建築に実装するには | 共通 |
| **5つ目** | 環境工学・**快適性**（暑い／寒い） | **安全・衛生**（人命に直結） |

- 給水の途中で異物が混入すると、人がそれを**飲んでしまう**。排水が滞留するとすぐに衛生問題になる（建物内で人が亡くなる事故も実際に起きている）。
- 火災報知器が作動しないと火災に気づかず**逃げ遅れる**。⇒ 空調よりも安全・衛生を重視する。

### 電気設備の構成 `[0:17:03, 0:18:54–0:20:20]`

- 流れ：電力会社 → 受電 → 受変電設備（変圧） → 幹線 → 分電盤 → 電灯・コンセント／動力
- 区分：**受変電・幹線／自家発電・蓄電池／電灯・コンセント／動力／情報・通信**の各設備
- 住宅は100V・200V（エアコンは200V）。大きなビル（タワースコラ）は**6600V**で受電する（電柱の一番上の線と同じ電圧）。変圧器で100V・200Vに下げて各所に配る。
- **非常用エレベーター・非常用消火ポンプ**は、電力会社からの電力が途絶えても動かなければならない → **非常用発電設備**を設置する。

## 4. 給排水衛生設備とは（定義）`[0:25:08]`

> ★**建物内・敷地内の水に関連する諸設備。飲用・調理・洗浄など健康で衛生的な生活を維持し、災害から守るための基幹となる設備。**

- 日本では水道から出る水は**いつでも飲める**ことが前提 → 設計・運用では、途中で異物が入らないようにする。
- 系統の流れ（スライドの系統図）：給水本管 → 量水器 → **受水槽** → 給水ポンプ → 上水揚水管 → 高置水槽 → 上水給水管 → 各階の水栓 → 排水管（＋通気管） → 排水ます → 下水道本管。地下の排水は排水槽 → **排水ポンプ**でくみ上げる。屋根の雨水はルーフドレン → 雨水排水管 → 雨水貯留槽 → ろ過装置 → 雑用水槽 → 雑用水給水管（トイレ洗浄・屋上緑化への散水）。

## 5. ★給排水衛生設備の構成（5分類）＝プリント設問1 `[0:26:27–0:37:28]`

| 設備 | 役割（スライド） | ポイント（授業の説明） |
|---|---|---|
| **給水設備** | 水道水（上水）を供給する設備。**常に飲用可の水質であること** | 人が飲む水を運ぶので**責任が非常に重い**。 |
| **給湯設備** | 上水を加熱して供給する設備。**加熱にエネルギーを使う／レジオネラ属菌に注意** | 浴槽は約200L。冬の水道水は10℃を下回り、それを40数℃まで加熱する。**40℃前後は細菌が繁殖しやすい** → **貯湯**タンクは**65℃以上**（「60度とか65度」に上げて貯める）。40℃のまま貯めると菌だらけになる。何年かに1回は集団感染が起き、高齢者が亡くなる事例が今もある → 正しく設計・運用する。`[0:27:50–0:30:30]` |
| **排水通気設備** | 建物内の排水を排除する設備。**トラップの封水を保護** | 下の「トラップ・封水・通気」を参照。`[0:30:40–0:34:05]` |
| **衛生器具設備** | 衛生器具や水栓などの設備（水栓・シャワーヘッド・便器など） | 洗濯機なども含む、最も身近な設備。 |
| **排水処理・雨水利用・浄化槽設備** | 雑用水、中水設備 | 屋上の雨水を貯めてろ過し、**雑用水**（トイレの洗浄水・屋上緑化の散水）に再利用する。飲み水には使えない。上水の節約になり、下水道へ一度に流さないことで**洪水を起きにくくする**。タワースコラも雨水を利用している。 |

### ★トラップ・封水・通気

- **トラップ**：排水管をS字などにクランクさせて、常に水がたまるようにした部分（洋式便器の中の水も同じ）。
- **封水**：トラップにたまった水。**水で「ふた」**をして、下水管内の**有毒ガス・臭気・衛生害虫**が室内に入るのを防ぐ。
- 排水管の中は普段は空気だけ。水と固形物が上から落ちてくると、空気が抜けなければ**下の方の圧力が上がり**、流れが悪くなる → 圧力変動で封水が**飛び出す／吸い込まれる**（封水が破れる）。
- **通気管**を排水管と**必ずセット**で設置する → 空気を上へ逃がし、排水を円滑にして**トラップ（封水）を保護**する。

## 6. ★給排水衛生設備の原則（4つ）＝プリント設問2 `[0:37:57–0:52:31]`

### ①衛生性（衛生性が失われると人命にかかわる）

- **上水**：**いかなるときも飲料に適した水質**であること。**水道法第4条の水質基準**（51項目）。
  - No.1–31 **人の健康の保護**：病原生物による汚染の指標（一般細菌・大腸菌）、無機物・重金属、一般有機物、消毒副生成物
  - No.32–51 **生活利用上の障害防止**：着色、味、発泡、カビ臭、臭気、基礎的性状（pH・味・臭気・色度・濁度）
  - 敷地内は建築設備の範囲 → 送られてきた水が**蛇口に届くまで水質を担保する**のは建築設備技術者。項目を一つ一つ覚える必要はないが、かなり厳格に守られている。
- **排水**：腐敗・臭気・病原菌の発生原因になる → **迅速に排除**。**トラップの封水保護**。
- **雑用水**：上水のように消毒されていない → **飛沫の飛散・レジオネラ属菌・誤飲の防止**。雑用水が上水に混ざり、飲まれてしまった事故例もある → 絶対に上水と混ざらないようにする。

### ②機能性・耐久性・更新性（直ちに設備機能を発揮できることが重要）

- 開栓したら湯水が**直ちに**出る。使用後は**滞りなく排水**する。
- **シンプルな構成**：水回りは縦にそろえる（排水管が途中で曲がっていると詰まりやすい）。
- 給水ポンプなどは**2重化**（2台セットで交互に運転し、1台が故障しても機能を維持できる）。下水道より低い階の排水は、排水槽 → 排水ポンプでくみ上げる（止まると地下のトイレが使えなくなる）。
- **メンテナンススペース**と、機器の**搬出入ルート**を確保する。

### ③環境への配慮（水資源の有効活用）

- **上水使用量の削減**・雨水利用・排水再利用・地下浸透・洪水の抑制。
- 節水型便器：1回の洗浄水量は**約13L**（1980年頃）→ **4.8L・3.8L**（約71%・75%の節水。TOTOホームページの資料）。
- 雨水や洗面所の排水を処理してトイレの洗浄水に使う。**東京23区は合流式**（雨水と汚水が同じ下水道）なので、ゲリラ豪雨で雨水を全部流すとパンクする → 敷地内で貯めたり浸透させたりする。
- 例：汚水まで処理して再利用し、余った水はビオトープに浸透させる水循環システム（北九州学園都市）。

### ④耐震性（BCP・レジリエンスにも関係）

- 機器や配管が地震で破損・倒壊しないようにする。**被災時に下水が使えることは重要**（東日本大震災・阪神淡路大震災では、水が流れないトイレが使えない状態になった）。
- 設備を強靭にする・貯めておく場所を作る＋**携帯トイレ・簡易トイレ・マンホールトイレ・仮設トイレ**を備える（建物の管理者も）。

## 7. 上下水道と敷地・建物の接点（実務）`[1:09:57–1:24:38]`

- 上水は水道局の**給水区域・配水系統**、下水は**処理区**ごとに管理されている。タワースコラは**芝浦処理区**（芝浦の水再生センターで処理され、東京湾へ放流）。自分の地域の水源は水道局のホームページで確認できる。
- **下水道台帳**（インターネットで閲覧できる）で、管の位置・**深さ**・大きさを確認して排水を設計する。⚠**下水道より低い位置に排水箇所**があれば、ポンプでのくみ上げが必要。上水道の詳細図はセキュリティ上、公開されにくい（役所で確認する）。

| 敷地で見るもの | 意味・チェック点 |
|---|---|
| 止水栓・量水器 | 上水の引込み（メーターボックス）。引込み管が計画中の建物に対して小さい場合は**引込み工事**が必要 |
| 最終桝 | 敷地内の排水の最後の桝 → ここに排水すれば下水道へ流れる |
| 公設桝 | 下水道局の桝（公共桝） |
| 集水桝 | 道路の雨水排水用（敷地の排水先ではない） |
| ガス引込み | ここからガス管を引けば建物にガスが来る。配管の径も確認する |
| 電柱の電線 | 上段3本＝**高圧6600V**（建物の規模によっては必要。スコラも6600V）／中段＝**低圧100V・200V**（住宅・アパートはこれで足りる）／下＝電話線・光ファイバー |

- ★**責任分界点**：**上水は水道メーター**まで水道局の責任で、メーターから建物側は「お客様」＝**建築設備**。**下水は公共桝**が下水道局のもので、**最終桝から宅地側**が建物側。ここが上下水道と建築設備の境目。`[1:23:00–1:24:38]`
- 敷地に降った雨は**地盤に浸透させるよう指導**されることが多い → **雨水浸透桝**（穴があいていて、たまった雨水がゆっくり地盤に浸透する。全部を下水に流すと洪水・パンクの原因になる）。**汚水桝**は底に溝（流れ道）があり、固形物が詰まらずに流れる。`[1:21:33–1:22:56]`
- 施工：**基礎のコンクリートを打つ前に**配管の貫通位置を決めておく（基礎ができた時点で仮配管が通っている）。配管の色は**青＝給水、赤＝給湯、緑＝追い焚き**（フルオートの浴槽で、浴槽の湯を給湯器に戻して再加熱する）、太いグレーの管＝**排水**。給水・給湯は**ヘッダー**から各所（トイレ・キッチン・洗面・浴室・洗濯機）へ分岐する。`[1:18:15–1:21:25]`

## 8. コラム：東京の上下水道の歴史 `[0:54:21–1:09:39]`

- 水循環：雨 → 河川 → 取水 → 浄水場 → 建物（建築設備）→ 下水管 → 水処理センター → 川・海へ放流。建築設備・上下水道は、**自然の水循環の一部**を借りて使っている。
- 東京の水系：**利根川**（群馬）・**荒川**（秩父）・**多摩川**（奥多摩）・**相模川**（山中湖方面）。

| 時期 | できごと |
|---|---|
| 江戸 | **神田上水**（1590、井の頭池・善福寺池方面）→ **玉川上水**（1654、多摩川）。ほかに千川上水（1696）・青山上水（1660）・亀有上水（1659）・三田上水（1664）。道の下の**木樋**（配水管・給水管）で**上水井戸**（屋外共同使用・屋内専用）へ水を送り、汲み上げて使った。トイレは汲取り式で、雑排水は少なく、雨水はドブへ流した。 |

| 明治 | **コレラ流行**（明治12年は死者10万6千人、明治19年は10万8千人）。木の水道管の汚染や手洗いの不徹底が原因とされる → **鉄管**に変更。**「コレラは日本に衛生概念を植え付けた＝衛生の母」**。上下水道の普及で収まった。 |

## 9. 試験直前チェック（間違えやすい点）

- ⚠設備Ⅲで新たに重視する観点は「快適性」ではなく**「安全・衛生」**。
- ⚠貯湯は40℃で貯めない → **65℃以上**（60〜65℃）。原因菌は**レジオネラ属菌**。
- ⚠**封水**＝トラップにたまった水（ふた）。**通気管**＝排水時の空気の逃げ道で、封水を守る。排水管と**セット**で設ける。
- ⚠**雑用水**は飲用不可・上水と混ぜない・飛沫に注意（「上水」と混同しない）。
- ⚠寿命は**建築物60年／建築設備15年**。ポンプは**2重化**。
- ⚠責任分界点は、上水＝**水道メーター**、下水＝**最終桝**（公共桝は下水道局のもの）。
- ⚠東京23区は**合流式**。水質基準は**水道法第4条・51項目**。

### 最重要まとめ

給排水衛生設備は、建物内・敷地内の水に関する設備であり、**上下水道の末端**にあたる。**衛生性（人命）・機能性/耐久性/更新性・環境への配慮・耐震性（BCP）**の4原則に基づいて計画し、給水・給湯・排水通気・衛生器具・排水処理/雨水利用の5つの設備で構成される。
