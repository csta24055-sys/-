1 給排水衛生設備の定義と位置づけ

◎建物内・敷地内の水に関連する諸設備。
飲用・調理・洗浄など健康で衛生的な生活を維持し、災害から守るための基幹となる設備。[0:25:08]
  • 建築の3分野：設計・計画＝体の構成・容姿／構造・材料＝骨格／環境・設備＝内臓や血管・神経。
  • 空調設備は建築設備Ⅱで扱った。建築設備Ⅲ＝空調以外：給排水衛生設備・消防（防災）設備・電気設備。
  • 給排水衛生設備は上下水道の末端にあたる。建物を計画するとき、上水道・下水道が敷地まで来ているかが大きな関心事になる。[0:23:03]

考えるべき観点（空調との違い） [0:12:54–0:16:50]

空調設備（設備Ⅱ）給排水衛生・電気（設備Ⅲ）
共通：物理を知る（空気・水）／テクノロジー（機械・工学）／エネルギー・コスト／設備を建築に実装
環境工学・快適性（暑い・寒い）◎安全・衛生（人命に直結）
「一番変わってくるのが安全・衛生」[0:14:09]

理由：給水に異物が混入すると人が飲んでしまう／排水が滞留するとすぐ衛生問題になる（建物内で人が亡くなる事故もある）／火災報知器が作動しないと逃げ遅れる。

3 給水・給湯・排水の基本的な流れ

概念図（スライド18の系統図をもとに作成）
上水給水本管 → 量水器 → 受水槽 → 給水ポンプ → 揚水管 → 高置水槽 → 給水管 → 各階の水栓
給湯上水を引き込み加熱 → シャワー・浴槽・キッチンへ（湯を貯める装置＝貯湯タンク）
排水器具 → トラップ → 排水管（＋通気管） → 排水ます → 下水道本管。下水道より低い階は排水槽 → 排水ポンプでくみ上げ
雨水・雑用水ルーフドレン → 雨水貯留槽 → ろ過 → 雑用水槽 → 雑用水ポンプ → 便器洗浄・屋上緑化への灌水

4 トラップ・封水・通気管の仕組み

  • トラップ：排水管をS字などにクランクさせ、常に水がたまるようにした部分（洋式便器の中の水も同じ）。
  • ◎封水：トラップにたまった水。水で「ふた」をして、下水管内の有毒ガス・臭気・衛生害虫が室内に入るのを防ぐ。[0:32:15]
  • 排水管内は普段は空気だけ。上から水と固形物が落ちると、空気が抜けなければ下の方の圧力が上がり、流れが悪くなる。圧力変動に耐えられず封水が飛び出す／吸い込まれる（封水が破れる）。
  • ◎通気管を排水管と必ずセットで設置する [0:33:34] → 空気を上に逃がし、排水を円滑にしてトラップ（封水）を保護する。

7 節水・雨水利用・BCP

  • 節水型便器：1回の洗浄水量は約13L（1980年頃）→ 便器の形状などの工夫で4.8L・3.8L（約71%・75%の節水）。[0:47:26]
  • 雨水利用・排水再利用：敷地に降った雨水や洗面所の排水を処理し、便器の洗浄水に使う → 上水の使用量を削減。
  • 洪水の抑制：東京23区は合流式（雨水と汚水が同じ下水道）。豪雨時に雨水を全部流すと下水道がパンク → 敷地内で貯留・地下浸透させる。[0:49:08]
  • ◎BCP：一番重要なのは電気、同じくらい重要なのが給排水、特にトイレ。飲み水は備蓄で賄えるが、水を排出できないと大問題になる。[0:24:05–0:25:06]

8 衛生性・耐久性・更新性・耐震性（4原則の詳細）

①衛生性 [0:37:57–0:42:20]

  • 上水：◎いかなるときも飲料に適した水質 [0:38:42]。水道局が水質を確認して送った水でも、敷地内は建築設備の範囲 → 蛇口に届くまで水質を担保するのは建築設備技術者。
  • 水道法第4条の水質基準（51項目）：No.1〜31＝人の健康の保護（病原生物の指標・無機物/重金属・一般有機物・消毒副生成物）、No.32〜51＝生活利用上の障害防止（着色・味・発泡・カビ臭・臭気・基礎的性状）。項目の暗記は不要だが、厳しく守られている（教員）[0:39:59]
  • 排水：腐敗・臭気・病原菌の発生原因 → 迅速に排除（途中で滞留させない）。トラップの封水保護。
  • 雑用水：上水のように消毒されていない → 飛沫の飛散・レジオネラ属菌・誤飲を防ぐ。◎雑用水が上水に混ざり飲まれた事故もある → 上水と混ぜない [0:42:12]

②機能性・耐久性・更新性 [0:42:33–0:46:40]

  • 開栓したら湯水が直ちに出る。使用後は滞りなく下水道まで流れる。
  • シンプルな構成：水回りは縦にそろえる（排水管が途中で曲がると詰まりやすい）。
  • 2重化：ポンプは機械なので、いつか壊れる → 2台セットで交互に運転し、1台が壊れても機能を維持。地下の排水ポンプも同じ（止まると地下のトイレが使えない）。
  • ◎メンテナンススペースを確保し、故障した機器を搬出するルートも考えて機械室を配置 [0:45:50]

④耐震性（BCP・レジリエンス） [0:51:06–0:52:31]

機器・配管を地震で壊さない。下水管が壊れると水の流れないトイレは使えない（東日本大震災・阪神淡路大震災）→ 設備の強靭化・貯留場所＋携帯・簡易・マンホール・仮設トイレの備え。

9 上下水道との接点・責任分界点

  • ◎責任分界点：上水は水道メーターまで水道局、メーターから建物側は「お客さま」＝建築設備。下水は公共ますが下水道局のもので、最終ますから宅地側が建物側。[1:23:00–1:24:38]
  • 下水道台帳で管の位置・深さを確認する。下水道より低い位置に排水する場所があれば、ポンプでくみ上げる。[1:13:11–1:13:51]
  • 敷地で確認するもの：止水栓・量水器（上水の引込み）、最終ます・公設ます、集水ます（道路の雨水用）、ガス引込み、電柱の電線（高圧6600V／低圧100・200V）。[1:13:54–1:17:37]

14 間違えやすいポイント○

  • 設備Ⅲの観点は「快適性」ではなく「安全・衛生」。
  • 封水は「水」、トラップは「封水がたまる管の形」、通気管は「封水を守る空気の通り道」。
  • 貯湯は40℃で貯めない → 65℃以上。原因菌はレジオネラ属菌（給湯と雑用水の両方で出てくる）。
  • 雑用水は飲めない。雨水利用＝「上水の代わりに飲む」ではない。
  • 寿命は建築物60年・設備15年（逆にしない）。
  • 責任分界点：上水はメーター、下水は最終ます。公共ますは下水道局。
