4 給排水衛生設備とは（定義）

建物内・敷地内の水に関連する諸設備。飲用・調理・洗浄など健康で衛生的な生活を維持し、災害から守るための基幹となる設備。[0:25:08]
  • 日本では水道から出る水はいつでも飲める前提 → 設計・運用では途中で異物が入らないようにする。
  • 用途：飲用・調理（スープ等）・洗浄（食器・手洗い・便器洗浄）。空調よりも健康・衛生に直結。
流れ：給水本管 → 量水器 → 受水槽 → 給水（揚水）ポンプ → 高置水槽 → 各階の水栓 → 排水管（＋通気管）→ 排水ます → 下水道本管。地下の排水は排水槽 → 排水ポンプでくみ上げ。屋根の雨水はルーフドレン → 雨水貯留槽 → ろ過 → 雑用水（トイレ洗浄・屋上緑化散水）。[0:26:27–]

5 給排水衛生設備の構成（5分類） プリント設問1

設備役割（スライド）ポイント（授業の説明）
給水設備水道水（上水）を供給する設備。常に飲用可の水質であること人が飲む水を運ぶ＝責任が非常に重い設備。[0:26:36]
給湯設備上水を加熱して供給する設備。加熱にエネルギーを使う／レジオネラ属菌に注意浴槽約200L、冬の水道水は10℃以下 → 40数℃まで加熱。40℃前後は細菌が繁殖しやすい → 貯湯タンクは65℃以上（「60度とか65度」に上げて貯める）。40℃のまま貯めると菌だらけ。何年かに1回集団感染で高齢者が亡くなる事例が今もある → 正しく設計・運用。[0:27:50–0:30:30]
排水通気設備建物内の排水を排除する設備。トラップの封水を保護下記「トラップ・封水・通気」参照。[0:30:40–0:34:05]
衛生器具設備衛生器具や水栓などの設備水栓・シャワーヘッド・便器・洗濯機など最も身近な設備。
排水処理・雨水利用・浄化槽設備雑用水、中水設備屋上の雨水を貯留・ろ過して雑用水（トイレ洗浄水・屋上緑化の散水）に再利用。飲み水には使えない。上水の節約＋下水道へ一度に流さず洪水を起きにくくする。タワースコラも雨水利用。[0:34:45–0:37:28]
トラップ・封水・通気（★頻出の仕組み）
  • トラップ：排水管をS字等にクランクさせ、常に水をためる部分（洋式便器の中の水も同じ）。
  • 封水：トラップにたまった水。水で「ふた」をして、下水管内の有毒ガス・臭気・衛生害虫の室内侵入を防ぐ。
  • 排水管内は通常空気だけ。水と固形物が落下すると、空気が抜けないと下部の圧力が上がり流れが悪化 → 圧力変動で封水が飛び出す／吸い込まれる（封水が破れる）。
  • 通気管を排水管と必ずセットで設置 → 空気を上へ逃がし、排水を円滑にしトラップ（封水）を保護。

6 給排水衛生設備の原則（4つ） プリント設問2

原則内容
①衛生性
失われると人命にかかわる		上水：いかなるときも飲料に適した水質であること。水道法第4条の水質基準（51項目：No.1–31人の健康の保護＝病原生物・重金属・一般有機物・消毒副生成物、No.32–51生活利用上の障害防止＝着色・味・発泡・カビ臭・臭気・基礎的性状）。敷地内は建築設備の範囲 → 蛇口に届くまで水質を担保するのは設備技術者。項目の暗記は不要だが厳格に守られている。
排水：腐敗・臭気・病原菌の発生原因 → 迅速に排除。トラップの封水保護。
雑用水：消毒されていない → 飛沫の飛散・レジオネラ属菌・誤飲の防止。雑用水が上水に混ざり飲まれた事故例あり → 絶対に上水と混ざらないように。[0:37:57–0:42:20]
②機能性・耐久性・更新性
直ちに機能を発揮		開栓時に湯水が直ちに出る。使用後は滞りなく排水。
シンプルな構成：水回りは縦にそろえる（排水管が途中で曲がると詰まりやすい）。
給水ポンプ等は2重化（2台セットで交互運転、1台故障でも機能維持）。下水道より低い階の排水は排水槽→排水ポンプでくみ上げ（止まると地下のトイレが使えない）。
メンテナンススペースと機器の搬出入ルートを確保。[0:42:33–0:46:40]
③環境への配慮
水資源の有効活用		上水使用量削減・雨水利用・排水再利用・地下浸透・洪水の抑制。
節水型便器：1回の洗浄水量 約13L（1980年頃）→ 4.8L・3.8L（約71%・75%節水、TOTO資料）。
雨水や洗面排水を処理してトイレ洗浄水に。東京23区は合流式（雨水と汚水が同じ下水道）→ ゲリラ豪雨で雨水を全部流すとパンク → 敷地内で貯留・浸透。例：汚水まで処理して再利用し、余剰はビオトープへ浸透（北九州学園都市の水循環システム）。[0:46:44–0:51:03]
④耐震性
BCP・レジリエンスにも関係		機器や配管が地震で破損・倒壊しないように。被災時の下水利用は重要（東日本大震災・阪神淡路大震災では水の流れないトイレが使えない状態に）。設備を強靭にする・貯める場所を作る＋携帯・簡易・マンホール・仮設トイレの備え（建物管理者も）。[0:51:06–0:52:31]

7 上下水道と敷地・建物の接点（実務）

  • 上水は水道局の給水区域・配水系統、下水は処理区で管理。タワースコラは芝浦処理区（芝浦の水再生センターで処理し東京湾へ放流）。自分の地域の水源は水道局HPで確認できる。[1:09:57–1:12:10]
  • 下水道台帳（ネットで閲覧可）で管の位置・深さ・大きさを確認して排水設計。下水道より低い位置に排水箇所があればポンプでくみ上げが必要。上水道の詳細図はセキュリティ上公開されにくく、役所で確認。[1:12:14–1:13:51]
敷地で見るもの意味・チェック点 [1:13:54–1:18:10]
止水栓・量水器上水の引込み（メーターボックス）。引込み管が計画建物に対して小さい場合は引込み工事が必要
最終桝敷地内排水の最後の桝 → ここに排水すれば下水道へ流れる
公設桝下水道局の桝（公共桝）
集水桝道路の雨水排水用（敷地の排水先ではない）
ガス引込みここからガス管を引けば建物にガスが来る。配管の径も確認
電柱の電線上段3本＝高圧6600V（規模によっては必要、スコラも6600V）／中段＝低圧100V・200V（住宅・アパートはこれでOK）／下＝電話線・光ファイバー
★責任分界点　上水：水道メーターまで水道局の責任、メーターから建物側は「お客様」＝建築設備。下水：公共桝は下水道局、最終桝から宅地側が建物側。ここが上下水道と建築設備の境目。[1:23:00–1:24:38]
  • 敷地に降った雨は地盤に浸透させるよう指導されることが多い → 雨水浸透桝（穴があり、たまった雨水がゆっくり地盤に浸透。全部下水に流すと洪水・パンクの原因）。汚水桝は底に溝（流れ道）があり、固形物が詰まらず流れる。[1:21:33–1:22:56]
  • 施工：基礎のコンクリート打設前に配管の貫通位置を決める（基礎完成時には仮配管が通る）。配管色は青＝給水、赤＝給湯、緑＝追い焚き（フルオート浴槽で浴槽の湯を給湯器に戻して再加熱）、太いグレー管＝排水。給水・給湯はヘッダーから各所（トイレ・キッチン・洗面・浴室・洗濯機）へ分岐。[1:18:15–1:21:25]

8 コラム：東京の上下水道の歴史

雨→河川→取水→浄水場→建物（建築設備）→下水管→水処理センター→放流→川・海

建築設備・上下水道は自然の水循環の一部を借りて使っている。東京の水系：利根川（群馬）・荒川（秩父）・多摩川（奥多摩）・相模川（山中湖方面）。[0:55:45–0:58:35]

時期できごと
江戸神田上水（1590、井の頭池・善福寺池方面）→玉川上水（1654、多摩川）。道の下の木樋（配水管・給水管）で上水井戸へ送り汲み上げて使用。トイレは汲取り、雑排水は少なく雨水はドブへ。
1892年三多摩が神奈川県→東京府へ（都心の水源＝玉川上水の流域を一体で管理するため）。
明治コレラ流行（明治12年死者10万6千人、明治19年10万8千人）。木の水道管の汚染・手洗い不徹底が原因とされる → 鉄管へ。「コレラは日本に衛生概念を植え付けた＝衛生の母」。上下水道の普及で収束。
近代化淀橋浄水場（1898〜1965、跡地が現在の新宿副都心・都庁）、村山下貯水池（多摩湖、1924・27年）、小河内ダム（奥多摩湖、1938〜1957年）。
1964年東京大渇水（オリンピック直前、小河内貯水池は2%、最大給水制限50%、24時間断水の地域も、自衛隊等の応援給水＝「東京サバク」）→ 利根川からの導水（武蔵水路1967）、東村山1960・朝霞1966・三郷1985浄水場。
現在東京都の水源はほとんど河川水。昭和30年頃までは多摩川水系が主 → 現在は利根川・荒川水系78%、多摩川水系19%。

9 試験直前チェック（間違えやすい点）

  • 設備Ⅲで新たに重視する観点は「快適性」ではなく「安全・衛生」。
  • 貯湯は40℃で貯めない → 65℃以上（60〜65℃）。原因菌はレジオネラ属菌。
  • 封水＝トラップの水（ふた）。通気管＝排水時の空気の逃げ道で封水を守る。排水管とセット。
  • 雑用水は飲用不可・上水と混ぜない・飛沫に注意（「上水」と混同しない）。
  • 寿命：建築物60年／建築設備15年。ポンプは2重化。
  • 責任分界点：上水＝水道メーター、下水＝最終桝（公共桝は下水道局）。
  • 東京23区は合流式。水質基準は水道法第4条・51項目。
最重要まとめ：給排水衛生設備＝建物内・敷地内の水に関する設備で、上下水道の末端。衛生性（人命）・機能性/耐久性/更新性・環境配慮・耐震性（BCP）の4原則で計画し、給水・給湯・排水通気・衛生器具・排水処理/雨水利用の5設備で構成される。
