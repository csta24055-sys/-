## 1. 直接排出の時間形（候補 5 つの検証）

指示書の候補（初期型・連続運用型・離散イベント型・状態依存型・終端型）を、全シナリオの核の項（F3）で数えた。結論：**時間形は「核の形」と「振幅の出どころ」の 2 つの軸に分かれる。** 状態依存は核の形ではなく、振幅が F4 で作られるという性質であり、連続・事象・終端のどれとも組み合わさる。

| 核の形（実時間での位置） | 直接単位 |
|---|---|
| 初期（$t=0$、A 段階の定数） | A13-01、A13-03、A13-04、X-01、A4-01、A4-02、A5-04 |
| 連続（年あたりの率 × 年重み、全年一定の密度） | B1-02、B2-01、B3-01（密度）、B6-03、B7-04 |
| 事象（原子 $\theta_\varepsilon(T;\tau)$） | B1-03、B4-02、B5-01 |
| 事象で切り替わる率（ゲート付き年セル） | B1-03、B3-01（交換の年の修繕の除外） |
| 終端（$t=T$：C 段階の定数、期末の状態量の窓） | C1-01、C2-01、C3-01、C4-01、X-14（定数）、B1-04（状態の窓） |

| 振幅の出どころ | 直接単位 |
|---|---|
| 状態（F4：冷媒の年初の残存量 $u$） | B1-02、B1-03、B1-04 |
| 静的（F1・F2） | 残り 18 |

- **材料製造時の排出**は初期（A 段階）で、**設備交換の段差**は事象の原子（B4-02：1 回あたり＝初期の製造・輸送・撤去の和）、**劣化・漏洩**は状態の振幅をもつ連続（B1-02）、**運用量**は連続（B6-03・B7-04・B2-01）、**解体の時点**は終端（$t=T$）。
- B1-04 の段階は B1（使用時）だが、時間形は終端である。**段階と時間形は別の属性**として持つ。

## 2. 最終集計先（5 つ）の検証

集計先を段階の和で定義した：D1 製造・施工（A1-A3・A4・A5）、D2 使用時の物質・機器（B1〜B5）、D3 運用エネルギー（B6）、D4 運用水・廃棄物（B7）、D5 解体・廃棄（C1〜C4）。各直接単位は 1 つの集計先に入り、B2-01 だけが D2 に＋、D3 に −（B2 を数えるとき）で入る（運用電力の施設管理分の**振替**）。

検査（全 1,293 組、08 章の再構成と同じ組。集計先は固定の 0/1 係数で評価、時間形は最小二乗で最良の固定係数を探した）：

| 総量 | 5 集計先の固定の 0/1 結合 | 時間形の合計の固定の線形結合 |
|---|---|---|
| SUM-01 アップフロント | D1 で厳密（最大相対残差 3.5e-16） | 初期だけで厳密（このモデルでは A 段階がすべて初期） |
| SUM-02 エンボディド | D1 + D2 + D5 で厳密（1.1e-13） | **表せない**（最良の固定係数でも最大相対残差 0.98：連続の率に B6・B7 と B1-02・B2-01・B3-01 が混ざるため） |
| SUM-03 ホールライフ | ΣD で厳密（1.0e-13） | 全形の和で厳密 |

**結論**：
1. 5 集計先は SUM-01〜03（したがって SUM-04〜06）を情報を失わずに運ぶ（F：1,293 組で相対 1e-9 以内。08 章の再構成でも組ごとに照合して不一致 0）。
2. 5 集計先では**段階の割合 SUM-07（14 段階）と段階別の値（X-02）が失われる**（14 → 5 の写像は階数 5 で単射でない）。詳細の内訳は段階・単位の値として保持し、集計先はその上の見出しとする。
3. 時間形（6 形）は集計先の代わりにならない（SUM-02 の反例）。**演算族の 5、時間形、集計先の 5 は別のもの**である。
4. 総量（SUM-01〜03）と派生指標（SUM-04〜08）は混ぜない：派生指標は総量の F1（比）であり、集計先に足し込まない。

## 3. 評価期間 $T$ と実時間 $t$

`tools/band_and_realtime.py`（[08_verification/results/realtime_vs_T.csv](../08_verification/results/realtime_vs_T.csv)）：1 シナリオ（H=130、$T^*=60$）で、実時間の累積 $M_{T^*}(t)$（初期は $t=0$、率と事象は起きた時、終端は $t=T^*$ だけ）と評価期間の関数 $C(t)$ を 240 点で比べた。

- $C(T^*)=M_{T^*}(T^*)$（相対 1e-9）。
- $t<T^*$ では $C(t)-M_{T^*}(t)=Z(t)$（終端の項：解体と期末の冷媒）が全点で成り立つ。差の最大は約 8.5×10^5 kgCO2e。
- したがって $C(T)$ を時間の累積排出と読んではいけない。$T$ を動かすと、終端の量と事象の数え方が同時に動く（旧 17 章 TH-4）。

## 4. 667 式への適用

667 式の台帳（02 章、権利保留）でも、補助算定 362・直接排出 162・最終集計 67 の階層が推定された。ただし依存の追跡ができないため、直接排出の 162 件が 70 単位のどの時間形・集計先に入るかは確定していない。40・21・5 の数に合わせる操作はしていない。
