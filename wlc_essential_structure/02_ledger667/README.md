# 02 667 式の全件監査台帳（権利保留・構造メタデータのみ）

- 台帳：[ledger667_audit.csv](ledger667_audit.csv)（667 行）、集計：[ledger667_summary.json](ledger667_summary.json)
- 生成：`python3 -I tools/build_ledger667.py <761da13 のチェックアウト> 02_ledger667`
- **権利：全行 HOLD。** 入力は旧研究が公開済みの構造メタデータ（`15_JCAT_CONVERSION/01_分類と変換状態_667件.csv`、`14_EQUATION_DISCLOSURE/05a_…対応表.csv`）だけ。式本文・係数・値・セル番地はこのセッションに無く、読んでも書いてもいない（01_rights）。

## 1. 「667」が数えているもの

667 は Excel のセル数ではない。旧 14 章が J-CAT 原版 5 ブックの全数式セル **3,818,483 個**を、参照の位置を抽象化して **4,241 個の正規化パターン**にまとめ、さらに参照の変種を同一視した **骨格（独立方程式）667 個**である（`original_formula_counts.json`：skeletons 667、patterns 4,241、methods 438）。1 つの ID は 1〜1,473,786 セルを代表する（台帳の `cells` 列、合計 3,818,483 を照合済み）。同じ算定規則でも、参照の形が違えば別の ID になりうる（同型候補の統合で扱う）。

| 本質的算定 | 322 | 2,663,463 | 排出・数量・係数・時間・集計の意味を持つ同型群の代表 |
| 意味を保って統合 | 269 | 95,669 | 同型候補（分類・呼び名・基本演算の集合が代表と一致）239、係数・区分の選択を決めるキーや判定 29（F1 の選択へ）、計算に使う定数 1（パラメータの記号へ）。元 ID は `merged_into` で代表に結ぶ |

## 4. 数学的な族（05 章の F1〜F5）

統合後の 322 型の主分類：F2 系 136（活動量×係数 71、時間成分つき 30、状態の候補 8、加重和 27）、F1 系 105（換算・準備 67、選択 37、最大値 1）、F5 系 48（集計 37、時間つきの集計 11）、F3 の生成（回数・年次・周期）33。基本演算の出現（667 件中）：四則 381、条件 225、検索 184、集計 109、条件付き集計 89、エラー処理 95、丸め 58、定数 35、MOD 19、文字列 3、実数乗 2、常用対数 1、順位 1。

意味を保つべき例外（`must_keep_meaning`）：

- **丸め 58 件**：値を決める丸めは表示用として落とさず、R-ROUND（格子計数、有限の定義域）として保持。
- **MOD 19 件**：年次・周期の判定は F3 の事象の生成。
- **実数乗 2・常用対数 1**（回帰による数量算定 EQ-0450〜0452）：有理の 5 族で厳密に表せない（16 章の証明、05 章 CE-1・2）。F1*（既知のスカラー関数）として扱う。
- **文字列 1**（EQ-0229 年・コードの抽出）：数値の選択に効くので、文字列ではなく組の添字に置き換える。

## 5. 限界

- 判定は構造メタデータからの推定で、2 つの ID が同じ式であることは主張しない（同型**候補**）。
- 族の割り当ても関数名と呼び名による。実際の式の同値性・依存関係・未使用の枝の確定は、権利者の許諾を得て非公開資料を参照できる環境で行う（再開手順は README）。
- 70 単位の独立モデルの設計・検証には使っていない。
