# 09 独立係数データベース（世界の一次資料、J-CAT に依存しない）

## 1. 作り方

1. **需要の逆算**：70 評価単位の入力 149 項目と式から、外部の係数が必要な量を 124 行に逆算した（[coefficient_demand.csv](coefficient_demand.csv)、`tools/build_coef_demand.py`）。うち 90 行は J-CAT の使用条件で流用が禁止された種類（排出原単位・更新周期・修繕率・フロン漏洩率・工事分倍率）で、独立の資料からの取得が必須。数量・面積・距離などの建物の入力は係数ではないので別に扱った。667 式の構造メタデータ（02 章）の小分類（工事分倍率・更新周期・修繕・冷媒・複合原単位など）は、この 124 行のどれかに入ることを確認した。
2. **並列調査**：8 つの調査エージェントが国・資料群ごとに一次資料を調べ、値・単位・地域・製法・年度・算定境界・出典 URL・利用条件を同じ形式で記録した（取得日 2026-11-27）。
   - ドイツ ÖKOBAUDAT・スイス KBOB
   - スウェーデン Boverket・フランス ADEME
   - 米国 EPA（GHG Emission Factors Hub、WARM、Supply Chain Factors）・英国 DESNZ
   - オーストラリア EPiC・国際 EPD・設備の EPD／PEP・CIBSE TM65
   - 日本の一次資料（環境省・経産省・国交省・NIES 3EID・業界団体）
   - 耐用年数・冷媒・IPCC（BBSR、RICS、EU F ガス規則、IPCC 2006／2019）
   - 日本の建物の数量・運用の統計（国交省・東京都・資源エネルギー庁・環境省）
   - 日本の修繕支出・ストック・副産物の統計（B3 の推定用）
3. **統合**：`tools/build_factor_db.py` が全行を需要台帳へ対応付け（カテゴリで先に絞る規則）、権利の 5 区分を付け、指標を出す。

## 2. 権利の 5 区分と公開の規則

| 区分 | 意味 | 値の行数 | 公開リポジトリでの扱い |
|---|---|---:|---|
| 1 公開アプリに組み込み可 | 開かれたライセンス（PDL1.0、OGL v3、米連邦政府の著作物、Licence Ouverte、CC BY 4.0 など） | 1,114 | 値を公開 |
| 2 研究・検証のみ | 非営利のみ、または独自条件（ÖKOBAUDAT の独自条件、EPiC 2026 の CC BY-NC-ND） | 130 | 値は非公開（`private/`、git の対象外）。出典と状態だけ公開 |
| 3 外部参照のみ | 開かれたライセンスの無い一次文書（EPD、論文、KBOB、3EID、業界資料）：個別の値の出典つき引用だけ | 482 | **算定で引用した 19 値だけ公開**。ほかは出典と状態だけ（データセットの実質的な再掲を避ける） |
| 4 利用条件未確認 | 規約ページが見つからない・読めない | 81 | 値は非公開 |
| 5 利用不可 | 明示の禁止・有償 | 0（値なし。INIES は有償の API、IDEA は有償） | 取得していない |

- 利用規約を回避した取得はしていない（ログインが必要な ADEME Base Empreinte、INIES の API、CIBSE の会員資料、有償の ASHRAE・CEN 規格は使っていない）。
- 判断の慎重側への寄せ：環境省のサプライチェーン DB（NIES の GLIO が元）は調査担当が区分 1 としたが、算定では区分 3 と同じ扱いの出典つき引用とした。Boverket の条件は「誰でも自由に利用できる（出典の明記）」だが大量の再掲は明記されていないため、許諾の確認を推奨（README の再開手順）。

## 3. 指標（124 需要行、[coverage_indicators.json](coverage_indicators.json)・[coverage_by_demand.csv](coverage_by_demand.csv)）

| 指標 | 値 | 定義 |
|---|---:|---|
| 実データ取得率 | **73.4%** | 一次資料の実数値が 1 つ以上ある需要行（地域で値が大きく変わる需要は日本の値がある場合だけ） |
| 商用利用可能なデータの取得率 | **62.9%** | 区分 1 の実数値がある需要行 |
| 日本の値がある割合 | 39.5% | |
| 海外の値だけ（地域感度の高い需要） | 4.8% | 上水・廃棄物処理など：海外値は日本の値と数えない |
| 実データに基づく推定だけの割合 | 0.0% | 推定で埋めた需要行のうち実データが無いもの（推定は 10 章で作り、実データの裏付けがある行にだけ使った） |
| 模擬データへの依存率 | **0%** | 実建物の算定（10 章）で使った模擬データ |
| 未取得率 | **21.8%** | |
| 2 つ以上の独立な出典がある割合 | 67.7% | |

10 章の建物の算定では、合計に対する割合で実データ R 3.3%、実データに基づく推定 E 91.8%、仮定 A 4.9%（運用エネルギーが推定 E に入るため E が大きい）。

## 4. 未取得の係数と代替候補

`coverage_by_demand.csv` の `status = NOT_OBTAINED` の行（調べた出典と理由つき）。主なもの：

| 需要 | 理由 | 代替候補 |
|---|---|---|
| 年間修繕率（部位別 10 行） | 国内外とも公開の一次の既定値が無い（『建築物のライフサイクルコスト』は有償の書籍） | 修繕支出の統計 × 3EID の建設補修部門の原単位による推定（実施中） |
| 大規模改修の周期・割合 | 公的資料なし | 長期修繕計画のガイドライン、改修の実績統計 |
| 解体作業のエネルギー | 公的資料なし | 解体工事の軽油使用量の調査、海外の EPD の C1 |
| 未数量工事の上乗せ率 | J-CAT の工事分倍率に当たる。独立の資料なし | 積算の実績（建物ごとの入力にする） |
| 系統係数の将来経路 | 政府の将来見通しを係数の形で取得していない | エネルギー基本計画の電源構成から推定 |
| 物価指数 | 未取得 | 日本銀行・総務省の物価指数（建設工事費デフレーター：国交省） |
| 積載率、端材の再使用率、廃棄経路の比率 | 未取得 | 国交省「建設副産物実態調査」（実施中）、トラック輸送の統計 |
| 冷媒機器の交換周期 | 対応付けの対象外（BIMMS-N の空調 20 年で代用中） | IPCC 表 7.9 の機器寿命 |
