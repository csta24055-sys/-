## 補助計算 → 直接排出の有向グラフ（要約）

```
入力 ──G（G-01〜G-16）──► L1 補助算定 ───────────────► L2a 一次の直接排出 ──► L2b 派生の直接排出
  数量：A13-05（端材の総量化）、A13-02（複合係数）、X-15（係数の選択）        A13-01 A13-03 X-01       A13-04（上乗せ）
  施工：A5-01〜03 ─────────────────────────► A5-04             A4-01 A4-02              B3-01（修繕）
  時間：B4-01（事象の時刻）、B4-03（回数）──────────────────────────────► B4-02（交換）  B5-01（改修）
  運用：X-06（電力係数の系列）→ B6-04（正味）→ B6-01；B6-02 ─────► B6-03、B2-01(＋B2／−B6)
  水：B7-01〜03 ──────────────────────────► B7-04
  状態：B1-02（冷媒の残存量 u、F4）───────────────────────────────► B1-03（交換時）、B1-04（期末）
  解体：C1-01 C2-01 C3-01 C4-01 X-14（入力のみ）
                                   L2 ──F5（構成表 22 行）──► L3（X-02、SUM-01〜03）──► L4 指標・L5 内訳
```

補助計算が直接算定に渡すもの：**数量**（A13-05 → A13-01・A13-03・A4-02・B4-02）、**係数**（A13-02・X-15 → A13-01・A13-03、X-06 → B6-01）、**状態**（B1-02 の $u$ → B1-03・B1-04）、**発生時刻・回数**（B4-01・B4-03 → B3-01・B4-02）、**年次の活動量**（B6-01・B6-02・B7-01〜03 → B6-03・B7-04・B2-01）。

## 除外と内部処理の原則

- 70 単位で**削除したものは 0**。9 単位は値を作らない判定として内部機構へ移し、報告は残す。
- 667 式で対象外にしたのは 3 件（常にエラーを返す参照切れ。旧 06 の手順 3 の判定と同じ根拠）。72 件は表示・転記で内部処理。どちらも元 ID を保持した。
