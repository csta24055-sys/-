# 改善版（v2）の変更内容と理由

対象：`output/yucaco_ch4_performance_customer_v2.pdf`（全38ページ）
もとにした版：新版 v1 `output/yucaco_ch4_performance_customer.pdf`（コミット `da210e3`。ファイルはそのまま残してあります）

## ねらい

- 新版 v1 のデザイン（白と紺、写真の扱い、余白、出典・補足・分析の区別）は土台として変えない。
- 旧版の「ひと目でわかる」説明力（数字の大きさ、文字の強弱、比較と流れの図解、やさしい言い回し）を取り戻す。
- 研究内容・数値・計算・出典・ページ順は変えない。

全ページ共通で行ったこと

| 項目 | v1 | v2 | 理由 |
|---|---|---|---|
| 注記の文字 | 20px | 22px | 離れた席から読める下限を上げた |
| 章ラベル（例：4-8 省エネの判定） | 20px | 22px | 「いま何の話か」を見つけやすく |
| 補足・分析のラベル | 17px | 19px | 情報の種類を見落とさないように |
| 主役の数字・結論 | 多くのページで 30〜70px | 45〜240px、太字 | 旧版と同じく「最初に見る場所」をはっきりさせた |
| 写真の説明文の影 | あり | なし | PDF の中で文字が二重に入り、コピー・検索で文字が重複していたため |

文字の大きさは 1920px 幅のスライドでの値です。3つの版を同じ物差しで測った結果は `output/compare/text_metrics.md` にあります。

## 外部デザインツールについて

Canva・Figma・Picsart Media Studio の連携を確認しましたが、今回は使っていません。

- Figma：接続はできましたが、アカウントの席が「View」（閲覧）で、ファイルの編集には使えない状態でした。
- Canva：接続できました。アップロードした素材の所有権は利用者に残るとの回答でしたが、AI の学習に使われるかどうかは「不明」との回答でした。
- Picsart Media Studio：動画・モーション向けの合成ツールで、静止画スライドの文字組みには向きません。

文字の大きさ・フォントの埋め込み・全38ページの一貫性を正確に管理でき、GitHub 上で作り直せる現在の方法（HTML/CSS → PDF）の方が品質を保てると判断しました。発表資料や写真を外部サービスに送ることもしていません。
