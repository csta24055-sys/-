# YUCACO読本 第4章「住まいの性能と評価」 顧客説明資料版

原本（読み合わせ用スライド 全38ページ）の構成・研究内容・計算・図表・論理展開をそのまま保ち、
住宅会社が商談や性能説明でそのまま使える水準の見た目と情報設計に作り直したものです。

- 完成品：`output/yucaco_ch4_performance_customer.pdf`（38ページ、13.333 × 7.5 in = 原本と同じ 16:9）
- 原稿：`src/deck.html`（1ページ = 1920 × 1080 px）と `src/deck.css`
- 素材：`src/assets/photos/`（写真 8点）、`src/assets/figures/`（原本の図 4-1・4-2・4-5）、`src/assets/fonts/`（同梱フォント）
- 書き出し：`tools/build.mjs`

## 書き出し方

```bash
node tools/build.mjs                      # PDF と 38枚の PNG（output/pages/）を書き出す
ONLY=5,6 NO_PDF=1 node tools/build.mjs    # 指定ページの PNG だけ（確認用）
```

書き出し時に、スライドからのはみ出し・文字の切れ・フッターとの重なりを自動で検査し、結果を表示します。

本文を書き換えて新しい文字（漢字など）が増えたときは、フォントのサブセットを作り直してください。

```bash
pip install fonttools
npm pack @expo-google-fonts/noto-sans-jp @expo-google-fonts/noto-serif-jp   # 静的 TTF（SIL OFL 1.1）
mkdir -p fonts && tar -xzf expo-google-fonts-noto-sans-jp-*.tgz -C fonts && tar -xzf expo-google-fonts-noto-serif-jp-*.tgz -C fonts
python3 tools/subset_fonts.py fonts       # 「≒」だけは BIZ UDPゴシック（apt の fonts-morisawa-bizud-gothic）から取る
```

## 共通のデザインルール

| 項目 | ルール | 理由 |
|---|---|---|
| 枠 | 上端に濃紺の細線、左上に章ラベル（例：`4-8` 省エネの判定）、その下に見出し、下端にフッター（資料名・出典ページ・ページ番号） | どのページでも「いま何の話か」「根拠は原本の何ページか」が同じ位置で分かるようにする |
| 余白 | 左右 120px、見出しの位置は全ページ共通 | 画面でも印刷でも、ページをめくったときに見出しが揺れない |
| 文字 | 見出し・本文は Noto Sans JP、表紙と章扉の題字だけ Noto Serif JP（明朝） | 説明は読みやすいゴシック、資料の「顔」だけ落ち着いた明朝。数字の大きな表示もゴシックで統一 |
| 文字の大きさ | 見出し 52px、本文 24〜28px、注記 20px、出典 15px（1920px 幅基準） | 大型画面で後ろの席から読め、A4 印刷でも本文が 10pt 以上になる |
| 改行 | 日本語は文節の切れ目で改行（`word-break: auto-phrase`） | 「セメン／ト」のような語の途中の改行を避ける |
| 色 | 濃紺（枠・見出し）と青（強調）を基本に、灰色を比較対象に使う | 強調は 1ページ 1か所に絞り、数字そのものを目立たせる |
| 情報の種類 | 原本の内容＝ラベルなし（フッターに原本ページ）、`補足`＝茶色ラベル（本にない情報）、`分析`＝緑ラベル（発表者の計算・考え）、本の中のずれ＝赤い数字 | 制度の説明・原本の引用・補足・独自分析を混同させない。色だけに頼らず必ず文字のラベルを付ける |
| 写真 | 暗く塗りつぶさず、そのままの色で大きく見せる。写真の上や下に「イメージ写真」「YUCACO住宅ではありません」と撮影者・ライセンスを必ず表示 | 原本は写真を薄く・暗くして背景に敷いていたため文字が読みにくかった。写真は説明を補う位置に置き、誤認を防ぐ表示を付ける |
| 図・グラフ | 角丸や影の付いた「カード」、意味のないアイコン、太い矢印の図形は使わない。値は棒の先に直接書き、比較対象は灰色、主役だけ青 | 装飾ではなく情報で見せる。グラフは目盛りを 0 から取り、量を正しく比べられるようにする |
| 予備資料 | 上端の線とラベルを灰色に変え、フッターに「予備」 | 本編と予備資料の境目が一目で分かる |

特定の住宅会社のロゴ・配色・レイアウト・言い回しは使っていません。色は濃紺・青・灰色を中心にした一般的な組み合わせで、ラベルの茶・緑は情報の種類を区別するためだけに使っています。

## 原本から変えたこと・変えていないこと

変えていないこと
- ページ数（38）とページの順番、各ページの主張、すべての数値・計算・単位・年・原本ページの参照
- 想定質問と答え（pp.30–36）の本文（【補足】【分析】の表記をラベルに置き換えただけ）
- 原本の図 4-1・4-2・4-5 は画像のまま掲載（作り直していない）

変えたこと（意味は変えていない）
- 見出しの言い回しを落ち着いた表現に（例：「がんばればよい」→「努力すればよい」、「みなさんと話したいこと」→「話し合いたい3つの問い」、「まとめ」→「この章のポイント」、ラベル「分析・私の計算」→「分析 発表者の計算」）
- 図解の形（例：p.9 を年表から「建物の種類ごとに、いつから必ず守る対象になったか」の帯グラフに、p.10 に住宅の断面図、p.6 に 10軒の家の割合図、p.17 を入れ替わりが見える対照表に、p.19 を目次と同じ 3列構成に）
- ページ間の案内（例：「法律の一覧は予備資料 A1（p.22）」）と、原本の図の「図の見方」（凡例・目盛りの説明と本編との対応だけ）
- 写真の配置（背景に薄く敷くのをやめ、説明の横に枠で置く）。写真は Wikimedia Commons の元画像を取り直し、トリミングのみ（p.2・3 のイタリアの写真は元画像の白い縁を切り落とし）
- 予備資料の目次にページ番号を追加、写真の出典に使用ページを追加
- 表紙の日付表記（2026.11.17 → 2026年11月17日）

## 写真について

- すべて Wikimedia Commons の写真で、YUCACO 住宅の実例ではありません。各写真の近くに「イメージ写真」「YUCACO住宅ではありません」と撮影者・ライセンスを表示しています（p.38 に一覧）。
- 原本 PDF に埋め込まれていた写真は暗く・薄く加工済みだったため、Commons から元画像（幅 1920px）を取り直しました。加工はトリミングのみです（元と同じライセンス）。
- 「木の外壁の住宅群（ウェールズ）」は、Commons の作者欄は Justin Bere ですが、画像に埋め込まれた著作権情報（EXIF）には Daniel Hayes とあります。出典表記は原本どおり Commons の作者欄に合わせています。
