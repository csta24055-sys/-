# 03 節点スペクトル：全方程式（実装の全項）

対象：独立概念モデルの統一系（架空データ）。**J-CAT 原版の式ではない。** `tools_equations_export.py` が `specs/system.py` の `EMIT`・`VALUE_AT_T`、`tstudy/rampstep.py`・`knots.py`・`interval.py`・`index.py` から書き起こしたもの。

## 1. 核（ランプ・ステップ核）

$$ h(T;\,s,\ell,g) \;=\; \big[g < T(1-\varepsilon)\big]\cdot \operatorname{clip}\!\Big(\frac{T-s}{\ell},\,0,\,1\Big),\qquad \varepsilon = 10^{-9},\quad \ell = 0 \Rightarrow \operatorname{clip}(\cdot)=1 $$

$$ \Phi(T) \;=\; \sum_j a_j\, h(T;\,s_j,\ell_j,g_j) \qquad (a_j \text{ は } T \text{ によらない}) $$

| 形 | $s$ | $\ell$ | $g$ | 値 |
|---|---|---|---|---|
| 定数 | 0 | 0 | $-\infty$ | $a$ |
| 原子（時刻 $\tau$ の事象） | $\tau$ | 0 | $\tau$ | $a\,[\tau < T(1-\varepsilon)]$ |
| 年セル（年 $y$） | $y-1$ | 1 | $-\infty$ | $a\,w_y(T)$、$w_y(T)=\operatorname{clip}(T-(y-1),0,1)$ |
| ゲート付き年セル | $y-1$ | 1 | $\tau$ | $a\,[\tau<T(1-\varepsilon)]\,w_y(T)$ |
| 密度（長さ $H$） | 0 | $H$ | $-\infty$ | $(aH)\,\min(T/H,1) = aT$（$T\le H$） |

年重み：$w_y(T) = [y \le T] + [y-1 < T][\neg(y \le T)]\,(T-(y-1))$。事象の年：$y(\tau) = \max(1, \lceil \tau(1-\varepsilon)\rceil)$。

## 2. 跳び形（標準形）

$$ E(T) = b + \sum_{j:\, t^{e}_j < T(1-\varepsilon)} \big(c^{0}_j + c^{1}_j T\big) + \sum_{j:\, t^{p}_j < T} \big(c^{0}_j + c^{1}_j T\big) $$

各項 $a\,h(T;s,\ell,g)$ の節点への置き方（`KnotSpectrum._add`）：
- $\ell=0,\ g=-\infty$：$b \mathrel{+}= a$
- $\ell=0,\ g$ 有限：事象節点 $(g,\ a,\ 0)$
- $\ell>0,\ g=-\infty$：格子節点 $(s,\ -as/\ell,\ a/\ell)$ と $(s+\ell,\ a(s+\ell)/\ell,\ -a/\ell)$
- $\ell>0,\ g \ge (s+\ell)(1-\varepsilon)$：事象節点 $(g,\ a,\ 0)$
- $\ell>0,\ g$ それ以外：事象節点 $(g,\ -as/\ell,\ a/\ell)$ と格子節点 $(s+\ell,\ a(s+\ell)/\ell,\ -a/\ell)$

評価：$E(T) = b + P^{0}_{e}[k_e] + P^{0}_{p}[k_p] + T\,(P^{1}_{e}[k_e] + P^{1}_{p}[k_p])$。$P$ は節点を時刻順に並べた累積和、$k_e,k_p$ は二分探索の位置。

Laplace–Stieltjes 表示（記録のみ。数値計算には使っていない）：
$$ \mathcal{L}\{dE\}(s) \text{ に対応して } \int_0^\infty e^{-sT} E(T)\,dT = \frac{1}{s^2}\sum_j \big(c^{1}_j + s\,(c^{0}_j + c^{1}_j t_j)\big)\,e^{-s t_j} \quad(+\,b/s) $$

## 3. 区間形（B1-04 の期末残存量に使用）

$$ E(T) = A_k + B_k\,(T-k) + \sum_{j \in \text{cell } k,\ \tau_j < T(1-\varepsilon)} \big(a_j + g_j\,(T-k)\big),\qquad k = \lceil T\rceil - 1 $$

$A_k = $ `b1.iA`、$B_k = $ `b1.iB`（年表 `cal`）、$a_j = $ `b1.e4a`、$g_j = $ `b1.e4g`、$\tau_j = $ `b1.tau1`（表 `dy`、`b1.p` が 1 の行）。厳密算術では跳び形と同じ関数。

## 4. 節点の格子（共通表 `index.add_events`）

$$ \text{周期}：\ \tau_n = n\,c \quad (n=1,2,\dots,\ \tau_n < H(1-\varepsilon)),\qquad \text{一覧}：\ \tau \in L,\ 0<\tau<H(1-\varepsilon) $$

各節点は `cell` $= y(\tau)-1$ を持つ。周期と一覧の両方を作り、どちらを数えるかは積和のマスクで決める。
- 表 `materials.events`：親 `materials`、周期の列 `refresh_cycle`
- 表 `equipment.events`：親 `equipment`、周期の列 `service_life`、一覧 `equipment.replacement_event_list`
- 表 `refrigerants.events`：親 `refrigerants`、周期の列 `service_life`、一覧 `refrigerants.change_years`
- 表 `boundary.events`：親 `boundary`、周期の列 `replacement_cycle`
- 表 `CYC.events`：親 `CYC`、周期の列 `value`

$H$ は年次表の長さ（架空データでは 130 年）。
