# 第6章：前提項目→式→結果の全関係台帳

- [links.json](links.json) は前提入力 **124項目**、独立概念式 **53式**、出力 **32種**をIDで機械的に関連付ける。
- すべての **式**には式IDと参照入力ID・出力IDがある。
- すべての **入力項目**について `linked_formula_ids`（紐付けがない場合は `NOT_YET_LINKED`）が存在し、未実装や孤立した項目を隠さない。
- 原版Excelの数百万セルとこの独立モデルの対応は `NOT_VERIFIED`。オリジナルの式をGitHubにコピーしない。
- 参照切れの入力ID: **0件**。項目未接続は **53件**で、後続の設計・ユーザビリティ検証が必要。

## 読み方
1. `links_by_input` で入力項目から利用式へ。
2. `links_by_formula` で式から複数入力と出力へ。
3. `outputs.json` の `producer_formula_ids` で算定出力の作り方へ。
4. `NOT_YET_LINKED`、`SCHEMA_DRAFT`、`NOT_EXECUTED` は開発の未完箇所。

## 実装条件
ある結果を「算出済み」と表示できるのは、その計算ステージの必要項目が揃い、原単位の利用権限が確認され、正しい単位と時間境界で計算され、テストに合格した場合のみ。欠損があれば `INCOMPLETE` と表示する。
