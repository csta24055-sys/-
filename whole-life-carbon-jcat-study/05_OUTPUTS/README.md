# 第5章：最終集計・レポート

[outputs.json](outputs.json)には **32種類**の出力IDと、それを算定する式IDを一覧化。

最低限のレポートとして、総WLC、アップフロント、エンボディド、A1〜C4段階別、tCO2e、kgCO2e/m2、kgCO2e/m2・年、資材別・設備別、年次推移、シナリオ比較、採用係数の根拠、未計上リスク、不確実性を表示する。

原則：
- `0`と`未計算`は異なる。
- 延床面積と評価期間が正の値でなければ面積/年原単位は作らない。
- 保存・CSV・PDF出力には「プロジェクト版、使用法、算定境界、日付、係数版、許諾、欠損、警告」を出す。
- D（リユース・リサイクルの範囲外便益など）はA1–C4に勝手に合算せず、将来扱いとする。
- カーボン貯蔵や炭酸化固定の見積は、何をいつ計上したか確定するまで独立した参考値として扱う。
- 検証結果がなければJ-CAT公式との一致・公認・互換を表明しない。
