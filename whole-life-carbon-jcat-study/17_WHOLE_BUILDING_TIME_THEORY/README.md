## 2. 主な結果（要約）

1. **建物全体は 1 本の区分一次関数。** SUM-03 と 14 段階の値は、評価期間 $T$ について、格子（年の境）と事象（更新・交換・改修の時刻）の節点を持つ区分一次関数で、節点形が厳密な表現になる（TH-0、TH-1）。
2. **跳びは事象の節点でだけ起きる。** 年の境では連続（区間形の丸めの跳びと、整数時刻の事象による区間形の初期化を除く）。事象では跳び、値は切り替えの直前まで左の式に乗る（TH-2）。**整数時刻 $K$ の事象の直後の細い帯 $T\in(K,\mathrm{sw}(K))$（幅は $K$ の相対 1e-9 程度）では、区間形の B1-04（と第 11 章の統一系）が基準計算と異なる**（実測：9 例中 2 例で B1-04 の相対差 最大 1.1、SUM-03 で 5e-5）。第 11 章の定義域 `valid_domain` はこの帯を除かないので、モデルとの一致の主張はこの帯を除いた $\mathcal{D}'$ に限る（03 の 0 節・TH-2 の 3、07 の 6 節）。
3. **評価期間 $T$ の関数は累積排出ではない。** $C(T) = M([0,T]) + Z(T)$（実時間の測度＋終わりの項）で、$dC/dT$ は実時間の排出率に冷媒の期末残存量の傾きを足したもの。$C(0^+)\ne0$（廃棄時の定数と初期充填の未回収分）。この分解は一意でない（TH-4）。
4. **符号付きの測度。** 単位ごとには負の部分がある（B3-01 の更新の年の修繕の除外、B1-03 の交換後の差し引き、B6 の −B2-01）。段階でまとめると密度は非負で、負の原子は B3 だけ（TH-4(d)）。
5. **変換。** ラプラス変換と有限の台のフーリエ変換は厳密（指数多項式）。フーリエ級数の部分和は近似で、跳びとギブスにより数百項でも誤差が数％残る。DMD・固有値分解の前提（時不変の線形の動的方程式）はこのモデルでは成り立たない：状態を持つのは冷媒の残存量だけで、それも交換で切り替わるアフィンの漸化式（B1-02・B1-03・B1-04 はこの状態に依る）。年増分が低い次数の漸化式を満たすとき（分子の小さい周期の交換・更新、補充ありの一定、補充なしの減衰）だけ、低次のモードが厳密に現れる（TH-7〜TH-11）。
6. **合計に入らない出力の式。** X-11 は $c\,G(T)$、回数は振幅 0 の品目を含む全事象の $\theta_\varepsilon$ の和、X-07 の年ごとの列は核の項を年セルで分けたもの（01 の 7 節）。X-07 は TH-4 の実時間の分解を年で区切ったものと、整数時刻の事象の年の帰属だけが違う（07 の 7 節）。

## 4. 未解決・制約（隠さない）

- 照合は保存した集合の点（標本）での一致で、すべての入力での一致の証明ではない。証明は 03 の恒等式に限る。
- 浮動小数の係数のもとでは、冷媒の期末残存量について厳密な連続性と数値の安定を同時に満たせない（05 の 3 節）。
- 実時間の分解は単位の意味で決めたもので、$C(T)$ だけからは一意に決まらない（TH-4(c)）。第 2 段階で扱う。
- $\varepsilon$ の帯（事象の時刻が $T$ や整数年から相対 1e-10〜1e-8）は定義域の外。
- **定義域の穴**：整数時刻の事象の直後の帯 $(K,\mathrm{sw}(K))$ は第 11 章の `valid_domain` の内側にあるが、そこでは正準形・統一系とも基準計算と一致しない（2 節の 2）。本章は主張を $\mathcal{D}'$ に縮めて記録した。第 11 章（完了済み）は変更していない。
- 年次表の長さ：照合の標本はすべて $H=130$。$H$ への非依存は証明し（TH-13）、同じ入力を 130 年と 160 年の表で比べる検査（8 シナリオ）で確かめたが、$H$ を変えた大規模な照合はしていない。
- 傾向の傾き $\beta$（TH-11）は数値で求めていない。X-04・X-05 の内訳は区分一次であることだけを確かめ、重みごとの式は照合していない。
