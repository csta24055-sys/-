# 01 建物全体の完全理想方程式 C(T)

対象：独立概念モデル（70 評価単位、架空データ）。J-CAT 原版の式・係数・値は含まない。
出発点：第 11 章の統一系（70 単位・1,789 ステップ・跳び形 23 本＋区間形 1 本）と、第 14 章 07「建物全体の統一方程式（完全版）」。
両者を作り直していない。14 章 07 の合成式（段階×単位の 0/±1 行列と節点スペクトル）をそのまま採用し、その要素を**核の項の 1 本の和**に展開した。

実装：`code/canon.py`（基準計算を読まない。係数はすべて積和①の列から取る）。照合：`code/verify_canon.py`（07 の 1 節）。

## 1. 階層（どの階層からも、下の階層へ完全に展開できる）

| 階層 | 対象 | 式 | 由来 |
|---|---|---|---|
| L0 | 建物の入力 $\mathbf{x}$ | シナリオ（数量・係数・周期・表・境界） | 生成器 |
| L1 | 積和①の列 | 振幅 $a_j$、時刻 $\tau_j$、年セル $k_j$、スカラー（1,528 ステップ） | 第 11 章 SPEC_MSP |
| L2 | 単位の値 $V_u(T)$ | $V_u(T) = \sum_{j \in J_u} a_j\,\kappa_j(T)$（21 単位。構成表は 22 行で、B2-01 が B2 と B6 に現れる） | 第 11 章 EMIT、本章 2 節 |
| L3 | 段階の値 $S_s(T)$ | $S_s(T) = \iota_s \sum_{u} \sigma_{s,u}\,\beta_{s,u}\,V_u(T)$（14 段階） | 14 章 07 の 3 節 |
| L4 | ホールライフ合計 | $C(T) = \sum_s S_s(T)$ ＝ SUM-03 | 14 章 07 の 2 節 |
| L5 | 節点形（最小の表現） | $C(T) = A_0 + \sum_{t\in\Lambda}[t<T](P_t + Q_t T) + \sum_{g\in E}\theta_\varepsilon(T;g)(p_g + q_g T)$ | 本章 4 節 |
| L6 | 実時間の分解 | $C(T) = M([0,T]) + Z(T)$ | 03 の TH-4 |

L5 の各節点の係数は、寄与した項（単位・段階・核の種類・入力の行）の和として保存する（`Canon.terms` を節点ごとにまとめる）。したがって L5 → L2 → L1 の逆展開ができる。

## 2. 核（第 11 章の 5 形＋区間形の窓）

$$ \kappa(T;\,s,\ell,g,\mathrm{lo},\mathrm{hi}) = [\mathrm{lo} < T \le \mathrm{hi}]\;\theta_\varepsilon(T;g)\;r_\ell(T-s),\qquad
\theta_\varepsilon(T;g) = [\,g < T(1-\varepsilon)\,],\quad r_0 \equiv 1,\quad r_\ell(x) = \operatorname{clip}(x,0,\ell)\ (\ell>0) $$

| 形 | $(s,\ell,g,\mathrm{lo},\mathrm{hi})$ | 振幅 $a$ の次元 | 役割の記号 |
|---|---|---|---|
| 定数 | $(0,0,-\infty,-\infty,\infty)$ | kgCO2e | $A^{\mathrm{init}}$（A 段階）、$A^{\mathrm{term}}$（C 段階・X-14） |
| 年セル $k$ | $(k,1,-\infty,-\infty,\infty)$ | kgCO2e/年 | $B^{(u)}_k$ |
| 密度 | $(0,H,-\infty,-\infty,\infty)$ | kgCO2e/年 | $B^{(u)}_\ast$（B3-01 の年間修繕、全年一定） |
| 原子 | $(\tau,0,\tau,-\infty,\infty)$ | kgCO2e | $\Gamma^{(u)}_j$ |
| ゲート付き年セル | $(k,1,\tau,-\infty,\infty)$ | kgCO2e/年 | $\Delta^{(u)}_m$（事象の年の補正） |
| 窓（区間形） | $(0,0,-\infty,K,K{+}1)$、$(K,1,-\infty,K,K{+}1)$、$(0,0,\tau,K,K{+}1)$、$(K,1,\tau,K,K{+}1)$ | kgCO2e、kgCO2e/年 | $R$：$\mathcal{A}_K$、$\mathcal{B}_K$、$\alpha^R_j$、$\gamma^R_j$ |

第 11 章との違いは 1 点だけで、密度と年セルの振幅を**率**（年あたり）で持つ（第 11 章は密度の振幅を $a\cdot H$ で持ち、$\operatorname{clip}((T-s)/\ell)$ を掛ける）。値は同じ関数で、率で持つと浮動小数の積 $a\cdot H$ の丸めが式に入らない（07 の 1.2 節：この違いで、基準計算が厳密に 0 を返す段階値を 1e-11 の残差なしに再現できる）。

## 3. 完全理想方程式（役割を分けた形）

$$ \boxed{\;
C(T) = \underbrace{A^{\mathrm{init}}}_{t=0} + \underbrace{A^{\mathrm{term}}}_{t=T}
+ \sum_{u\in\mathcal{U}_B}\sum_{k=0}^{H-1} B^{(u)}_k\, w_k(T) + B^{(\mathrm{B3})}_\ast \min(T,H)
+ \sum_{u\in\mathcal{U}_\Gamma}\sum_{j} \Gamma^{(u)}_j\,\theta_\varepsilon(T;\tau_j)
+ \sum_{u\in\mathcal{U}_\Delta}\sum_{m} \Delta^{(u)}_m\,\theta_\varepsilon(T;\tau_m)\,w_{k_m}(T)
+ \iota_{\mathrm{B1}} R(T)\; } $$

- $w_k(T) = \operatorname{clip}(T-k,0,1)$（年重み）。$\theta_\varepsilon$ は事象の規則（$\varepsilon = 10^{-9}$）。
- $\mathcal{U}_B$ = {B1-02, B2-01（段階 B2）, B6-03, B2-01（段階 B6 の差し引き）, B7-04}（年セル）。B3-01 の全年一定の率は別の項 $B^{(\mathrm{B3})}_\ast\min(T,H)$（$\sum_k w_k(T) = \min(T,H)$ なので年セルの和と重ねて数えない）。$\mathcal{U}_\Gamma$ = {B1-03（原子）, B4-02, B5-01}、$\mathcal{U}_\Delta$ = {B1-03（ゲート付き）, B3-01（ゲート付き）}。
- **すべての係数は符号と段階の述語を含む値**：$B^{(u)}_k = \iota_{s}\,\sigma_{s,u}\,\beta_{s,u}\,a$（$\iota_s$ は段階が評価範囲にあるか、$\sigma$ は構成表の符号、$\beta$ は B2 を数えるときだけ B6 から B2-01 を引く述語）。$\Gamma$、$\Delta$、$A$、$R$ も同じ。式の中で符号を重ねて掛けない。
- $R(T)$：冷媒の期末残存量（B1-04）。区間形

$$ R(T) = \mathcal{A}_K + \mathcal{B}_K\,(T-K) + \sum_{j \in \text{セル }K} \theta_\varepsilon(T;\tau_j)\big(\alpha^R_j + \gamma^R_j (T-K)\big),\qquad K = \lceil T\rceil - 1 $$

  を窓の核の和として持つ。厳密な算術では跳び形（定数・年セル・原子・ゲート付き年セル）と同じ関数である（第 11 章 D-09）。**ただし整数の時刻 $K$ の交換の直後の帯 $T\in(K,\mathrm{sw}(K))$ を除く**：区間形は初期化を $T>K$ で、跳び形（とモデル）は $T\ge\mathrm{sw}(K)$ で効かせる（03 の TH-2 の 3）。
- 同じ種類の項でも、単位が違えば別の記号のまま残す（上付きの $(u)$）。たとえば B6 の $-B^{(\mathrm{B2\text{-}01})}_k$ と B2 の $+B^{(\mathrm{B2\text{-}01})}_k$ は、B2 を数えるときは合計で打ち消すが、段階の値では別の役割である。

## 4. 節点形（L5）：すべての項を節点に集める

各項を「切断べき」$[c<T](p+qT)$ の和に書き直す（03 の補題 L-1）。

| 核 | 節点への寄与 |
|---|---|
| 定数 $a$ | $A_0 \mathrel{+}= a$ |
| 原子 $a\,\theta_\varepsilon(T;g)$ | 事象の節点 $g$：$(a,\ 0)$ |
| 傾き $a\,r_\ell(T-s)$ | 格子 $s$：$(-as,\ a)$、格子 $s+\ell$：$(a(s+\ell),\ -a)$ |
| ゲート付き $a\,\theta_\varepsilon(T;g)\,r_\ell(T-s)$、$s < g < (s+\ell)(1-\varepsilon)$ | 事象 $g$：$(-as,\ a)$、格子 $s+\ell$：$(a(s+\ell),\ -a)$ |
| 同上、$g \ge (s+\ell)(1-\varepsilon)$ | 事象 $g$：$(a\ell,\ 0)$ |
| 窓 $[K<T\le K{+}1]\,f(T)$（前提：$T\le K$ で $f=0$、すなわち傾きの始まり $\ge K$、ゲート $\ge K$） | $f$ がゲートなしの定数 $a$ なら $A_0$ に足す代わりに格子 $K$：$(a,0)$；それ以外は $f$ 自身の節点。どちらも加えて格子 $K{+}1$：$(-a\,f_{K+1},\ 0)$（$f_{K+1}$ は窓の終わりでの核の値） |
| 窓の中で決して数えられない事象（$g \ge (K{+}1)(1-\varepsilon)$） | 寄与なし（窓の中で恒等的に 0） |

$$ \boxed{\; C(T) = A_0 + \sum_{t\in\Lambda}[\,t<T\,]\,(P_t + Q_t\,T) + \sum_{g\in E}\theta_\varepsilon(T;g)\,(p_g + q_g\,T)\;} $$

- $\Lambda \subseteq \{0,1,\dots,H\}$（格子の節点：年の境界）、$E$ は事象の時刻（周期の倍数 $n c$ と明示の一覧）。
- 係数 $(P_t,Q_t)$、$(p_g,q_g)$ は有理数（浮動小数の振幅・時刻の積と和を厳密に計算した値）。同じ位置の寄与は足し合わせ、0 になった節点は除く。
- 評価：$T$ 以下の節点の累積和を二分探索で引く。1 回の評価は節点の数 $N$ に対して $O(\log N)$（`timechar.KF`）。
- 事象の規則の境目：実数では $T > g/(1-\varepsilon)$ で数える。浮動小数の規則 $g < \mathrm{fl}(T\cdot\mathrm{fl}(1-\varepsilon))$ は、$g/\mathrm{fl}(1-\varepsilon)$ から 2 ulp 程度以内の浮動小数 $\mathrm{sw}(g)$ で切り替わる（03 の補題 L-2。実測の最大 1.5 ulp）。この章の厳密な検査は、モデルと同じ浮動小数の規則で行う。

## 5. 段階・単位への展開と、他の単位との関係

- 段階 $s$ の値：上の式で段階 $s$ の項だけを足す（`Canon.value(T, s)`）。同じ節点形が段階ごとに作れる（`KF(can, s)`）。
- 単位 $u$ の値（21 単位）：符号と段階の述語を掛ける前の項（`Canon.unit_terms[u]`）。
- 残り 49 単位は C(T) に直接入らない（補助の量・検査・指標・内訳）。それぞれの T 依存は 06 で全出力について分類した。合計から作る単位は C(T) の関数として閉じた形を持つ（述語つき）。合計から作らない T 依存の出力の式は 7 節：

$$ \mathrm{SUM04} = [A>0]\frac{C(T)}{A},\quad \mathrm{SUM05}(T) = [A>0]\frac{C(T)}{A\,T},\quad \mathrm{SUM06} = 10^{-3}C(T),\quad \mathrm{share}_s(T) = [C>0][\text{負の段階 0 個}]\frac{S_s(T)}{C(T)},\quad \mathrm{SUM01}(T) = \sum_{s\in\{A1\text{-}A3,A4,A5\}} S_s,\ \ \mathrm{SUM02}(T) = \sum_{s\notin\{B6,B7\}} S_s $$

## 7. $C(T)$ の項ではない $T$ 依存の出力の式

独立レビューの指摘（「残りの単位の $T$ 依存の出力にも核・節点の式を与え、基準計算と照合すること」）への対応。式は第 11 章の統一系の仕様（`specs/at_t.py`）を本章の核の語彙で書き直したもので、照合は `code/units_eq.py`（07 の 7 節）。

| 出力 | 式 | 区切り | 照合 |
|---|---|---|---|
| X-11 の値 | $c_{11}\,G(T)$、$G(T) = \sum_{k} \gamma_{k}\,w_k(T)$、$c_{11} = [\text{述語}]\cdot\text{床面積}\cdot\text{電力原単位}\cdot\text{換算}$（$T$ によらない） | 格子だけ（連続な区分一次） | 比 $\mathrm{X11}(T)/G(T)$ が各シナリオで一定（$\gamma_k$ は X-06 の `by_year` の $k{+}1$ 番目。0 番目は施工時の値） |
| 回数：B4-01 の `events`・`n_events`、B4-03 の $n_i(T)$、X-08 の `count`、B5-01 の `n_events`、X-10 の $1+n_i(T)$ | $N_i(T) = \sum_{\tau\in E_i}\theta_\varepsilon(T;\tau)$、$E_i$ は**振幅が 0 の品目を含む**すべての事象の時刻（周期 $c$ なら $\tau_n = \mathrm{fl}(nc)$） | 全事象の時刻。$C$ の節点より細かいことがある（03 の TH-14） | B4-01 の一覧（$T$ での一覧が $T=H$ の一覧の $\tau<\mathrm{fl}(T\,\mathrm{fl}(1-\varepsilon))$ の部分、件数の和）、X-08 の回数（$\#\{n:\mathrm{fl}(nc)<\mathrm{fl}(T\,\mathrm{fl}(1-\varepsilon))\}$） |
| X-08 の `emission` | $E_c(T) = N_c(T)\,U_c$（$U_c$ は周期 $c$ の行の 1 回あたりの排出の和、$T$ によらない） | 周期 $c$ の事象 | 回数を照合（積は定義そのもの） |
| X-04 の `by_stage_recomputed`・`by_gas`、X-05 の `by_stage_co2` | 段階 $s$ の項を係数の行 $f$ ごとに分けた $L_s[f](T) = \sum_{j\in(s,f)} a_j\kappa_j(T)$ に、行の重み（ガス量、CO2 の量）を掛けた和：$\sum_f L_s[f](T)\,\omega_f$。核は段階の項と同じで、振幅だけが違う節点形 | 段階の節点の部分集合 | 06 の分類（区切り区間ごとに一次）。重み $\omega_f$ ごとの式の照合はしていない |
| X-07 の `by_year`・`cumulative`・`value` | $s_0 = A^{\mathrm{init}}$；$1\le y\le Y=\lceil T\rceil$ で $s_y(T) = \sum_{j:\ \mathrm{cell}(j)=y-1} a_j\kappa_j(T) + [y=Y]\,Z(T)$；$\mathrm{cum}_y = \sum_{y'\le y}s_{y'}$、$\mathrm{value} = \mathrm{cum}_Y = C(T)$。年セル $\mathrm{cell}(j)$ は、年セル・ゲート付き年セルの項は $k$、原子は事象の年セル $k_\tau = \max(1,\lceil\tau(1-\varepsilon)\rceil)-1$、密度は年ごとに $w_k$ で分ける | 格子と事象 | 全年で一致（相対 1e-9）。03 の TH-4 の実時間の測度を年 $(y-1,y]$ で区切ったものとは、**整数時刻の事象 $\tau = K$ が数えられるときだけ**異なる（X-07 は年 $K$、TH-4 は $\mathrm{sw}(K)>K$ なので年 $K{+}1$）。合計はどちらも $C(T)$ |
| QA-02・QA-03 の判定、X-10 の `n_excluded`、X-02 の `complete` | 判定に入る量（事象の一覧・使用の有無）の述語 | その量の区切り | 06 の分類（階段）だけ |

X-07 は、モデル自身が持つ「年ごとの配分」であり、第 2 段階（18 章）の工程関数の年ごとの量とは整数時刻の事象の扱いで異なる。どちらも $C(T)$ の分解であり、$C$ だけからは一意に決まらないこと（TH-4(c)）の具体例になる。
