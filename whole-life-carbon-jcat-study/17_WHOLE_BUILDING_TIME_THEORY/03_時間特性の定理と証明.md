# 03 建物全体の時間特性：定理と証明

対象は 01 の完全理想方程式 $C(T)$（独立概念モデル、架空データ）。各定理に、**証明**（恒等式としての根拠）と**検証**（モデルの浮動小数の入力そのものの上で、有理数で厳密に評価した恒等式の照合。07 に件数）を付ける。
「厳密」は、浮動小数で与えられた振幅・時刻を有理数とみなしたときに式が等号で成り立つことを言う。実数の入力についての主張ではない（入力そのものが浮動小数だから）。

**証拠の水準**：P＝証明あり、E＝有理数での厳密な照合（標本の点で）、F＝浮動小数での測定、S＝統計的な確認（第 4 段階）。

## 0. 記号と定義域

- 評価期間 $T\in(0,H]$。事象の規則 $\theta_\varepsilon(T;g)=[g<T(1-\varepsilon)]$、$\varepsilon=10^{-9}$。年重み $w_k(T)=\operatorname{clip}(T-k,0,1)$。
- 定義域 $\mathcal{D}$：第 11 章の `scenarios.valid_domain` の内側（事象の時刻が $T$ や整数年から相対 1e-10〜1e-8 の距離にない組）。この帯の中では判定が丸めで決まる。
- 節点：格子 $\Lambda\subseteq\{0,\dots,H\}$（規則 $[t<T]$）と事象 $E$（規則 $\theta_\varepsilon$）。区切り点の集合 $\Pi = \{0,\dots,H\}\cup\{\mathrm{sw}(g): g\in E\}$。

## 補題

**L-1（核から切断べきへ）** 01 の 4 節の表のとおり、各核は $[c<T](p+qT)$ または $\theta_\varepsilon(T;g)(p+qT)$ の有限和に等しい。

*証明.* $\operatorname{clip}(x,0,\ell) = [x>0]\,x - [x>\ell]\,(x-\ell)$（$x$ で場合分け）。$x=T-s$ とおくと傾きの寄与 $(-as,a)$ と $(a(s+\ell),-a)$ を得る。ゲート付き：$s<g$ かつ $g<(s+\ell)(1-\varepsilon)$ なら、$\theta_\varepsilon(T;g)=1$ となる $T$ は $T>g/(1-\varepsilon)>s$ を満たすので $[x>0]$ は 1、また $T > s+\ell$ なら $\theta_\varepsilon = 1$ だから $\theta_\varepsilon\cdot\operatorname{clip} = \theta_\varepsilon\,(T-s) - [T>s+\ell](T-s-\ell)$。$g\ge(s+\ell)(1-\varepsilon)$ なら $\theta_\varepsilon=1 \Rightarrow T> s+\ell$ で $\operatorname{clip}=\ell$。窓：$[K<T\le K{+}1] = [K<T]-[K{+}1<T]$、$T>K{+}1$ で核は定数（傾きは飽和、事象は数えられている：$g<(K{+}1)(1-\varepsilon)$ の場合。そうでない事象は窓の中で恒等的に 0）。∎ 〔P〕

ゲート付き年セルの前提 $s<g$ は、事象の年セルの作り方 $k=\max(1,\lceil g(1-\varepsilon)\rceil)-1 < g(1-\varepsilon)$ から常に成り立つ（実装は前提が破れると停止する。停止は 0 件）。

**L-2（浮動小数の事象の規則）** $T\mapsto \mathrm{fl}(T\cdot d)$（$d=\mathrm{fl}(1-\varepsilon)$）は単調非減少なので、$g<\mathrm{fl}(T d)$ を満たす浮動小数 $T$ の集合は上に閉じている。その最小元を $\mathrm{sw}(g)$ とすると、事象は $T\ge\mathrm{sw}(g)$ で数えられ、$\lvert\mathrm{sw}(g) - g/d\rvert$ は数 ulp 以下である。

*証明.* 丸めは単調。$u=2^{-53}$ として $g<\mathrm{fl}(xd)\le xd(1+u)$、$\mathrm{fl}(x^- d)\le g \Rightarrow x^- d(1-u)\le g$（$x^-$ は 1 つ下の浮動小数）。よって $g/(d(1+u)) < \mathrm{sw}(g) \le \mathrm{next}(g/(d(1-u)))$。∎ 〔P〕 実測の最大は 07 の 2 節（1.5 ulp）。

## TH-0 正準形

$\mathcal{D}$ の各組で、SUM-03 と 14 段階の値と、合計に入る 22 単位の値は、01 の核の和（L2〜L4）と節点形（L5）に等しい。

*証明.* 14 章 07 の合成式（段階×単位の行列）、第 11 章の EMIT（各単位の値は核の和）、B2-01 はスカラー $\rho$ と年セルの和の積（振幅に吸収）、B1-04 は区間形（窓の核の和）、L-1 による節点への変換の和。∎ 〔P〕
*検証.* 1,293 組で基準計算と照合（07 の 1 節）。節点形と核の和の厳密な一致は各シナリオの標本 60 点で照合。〔E〕

## TH-1 区分的な一次式

$\Pi$ の隣り合う 2 点の開区間 $(a,b)$ で $C(T)=\alpha+\beta T$、$\alpha = A_0+\sum_{c\le a}p_c$、$\beta=\sum_{c\le a}q_c$（和は位置 $a$ 以下の全節点）。

*証明.* 区間の中で各指示関数は一定（格子は $t\le a$ なら 1、事象は $\mathrm{sw}(g)\le a$ なら 1）。∎ 〔P〕
*検証.* すべての区間で 3 点が一直線上にあること、係数が累積和に等しいことを厳密に照合。〔E〕

## TH-2 連続性と跳び

1. 格子の節点 $t$ での跳びは $P_t+Q_t t$。傾きの核だけなら厳密に 0（始まり $-as+as$、終わり $a(s+\ell)-a(s+\ell)$）。
2. 区間形の窓（B1-04）の寄与は、厳密な入力なら連続（冷媒の量は年の境で連続：$\mathcal{A}_{K+1} = \mathcal{A}_K + \mathcal{B}_K + \sum_j(\alpha_j+\gamma_j)$）。浮動小数の係数では各係数を別々に丸めるので、丸めの大きさ（実測で係数の大きさの相対 2e-16 程度）の跳びが残る。
3. 整数の時刻 $\tau = K{+}1$ の事象は年セル $K$ に属するが、窓 $(K,K{+}1]$ の中では決して数えられない。区間形は、その交換による初期化を次のセルの係数 $\mathcal{A}_{K+1}$ に入れるので、B1-04 は格子の節点 $K{+}1$ で跳び、ほかの単位（B1-03 など）の同じ事象は $\mathrm{sw}(\tau)\approx\tau(1+10^{-9})$ で跳ぶ。2 つの位置の差は $\varepsilon$ の帯の中だけである（$\mathcal{D}$ の外）。
4. 事象の節点 $g$ での跳びは $J_g = p_g + q_g\,\mathrm{sw}(g)$。$T<\mathrm{sw}(g)$ の値は左の区間の式に乗る（実数の規則では $T=\tau/(1-\varepsilon)$ で左連続）。

*証明.* TH-1 の係数の差。2 は D-08 の漸化式（年の境で状態は同じ値）。3 は区間形の定義（$K=\lceil T\rceil-1$ のセルの係数を使う）と事象の規則。∎ 〔P〕
*検証.* 隣り合う区間の外挿で跳びを求め、理論値と厳密に照合。さらに事象の前後で**核の和**から跳びを求めて照合（各シナリオ 12 事象）。格子の跳びは 3 種類（0、丸め、整数時刻の事象）に分類し、丸めの跳びが相対 1e-12 を超えた区間は 0 件。〔E〕

## TH-3 導関数（古典・超関数）

区間の内側で $C'(T) = \sum_{t\in\Lambda,\,t<T} Q_t + \sum_{g:\,\mathrm{sw}(g)\le T} q_g$。超関数として

$$ \frac{dC}{dT} = \sum_{t<T} Q_t + \sum_{\mathrm{sw}(g)\le T} q_g \;+\; \sum_{g\in E} J_g\,\delta\big(T-\mathrm{sw}(g)\big) \;+\; \sum_{t\in\Lambda} (P_t + Q_t t)\,\delta(T-t), $$

$$ \frac{d^2C}{dT^2} = \sum_{t\in\Lambda} Q_t\,\delta(T-t) + \sum_{g\in E} q_g\,\delta(T-\mathrm{sw}(g)) + \sum_{g} J_g\,\delta'(T-\mathrm{sw}(g)) + \sum_{t}(P_t+Q_t t)\,\delta'(T-t). $$

傾きは節点 $c$ で $q_c$（格子は $Q_t$）だけ変わる。〔P〕〔E：傾きの変化を全区間で照合〕

## TH-4 実時間の分解（評価期間 $T$ と実時間 $t$ の区別）

T によらない符号付き測度 $M$（$t=0$ の原子、年セル・密度の流れ、事象の時刻の原子）と、終わりの項 $Z(T)=A^{\mathrm{term}}+\iota_{\mathrm{B1}}R(T)$ があって

$$ C(T) = M\big([0,T)\big) + Z(T),\qquad \frac{dC}{dT} = \rho(T) + Z'(T)\quad(\text{区間の内側}), $$

$\rho$ は $M$ の密度。作り方：定数（A 段階）→ $t=0$ の原子、年セル $k$ の率 $a$ → $[k,k{+}1)$ の密度 $a$、密度 → $[0,H)$ の密度、原子 → $\mathrm{sw}(\tau)$ の原子、ゲート付き年セル $a\,\theta_\varepsilon(T;g)\,w_k(T)$ → $\mathrm{sw}(g)$ に原子 $a(\mathrm{sw}(g)-k)$、$[\mathrm{sw}(g),k{+}1)$ に密度 $a$。

*証明.* $T\ge\mathrm{sw}(g)$ で $a\,w_k(T) = a(\mathrm{sw}(g)-k) + a\operatorname{clip}(T-\mathrm{sw}(g),0,k{+}1-\mathrm{sw}(g))$、$T<\mathrm{sw}(g)$ で両辺 0。ほかは定義から。∎ 〔P〕〔E：全区間で照合〕

**帰結.**

- (a) **$dC/dT$ は実時間の排出率ではない。** 差は $Z'(T)$ で、冷媒の期末残存量の傾き（補充しない機器があれば負）。期末残存量を数える建物では、ほぼすべての区間で $Z'\ne0$（07 の 2 節）。
- (b) **$C(0^+)\ne0$。** $C(0^+) = A^{\mathrm{init}}+A^{\mathrm{term}}+R(0^+)$。評価期間を 0 に近づけても、廃棄時の排出と初期充填の未回収分が残る（評価期間の関数は累積排出ではない）。
- (c) **分解は一意ではない。** $C$ だけからは $M$ と $Z$ を決められない（定数を $t=0$ に置くか $t=T$ に置くかは $C$ を変えない。$R(T)$ も、「漏洩の負の流れ＋交換の正の原子＋初期の原子」に書き換えられる）。本章の分解は単位の意味（A は施工時、C と B1-04 は廃棄時）で決めた。第 2 段階はこの非一意性を前提にする。
- (d) **符号。** 単位ごとの $M$ は負の部分を持つ：B3-01（更新の年の修繕の除外：事象の時刻に負の原子、残りの年に負の密度）、B1-03（交換後の漏洩分の差し引き：負の密度）、B6 の −B2-01（付け替え）。段階ごとにまとめると、密度はすべての標本で非負、原子が負になるのは B3 だけ（07 の 2 節）。B3 の負の原子は「その年の修繕を、交換の時刻にさかのぼって取り消す」年単位の計上規則の表れで、物理的な負の排出ではない。

## TH-5 年ごとの増分

$y = 2,\dots,H$ で $C(y)-C(y-1) = M\big([y-1,y)\big) + Z(y) - Z(y-1)$（実現した流れと事象、終わりの項の変化の和）。〔P〕〔E：全年で照合〕
（$C(0)$ は定義されないので $y=1$ は除く。$\lim_{T\downarrow0}$ は TH-4(b)。）

## TH-6 累積（積分）

$$ \int_0^T C(u)\,du = A_0 T + \sum_{c<T}\Big(p_c (T-c) + q_c \frac{T^2-c^2}{2}\Big) $$

（各節点の切断べきの積分）。$\int_0^T C$ は連続で区分的に二次、一階導関数は $C$ そのもの。〔P〕〔E：全区切り区間の累積と照合〕

## TH-7 ラプラス変換（厳密）

有限区間 $[0,H]$ で

$$ \mathcal{L}_H[C](s) = A_0\frac{1-e^{-sH}}{s} + \sum_{c<H}\Big[F_c(H)-F_c(c)\Big],\qquad F_c(u) = -e^{-su}\Big(\frac{p_c+q_c u}{s}+\frac{q_c}{s^2}\Big). $$

節点形を $T>H$ にそのまま延ばした関数 $\hat C$ では $\mathcal{L}[\hat C](s) = A_0/s + \sum_c e^{-cs}\big((p_c+q_c c)/s + q_c/s^2\big)$。指数多項式で、指数が節点の位置そのものなので、変換から節点と係数を一意に読み戻せる（ラプラス変換の一意性）。〔P〕〔F：区分ごとのガウス積分と相対 5e-14 以内〕
モード分解のような「近似」は要らない。年セルの部分は $\mathcal{L}[w_k](s) = (e^{-ks}-e^{-(k+1)s})/s^2$、事象は $e^{-\mathrm{sw}(g)s}/s$。

## TH-8 フーリエ級数（厳密な係数、近似としての部分和）

$[0,H]$ の係数は $c_n = \mathcal{L}_H[C](2\pi i n/H)/H$（閉じた形）。$C$ は実数なので $c_{-n}=\overline{c_n}$（複素の和は実数の $\cos$・$\sin$ の和に戻る）。

- 部分和は、連続点で $C$ に、跳びでは中点に収束する（有界変動関数のディリクレの定理）。周期の延長で $T=0$ と $T=H$ がつながるので、そこでも中点 $(C(0^+)+C(H))/2$ に収束する（$C$ は増えるので大きな跳び）。
- $|c_n| = O(1/n)$（跳びと境界の食い違いがある限り）。ギブスの行き過ぎ（跳びの約 9％）は消えない。
- したがって**有限項のフーリエ級数はこのモデルの厳密な表現にならない**（節点の値・左連続性を再現できない）。誤差は 04 に実測。〔P〕〔F〕

## TH-9 年増分の線形漸化式とモード分解の前提

年増分の列 $d_y$ が次数 $L$ の線形漸化式 $\sum_{i=0}^{L} c_i d_{y-i}=0$ を満たすとき、またそのときに限り、$d_y$ は $L$ 個の（重複を含む）モードの和 $\sum_m \mathrm{poly}_m(y)\,\lambda_m^{\,y}$ で書け、DMD（ハンケル行列、階数 $L$）が厳密に固有値 $\lambda_m$ を与える。最小の $L$ は有理数の上でバーレカンプ・マッシー法で求まる（$2L\le n$ なら一意）。

モードが生じる仕組み（定理として）：一定の年次表 → $\lambda=1$、直線の低下 → $\lambda=1$（重根）、冷媒の減衰 → $\lambda=q_d$、整数の周期 $c$ の更新 → 1 の $c$ 乗根。任意の年次表（表で与える系列）や、整数でない周期の事象は低い次数を作らない。

このモデルで線形の動的方程式（状態の漸化式）を持つのは冷媒の残存量だけ（D-08：$u_k = p_{k-1}m_0 + (1-p_{k-1})q\,u_{k-1}$）。ほかの量は状態を持たない重ね合わせなので、モード分解は「表現」としてしか使えず、その成否は上の漸化式の次数で決まる。〔P〕〔E：次数〕〔F：DMD〕 結果は 04。

## TH-10 有限の革新率（FRI）：フーリエ係数から事象の時刻を厳密に戻す

跳びだけの関数 $f(T)=A+\sum_{j=1}^{K}J_j\,\theta(T;\tau_j)$ では、$X_n = \int_0^H f'(T)e^{-i\omega_n T}dT = \sum_j J_j e^{-i\omega_n\tau_j}$（$\omega_n = 2\pi n/H$）。$X_n$ は $C(H)e^{-i\omega_n H}-C(0^+)+i\omega_n\mathcal{L}_H[f](i\omega_n)$ で、$K$ 項の指数和だから、$2K+1$ 個の係数から消去フィルタ（プロニー法）で $\tau_j$ と $J_j$ が厳密に（厳密な算術で）求まる。浮動小数では条件数が $K$ と最小間隔で悪化する。〔P〕〔F：04〕
傾きを持つ関数（年セル）では 2 階導関数が $\delta$ と $\delta'$ の和になり、同じ方法が重複根つきで使える（本章では跳びだけの段階で測定）。

## TH-11 周期と準周期、長期の傾向

- 事象の節点の集合は等差数列 $\{n c_i\}$ と一覧の和集合。周期がすべて整数（または公約数を持つ）で年次表がある年から一定なら、年増分はその年から周期 $L=\mathrm{lcm}(c_i)$ の周期列になる（TH-9 の 1 の $L$ 乗根）。
- 長期の傾向：$C(T) = \alpha + \beta T + (\text{周期・準周期の部分}) + (\text{年次表の変化による部分})$。周期 $c$ の更新の平均の傾きは $\Gamma/c$。傾向の傾き $\beta$ は、年あたりの流れ $\sum B$ と更新の平均 $\sum\Gamma/c$ と冷媒の終わりの項の傾きの和。役割ごとの寄与は 07 の 2 節。

## TH-12 係数の影響

$\partial C/\partial a_j = \kappa_j(T)$（02 の 5 節）。節点の位置について：$C$ は事象の時刻 $\tau$ について、$T$ が $\mathrm{sw}(\tau)$ を横切る点を除いて局所的に一定。〔P〕

## TH-13 境界条件

- $T\to0^+$：TH-4(b)。
- $T = H$：格子の節点 $H$ は規則 $t<T$ で効かない。$C$ は $H$ で左から連続。$T>H$ は定義されない。
- $\varepsilon$ の帯：TH-2 の 3、L-2。
- 端の年：年セル $H-1$ の終わりで流れが止まる（密度も $H$ で止まる）。

## TH-14 合計から作る単位の時間特性

区間 $(a,b)$ で $C = \alpha + \beta T$ なら

- SUM-05 $= C/(AT) = \beta/A + \alpha/(AT)$：区間ごとの双曲線。$d\,\mathrm{SUM05}/dT = -\alpha/(AT^2)$ なので、区間の切片 $\alpha$ の符号で増減が決まる。$T\to0^+$ で $C(0^+)>0$ なら $+\infty$。
- 段階の割合 $S_s/C$：区間ごとの一次分数関数。
- 回数・判定・欠損の数え上げ：区間ごとの定数（階段）。
- 年次の列（by_year）：長さが $\lceil T\rceil$ で変わる。

06 で、全 70 単位の全出力をこの分類で測った。
