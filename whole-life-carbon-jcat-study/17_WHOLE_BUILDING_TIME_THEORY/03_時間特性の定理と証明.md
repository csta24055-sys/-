# 03 建物全体の時間特性：定理と証明

対象は 01 の完全理想方程式 $C(T)$（独立概念モデル、架空データ）。各定理に、**証明**（恒等式としての根拠）と**検証**（モデルの浮動小数の入力そのものの上で、有理数で厳密に評価した恒等式の照合。07 に件数）を付ける。
「厳密」は、浮動小数で与えられた振幅・時刻を有理数とみなしたときに式が等号で成り立つことを言う。実数の入力についての主張ではない（入力そのものが浮動小数だから）。

**証拠の水準**：P＝証明あり、E＝有理数での厳密な照合（標本の点で）、F＝浮動小数での測定、S＝統計的な確認（第 4 段階）。

## 0. 記号と定義域

- 評価期間 $T\in(0,H]$。事象の規則 $\theta_\varepsilon(T;g)=[g<T(1-\varepsilon)]$、$\varepsilon=10^{-9}$。年重み $w_k(T)=\operatorname{clip}(T-k,0,1)$。
- 定義域 $\mathcal{D}$：第 11 章の `scenarios.valid_domain` の内側（周期の事象の時刻が $T$ や整数年から相対 1e-10〜1e-8 の距離にない組）。この帯の中では判定が丸めで決まる。
- **縮めた定義域 $\mathcal{D}'$**（独立レビューで見つかった穴への対応）：$\mathcal{D}$ から、**整数の時刻 $K$ の事象**（一覧の交換年を含む、すべての出所）について $T\in(K, \mathrm{sw}(K)]$ を除いたもの。`valid_domain` は一覧の事象を調べないので、この細い帯（幅は $K$ の相対 1e-9 程度）が $\mathcal{D}$ に残る。そこでは第 11 章の統一系と本章の正準形がどちらも基準計算と異なる（TH-2 の 3、07 の 6 節）。以下の「モデルとの一致」は $\mathcal{D}'$ での主張である。
- 節点：格子 $\Lambda\subseteq\{0,\dots,H\}$（規則 $[t<T]$）と事象 $E$（規則 $\theta_\varepsilon$）。区切り点の集合 $\Pi = \{0,\dots,H\}\cup\{\mathrm{sw}(g): g\in E\}$。

## 補題

**L-1（核から切断べきへ）** 01 の 4 節の表のとおり、各核は $[c<T](p+qT)$ または $\theta_\varepsilon(T;g)(p+qT)$ の有限和に等しい。

*証明.* $\operatorname{clip}(x,0,\ell) = [x>0]\,x - [x>\ell]\,(x-\ell)$（$x$ で場合分け）。$x=T-s$ とおくと傾きの寄与 $(-as,a)$ と $(a(s+\ell),-a)$ を得る。ゲート付き：$s<g$ かつ $g<(s+\ell)(1-\varepsilon)$ なら、$\theta_\varepsilon(T;g)=1$ となる $T$ は $T>g/(1-\varepsilon)>s$ を満たすので $[x>0]$ は 1、また $T > s+\ell$ なら $\theta_\varepsilon = 1$ だから $\theta_\varepsilon\cdot\operatorname{clip} = \theta_\varepsilon\,(T-s) - [T>s+\ell](T-s-\ell)$。$g\ge(s+\ell)(1-\varepsilon)$ なら $\theta_\varepsilon=1 \Rightarrow T> s+\ell$ で $\operatorname{clip}=\ell$。窓：$[K<T\le K{+}1] = [K<T]-[K{+}1<T]$、$T>K{+}1$ で核は定数（傾きは飽和、事象は数えられている：$g<(K{+}1)(1-\varepsilon)$ の場合。そうでない事象は窓の中で恒等的に 0）。∎ 〔P〕

ゲート付き年セルの前提 $s<g$ は、事象の年セルの作り方 $k=\max(1,\lceil g(1-\varepsilon)\rceil)-1 < g(1-\varepsilon)$ から常に成り立つ（実装は前提が破れると停止する。停止は 0 件）。

**L-2（浮動小数の事象の規則）** $T\mapsto \mathrm{fl}(T\cdot d)$（$d=\mathrm{fl}(1-\varepsilon)$）は単調非減少なので、$g<\mathrm{fl}(T d)$ を満たす浮動小数 $T$ の集合は上に閉じている。その最小元を $\mathrm{sw}(g)$ とすると、事象は $T\ge\mathrm{sw}(g)$ で数えられ、$\lvert\mathrm{sw}(g) - g/d\rvert$ は数 ulp 以下である。

*証明.* 丸めは単調。$u=2^{-53}$ として $g<\mathrm{fl}(xd)\le xd(1+u)$、$\mathrm{fl}(x^- d)\le g \Rightarrow x^- d(1-u)\le g$（$x^-$ は 1 つ下の浮動小数）。よって $g/(d(1+u)) < \mathrm{sw}(g) \le \mathrm{next}(g/(d(1-u)))$、すなわち $g/d$ から 2 ulp 程度以内。∎ 〔P〕 実測の最大は $g/d$（$d = \mathrm{fl}(1-\varepsilon)$）に対して 1.5 ulp（07 の 2 節）。実数の $g/(1-\varepsilon)$ との差はさらに $\mathrm{fl}(1-\varepsilon)$ の丸めの分を含む。

## TH-0 正準形

(i) **表現の恒等式.** 核の和（L2〜L4）と節点形（L5）は、すべての $T\in(0,H]$ で有理数として等しい。合計についても、各段階の項だけ・各単位の項だけについても同じ。〔P〕
(ii) **モデルとの一致.** $\mathcal{D}'$ の組で、SUM-03、評価範囲に入る段階の値、合計に入る **21 単位**（構成表は 22 行。B2-01 は B2 と B6 に現れる）の値は、統一系（第 11 章）と基準計算に相対 1e-9 で一致する。〔F：保存した集合の組で照合。厳密な等号ではない（基準計算は浮動小数の計算）〕

*証明（i）.* 14 章 07 の合成式（段階×単位の行列）、第 11 章の EMIT（各単位の値は核の和）、B2-01 はスカラー $\rho$ と年セルの和の積（振幅に吸収）、B1-04 は区間形（窓の核の和）、L-1 による節点への変換の和。∎
*検証.* (i)：核の和と節点形を、各シナリオの区間の中点（最大 60 点）、区切り点そのものとその隣の浮動小数（最大 60 点×3）、照合の評価期間（1,293 組）で有理数として照合し、段階ごと・単位ごとの節点形も照合した（07 の 2 節・補足）。〔E〕 (ii)：07 の 1 節。

## TH-1 区分的な一次式

$\Pi$ の隣り合う 2 点の開区間 $(a,b)$ で $C(T)=\alpha+\beta T$、$\alpha = A_0+\sum_{c\le a}p_c$、$\beta=\sum_{c\le a}q_c$（和は位置 $a$ 以下の全節点）。

*証明.* 区間の中で各指示関数は一定（格子は $t\le a$ なら 1、事象は $\mathrm{sw}(g)\le a$ なら 1）。∎ 〔P〕
*検証.* 節点形（コード）の内部の整合として全区間で照合した（節点形は作り方から区分一次なので、これは実装の確認にすぎない）。**核の和そのもの**については、各関数で無作為の最大 100 区間で、3 点が一直線上にあり係数が節点の累積和に等しいことを有理数で照合した（07 の補足）。〔E〕

## TH-2 連続性と跳び

1. 格子の節点 $t$ での跳びは $P_t+Q_t t$。傾きの核だけなら厳密に 0（始まり $-as+as$、終わり $a(s+\ell)-a(s+\ell)$）。
2. 区間形の窓（B1-04）の寄与は、厳密な入力なら連続（冷媒の量は年の境で連続：$\mathcal{A}_{K+1} = \mathcal{A}_K + \mathcal{B}_K + \sum_j(\alpha_j+\gamma_j)$）。浮動小数の係数では各係数を別々に丸めるので、丸めの大きさ（実測で係数の大きさの相対 2e-16 程度、最大 6.1e-16）の跳びが残る。
3. 整数の時刻 $\tau = K{+}1$ の交換は年セル $K$ に属するが、窓 $(K,K{+}1]$ の中では決して数えられない。区間形と、冷媒の年初の量 $u_{K+1}$（B1-02 の振幅）は、その交換による初期化を次のセルの係数に入れるので、$T > K{+}1$ で初期化が効く。モデル（基準計算）は交換が数えられる $T\ge\mathrm{sw}(K{+}1)\approx (K{+}1)(1+10^{-9})$ から初期化する。したがって $T\in(K{+}1, \mathrm{sw}(K{+}1))$ では、正準形（と第 11 章の統一系）は基準計算と**異なる**（実測：B1-04 で最大相対 1.1、SUM-03 で 5e-5。07 の 6 節）。この帯は $\mathcal{D}$ には一部が残る（周期でなく一覧の交換を `valid_domain` は調べない）ので、主張を $\mathcal{D}'$ に限る。帯の外では、区間形の跳び（格子の $K{+}1$）と跳び形の跳び（$\mathrm{sw}(K{+}1)$）は同じ大きさ（07 の補足 S4：相対差は残存量の 1e-12 以下）。
4. 事象の節点 $g$ での跳びは $J_g = p_g + q_g\,\mathrm{sw}(g)$。$T<\mathrm{sw}(g)$ の値は左の区間の式に乗る（実数の規則では $T=\tau/(1-\varepsilon)$ で左連続）。

*証明.* TH-1 の係数の差。2 は D-08 の漸化式（年の境で状態は同じ値）。3 は区間形の定義（$K=\lceil T\rceil-1$ のセルの係数を使う）と事象の規則。∎ 〔P〕
*検証.* **核の和**から跳びと傾きの変化を求めて理論値と照合した：timechar で事象の前後（各シナリオ最大 12 事象、計 4,094 事象）、補足で無作為の隣り合う区間（各関数最大 40 組）。整数時刻の事象の位置では、B1-04 以外の項の跳びが厳密に 0 であること、B1-04 の区間形の跳び（$K$）が独立に作った跳び形の跳び（$\mathrm{sw}(K)$）と一致することを照合した（補足 S4）。節点形どうしの比較（隣り合う区間の外挿）は実装の確認にすぎない。〔E〕

## TH-3 導関数（古典・超関数）

区間の内側で $C'(T) = \sum_{t\in\Lambda,\,t<T} Q_t + \sum_{g:\,\mathrm{sw}(g)\le T} q_g$。$C$ は $(0,H]$ でだけ定義されるので、**開区間 $(0,H)$ の上の超関数**として（$\Lambda^\circ = \Lambda\cap(0,H)$、$E^\circ = \{g : \mathrm{sw}(g)\in(0,H)\}$）

$$ \frac{dC}{dT} = \sum_{t<T} Q_t + \sum_{\mathrm{sw}(g)\le T} q_g \;+\; \sum_{g\in E^\circ} J_g\,\delta\big(T-\mathrm{sw}(g)\big) \;+\; \sum_{t\in\Lambda^\circ} (P_t + Q_t t)\,\delta(T-t), $$

$$ \frac{d^2C}{dT^2} = \sum_{t\in\Lambda^\circ} Q_t\,\delta(T-t) + \sum_{g\in E^\circ} q_g\,\delta(T-\mathrm{sw}(g)) + \sum_{g\in E^\circ} J_g\,\delta'(T-\mathrm{sw}(g)) + \sum_{t\in\Lambda^\circ}(P_t+Q_t t)\,\delta'(T-t). $$

傾きは節点 $c$ で $q_c$（格子は $Q_t$）だけ変わる。格子の節点 $t=0$ は $(0,H)$ の外にあり、その係数は $C(0^+) = A_0 + P_0$ と $C'(0^+) = Q_0 + \dots$ に入る（$\delta$ の項にはならない）。$C$ を $T\le0$ で 0 とおいて $\mathbb{R}$ の上の超関数とみるとき（因果的な延長）は、$dC/dT$ に $C(0^+)\,\delta(T)$、$d^2C/dT^2$ に $C'(0^+)\,\delta(T) + C(0^+)\,\delta'(T)$ を加え、$T=H$ には延長の決め方（TH-7 の $\hat C$ なら格子 $H$ の項）に応じた項が加わる。〔P〕〔E：傾きの変化を全区間で照合〕

## TH-4 実時間の分解（評価期間 $T$ と実時間 $t$ の区別）

T によらない符号付き測度 $M$（$t=0$ の原子、年セル・密度の流れ、事象の時刻の原子）と、終わりの項 $Z(T)=A^{\mathrm{term}}+\iota_{\mathrm{B1}}R(T)$ があって

$$ C(T) = M\big([0,T]\big) + Z(T),\qquad \frac{dC}{dT} = \rho(T) + Z'(T)\quad(\text{区間の内側}), $$

$\rho$ は $M$ の密度。事象の原子は浮動小数の規則に合わせ、$\mathrm{sw}(\tau)\le T$ のとき数える（閉区間。密度には開閉の違いはない）。作り方：定数（A 段階）→ $t=0$ の原子、年セル $k$ の率 $a$ → $[k,k{+}1)$ の密度 $a$、密度 → $[0,H)$ の密度、原子 → $\mathrm{sw}(\tau)$ の原子、ゲート付き年セル $a\,\theta_\varepsilon(T;g)\,w_k(T)$ は 2 つの場合に分ける：
- $\mathrm{sw}(g) < k{+}1$：$\mathrm{sw}(g)$ に原子 $a(\mathrm{sw}(g)-k)$、$[\mathrm{sw}(g),k{+}1)$ に密度 $a$；
- $\mathrm{sw}(g) \ge k{+}1$（事象がそのセルの中で数えられない場合。整数時刻 $g = k{+}1$ の事象はすべてこれ）：$\mathrm{sw}(g)$ に原子 $a$（$=a\ell$）、密度なし。

*証明.* 第 1 の場合、$T\ge\mathrm{sw}(g)$ で $a\,w_k(T) = a(\mathrm{sw}(g)-k) + a\operatorname{clip}(T-\mathrm{sw}(g),0,k{+}1-\mathrm{sw}(g))$、$T<\mathrm{sw}(g)$ で両辺 0。第 2 の場合、$T\ge\mathrm{sw}(g)\ge k{+}1$ で $w_k(T)=1$、$T<\mathrm{sw}(g)$ で 0。ほかは定義から。∎ 〔P〕〔E：節点形に対して全区間、核の和に対して各関数最大 100 区間で照合〕

**帰結.**

- (a) **$dC/dT$ は実時間の排出率ではない。** 差は $Z'(T)$ で、冷媒の期末残存量の傾き（補充しない機器があれば負）。期末残存量を数える建物では、ほぼすべての区間で $Z'\ne0$（07 の 2 節）。
- (b) **$C(0^+) = A^{\mathrm{init}}+A^{\mathrm{term}}+\iota_{\mathrm{B1}}R(0^+)$**（このとき $\theta_\varepsilon$ の事象は数えられていない）。A 段階・C 段階・B1 のどれかが評価範囲にあって量が 0 でなければ $C(0^+)\ne0$：評価期間を 0 に近づけても、廃棄時の排出と初期充填の未回収分が残る（評価期間の関数は累積排出ではない）。節点形の $A_0$ は $R(0^+)$ を含まない（区間形の窓は格子の節点 0 に置かれる）ので、$C(0^+) \ne A_0$ になりうる（実測：07 の補足）。
- (c) **分解は一意ではない。** $C$ だけからは $M$ と $Z$ を決められない（定数を $t=0$ に置くか $t=T$ に置くかは $C$ を変えない。$R(T)$ も、「漏洩の負の流れ＋交換の正の原子＋初期の原子」に書き換えられる）。本章の分解は単位の意味（A は施工時、C と B1-04 は廃棄時）で決めた。第 2 段階はこの非一意性を前提にする。
- (d) **符号。** 単位ごとの $M$ は負の部分を持つ：B3-01（更新の年の修繕の除外：事象の時刻に負の原子、残りの年に負の密度）、B1-03（交換後の漏洩分の差し引き：事象の時刻に負の原子、残りの年に負の密度）、B6 の −B2-01（付け替え）。段階ごとにまとめると、密度はすべての標本で非負、原子が負になるのは B3 だけ（07 の 2 節）。B3 の負の原子は「その年の修繕を、交換の時刻にさかのぼって取り消す」年単位の計上規則の表れで、物理的な負の排出ではない。

## TH-6 累積（積分）

$$ \int_0^T C(u)\,du = A_0 T + \sum_{c<T}\Big(p_c (T-c) + q_c \frac{T^2-c^2}{2}\Big) $$

（各節点の切断べきの積分）。$\int_0^T C$ は連続で区分的に二次、一階導関数は $C$ そのもの。〔P〕〔E：全区切り区間の累積と照合〕

## TH-7 ラプラス変換（厳密）

有限区間 $[0,H]$ で

$$ \mathcal{L}_H[C](s) = A_0\frac{1-e^{-sH}}{s} + \sum_{c<H}\Big[F_c(H)-F_c(c)\Big],\qquad F_c(u) = -e^{-su}\Big(\frac{p_c+q_c u}{s}+\frac{q_c}{s^2}\Big). $$

節点形を $T>H$ にそのまま延ばした関数 $\hat C$ では $\mathcal{L}[\hat C](s) = A_0/s + \sum_c e^{-cs}\big((p_c+q_c c)/s + q_c/s^2\big)$。指数多項式で、指数が節点の位置そのものなので、変換から節点と係数を一意に読み戻せる（ラプラス変換の一意性）。〔P〕〔F：区分ごとのガウス積分と最大相対 1.4e-13（07 の 3 節）〕
モード分解のような「近似」は要らない。年セルの部分は $\mathcal{L}[w_k](s) = (e^{-ks}-e^{-(k+1)s})/s^2$、事象は $e^{-\mathrm{sw}(g)s}/s$。

## TH-8 フーリエ級数（厳密な係数、近似としての部分和）

$[0,H]$ の係数は $c_n = \mathcal{L}_H[C](2\pi i n/H)/H$（閉じた形）。$C$ は実数なので $c_{-n}=\overline{c_n}$（複素の和は実数の $\cos$・$\sin$ の和に戻る）。

- 部分和は、連続点で $C$ に、跳びでは中点に収束する（有界変動関数のディリクレの定理）。周期の延長で $T=0$ と $T=H$ がつながるので、そこでも中点 $(C(0^+)+C(H))/2$ に収束する（$C$ は増えるので大きな跳び）。
- $|c_n| = O(1/n)$（跳びと境界の食い違いがある限り）。ギブスの行き過ぎ（跳びの約 9％）は消えない。
- したがって**有限項のフーリエ級数はこのモデルの厳密な表現にならない**（節点の値・左連続性を再現できない）。誤差は 04 に実測。〔P〕〔F〕

## TH-8b フーリエ変換（有限の台と、延長した関数の超関数としての変換）

規約 $\mathcal{F}[f](\omega) = \int f(t)\,e^{-i\omega t}\,dt$。

1. **有限の台（モデルが定義する範囲）.** $C_H = C\cdot\mathbf{1}_{(0,H]}$ は可積分で、$\mathcal{F}[C_H](\omega) = \mathcal{L}_H[C](i\omega)$（TH-7 の閉じた形に $s = i\omega$ を入れたもの）。$\omega$ の整関数で、$\omega=0$ では $\int_0^H C$（TH-6）に等しい（$s\to0$ の極限）。フーリエ係数は標本 $c_n = \mathcal{F}[C_H](2\pi n/H)/H$（TH-8）で、有限の台の関数は $\omega_n = 2\pi n/H$ の標本で決まる（周波数の側の標本化定理）。〔P〕〔E：$\omega_n$ での係数を区分ごとの数値積分と照合（07 の 3 節・補足）。整数でない $\omega$ では照合していない〕
2. **延長した関数（超関数）.** 節点形を $T>H$ にそのまま延ばし、$T\le0$ で 0 とした $\hat C$（TH-7）は一次で増えるので可積分ではないが、緩増加の超関数である。$\theta$ をヘヴィサイド関数として $\mathcal{F}[\theta] = \pi\delta(\omega) - i\,\mathrm{p.v.}\frac1\omega$、$\mathcal{F}[t\,\theta(t)] = i\pi\delta'(\omega) - \mathrm{f.p.}\frac{1}{\omega^2}$（f.p. はアダマールの有限部分）、移動 $\mathcal{F}[f(t-c)] = e^{-ic\omega}\mathcal{F}[f]$ を使い、$p_c + q_c T = (p_c+q_c c) + q_c(T-c)$ と分けると

$$ \mathcal{F}[\hat C](\omega) = A_0\Big(\pi\delta(\omega) - i\,\mathrm{p.v.}\tfrac1\omega\Big) + \sum_c e^{-ic\omega}\Big[(p_c+q_c c)\Big(\pi\delta(\omega) - i\,\mathrm{p.v.}\tfrac1\omega\Big) + q_c\Big(i\pi\delta'(\omega) - \mathrm{f.p.}\tfrac{1}{\omega^2}\Big)\Big]. $$

   $\omega\ne0$ では TH-7 の $\mathcal{L}[\hat C](i\omega)$ と一致し、$\omega=0$ に台を持つ部分（$\delta$、$\delta'$）は長期の水準と傾き（$A_0+\sum(p_c+q_cc)$、$\sum q_c$）を表す。$T>H$ の延長はモデルが定めないので、この変換は延長の選び方に依る（1 は依らない）。〔P〕

## TH-9 年増分の線形漸化式とモード分解の前提

年増分の列 $d_y$ が次数 $L$ の線形漸化式 $\sum_{i=0}^{L} c_i d_{y-i}=0$（$c_0 = 1$）を満たし、$c_L\ne0$（特性多項式に 0 の根がない）とき、またそのときに限り、$d_y$ は $L$ 個の（重複を含む）モードの和 $\sum_m \mathrm{poly}_m(y)\,\lambda_m^{\,y}$ で書け、ハンケル行列による DMD（階数 $L$）は厳密な算術で固有値 $\lambda_m$ を与える。0 の根が重複度 $m$ で現れると、その表現は $y\ge y_0 + m$ からだけ成り立ち（$m$ 項の過渡）、DMD の 0 固有値はモードではなく過渡を表す。最小の $L$ は有理数の上でバーレカンプ・マッシー法で求まる（$2L\le n$ なら一意）。

モードが生じる仕組み：一定の年次表 → $\lambda=1$；直線の低下 → $\lambda=1$ の重根（低下が列の終わりまで続くとき。途中で下限に達すると特性多項式は $x^m(x-1)$ の形）；補充しない冷媒の減衰 → $\lambda=q_d$；周期 $c = p/q$（既約）の更新 → 周期 $p$ の列、すなわち 1 の $p$ 乗根（複数の周期では分子の最小公倍数）。任意の年次表（表で与える系列）、無理数や分子の大きい周期、一覧の事象は低い次数を作らない。

本章は特性多項式の根を有理数の漸化式から求めた。ハンケル行列の DMD そのものは、合計の次数が 40 以下で一意に決まるシナリオが無かったので実行していない（07 の 4 節）。

**状態の方程式の前提.** このモデルで状態の漸化式を持つのは冷媒の残存量だけで、それは交換の有無 $\chi_{d,k}$ で**切り替わるアフィン（非斉次）の漸化式** $u_{d,k+1} = \chi_{d,k}\,m_{0,d} + (1-\chi_{d,k})\,q_d\,u_{d,k}$ である（D-08）。DMD・固有値分解が前提とする時不変の線形系 $x_{k+1} = A x_k$ ではない：定数項 $m_0$ を持ち、係数が年で切り替わる。状態に定数 1 を加えて斉次化しても $x_{k+1} = A_k x_k$、$A_k = \begin{pmatrix}(1-\chi_k)q & \chi_k m_0\\ 0 & 1\end{pmatrix}$ は年で変わる。B1-02（$r\,\mathrm{GWP}\,u_{d,k}$）、B1-03（交換時の $\lambda_{\mathrm{loss}}\mathrm{GWP}\,u_{d,k}$ と差し引き）、B1-04（$\kappa_R u_{d,K}$）の値はこの状態に依る。時不変の写像が得られるのは (1) 交換のない期間（$A = \mathrm{diag}(q,1)$、固有値 $q$ と 1）、(2) 交換が $p$ 年ごとに周期的に起きる場合の $p$ 年の写像 $\Phi = A_{k+p-1}\cdots A_k$（$x_{k+p} = \Phi x_k$）に限る。ほかの量は状態を持たない重ね合わせなので、モード分解は「表現」としてしか使えず、その成否は上の漸化式の次数で決まる（低い次数は、補充ありの一定の状態、補充なしで交換のない減衰 $q$、分子の小さい周期の交換や更新で生じる。整数の周期に限らない）。〔P〕〔E：次数と特性多項式〕 結果は 04 と 07 の 4 節。

## TH-10 有限の革新率（FRI）：フーリエ係数から事象の時刻を厳密に戻す

跳びだけの関数 $f(T)=A+\sum_{j=1}^{K}J_j\,[T\ge\mathrm{sw}(\tau_j)]$ では、$X_n = \int_0^H f'(T)e^{-i\omega_n T}dT = \sum_j J_j e^{-i\omega_n\mathrm{sw}(\tau_j)}$（$\omega_n = 2\pi n/H$）。部分積分で $X_n = f(H)e^{-i\omega_n H}-f(0^+)+i\omega_n\mathcal{L}_H[f](i\omega_n)$。$K$ 項の指数和だから、$2K+1$ 個の係数から消去フィルタ（プロニー法）で切り替え点 $\mathrm{sw}(\tau_j)$（実数の規則では $\tau_j/(1-\varepsilon)$）と $J_j$ が厳密に（厳密な算術で）求まる。$\tau_j$ そのものとの差は $\tau_j\cdot10^{-9}$ 程度。浮動小数では条件数が $K$ と最小間隔で悪化する。〔P：厳密な算術、任意の $K$〕〔F：浮動小数での回収は、跳びだけの段階（B4・B5）で $K\le6$ のときに確認。$K=20$ の 1 件では失敗（04 の 2.4）。傾きを持つ段階・$C$ 全体には適用していない〕
傾きを持つ関数（年セル）では 2 階導関数が $\delta$ と $\delta'$ の和になり、同じ方法が重複根つきで使える（本章では跳びだけの段階で測定）。

## TH-11 周期と準周期、長期の傾向

**準周期の部分の定義.** 周期 $c>0$ の事象の列 $\tau_n = \mathrm{fl}(nc)$ の回数を $N_c(T) = \#\{n\ge1 : \tau_n < T(1-\varepsilon)\}$ とする。実数の規則（$\tau_n = nc$）では $N_c(T) = \lceil T(1-\varepsilon)/c\rceil - 1$ だから

$$ N_c(T) = \frac{T(1-\varepsilon)}{c} + \Pi_c(T),\qquad \Pi_c(T) = \lceil x\rceil - 1 - x \in [-1, 0),\quad x = \frac{T(1-\varepsilon)}{c}, $$

$\Pi_c$ は周期 $c/(1-\varepsilon)$ の周期関数（のこぎり波）。振幅 $\Gamma$ の事象の和は $\Gamma N_c(T) = \Gamma\,T(1-\varepsilon)/c + \Gamma\,\Pi_c(T)$ で、**準周期の部分** $\Gamma\Pi_c(T)$ は $|\Gamma\Pi_c(T)| \le |\Gamma|$。事象の年の補正（ゲート付き年セル）$a\,\theta_\varepsilon(T;\tau_n)\,w_{k_n}(T)$ は $a\,[T\ge k_n+1] + r_n(T)$（$r_n$ は $[\mathrm{sw}(\tau_n), k_n{+}1)$ だけで 0 でなく $|r_n|\le|a|$）と書け、$k_n+1 = \lceil\tau_n(1-\varepsilon)\rceil\in[\tau_n(1-\varepsilon), \tau_n(1-\varepsilon)+1)$ だから

$$ \sum_n a\,\theta_\varepsilon(T;\tau_n)w_{k_n}(T) = \frac{a\,T}{c\,(1-\varepsilon)} + \Pi'(T),\qquad |\Pi'(T)| \le |a|\Big(2 + \frac{1}{c(1-\varepsilon)} + \Big\lceil \frac1c\Big\rceil\Big) $$

（$\#\{n : k_n+1\le T\}$ は $\lfloor (T-1)/(c(1-\varepsilon))\rfloor$ と $\lfloor T/(c(1-\varepsilon))\rfloor$ の間。$r_n$ は $a\theta_\varepsilon w_{k_n} - a[T\ge k_n+1]$ で、整数時刻の事象では $[k_n{+}1,\mathrm{sw}(\tau_n))$ の $-a$ も含み、台は年 $k_n$ の付近の長さ 1 程度の区間なので、同時に 0 でない $r_n$ は高々 $\lceil 1/c\rceil+1$ 個）。〔P〕 浮動小数の $\tau_n = \mathrm{fl}(nc)$ と規則 $\mathrm{fl}(T\,\mathrm{fl}(1-\varepsilon))$ では、境目が L-2 の数 ulp だけずれるので、$\Pi_c$ の周期性は帯の外でだけ成り立つ（有界性は変わらない）。

**周期になる条件.** 次の前提がすべて成り立てば、年増分はある年から周期 $L$ の周期列になる（TH-9 の 1 の $L$ 乗根）：(1) 一覧の事象がない；(2) 年次表がある年から一定；(3) 冷媒の機器は補充あり（または漏洩なし）か、周期的に交換される（補充なしで交換されない機器は $\lambda=q_d$ の減衰を作る）；(4) 周期が有理数 $c_i = p_i/q_i$（既約）。$L$ は分子 $p_i$ の最小公倍数（$c = 0.75$ なら周期 3）。無理数の周期では年増分は周期列にならず、$\Pi_c$ の標本は準周期（スツルム列）になる。

**長期の傾向.** 前提 (2) のもとで $C(T) = \alpha + \beta T + \sum_i \Gamma_i\Pi_{c_i}(T) + \sum \Pi' + (\text{冷媒の部分})$。傾き $\beta$ は、年あたりの流れ（一定になった年セルの率の和）、更新の平均 $\sum_i\Gamma_i(1-\varepsilon)/c_i$、事象の年の補正の平均 $\sum a/(c(1-\varepsilon))$（B3-01 の除外は $-a_i$、B1-03 の差し引き）の和。冷媒の部分は、周期的な交換なら状態が周期 $L$ の列になり同じ形（平均の傾き＋有界の周期の部分）、補充なしで交換がなければ流れが $q_d^k$ で減衰し、期末残存量の項 $\iota_{\mathrm{B1}}R(T)$ は 0 に近づく。〔P〕 本章は $\beta$ を標本で数値として求めていない（07 に該当の表はない）。周期の部分の存在は TH-9 の漸化式の次数（07 の 4 節）で間接に確かめた。

## TH-14 合計から作る単位の時間特性

区間 $(a,b)$ で $C = \alpha + \beta T$ なら

- SUM-05 $= C/(AT) = \beta/A + \alpha/(AT)$：区間ごとの双曲線。$d\,\mathrm{SUM05}/dT = -\alpha/(AT^2)$ なので、区間の切片 $\alpha$ の符号で増減が決まる。$T\to0^+$ で $C(0^+)>0$ なら $+\infty$。
- SUM-04・SUM-05 は $A>0$ のときだけ定義される。段階の割合 $S_s/C$ は $C>0$ かつ評価範囲の段階の値がどれも負でない区間でだけ定義され、そこで区間ごとの一次分数関数。
- 回数（B4-01 の n_events、B4-03 の $n_i(T)$、B5-01 の n_events、X-08 の count、X-10 の $1+n_i$）：$N(T) = \sum_{\tau\in E^{\mathrm{all}}}\theta_\varepsilon(T;\tau)$。$E^{\mathrm{all}}$ は**振幅が 0 の品目を含むすべての事象の時刻**で、$C$ の節点（振幅が 0 でない項の事象）より多いことがある。回数はこの細かい分割の上の階段で、$C$ の区切り $\Pi$ の区間の内側でも変わりうる（06：数量 0 の品目）。照合は 07 の 7 節。
- 判定・欠損の数え上げ：判定に入る量の区切りの上の階段。
- 年次の列（by_year）：長さが $\lceil T\rceil$ で変わる。
