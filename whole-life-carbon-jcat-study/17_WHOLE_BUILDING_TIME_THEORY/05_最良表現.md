# 05 最良の表現とその理由

## 1. 採用する表現（2 つを併用し、役割を分ける）

| 目的 | 採用する表現 | 理由 |
|---|---|---|
| 値の評価・節点の性質・微分・積分 | **節点形**（L5）$C(T)=A_0+\sum_{t}[t<T](P_t+Q_tT)+\sum_g\theta_\varepsilon(T;g)(p_g+q_gT)$、B1-04 だけ区間形の窓 | 厳密（TH-0）。評価は二分探索 2 回。跳び・傾き・積分・ラプラス変換が係数から閉じた形で出る。節点の係数は寄与した単位・入力の行まで戻せる（`code/expand.py`） |
| 意味の理解・第 2 段階（動的 LCA） | **役割を分けた理想方程式**（01 の 3 節）と**実時間の分解** $C(T)=M([0,T])+Z(T)$（TH-4） | 係数の役割（初期・流れ・事象・事象の年の補正・終わりの状態・廃棄時の定数）を混ぜない。評価期間 $T$ と実時間 $t$ の違い（$dC/dT \ne$ 排出率）がこの形でだけ見える |
| 変換が必要な解析（畳み込み・気候影響） | **ラプラス変換**（指数多項式） | 厳密。節点＝指数で、逆変換に近似が要らない |

## 2. 採用しない表現と理由

| 表現 | 理由 |
|---|---|
| 有限項のフーリエ級数 | 跳びで中点に収束しギブスの行き過ぎが残る（TH-8）。512 項でも最大誤差の中央値 2.8％、最悪 16％（07 の 3 節） |
| POD／SVD | 建物ごとに節点の位置が違い、共通の少数のモードに載らない（第 10 章 EXP-04） |
| DMD・固有値分解（建物全体） | 時不変の線形の動的方程式が成り立たない（冷媒の状態は交換で切り替わるアフィンの漸化式）。合計の年増分の漸化式は 347 件中 345 件で最大の次数（07 の 4 節） |
| ウェーブレット | ハールは $C$（区分一次）を有限項で表せない（$C'$ と跳びの部分だけ厳密）。跳びの部分のハールと連続な部分のフェイバー・シャウダーを合わせれば有限項で厳密だが、$\mathrm{sw}(g)$ が細かい 2 進の位置にあるため事象 1 つに 50〜60 程度の係数が要る（04 の 2.8） |

## 3. 簡潔さと正確さの両立について

- 「最も簡潔」：節点形の自由度は（格子 $H+1$ 個）＋（相異なる事象の時刻）で、核の項の数以下（07 の 2 節：項／節点の比の中央値 7.2）。**節点ごとに係数を持つ表現の中では**これが最小である（節点の位置と跳び・傾きの変化は $C$ から一意に決まる：TH-2・TH-7 の一意性。どの節点の係数も省けない）。節点ごとに係数を持たない表現ならさらに少ない自由度もありうる：たとえば周期の事象を（周期 $c_i$、振幅、開始）の組で持ち $\Gamma_i N_{c_i}(T)$ と書く**周期ブロック形**は、品目ごとに $O(1)$ の数で多数の節点を表す（評価には回数 $N_c(T)$ の計算が要り、浮動小数の切り替え点は $\mathrm{fl}(nc)$ ごとに決まる）。本章は、節点の係数から単位・入力の行へ戻せることと、微分・積分・変換が閉じた形になることを優先して、節点形を採った。自由度の最小性を周期ブロック形まで含めて示したわけではない。
- 「最も正確」：基準計算との一致（1,293 組のうち定義域の内側の全組で相対 1e-9 以内、不一致 0。整数時刻の交換の直後の細い帯 $(K,\mathrm{sw}(K))$ は縮めた定義域 $\mathcal{D}'$ の外）と、核の和との厳密な一致。
- 「最も理解しやすい」：役割を分けた形（01 の 3 節）。節点形と項の対応は表で戻せる。

両立しない点が 1 つある：浮動小数の係数では、冷媒の期末残存量について「厳密な連続性（跳び形）」と「桁落ちのない値（区間形）」を同時に満たせない（04 の 2.1）。本章は値の正しさを優先して区間形を採り、年の境の丸めの跳び（係数の相対 2e-16 程度、最大 6.1e-16）を記録した。
