# 06 全 70 評価単位の時間特性（全出力の分類）

`code/units_time.py` が、統一系（第 11 章）を、区切り区間（格子と事象の切り替え点の間）ごとに 3 点で評価し、公開出力の葉ごとに $T$ への依存を分類した（浮動小数での測定、相対 1e-8）。`code/make_docs1.py` が `results/units_time.json` から書き出した。対象は独立概念モデルと架空データ。

分類：**一定**（すべての $T$ で同じ）、**階段**（区間ごとに一定。回数・判定・欠損の数・事象の一覧の要素）、**区分一次**（区間ごとに一次式、跳びを含む）、**双曲**（$T\cdot$値が区間ごとに一次：年平均）、**比**（$C(T)\cdot$値が区間ごとに一次：段階の割合）、**その他**、**期間で現れる**（出力のキーが一部の $T$ にだけある：年次の列の要素など）。列の長さが $T$ で変わる出力は別に数えた。

各欄はその分類になった（シナリオ×出力の葉）の数。理論の欄は第 11 章 UNITS_70 の「使う構造」（① 積和①だけ＝$T$ によらない、K 節点スペクトル、②a・②b 評価期間の積和）。

標本：54 シナリオ（dev_design, dev_edge, new_defects, new_population, new_special, rep_boundary, rep_constructed, rep_defects, rep_evaluation, rep_scale_L）。

- 「その他」に分類された葉：B4-01 `/n_events`（1）、B4-03 `/by_item[]`（1）。
  いずれも edge `zero_quantities`（数量 0 の品目）で、排出の振幅が 0 の事象は $C(T)$ の節点にならない（正準形から除かれる）が、回数には数えられるので、正準形の区間の内側で回数が変わる。回数の出力は事象の規則の階段関数であり、$C$ の区切りとは一致しない場合がある。
- 出力の葉ごとの分類（全キー）は `results/units_time.json` の `units`。

## 理論との対応（03 の TH-14）

- 合計・段階の値（SUM-01〜03、X-02 の by_stage、X-04・X-05 の内訳、X-07 の累積、SUM-06）：区分一次（TH-1）。A 段階だけの SUM-01 は一定。
- SUM-05（年平均・床面積当たり）：双曲。SUM-07 の割合：比（一次分数）。
- 回数・事象の一覧・判定（B4-01、B4-03、B5-01 の n_events、QA-02、QA-03、X-08、X-10）：階段。
- 年次の列（by_year）：長さが $\lceil T\rceil$ で変わり、要素は期間で現れる。
