# 第7章：全資料から読み取れたこと・読み取れないこと

## 7.1 検証済みの観察
1. 原版は5つのExcel、マニュアルPDF1件。Excelは**198シート**。\
   [全シート台帳](../02_SOURCES/ALL_198_SHEETS.json) に各シートの表示状態と数式ノード数を保存。
2. 数式XMLノード計3,818,483件。多くは共有・コピーされた表計算式。固有演算方式数や互換性の証拠ではない。
3. 標準算定77、簡易算定73、詳細算定24、分類表13、集計表11シート。
4. 標準は主要14細目、簡易は主要6細目。詳細は独立したAIJ-LCAツールとの連携を前提にする。
5. 入力は概ね A1～A5/B2～B5/C1～C4、B1、B6～B7 に分割。設備の各種標準推定値、統計値、資材構成、GHG/CO2系の内訳シートがある。
6. 出力にはA1～A5、使用段階、解体、WLC、面積原単位、年原単位、グラフ、炭素貯蔵・固定などが含まれる。

## 7.3 既知の元Excel警告（要再検証）
先行XML解析では`#REF!` `#VALUE!` `#N/A` `#DIV/0!`の保存表記・式中文字列が検出された。**これはXML文字列出現であり故障セル数ではない**。
原版の入力値、出力キャッシュ、外部参照が関係する可能性。未入力状態と再計算環境をそろえない限り根本原因は断定不可。

| 元ファイル | #REF! | #DIV/0! | #VALUE! | #N/A |
|---|---:|---:|---:|---:|
| 標準 | 1,278 | 84 | 4 | 327 |
| 簡易 | 70 | 0 | 0 | 327 |
| 詳細 | 68 | 0 | 0 | 0 |
| 分類表 | 0 | 0 | 0 | 0 |
| 集計表 | 0 | 5 | 6 | 0 |

## 7.4 段階的検証
- **構造**：ファイル枚数、シート名、隠しシート、セル数、データ検証数。
- **表計算式**：出典、式の文脈、引数型、外部依存。原式の無断転載はしない。
- **データ**：係数ごとの許諾、変換、年度、GWP、更新周期、既知欠損。
- **動作**：独立数学テスト、単位・時点・二重計上検査。
- **機能**：入力→式→出力の全リンク、未計算警告、ユーザー向け説明。
- **公開**：第1章の承認と権利者への照会が完了していること。

## 7.5 検証済み/未検証の管理
`OBSERVED` = 直接確認、`SAMPLED` = 標本確認、`INFERRED` = 設計推定、`NOT_VERIFIED` = 未検証、`RESTRICTED` = 禁止/権利待ち。

全出力にこの区分を保存し、`INFERRED` と `OBSERVED` を混同しない。元資料から読み取れなかった部分を推測で埋めない。
