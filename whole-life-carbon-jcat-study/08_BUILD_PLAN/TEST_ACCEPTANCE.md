# 完了判定・否定テスト（PRレビュー時）

## 原則
**禁止事項ゲートは、速度・見栄え・完成度より優先。** 係数・原版の出典が曖昧な状態で公開不可。

- [ ] 元ZIP/Excel/マニュアル/VBA/秘密情報がGit変更に含まれていない
- [ ] 公式原単位・更新周期・修繕率・漏洩率・工事倍率が移植されていない
- [ ] 独立係数に許諾、出典、適用年月、地域、分母単位、GHG範囲あり
- [ ] すべての式が既存入力ID・出力IDを参照、未接続項目はリスク扱い
- [ ] UNKNOWNとEXPLICIT_ZEROの違いを保証
- [ ] すべての出力にステージ、境界、単位、期間、根拠、版を添付
- [ ] 毎年のグリッド排出係数の変化/固定が区別される
- [ ] 更新・建替年の端数、使用期間境界の検査
- [ ] 冷媒の初期充填・漏洩・回収・更新は二重計上しない
- [ ] 輸送と製造の二重計上、B2/B6、B1/Cの二重計上を検査
- [ ] 施工廃棄物と解体廃棄物を区分
- [ ] 延床面積0・評価期間0・負数量・NaNを不合格とする
- [ ] 機能単位が同じ物件同士だけ比較する
- [ ] 実装した計算と数値結果を独立した手計算・検証例で照合
- [ ] 外部AIJ-LCA・EPD・原単位の権利調査完了
- [ ] 法律・使用条件に関する未解決の事象をPASS扱いしない

## テスト分類
**T01** 許諾ゲート / **T02** 単位 / **T03** 欠損 / **T04** 材料 / **T05** A4-A5 / **T06** 冷媒 / **T07** 修繕更新 / **T08** 年次 / **T09** 廃棄 / **T10** 報告 / **T11** 比較 / **T12** UI。
数値実装前はステータス `NOT_EXECUTED` と明記。
