# 第8章：誰でも使える独立ソフトの開発ロードマップ

## 決定方針
- **一般ユーザー**：選択式・ボタン主体で建物、面積、構造、用途、主要材料、設備・運用を段階入力。説明と単位換算はUIで補助。
- **専門家**：数量明細・EPD・排出係数・冷媒・更新周期・廃棄を個別入力。結果の感度分析と監査ログ。
- **エンジン**：UIと分離。算定式IDと前提IDで一意につなぎ、計算不能時は明示的に停止。
- **係数**：J-CATから移植せず、商用再利用や再配布が適法に許された独立データセットのみ。
- **履歴**：変更したパラメータ・入力・係数版・結果を追跡可能に。
- **検証**：実数の係数を使う前に、自由に使える架空テストデータで式と動作を検算。

## 実装の推奨順
| フェーズ | 開発・調査 | 完了ゲート |
|---|---|---|
| G0 **権利** | 第1章を遵守。係数・EPD・規格・AIJ-LCAの許諾、コンプライアンス審査 | 公開する全ファイルを検査 |
| G1 **スキーマ** | 124入力項目の要否・単位・UIグループを確定、未接続項目を接続か削除と判断 | 参照切れ0、必須項目の定義が決定 |
| G2 **算定核** | 適法な独立式・単位換算・A1–A3・A4・A5から開始 | 手計算一致、境界テスト |
| G3 **年間** | B6/B7の年度別係数と年次積算、買電・創エネの収支 | 年別結果の積算が一致 |
| G4 **設備** | B1冷媒、B2～B5修繕・交換・建替 | 年次イベントと二重計上を確認 |
| G5 **終了** | C1–C4の解体・処理・最終処分、質量収支 | 総量保存と境界を確認 |
| G6 **集計** | ステージ、用途、資材、年次、面積原単位、比較 | トレーサビリティ有 |
| G7 **UI** | 初心者/専門、入力支援、エラー説明、CSV・PDF出力 | 使用者試験・アクセシビリティ |
| G8 **運用** | 出典アップデート、係数版の監査、回帰テスト、認証 | 権利者確認、回帰品質、情報保護 |

## すべきこと / すべきでないこと
**すべき**：フォームを分類、入力モード分離、計算API実装、すべての係数を外部管理、パラメータ変更前後の比較、単位テスト、出典トレース、未入力の説明、入力履歴を持つ。
**しない**：J-CATのマクロ・原版式・原単位の公開転載、完全互換を宣言、未検証係数の自動埋め込み、失敗や未達を合格扱い、他のプロジェクトやmainへ混在、権限確認なしに個人案件を公開。

## 技術上の留意事項
- 「Excelの数百万セルをWebで実行」を目標にしない。式IDごとに独立関数として管理。
- データのキャッシュ/更新やクラウド保存に個人案件の守秘義務・学内規則がかかり得る。
- Gitで修正して良いものは独立仕様・実装コードのみ。権利保護された原本を自動取り込みしない。
- 全性能や全機能の実装が完了するまでは「研究草案／未検証」を維持する。
