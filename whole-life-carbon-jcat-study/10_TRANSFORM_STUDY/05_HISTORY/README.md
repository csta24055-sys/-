# 05 方程式・変換・分類の改良履歴（成果物 6）

## 変換の種類を増やす前に検討したこと（指示書の第7章）

- 節点スペクトル（H-05）は、新しい変換方式として足したのではなく、マスク付き積和の因子に述語 [t_j < T] を入れた形の、速い実装として位置づけた。変換方式の数は増やしていない。
- 「最初に合ったもの」の検索は、積和の形に入らなかった。キーが一意なら積和で書けるので、入力に「キーは一意」という条件を課して 1 つの形を保つか、順序つきの検索を第 2 の演算として数えるかは、未決である（[../07_DECISIONS/README.md](../07_DECISIONS/README.md)）。
