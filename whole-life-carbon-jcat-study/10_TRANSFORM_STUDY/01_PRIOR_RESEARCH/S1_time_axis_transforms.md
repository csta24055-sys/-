## TH-S1-01　フーリエ級数・フーリエ変換（のこぎり波・小数部分・床関数の級数を含む）

- 英語名：Fourier series and Fourier transform (sawtooth / fractional part / floor function)　／　族：時間軸の積分変換（周期関数の調和展開）
- 関連度：中（回数関数を直接近似する手段としては、倍数の行で誤差 1/2 が消えず不適。ただし「位相 psi」という共通の補助変数と、積分量への書き換えという 2 つの再構成の手掛かりを与える。）
- 扱う型：F04、F05、F06、F07　／　厳密か近似か：F04・F07 は有限項では近似（T'/c が整数の行で 1/2 の誤差）。K→∞ でも整数点では中点に収束するので基準と一致しない。積分量（m>=1）はベルヌーイ多項式の閉じた形なら厳密、そのフーリエ打ち切りは一様に収束する近似。F05・F06 は対象外に近い。

### 1 何を意味する理論・方程式か

周期 1 の関数 f を f(x) = sum_k c_k e^{2 pi i k x}、c_k = int_0^1 f(x) e^{-2 pi i k x} dx と表す写像で、定義域は周期関数（可積分または 2 乗可積分）、値域は係数の列である。2 乗可積分なら Parseval の式（DLMF 式 1.8.5、1.8.6）により内積が保たれる。この研究に直接かかわる恒等式は、整数でない x について {x} = 1/2 - (1/pi) sum_{k>=1} sin(2 pi k x)/k、したがって floor(x) = x - 1/2 + (1/pi) sum_{k>=1} sin(2 pi k x)/k である（S-WP-FLOOR。DLMF 式 24.8.3 の n=1、0<x<1 の場合と同じ）。回数は x = T'/c（T' = T(1-1e-9)）として N = ceil(x) - 1 で、整数でない x では floor(x) に等しく、整数の x では x - 1 である。級数は不連続点で左右の極限の平均に収束する（DLMF §1.8）ので、整数の x では N + 1/2 を返し、基準計算の値 N と 1/2 ずれる。フーリエ変換は周期のない関数に対する同じ写像で、畳み込みを積に変える。

### 2 なぜ開発され、何を解決するか

平行移動で不変な線形の作用素（微分、畳み込み）は複素指数関数を固有関数に持つので、指数関数で展開すると作用素が掛け算になる。熱伝導の方程式を解くために導入され、定数係数の線形の微分方程式・差分方程式を代数の問題に変える手段になった（導入の経緯は出典未確認（調査担当の知識））。解決する問題は「重ね合わせで書ける量を、周波数ごとの独立な成分に分けて扱う」ことである。不連続な関数を有限項で打ち切ると、不連続点の近くで一様に収束しない（DLMF §1.8 が非一様収束を明記）。この現象の回復法を扱った総説が S-GS1997 である（要旨の水準でのみ確認）。

### 3 どの分野でどう使われているか

信号処理（スペクトル解析、フィルタの設計）、偏微分方程式のスペクトル法、結晶学、潮汐の予測、時系列の季節成分の分離で使われる（一般的な用途。出典未確認（調査担当の知識））。数論では、のこぎり波 ((x)) の有限フーリエ展開がデデキント和の計算に使われる（S-BECK2003 式(3)(4)）。数値積分では、台形則の誤差がフーリエ係数の折り返しの和で表される（S-TW2014 式(5.9)）。建築 LCA・動的 LCA での使用例は、この調査の検索では見つからなかった（動的 LCA は時間領域の畳み込みを直接使う。TH-S1-06）。

### 4 主要方程式・数学的原理・成立条件

係数の減り方は関数の滑らかさで決まる：跳びがあれば |c_k| は 1/k、連続で折れがあれば 1/k^2 の速さである（一般則は出典未確認（調査担当の知識）。周期ベルヌーイ関数については DLMF 式 24.8.3 が B~_n(x) = -n!/(2 pi i)^n sum_{k!=0} e^{2 pi i k x}/k^n を与え、n=1 は 0<x<1、n>=2 は 0<=x<=1 で成り立つ）。跳びのある点では級数は (f(x-)+f(x+))/2 に収束し、収束は一様でない（DLMF §1.8。条件は f が絶対可積分で、その点に左右の微分係数があること）。跳びのすぐ隣では打ち切り和が跳びの約 0.0895 倍だけ行き過ぎ、項数を増やしても行き過ぎの大きさは減らない（ギブス現象。走り書き検算で K=400 のとき 0.08949）。跳びから距離 delta（x の単位）だけ離れた点での K 項打ち切りの誤差は 1/(2 pi K delta) の大きさである（出典未確認（調査担当の知識）。検算の 95％点は K=16、64、256 で 0.072、0.019、0.0049 で、1/K に比例した）。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、対象が少数の調和成分で表せる場合と、畳み込みを積に置き換えられる場合である。回数関数は跳びを持つので係数が 1/k でしか減らず、K 項の打ち切りでは、T'/c が整数から遠い行では誤差が 1/K で減るが、整数に近い行では 1/2 近くの誤差が残る（検算：一様な位相で K=4〜256 のどれでも最大誤差は 0.48〜0.50）。T'/c がちょうど整数の行（T=60、c=15 など）では、打ち切り和は K によらず N+1/2 を返す（検算：x=4 で 3.5、基準は 3）。誤差の原因は、打ち切り（高い調和成分の欠落）と、不連続点での中点収束の 2 つである。回数の直接計算は ceil 1 回で済むので、フーリエ級数は計算量の面では得にならない（周期の値 1 つにつき K 回の三角関数）。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：N(T,c) ≈ T'/c - 1/2 + (1/pi) sum_{k=1}^{K} sin(2 pi k T'/c)/k。更新の排出は E ≈ sum_c U_c (T'/c - 1/2) + (1/pi) sum_{k=1}^{K} (1/k) Im( sum_c U_c e^{2 pi i k T'/c} ) と書ける（U_c は周期の値ごとの 1 回分の排出の合算）。これは K が有限なら近似で、厳密になるのは K→∞ かつ T'/c が整数でない場合だけである。F07（連続時間で書いた場合）：残存量は R(t) = m0 exp(-lambda c psi(t))、psi は位相（下記）で、交換で跳ぶので係数はやはり 1/k で減る。F05：年重みは w_y(T) = (T-y+1)_+ - (T-y)_+ で周期関数ではなく、フーリエ級数の対象にならない。F06：max(下限, g_0 - d k) は連続で折れがあるだけなので、周期化すれば係数は 1/k^2 で減るが、周期化の根拠がない。行ごとに基本周波数 1/c が違うので、周期の値が格子に乗らない限り、行をまたいだ共通の基底は無い（格子に乗る場合は TH-S1-02）。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】(a) 位相の導入：psi(T,c) = T'/c - N(T,c)（0 < psi <= 1。左連続の小数部分）を補助変数にすると、F04 は N = T'/c - psi、F07 の交換後の経過は c psi、F05 の年数と最終年の重みは Y - 1 = N(T,1)、w_Y = T - N(T,1) と書け、時間の規則はすべて「周期 c のくしの回数と位相」になる（F05 は c = 1 年の F04 である）。(b) 積分した量への書き換え：I_m(T,c) = sum_{n>=1} (T' - n c)_+^m は m >= 1 で連続になり、閉じた形 c^m [B_{m+1}(x) - B_{m+1}(psi)]/(m+1)（x = T'/c、B はベルヌーイ多項式）を持つ（検算：m = 0、1、2 で相対差 1.1e-13 以内）。その周期部分 B_{m+1}(psi) のフーリエ係数は 1/k^{m+1} で減り、m >= 1 では級数が一様に収束してギブス現象が起きない（検算：B_2 の K 項打ち切りの最大誤差は K=16 で 0.0061、K=256 で 0.00040）。したがって、回数そのもの（m=0）ではなく、年別・累積の系列（X-07）や修繕の年数のような積分量（m>=1）を変換の対象に取り直せば、フーリエ型の近似の誤差は一様に抑えられる。ただし回数そのものを復元するには微分に当たる操作が要り、1/k の減り方に戻る。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】のこぎり波のフーリエ級数は、ラプラス領域の核 1/(e^{sc}-1) の極による展開（1/(sc) - 1/2 + sum_{k>=1} 2 sc/((sc)^2 + 4 pi^2 k^2)。検算で数値確認）を逆変換したものであり、ポアソン和公式、オイラー・マクローリンの剰余項と同じ恒等式の別の書き方である。したがってフーリエ級数を独立の変換方式として数える必要は無く、TH-S1-03 の核の 3 つの展開の 1 つとして扱える。条件を変える案：(T, c) を刻み h の格子に限れば、有限項（q-1 項）の離散フーリエ和で回数が厳密になる（TH-S1-02）。打ち切りの重み（フェイエール和）は行き過ぎを消すが遷移の幅を広げる（検算：K=16 の 95％点は 0.072 から 0.14 に悪化）。四捨五入で整数に戻す案は、K=0 でも round(x - 1/2) = floor(x) が成り立つので、不連続な演算を別の場所へ移しただけであり、変換方式の削減にはならない（検算でも丸め後の誤りは 0 だが、それは丸めが床関数そのものだからである）。

### 限界

行ごとに周波数が違い、共通の基底が無い。T が c の倍数になる行（実務で多い組合せ）が最悪の場合で、K を増やしても 1/2 の誤差が消えない。計算量は直接計算より多い。丸めによる復元は床関数の言い換えである。ギブス現象の回復法（S-GS1997）は不連続点の位置を必要とし、この問題では不連続点の位置（c の倍数）を知ることが回数を知ることと同じなので循環する（独自の見解）。

### 主張の区別

- 【文献で実証済み】{x} = 1/2 - (1/pi) sum sin(2 pi k x)/k（x が整数でないとき）。不連続点では左右の平均に収束し、収束は一様でない（出典：S-WP-FLOOR、S-DLMF-24.8、S-DLMF-1.8）
- 【文献の記載（未読・要旨のみ）】有限フーリエ和の情報から、滑らかな区間ごとに高い精度で点の値を回復できる（ギブス現象の解消）（出典：S-GS1997）
- 【独自仮説】回数関数の K 項打ち切りは、T'/c が整数の行で K によらず N+1/2 を返す。一様な位相では 95％点の誤差が 1/K に比例する（走り書き検算、作成者のみ）（出典：なし）
- 【独自仮説】積分量 I_m（m>=1）は c^m [B_{m+1}(x) - B_{m+1}(psi)]/(m+1) で厳密に表せ、周期部分のフーリエ級数は一様収束する（出典：S-DLMF-24.8）

### 実験の案

- 架空シナリオの更新の排出（B4-02 の合計）を K = 0、4、16、64、256 の打ち切りで計算し、行を「T が c の倍数」「それ以外」に分けて誤差の符号つき平均・95％点を測る。倍数の行で誤差が U_c/2 に張り付かなければ、この項の主張（中点収束）は反証される。
- 年別・累積の系列（X-07 に相当）を、積分量の閉じた形（ベルヌーイ多項式）と、その周期部分の K 項打ち切りの両方で作り、基準の by_year の累積と比べる。打ち切りの最大誤差が (1/pi^2) sum_{k>K} 1/k^2 を超えたら反証。
- 評価点を格子の半刻みだけずらす再構成（N = floor((p - 1/2)/q)）で、必要な項数 K と誤差の関係を測る。K が q の数倍で誤差 0.5 未満にならなければ反証。

## TH-S1-02　離散フーリエ変換・高速フーリエ変換（格子上の有限フーリエ展開）

- 英語名：Discrete Fourier transform / FFT (finite Fourier expansion on a lattice)　／　族：時間軸の離散変換（巡回群の調和解析）
- 関連度：中（格子の仮定の下で回数が有限項で厳密になることを示す根拠になる。ただし独立の変換方式としてではなく、有理母関数（TH-S1-04・05・12）の計算手段として使うのが筋である。）
- 扱う型：F04、F07、F05　／　厳密か近似か：T と c が共通の刻みの整数倍なら F04・F07（整数年周期）は厳密。格子に乗らない周期を丸めた場合は近似（境界の近くの行で回数が 1 ずれる）。F05 は内積の書き換えにとどまる。

### 1 何を意味する理論・方程式か

長さ n の列 x_0..x_{n-1} を X_k = sum_m x_m e^{-2 pi i k m/n} に写す可逆な線形写像で、定義域も値域も C^n である。巡回シフトを対角化し、巡回畳み込みを成分ごとの積に変える。FFT はこの写像を N log N の手間で計算する算法で、直接計算の N^2 回に対して 2 N log2 N 回未満の演算で済む（S-CT1965。検索結果の記載）。この研究にかかわる恒等式は、整数 m と正の整数 q についての、のこぎり波の有限フーリエ展開 ((m/q)) = (i/(2q)) sum_{k=1}^{q-1} cot(pi k/q) e^{2 pi i k m/q} である（S-BECK2003 式(3)。((x)) は整数でない x で {x} - 1/2、整数で 0）。連続のフーリエ級数と違い、項数が有限（q-1 項）で、打ち切りが無い。

### 2 なぜ開発され、何を解決するか

フーリエ級数を計算機で求める手間（N^2）を下げるために FFT が作られた（S-CT1965 の題名と検索結果の記載）。解決する問題は、スペクトルの計算と畳み込みの計算を、標本の数にほぼ比例する手間で行うことである。のこぎり波の有限展開は、デデキント和 s(a,b) = sum_{k mod b} ((ka/b))((k/b)) を余接の和 (1/(4b)) sum cot(pi k a/b) cot(pi k/b) に書き直すために使われてきた（S-BECK2003 式(2)(4)）。

### 3 どの分野でどう使われているか

ディジタル信号処理、多項式・多倍長整数の乗算、スペクトル法、確率分布の和の分布（畳み込み）の計算で使われる（一般的な用途。出典未確認（調査担当の知識））。数論では、格子点の数え上げ・デデキント和・フロベニウス問題に有限フーリエ展開が使われる（S-BECK2003 と、検索で見つかった関連論文の題名）。動的 LCA の道具は、時間分布の畳み込みを時間領域で直接行っており、FFT を使うという記載はこの調査では見つからなかった（S-MULLER2025）。

### 4 主要方程式・数学的原理・成立条件

S-BECK2003 式(3) の実部・虚部を取ると ((m/q)) = -(1/(2q)) sum_{k=1}^{q-1} cot(pi k/q) sin(2 pi k m/q) となる（独自の変形）。これから floor(m/q) = m/q - 1/2 + (1/2)[q が m を割り切る] + (1/(2q)) sum_{k=1}^{q-1} cot(pi k/q) sin(2 pi k m/q) が従う（独自の変形。検算：q <= 400、m <= 1500 で絶対差 5.3e-13 以内）。成り立つ条件は m と q が整数であること、すなわち T と c が共通の刻み h の整数倍（T = p h、c = q h）であることである。巡回畳み込みの定理は DFT(x ⊛ y) = DFT(x)·DFT(y) で、直線の畳み込みには長さ len(x)+len(y)-1 以上への 0 詰めが要り、足りないと折り返しが混ざる。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは畳み込み（n^2 → n log n）である。格子上の事象の系列 b_n = sum_{q | n} U_q は、周期ごとに倍数へ足し込めば sum_q P/q（P log P 程度）の手間で作れるので、ここでは FFT は要らない。FFT が効くのは、事象の系列と 1 回分のプロファイル（冷媒の減衰、年別の配分）との畳み込みを全年について一度に求める場合である。誤差は、厳密な演算では 0、浮動小数点では丸め（n log n に応じた増え方）だけである。周期が格子に乗らない行を格子へ丸めると、n c が T' か年の境界の近くにある行で回数や所属年が 1 ずれる。これが近似の誤差の原因になる。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04（格子上）：T = p h、c = q h のとき、基準の規則（n c < T' を数える）は N = floor((p-1)/q) になり、上の有限和で m = p - 1 として厳密に求まる。F07：整数年の周期 q なら年次の漏洩 l_y = m0 r rho^{(y-1) mod q}（rho = 1 - r）は周期 q の列で、長さ q の DFT で厳密に表せる。F05：年次量の列と年重みの内積であり、DFT にしても Parseval の式で同じ内積になるだけで得は無い。F06：周期性が無いので DFT の対象ではない（入力の列として扱う）。厳密なのは格子に乗る行で、格子に乗らない行は近似になる。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】長さ P（P h >= T の最大値）の時間の格子の上で、(1) 事象の系列 B = sum_c U_c·(周期 q_c のくし) を作り、(2) プロファイル（F04 は単位インパルス、F07 は等比の列、修繕は「事象の年を除く」箱）を畳み込み、(3) 累積和を取り、(4) 添字 p で読む、という 1 本の手順に F04・F07・修繕（B3-01）・年別と累積の系列（X-07）が入る。DFT の領域では (2) は積、(3) は k != 0 の成分に 1/(1 - e^{-2 pi i k/P}) を掛ける操作である。累積和は巡回でないので、直流成分（傾向の部分 T/c - 1/2）は解析的に分けて扱う必要がある。これは「多項式の部分＋周期の部分」というベルヌーイ多項式の分解（TH-S1-09）と同じ分け方である。全年の出力（by_year、T を変えた掃引）は 1 回の逆変換でまとめて得られる。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】DFT は Z 変換を 1 の冪根の上で評価したものであり、格子の仮定の下では回数の列は有理型の母関数 z^{q+1}/((1-z)(1-z^q)) を持つ（TH-S1-04、TH-S1-05）。したがって DFT を独立の変換方式とせず、「有理母関数の係数取り出し」の計算手段の 1 つに位置づけられる。条件の工夫：刻み h を 0.1 年や 1/12 年に取り、格子に乗らない行だけを「境界に近い行」として印を付けて直接計算で補正する混合にすれば、厳密さを保ったまま大半の行を 1 つの手順に入れられる（印の付く行の割合は測定が要る）。

### 限界

周期が実数で格子に乗らない行には厳密に使えない。回数だけなら直接計算のほうが速く、得になるのは全年の系列やプロファイルとの畳み込みをまとめて出す場合に限られる。累積和は巡回群の上の演算でないので、直流成分の扱いを別に決める必要がある。

### 主張の区別

- 【文献で実証済み】((m/q)) = (i/(2q)) sum_{k=1}^{q-1} cot(pi k/q) e^{2 pi i k m/q}（のこぎり波の離散フーリエ級数）（出典：S-BECK2003）
- 【文献の記載（未読・要旨のみ）】FFT は N^2 の演算を 2 N log2 N 未満に下げる（出典：S-CT1965）
- 【独自仮説】格子上では N = floor((p-1)/q) が q-1 項の有限和で厳密に求まる（走り書き検算、作成者のみ）（出典：S-BECK2003）

### 実験の案

- 架空シナリオの周期と評価期間が、刻み h = 1、0.5、0.1、0.01 年の格子に乗る行の割合を数える。h = 0.1 で乗らない行が多数なら、格子による統合の前提が崩れる。
- 周期を格子へ丸めた場合の B4-02・B1-02 の誤差を測り、境界に近い行（n c と T' または年の境界との距離が h 未満）だけを直接計算に置き換えた混合で相対差 1e-9 以内になるかを確かめる。ならなければ反証。
- 事象の系列とプロファイルの畳み込み→累積和→読み出しの 1 本の手順で B4-02、B1-02、B3-01 の by_year を作り、基準の by_year と要素ごとに比べる。

## TH-S1-03　ラプラス変換（遅延項 exp(-sc)、周期インパルス列 1/(1-exp(-sc)) を含む）

- 英語名：Laplace transform (delay terms, periodic impulse trains, numerical inversion)　／　族：時間軸の積分変換（片側・因果的な信号）
- 関連度：高（F04〜F07 を 1 つの核 1/(e^{sc}-1) と遅延・積分器の原子で書ける見通しを与え、列挙・フーリエ・オイラー・マクローリンを同じ核の展開として 1 つにまとめる根拠になる。）
- 扱う型：F04、F05、F06、F07　／　厳密か近似か：変換の領域の式と、原子ごとの解析的な逆変換は F04・F05・F06・F07（階段の率で書いた場合）で厳密。数値逆変換（ゲイバー・ステフェスト、オイラー、タルボット）は回数関数に対して近似で、傾向の部分しか再現しない。連続時間の減衰で F07 を置き換えるのは近似。

### 1 何を意味する理論・方程式か

t >= 0 の関数（または超関数）f を F(s) = int_0^inf f(t) e^{-st} dt に写す変換で、値域は右半平面で解析的な関数である。主な対応は、積分が 1/s、遅延 f(t-a)H(t-a) が e^{-as} F(s)、畳み込みが積、である（教科書の標準的な性質。出典未確認（調査担当の知識））。周期 T0 の関数の変換は (1/(1 - e^{-s T0})) int_0^{T0} e^{-st} f(t) dt である（S-PROOFWIKI-LP。出典は Spiegel 1965 の Theorem 1-14）。事象の列 sum_{n>=1} delta(t - n c) の変換は e^{-sc}/(1 - e^{-sc}) = 1/(e^{sc} - 1) で、回数関数の変換は 1/(s (e^{sc} - 1)) になる（独自の計算。等比級数）。逆変換（ブロムウィッチ積分）は跳びの点で左右の平均を返す。

### 2 なぜ開発され、何を解決するか

線形の常微分方程式の初期値問題や回路の過渡応答を、代数の計算に変えるために使われるようになった（経緯は出典未確認（調査担当の知識））。経済の分野では、割引率を s とすると、キャッシュフローの現在価値がそのラプラス変換に一致することが指摘されている（S-GRUBB1967、S-BUSER1986。要旨・検索結果の水準で確認）。解決する問題は、遅れ・蓄積・減衰・繰り返しを含む線形の時間発展を、s の有理式と指数関数の積として閉じた形で扱うことである。

### 3 どの分野でどう使われているか

制御工学（伝達関数）、回路解析、待ち行列と再生理論（分布の変換）、熱伝導、薬物動態で使われる（一般的な用途。出典未確認（調査担当の知識））。待ち行列などの確率モデルでは、変換の数値逆変換が実用の計算手段になっている（S-AW2006）。台形則をブロムウィッチ積分の変形した積分路に適用する逆変換（タルボットの積分路など）は、点の数 n に対して O(e^{-1.90 n})〜O(e^{-2.72 n}) の速さで収束する（S-TW2014 の表 15.1）。経済性の評価では現在価値の計算に対応する（S-GRUBB1967、S-BUSER1986）。

### 4 主要方程式・数学的原理・成立条件

核 K_c(s) = 1/(e^{sc} - 1) には 3 つの展開がある。(i) 等比級数 sum_{n>=1} e^{-n s c}（Re s > 0）：項ごとに逆変換すると事象の列挙になり、厳密である。(ii) s = 0 のまわりのローラン展開 1/(sc) - 1/2 + sc/12 - (sc)^3/720 + …（ベルヌーイ数の母関数。S-MAHAJAN が sum = 1/(e^D - 1) = 1/D - 1/2 + D/12 - D^3/720 + … を示す）：傾向の部分 T/c - 1/2 を与える。(iii) 極による展開 1/(sc) - 1/2 + sum_{k>=1} 2 sc/((sc)^2 + 4 pi^2 k^2)（出典未確認（調査担当の知識）。検算で x = 0.7、20 万項のとき絶対差 1.8e-7）：s = 2 pi i k/c の極の留数 e^{2 pi i k T/c}/(2 pi i k) の和がのこぎり波のフーリエ級数になる。1/(s(e^{sc}-1)) の s = 0 の 2 位の極の留数は T/c - 1/2 である（独自の計算）。数値逆変換の枠組みは f(t) ≈ (1/t) sum_k omega_k F(alpha_k/t) である（S-AW2006）。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、畳み込み・蓄積・繰り返しが s の式の積になり、項ごとに閉じた形で逆変換できる場合である。数値逆変換は、変換の特異点がすべて負の実軸にあり、元の関数が t > 0 で無限回微分できる「良い変換」に対して、ゲイバー・ステフェスト法で約 0.90 M 桁（必要な計算精度は約 2.2 M 桁）の精度が得られると報告されている（S-AW2006）。同じ文献は、近似式が連続関数なので不連続点の近くでは良い近似になり得ないこと、良い変換以外では精度が変換に依存することを述べている。回数関数の変換は虚軸上に極を持ち、元の関数は階段なので、この「良い変換」に入らない。検算では、ステフェスト法（12 項、倍精度）は T=60、c=7 で 8.0715（基準 8、T/c - 1/2 = 8.0714）、T=60、c=15 で 3.5001（基準 3）を返し、s = 0 の極の寄与（傾向の部分）だけを再現した。誤差の原因は、逆変換の不良設定性、丸めの増幅、虚軸上の極（振動成分）を実軸上の標本では分解できないことである。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：更新の排出の変換は E^(s) = (1/s) sum_c U_c/(e^{s c} - 1) で、変換の領域では厳密な恒等式である。F05：年 y の率 h_y = q_y g_y を区間 (y-1, y] で一定とすると、累積は E(T) = int_0^T h(t) dt = sum_y w_y h_y に厳密に一致する（w_y = min(1, T-(y-1)) は区間と (0,T] の重なりの長さだから）。その変換は (1/s^2) sum_{k>=0} (h_{k+1} - h_k) e^{-s k}（h_0 = 0）で、逆変換は E(T) = sum_k (h_{k+1} - h_k)(T - k)_+ である（検算：相対差 2.1e-15）。F06：g(k) = g_0 - d k + d (k - k*)_+（k* = (g_0 - 下限)/d）は g_0/s - d/s^2 + d e^{-s k*}/s^2 に対応し、max による折れが遅延つきの 2 重積分器になる（検算：絶対差 1.5e-15）。F07：基準計算は年単位の規則（漏洩 = 年初の残存量 × r × w_y）なので、連続時間の指数減衰 e^{-lambda t} とは一致しない。年次の率 l_y = r R_y を階段の率として F05 の形に入れれば厳密になる。厳密なのは F04・F05・F06 と階段の率で書いた F07、近似になるのは数値逆変換を使う場合と連続時間の減衰で置き換える場合である。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】F04〜F07 の時間についての出力は、変換の領域で sum_j alpha_j e^{-s tau_j}/s^{m_j+1} の形（遅延と積分器の積。m=0 は階段、m=1 は傾斜）に書ける。これに対する逆変換は 1 本の式 Phi(T) = sum_j alpha_j (T - tau_j)_+^{m_j}/m_j!（m=0 は tau_j < T' のとき 1 とする厳密な不等号）である。評価単位の違いは原子の一覧 {(alpha_j, tau_j, m_j)} というデータだけになる：更新は (e_i, n c_i, 0)、年重み付き和は (h_{k+1} - h_k, k, 1)、修繕は事象の年で 0 になる率の差分、冷媒の漏洩は年次の率 r R_y の差分である。検算では、この 1 つの関数で更新・年次量×係数・修繕（更新年を除く）・冷媒の漏洩の 4 種を、基準の規則を書き写した総当たり計算と相対差 2e-14 以内で再現した（作成者のみの確認。基準計算そのものは実行していない）。ただし原子を作る前処理（n c の列挙、R_y の漸化式）が残り、手順書 5 節の 4 により変換方式とは別に数える必要がある。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】(a) 周期化を演算子の中へ入れる：核 1/(e^{sc}-1) を掛けた原子の逆変換は sum_{n>=1} (T' - n c)_+^m/m! = c^m [B_{m+1}(x) - B_{m+1}(psi)]/(m+1)!（x = T'/c、psi = x - N）で閉じる（検算：m <= 2）。これで列挙の前処理が消え、非線形の要素は位相 psi（のこぎり波）1 つになる。(b) 極の移動：1/(s + lambda)^{m+1} を許すと連続時間の減衰が同じ族に入る。(c) s = 0 への制限をやめる：窓を掛けた信号の変換を s = 割引率で評価すれば現在価値（ライフサイクルコスト）になり、s → 0 の極限が排出の合計である。LCA と LCC を同じ演算子で扱える。(d) フーリエ級数・ポアソン和公式・オイラー・マクローリンは核の展開 (iii)(ii) に当たるので、この族の中の計算の選び方であり、別の変換方式として数えなくてよい。

### 限界

数値逆変換は階段関数を分解できない（検算で T=60、c=15 のとき 3.5001、基準 3）。行についての和 sum_c U_c/(e^{sc}-1) は、周期の値の数だけ項が残り、変換だけでは圧縮されない。年次の表（任意の列）は原子の数が年数だけ要る。値の側の非線形（買電量の max(0, ·)、端材率の 1/(1-r)）は時間の変換の対象ではない。

### 主張の区別

- 【文献で実証済み】周期関数のラプラス変換は (1/(1 - e^{-sT})) × 1 周期分の積分（出典：S-PROOFWIKI-LP）
- 【文献で実証済み】数値逆変換は、特異点が負の実軸にあり元の関数が無限回微分できる変換に対して約 0.90 M 桁の精度を出す。近似式は連続なので不連続点の近くでは良い近似にならない（出典：S-AW2006）
- 【文献の記載（未読・要旨のみ）】現在価値はキャッシュフローのラプラス変換に一致する（出典：S-GRUBB1967、S-BUSER1986）
- 【文献で実証済み】sum = 1/(e^D - 1) = 1/D - 1/2 + D/12 - D^3/720 + …（演算子の形のオイラー・マクローリン。著者は類推による導出と断っている）（出典：S-MAHAJAN）
- 【独自仮説】F04〜F07 の時間の出力は遅延×積分器の原子の和で書け、1 本の逆変換の式で厳密に求まる（走り書き検算、作成者のみ）（出典：なし）
- 【独自仮説】核 1/(e^{sc}-1) の 3 つの展開（等比・ローラン・極）が、列挙・傾向の近似・フーリエ級数に対応する（出典：S-MAHAJAN、S-DLMF-24.8）

### 実験の案

- 原子の一覧だけを入力とする 1 本の評価関数 Phi で B4-02、B3-01、B1-02、B5-01、B6-03、B7-04、X-11 の合計を作り、基準計算と相対差 1e-9 で比べる。周期が 1 年未満で 1 年に複数の事象が入る行、最終年に事象が入る行、T が整数でない場合を必ず含める。1 つでも原子で書けない単位があれば「1 本の式」の主張は反証される。
- E^(s) = (1/s) sum_c U_c/(e^{sc}-1) をゲイバー・ステフェスト、オイラー、タルボットで数値逆変換し、基準の更新の排出と比べる。誤差が sum_c U_c (psi_c - 1/2)（近似 − 基準） に一致すれば「数値逆変換は傾向の部分だけを返す」ことの確認になり、一致しなければこの説明は反証される。
- 周期化した原子の閉じた形（ベルヌーイ多項式、m <= 2）で列挙の前処理を置き換え、原子の数と計算時間、基準との差を測る。

## TH-S1-04　Z 変換（定数係数の線形漸化式、周期的なリセットを含む）

- 英語名：Z-transform (linear constant-coefficient recurrences, periodic reset)　／　族：時間軸の離散変換（因果的な列）
- 関連度：高（F07（リセットつきの等比の漸化式）を厳密に扱える唯一の標準的な枠であり、格子の上では F04〜F06 も同じ有理式の族に入るので、1 演算子への統合の核になる。）
- 扱う型：F04、F05、F06、F07　／　厳密か近似か：年（または刻み h）の格子の上で F04・F05・F06・F07 のすべてが厳密。周期が有理数なら事象の年の並びも周期的で厳密。周期が格子に乗らない実数のときは、列挙（厳密）か丸め（近似）になる。

### 1 何を意味する理論・方程式か

列 x[n]（n >= 0）を X(z) = sum_n x[n] z^{-n} に写す変換で、値域は収束域で解析的な関数（ローラン級数）である（S-WP-ZT）。主な対応は、k だけの遅延が z^{-k} の積、累積和が 1/(1 - z^{-1}) の積、後退差分が (1 - z^{-1}) の積、a^n x[n] が X(z/a)、畳み込みが積、である（S-WP-ZT の性質の表）。定数係数の線形差分方程式は多項式の比 H(z) = B(z)/A(z)（伝達関数）になる。時間領域の列の積（項ごとの積）は、変換の領域では複素積分による畳み込みになる（S-WP-ZT）。標本化した信号のラプラス変換で z = e^{sT0} と置いたものに当たる（S-WP-ZT の starred transform の記述）。

### 2 なぜ開発され、何を解決するか

標本値系（サンプル値制御）の解析のために 1947 年に Hurewicz らが再導入し、1952 年に Ragazzini と Zadeh が z 変換と名づけ、Jury が拡張した（S-WP-ZT）。考え方そのものは母関数として 1730 年の de Moivre にさかのぼり、Laplace も知っていた（S-WP-ZT）。解決する問題は、差分方程式で書かれた離散時間の系を、連続時間のラプラス変換と同じ代数の手順（極と零点、部分分数）で扱うことである。

### 3 どの分野でどう使われているか

ディジタルフィルタの設計、離散時間の制御、時系列の自己回帰移動平均モデル、確率母関数として使われる（S-WP-ZT と一般的な用途）。逆変換の方法は、留数による周回積分、冪級数への展開、部分分数展開と表引きの 3 つである（S-WP-ZT）。建築 LCA の更新・冷媒の計算に Z 変換を使った例は、この調査の検索では見つからなかった。

### 4 主要方程式・数学的原理・成立条件

y[n] = sum_k b_k x[n-k] - sum_{k>=1} a_k y[n-k] は Y = (B/A) X と同値である（S-WP-ZT）。極の位置が列の型を決める：z = 1 の m 位の極は m-1 次の多項式、1 の q 乗根の極は周期 q の列、z = rho の極は等比 rho^n を与える（標準的な事実。出典未確認（調査担当の知識））。以下は母関数の変数（z^{-1} を z と書く）での独自の計算である。格子上の回数：sum_{p>=0} N(p,q) z^p = z^{q+1}/((1-z)(1-z^q))（検算：q = 1〜40、p <= 300 で完全一致）。整数年の周期 c で交換する冷媒の年次の漏洩：sum_y l_y z^y = m0 r z (1 - rho^c z^c)/((1 - rho z)(1 - z^c))、rho = 1 - r（検算：絶対差 3.8e-14）。下限つきの直線低下：g_0/(1-z) - d z/(1-z)^2 + d z^{K+1}/(1-z)^2 + d (K - k*) z^K/(1-z)、K = ceil(k*)、k* = (g_0 - 下限)/d。成り立つ条件は、時間が共通の刻みの格子に乗ることと、係数が時間によらないことである。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、次数 r の漸化式として 1 項あたり r 回の演算で列を作れること、部分分数で閉じた形が得られること、行列の冪で n 項目を log n 回の行列の積で求められること（後者は出典未確認（調査担当の知識））である。誤差は有理数の演算では 0 である。浮動小数点では、単位円上の重複した極（累積和、多項式の成長）で丸めが積み上がる。分母 prod_c (1 - z^{q_c}) を展開して 1 本の高次の漸化式にすると係数が大きくなり条件が悪くなるので、周期ごとの並列の形（因数のまま）で持つ必要がある（独自の見解。測定が要る）。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F07：補充しない機器の R_{y+1} = rho R_y は 1 次の差分方程式で、整数年の周期 c の交換は「年 n c の終わりに m0 (1 - rho^c) を注ぎ足す入力」として同じ方程式に入る。年初の残存量は R_y = m0 rho^{(y-1) mod c} になる。評価期間の漏洩の合計は sum_y w_y r R_y（F05 の形）で、最終年の按分は基準の規則どおり w について 1 次である。更新時の漏洩（B1-03）は、交換の直前の残存量が m0 rho^{直前の交換からの年数} なので、整数年の周期なら 回数 × m0 rho^c × 損失率 × GWP になる。周期が整数でない場合、事象の属する年 ceil(n c (1-1e-9)) の並びは c が有理数 a/b のとき a 年を周期として繰り返すので、分母 (1 - z^a) の有理式で厳密に書ける（検算：周期が実数の場合も、交換の年の集合から作る閉じた形で相対差 2.2e-12）。F04・F05・F06 は上の有理式で厳密である（F06 は折れの位置 K までの過渡の項を持つ）。近似になるのは、周期が格子に乗らず、事象の年の並びが周期的にならない場合を有理式で打ち切るときだけである。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】格子の上では、F04〜F07 のどの列も「有理式 B(z)/A(z) のインパルス応答」である。したがって 1 つの演算子「係数の組 (B, A) を受け取り、漸化式を p ステップ進めて p 番目の値を返す」に入れられる。行についての和は並列接続（有理式の和）、プロファイルとの畳み込みは直列接続（有理式の積）、年次量と係数の項ごとの積はアダマール積で、定数係数の漸化式を満たす列の集まりは和・コーシー積・アダマール積で閉じている（S-KT2022 の定理 9 の記載。検索結果の水準で確認）。年次の表（任意の値の列）は分子の多項式 B(z) = sum_y h_y z^y として同じ演算子に入る。評価期間が整数でない場合は、整数年までの状態 x_{Y-1} に、最終年の遷移を I + w_Y (M - I) として掛ける（蓄積も R_{Y+1} = R_Y (1 - r w) も w について 1 次だから。独自の導出）。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】Z 変換は、標本化した信号のラプラス変換（z = e^{s h}）、通常型の母関数（z ↔ 1/z）、DFT（単位円上の評価）と同じ変換の別の表示である（S-WP-ZT が 3 つの関係を述べる）。したがって格子の仮定の下では、ラプラス・Z・母関数・DFT を 1 種類と数えられる。成立条件の工夫：(a) 年によって変わる係数（電力の係数）は LTI の外だが、アダマール積で同じ族に入る。(b) 最終年の按分は読み出しの 1 次補間に追い出せる。(c) 実数の周期は、有理数への丸めと「境界に近い行」の個別の補正で扱う。max(下限, ·) を別の半環（max と + の代数）の線形演算と見て同じ行列積の枠に入れる案は、この観点の範囲の外であり、仮説として記録するにとどめる。

### 限界

周期の値の種類が増えると次数（状態の数）が増える。明示の事象年の一覧を持つ行は有限長の入力になり、圧縮されない。事象の属する年の規則（許容幅 1e-9 つきの ceil）を係数の作り方に正しく写す必要がある。係数が時間で変わる部分は、アダマール積か時変の行列積になり、単純な伝達関数ではない。

### 主張の区別

- 【文献で実証済み】遅延は z^{-k}、累積和は 1/(1 - z^{-1})、畳み込みは積、a^n x[n] は X(z/a) に対応する。差分方程式は有理の伝達関数になる（出典：S-WP-ZT）
- 【文献で実証済み】z 変換は 1947 年に Hurewicz が再導入し、1952 年に Ragazzini と Zadeh が名づけた。考え方は de Moivre の母関数（1730 年）にさかのぼる（出典：S-WP-ZT）
- 【文献の記載（未読・要旨のみ）】定数係数の漸化式を満たす列は和・コーシー積・アダマール積で閉じている（出典：S-KT2022）
- 【独自仮説】格子上の回数・冷媒の年次の漏洩・下限つきの直線低下は、上に書いた有理式を母関数に持つ（走り書き検算、作成者のみ）（出典：なし）

### 実験の案

- 状態空間（または有理式の係数）だけをデータとして、B1-02・B1-03・B1-04 を整数年の周期、有理数の周期（7.5 年、12.5 年など）、明示の交換年の一覧について作り、基準計算と相対差 1e-9 で比べる。有理数の周期で事象の年の並びが予測と違えば反証。
- 周期の値の種類を 5、20、100 と増やし、分母を展開した 1 本の漸化式と、周期ごとの並列の形とで、倍精度の誤差の増え方を比べる。
- 年次量（直線）× 電力の係数（下限つきの直線低下）のアダマール積を、次数 3 以下の有理式＋折れまでの過渡の項として作り、sum_y w_y q_y g_y を再現できるか確かめる。

## TH-S1-05　母関数（通常型・指数型・ディリクレ級数、係数の取り出し、1/(1-z) による部分和、ランベルト級数）

- 英語名：Generating functions (ordinary, exponential, Dirichlet series; coefficient extraction; partial sums; Lambert series)　／　族：列の代数的な符号化
- 関連度：高（更新の排出を「時間軸の事象の系列 b（T によらない）＋前からの和」に分ける厳密な式を与え、評価期間の掃引・年別の系列・合計を 1 つの配列から読める形にする。）
- 扱う型：F04、F05、F06、F07　／　厳密か近似か：格子の上で F04〜F07 のすべてが厳密。F05 の最終年の按分は累積の列の 1 次補間として厳密。格子に乗らない周期を丸めた場合だけ近似。

### 1 何を意味する理論・方程式か

列 a_n を形式的冪級数 A(z) = sum_n a_n z^n に符号化し、列に対する操作を級数の代数の操作に置き換える方法である。通常型では、ずらしが z の積、部分和が 1/(1-z) の積、畳み込み（コーシー積）が級数の積に対応する（標準的な規則。S-WILF は取得に失敗したので出典未確認（調査担当の知識）。部分和の規則は検索結果の記載で確認）。ディリクレ級数 sum_n a_n n^{-s} では、積がディリクレ畳み込み（約数についての和）に対応する（同上）。ランベルト級数は sum_{n>=1} f(n) q^n/(1 - q^n) = sum_{m>=1} (f*1)(m) q^m で、係数が約数についての和になる（S-SCHMIDT2020 の定義式）。係数の取り出し [z^n] A(z) が読み出しの操作である。

### 2 なぜ開発され、何を解決するか

線形の漸化式を解くために de Moivre が 1730 年に導入した考え方である（S-WP-ZT の記載）。解決する問題は、数え上げ・漸化式・和の公式を、級数の四則と部分分数という一様な手順に置き換えることである。ランベルト級数は、約数についての和を持つ数論的関数を通常型の母関数として扱うために使われる（S-SCHMIDT2020 の要旨）。

### 3 どの分野でどう使われているか

組合せ論、算法の解析、確率論（確率母関数）、数論（ディリクレ級数、ランベルト級数）、統計物理（分配関数、転送行列）で使われる（一般的な用途。出典未確認（調査担当の知識））。列の型を当てて閉じた形を求める計算機代数の手順（多項式、定数係数の漸化式、ホロノミック）にも使われる（S-KT2022 の要旨）。建築 LCA の更新回数に母関数を使った例は、この調査の検索では見つからなかった。

### 4 主要方程式・数学的原理・成立条件

有理式の母関数を持つことと、定数係数の線形漸化式を満たすことは同値で、係数は a_n = sum_j（n の多項式）× gamma_j^n の形になる（標準的な定理。出典未確認（調査担当の知識））。極がすべて 1 の冪根なら列は準多項式（周期的に係数が変わる多項式）で、floor(n/q) = (n - (n mod q))/q はその例である（同上）。独自の計算：格子上の更新の排出を E(p) = sum_q U_q N(p,q) とすると、sum_p E(p) z^p = (z/(1-z)) sum_q U_q z^q/(1 - z^q) である。右辺の和はランベルト級数なので、E(p) = sum_{n=1}^{p-1} b_n、b_n = sum_{q | n} U_q が成り立つ（検算：周期 40 種、p <= 600 で絶対差 4.5e-13）。b_n は「格子の時刻 n に起きる更新の排出」で、評価期間 T によらない。成り立つ条件は、T と周期が共通の刻みの格子に乗ることである。

### 5 計算削減の仕組みと誤差の原因

b_n を 1 回作れば（周期ごとに倍数へ足し込む。手間は sum_q P/q）、どの評価期間についての合計も、年別の配列も、累積の系列も、b の前からの和として読める。評価期間を変える掃引や年別の系列（X-07）を何度も作る場合に、行についての和をやり直さずに済む。誤差は格子の上では 0 で、周期を格子へ丸めた場合に限り、境界の近くの行で回数が 1 ずれる。1 つの評価期間だけなら、周期の値ごとの直接計算（旧研究で分かっている U_c × N の和）と手間は変わらない。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：上の式で厳密（格子上）。F05：累積の列 C_Y = sum_{y<=Y} h_y の母関数は H(z)/(1-z) で、評価期間が整数でない場合の年重み付き和は、C の隣り合う 2 項の 1 次補間 E(T) = (1 - w_Y) C_{Y-1} + w_Y C_Y に厳密に等しい（sum_y w_y h_y = C_{Y-1} + w_Y h_Y だから）。F06：下限つきの直線低下は分母 (1-z)^2 の有理式＋過渡の項、段階的な系列は分母 (1-z) の有理式である。F07：分母 (1 - rho z)(1 - z^c) の有理式である（TH-S1-04）。厳密なのは格子の上のすべてで、近似は格子へ丸める場合だけである。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】1 つの演算子「有理式の母関数の係数の取り出し [z^p] B(z)/A(z)」に、F04・F05・F06・F07 が入る。周期をまたいだ統合には 2 変数の母関数 G(z, u) = sum_q U_q u^q z^{q+1}/((1-z)(1-z^q)) を使え、建物のデータは周期ごとの重み U_q の列だけになる。周期の軸についてはディリクレ級数 D_U(s) = sum_q U_q q^{-s} が自然で、b = U * 1（ディリクレ畳み込み）は zeta(s) D_U(s) に対応する（TH-S1-10）。F01・F03 の行の和は「係数の総和＝母関数の z = 1 での値」として形式的には同じ枠に入るが、これは和を言い換えただけで、統合の実質は無い（正直な評価）。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】通常型の母関数は Z 変換・ラプラス変換、ディリクレ級数はメリン変換の離散版であり、母関数という名前の下に「加法的な畳み込み（時刻のずらし・蓄積）」と「乗法的な畳み込み（周期の拡大縮小）」の 2 つの構造がある。F04 はこの両方を持つ：事象は n c という加法的な位置に起き、回数は T/c という比だけで決まる。ランベルト級数は、加法的な母関数の係数が乗法的な畳み込み U * 1 になるという形で、2 つの構造をつなぐ。したがって「ランベルト型の作用素 U ↦ sum_q U_q P_q(z)/(1 - z^q)（P_q は 1 回分のプロファイル）に 1/(1-z) を続ける」という 1 つの作用素が、周期的な事象を持つ型（F04、F07、修繕、建替）に共通の候補になる。

### 限界

格子の仮定が要る。配列 b の長さは T の最大値／刻み で、刻みを細かくすると増える。周期の値が互いに通約できない実数で多数ある場合、ランベルト級数の形は厳密には使えない。係数の取り出しそのものは、漸化式を回すか部分分数に分けるかの計算で、母関数は記法であって計算手段を別に選ぶ必要がある。

### 主張の区別

- 【文献で実証済み】sum f(n) q^n/(1-q^n) = sum (f*1)(m) q^m（ランベルト級数の係数は約数についての和）（出典：S-SCHMIDT2020）
- 【文献の記載（未読・要旨のみ）】部分和の母関数は元の母関数に 1/(1-z) を掛けたもの（出典：S-WILF）
- 【独自仮説】格子上の更新の排出は E(p) = sum_{n<p} sum_{q|n} U_q（事象の系列 b = U*1 の前からの和）に等しい（走り書き検算、作成者のみ）（出典：S-SCHMIDT2020）
- 【独自仮説】sum_y w_y h_y は累積の列の 1 次補間 (1 - w_Y) C_{Y-1} + w_Y C_Y に等しい（出典：なし）

### 実験の案

- 架空シナリオの周期ごとの合算 U_q から b_n を作り、B4-02 の value と by_year、X-08 の合計を、評価期間を 1 年から 100 年まで掃引して基準と比べる。by_year の所属年（事象は ceil(tau(1-1e-9)) の年に置く）が合わなければ反証。
- 架空シナリオに現れる周期の値の種類と、それらが乗る最も粗い刻みを数える。
- 評価期間を多数変える場合について、行についての和のやり直しと、b の前からの和の読み出しの演算回数を比べる。

## TH-S1-06　畳み込みと畳み込み定理（事象のインパルス列とプロファイルの畳み込み、階段との畳み込みによる累積）

- 英語名：Convolution and the convolution theorem (impulse train * profile; cumulative sums as convolution with a step)　／　族：平行移動で不変な線形演算
- 関連度：高（動的 LCA の既存の方法と同じ演算であり、F04〜F07 を「データ * 核」に分ける厳密な書き方を与える。時間の軸と周期の軸の両方が畳み込みになるという見方は、変換方式の数を 1〜2 に絞る議論の土台になる。）
- 扱う型：F04、F05、F06、F07、F01、F09　／　厳密か近似か：F04・F05・F06・F07・修繕は畳み込みの式で厳密（F07 と修繕は年の格子の上）。周期の軸の乗法的な畳み込みも式としては厳密だが、対数の軸を等間隔の格子に載せて数値で畳み込むと、跳びの位置が格子に合わず近似になる。F01・F09 は内積の言い換え。

### 1 何を意味する理論・方程式か

2 つの関数（または列）f、g から (f*g)(t) = int f(tau) g(t - tau) d tau（離散では sum_k a_k b_{n-k}）を作る双線形の演算で、可換・結合的であり、デルタ関数が単位元である。ずらしたデルタとの畳み込みは平行移動、階段との畳み込みは累積（積分・前からの和）、くしとの畳み込みは周期化である。畳み込み定理は、変換（フーリエ、ラプラス、Z、DFT）が畳み込みを積に写すことを言う（Z 変換については S-WP-ZT。ディラックのくしについては、超関数の畳み込み定理がポアソン和公式になると S-WP-DIRAC が述べる）。「事象の列 × 1 回分のプロファイル」は y(t) = sum_n p(t - tau_n) = (くし * p)(t) と書ける。

### 2 なぜ開発され、何を解決するか

線形で時不変な系の応答が、入力と単位応答の畳み込みになることから使われる（重ね合わせの原理。出典未確認（調査担当の知識））。独立な確率変数の和の分布、再生方程式の解も畳み込みで書ける（再生方程式は S-WP-RENEWAL）。解決する問題は、「いつ起きるか」（入力の列）と「1 回で何が起きるか」（プロファイル）を分けて持ち、重ね合わせで全体を作ることである。

### 3 どの分野でどう使われているか

信号・画像のフィルタ、確率論、線形系の応答の計算で使われる（一般的な用途）。動的 LCA では、供給連鎖に沿って工程ごとの相対的な時間分布を畳み込み、中間フローの絶対時刻の系列を作る（S-MULLER2025。Cardellini らの Temporalis の方法を採用したと述べる）。同じ文献は、ESPA について「動的なインベントリは畳み込みと冪級数展開で導かれる」と述べる（S-MULLER2025 による S-ESPA2014 の説明）。動的な特性化では、時刻ごとのインベントリに時間依存の特性化係数を掛けて時間ステップについて足す（S-LEVASSEUR2010。検索結果の記載で、添字の付け方は未確認）。物質フロー分析の動的ストックモデルでは、年齢コホートごとに寿命を与え、寿命が尽きたときに使用段階を終える（S-WP-DSM）。

### 4 主要方程式・数学的原理・成立条件

存在の条件は可積分性（または総和可能性）で、畳み込み定理は両方の変換が共通の領域で存在するときに成り立つ（標準的な条件。出典未確認（調査担当の知識））。離散の場合、直線の畳み込みと巡回の畳み込みを区別する必要があり、台の長さは足し算になる。独自の整理：回数は N(T,c) = (くし_c * H0)(T')、H0 は厳密な不等号の階段。年重み付き和は E(T) = (h * H)(T)、h は年ごとに一定の率。冷媒の年次の漏洩は (交換の列 * 等比のプロファイル)(y) で、次の交換での打ち切りは「m0 (1 - rho^c) の注ぎ足し」という入力に書き直せる。下限つきの直線低下は g = (g_0 delta - d delta' 相当の組合せ) を 2 回累積したもの、すなわち疎なインパルスの列に H を 2 回畳み込んだものである。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、プロファイルを行ごとに持たず共通に 1 つ持てる場合（sum_i e_i (くし_{c_i} * p) = (sum_c U_c くし_c) * p）と、FFT で n log n にできる場合である。誤差は厳密な演算では 0 である。連続のプロファイルを格子に載せるときの離散化、長い裾の打ち切りが近似の誤差の原因になる。供給連鎖の全域に時間分布を持たせる動的 LCI については、プロセスの網が大きく時間の幅が広いと、時間情報を落とさない解析的な解は計算できないとする記載がある（S-DYNLCI-ESM。検索結果の記載で、本文は未読）。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：N = (くし_c * H0)(T')。年別の配列は、くしを事象の属する年ごとに集めたものである。F05：E(T) = (h * H)(T) で、最終年の按分は H との畳み込み（積分）が自動的に与える。F07：漏洩の列 = 交換の列 * 等比のプロファイル。更新時の漏洩（B1-03）は交換の列に「直前の残存量」を重みとして付けたもの、廃棄時の未回収量（B1-04）は終わりの時点の残存量の読み出しである。修繕（B3-01）：率 e0 r から、(事象の属する年のくし * 幅 1 年の箱) × e0 r を引いたものの累積である（事象の属する年が重ならない場合）。F06：疎なインパルスの列 * H * H。すべて厳密である（F07 と修繕は年の格子の上で）。近似になるのは、年によって変わる係数との積（畳み込みではなく項ごとの積）を畳み込みで代用しようとする場合である。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】(1) 時間の軸：どの型も「インパルスのデータ * 核」を T で読んだもので、核は H0（回数）、H*H（按分つきの蓄積）、等比の列（減衰）であり、後の 2 つは H またはその減衰つきの版の繰り返しの畳み込みである。(2) 周期の軸：行をまたいだ集計 sum_i e_i N(T, c_i) = int U(dc) phi(T'/c)（phi(x) = ceil(x) - 1）は、乗法的な畳み込みである。u = ln T、v = ln c と置けば普通の畳み込み (U∘exp) * (phi∘exp) になる。(3) したがって、時間の蓄積も周期についての集計も「可換群の上の畳み込み＋1 点での読み出し」で、群が (R,+)、(Z,+)、Z_q、(R_+,×) と変わるだけである。フーリエ・Z・DFT・メリンはそれぞれの群での対角化に当たる。(4) F01・F03・F09 の和 sum_i a_i f_i は「畳み込み (a * f~) の原点での値」と書けるが、これは内積の言い換えである。この言い方が手順書 5 節の「1 つの演算子」と認められるには、群の違いを添字の計算というデータだけで表し、コードの経路を 1 本にする必要がある。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】周期的な事象の列は、1 回のずらし delta_c の等比級数 くし_c = sum_{n>=1} delta_c^{*n} = delta_c * (delta - delta_c)^{-1} であり、畳み込みの代数の中での逆元（ノイマン級数）である。したがって必要な演算は「畳み込み」と「畳み込みについての逆元」の 2 つで、ずらしの有理式の全体が 1 つの代数になる（変換の領域では s または z の有理式と指数関数）。再生方程式 m = F + m * dF の解が m = sum_n F^{n*} になるのと同じ構造で（S-WP-RENEWAL が方程式を示す）、再生理論（TH-S1-07）は確率的な寿命の場合への拡張に当たる。動的 LCA の特性化の核（時間依存の特性化係数）を掛ける拡張は、この枠に核を 1 つ足すだけで、変換方式は増えない。

### 限界

年によって変わる係数と年次量の積は、畳み込みではなく項ごとの積である。買電量の max(0, 消費 - (発電 - 売電)) のような値の側の非線形は畳み込みで書けない。1 年に複数の事象が入る行では、「事象の属する年を除く」修繕の規則が集合（重複を 1 回と数える）なので、くしと箱の畳み込みそのままでは合わない（集合への置き換えが要る）。

### 主張の区別

- 【文献で実証済み】動的 LCA（時間明示 LCA）は、工程ごとの相対的な時間分布を供給連鎖に沿って畳み込み、絶対時刻の系列を作る（出典：S-MULLER2025）
- 【文献の記載（未読・要旨のみ）】ESPA は動的なインベントリを畳み込みと冪級数展開で導く（出典：S-MULLER2025、S-ESPA2014）
- 【文献の記載（未読・要旨のみ）】動的 LCA の影響評価は、時刻ごとのインベントリ × 時間依存の特性化係数を時間ステップについて足す（出典：S-LEVASSEUR2010）
- 【独自仮説】F04〜F07 と修繕は「インパルスのデータ * 核」を T で読む形に書け、周期についての集計は対数の軸での畳み込みになる（出典：なし）

### 実験の案

- 「くし * プロファイル → 累積 → 読み出し」の 1 本の手順で B1-02、B3-01、B4-02、B5-01 の by_year を作り、基準の by_year と要素ごとに比べる。1 年に複数の事象が入る行（周期 1 年未満）で修繕が合わなければ、集合への置き換えが要ることの確認になる。
- ln c と ln T を等間隔の格子に載せ、U と phi の畳み込みを数値で計算して、基準の更新の排出との差を格子の細かさごとに測る。格子を細かくしても倍数の行で誤差が残れば、「対数の軸の数値畳み込みで厳密になる」という見込みは反証される。
- 核を 1 つ足す拡張（時間依存の特性化係数に当たる架空の核）で、演算子のコードを変えずにデータだけで計算できることを確かめる（基準が無いので整合の確認のみ）。

## TH-S1-07　再生理論（再生方程式、再生関数、ラプラス領域の解、初等再生定理、再生報酬定理）と取替・保全の計画

- 英語名：Renewal theory (renewal equation, renewal function, elementary renewal theorem, renewal-reward) and replacement / maintenance scheduling　／　族：繰り返し事象の確率モデル
- 関連度：高（F04 と F07 に最も近い既存の理論で、建築 LCA の文献（切り上げと年割りの比較）と直接つながる。確定的な寿命での厳密な閉じた形と、確率的な寿命による平滑化の族の両方を与える。）
- 扱う型：F04、F07、F05　／　厳密か近似か：確定的な寿命の数え上げと再生報酬の閉じた形は F04・F07・修繕・建替で厳密。初等再生定理・2 次の漸近式・年割り・確率的な寿命による平滑化は近似（T/c が 1〜6 と小さく、格子的な寿命では残りが減らない）。

### 1 何を意味する理論・方程式か

正の値を取る独立同分布の寿命 S_1, S_2, … の和で事象の時刻を定め、時刻 t までの事象の数 X_t を調べる理論である（S-WP-RENEWAL。寿命の分布は正の数の上の任意の分布でよい）。再生関数 m(t) = E[X_t] は再生方程式 m(t) = F_S(t) + int_0^t m(t-s) f_S(s) ds を満たす（S-WP-RENEWAL）。初等再生定理は lim m(t)/t = 1/E[S_1]、再生報酬定理は報酬の長期の平均率が E[W_1]/E[S_1] になることを言う（S-WP-RENEWAL）。変換の領域では m^(s) = F^(s)/(1 - F^(s))（F^ は寿命の分布のラプラス・スティルチェス変換）で、寿命が確定値 c なら F^(s) = e^{-sc}、m^(s) = 1/(e^{sc} - 1) となり、TH-S1-03 の核に一致する（標準的な結果と独自の計算。出典未確認（調査担当の知識））。確定的な寿命の場合、X_t = floor(t/c) で、期末を含めない数え方では N = ceil(t/c) - 1 である。

### 2 なぜ開発され、何を解決するか

自己更新する集団（人口）と工業設備の取替の問題から始まった。Lotka の 1939 年の論文は題名に「工業の取替への特別の言及」を持ち（S-LOTKA1939。題名と書誌のみ確認）、Feller の 1941 年の論文が再生理論の積分方程式を厳密に扱った（S-FELLER1941。書誌のみ確認）。解決する問題は、寿命がばらつく部品を取り替え続けるとき、ある期間の取替の数とその費用の期待値を求めることである。保全の分野では、故障時または一定の年齢に達した時に取り替える年齢取替と、故障と無関係に一定の間隔で取り替える一斉取替の方策が扱われる（S-BP1965 を引く Marshall & Proschan の論文の説明。検索結果の水準で確認）。

### 3 どの分野でどう使われているか

信頼性・保全（予備品の数、取替の費用率）、在庫、待ち行列、保険の破産理論、人口動態で使われる（一般的な用途と S-WP-RENEWAL）。S-WP-RENEWAL には、機械の寿命が [0, 2] 年の一様分布、故障時の費用 2600、予防取替の費用 200 のとき、費用率 E[W]/E[S] を最小にする取替の年齢が t = 2/3 になる例がある。建築 LCA では、評価期間 T と部材の耐用年数 t から取替の数を Roundup(T/t - 1) で求める方法（EN 15978 と整合し、DGNB の体系も定めると著者が述べる）と、1 回分の影響を年当たりにして (T - t) を掛ける「年割り」の方法が比べられている（S-FRANCART2021）。同じ文献は、年割りの方法が「端数つきの取替回数を使うことと同値」であると述べ、耐用年数 30 年・100 年の例で 3 回と 2.33 回を示す。耐用年数を確率分布として扱う建築 LCA・LCC の研究もある（S-GOULOUTI2020。検索結果の水準で確認）。

### 4 主要方程式・数学的原理・成立条件

m(t) = sum_{n>=1} F^{n*}(t)（F^{n*} は n 重の畳み込み。標準的な式で出典未確認（調査担当の知識））。寿命の分布が非格子的で 2 次モーメントが有限なら、U(t) = sum_{n>=0} F^{n*}(t) = t/mu + E[S^2]/(2 mu^2) + o(1) が成り立つ（S-RENEWAL-2ND などの検索結果の記載）。これから m(t) = t/mu + (sigma^2 - mu^2)/(2 mu^2) + o(1) となる（独自の書き換え）。確定的な寿命（sigma = 0、格子的）では定数項は -1/2 だが、o(1) は成り立たず、残りは 1/2 - psi（psi は位相）として永久に振動する（独自の計算）。主要再生定理は、非負・可積分・非増加の g について int_0^t g(t-x) m'(x) dx → (1/mu) int_0^inf g(x) dx を言う（S-WP-RENEWAL）。確定的な寿命での再生報酬の厳密な形は C(T) = N × (1 周期分の報酬) + (途中の周期の報酬(経過年数)) である（独自の整理）。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、事象を 1 つずつ模擬する代わりに、再生関数の閉じた形や漸近式で回数と費用を出せる場合である。誤差の原因は、(1) 漸近式を t/mu が小さい範囲で使うこと、(2) 格子的な寿命での振動する残り、(3) 期末の途中の周期の扱い、である。建物の部材では T/c は 1〜6 程度で、漸近定理の前提（t → ∞）から遠い。S-FRANCART2021 は、年割りの方法の結果が常に切り上げの方法以下になること、平均の差は小さいが、評価期間の終わりの直前に大きな取替がある場合に差が大きくなること（90 年目の取替が切り上げでは約半分を占め、年割りでは約 9 分の 1 になる例）を報告している。検算：位相が一様なら (ceil(x) - 1) - (x - 1) の平均は 1/2（標本で 0.489）、T = 60 で c = 10、15、20、30 のときは 0、c = 25、35、45 のときは 0.6、0.286、0.667 である。

### 6 建築 LCA のどの計算にどう適用できるか

F04 は確定的な寿命の再生過程の数え上げで、N(T,c) = ceil(T'/c) - 1 は S-FRANCART2021 の Roundup(T/t - 1) と同じ形である（独立概念モデルの式と文献の式の形が同じという意味で、道具どうしの一致を言うものではない）。【独自仮説】年割りの T/c - 1 は、c が T を割り切る行では切り上げと一致し、割り切らない行では 1 - psi だけ小さい。位相が一様なら平均 1/2 の負の偏りになる。偏りのない滑らかな式は T/c - 1/2（確定的な寿命の再生関数の漸近式）である。F07：1 周期の中の累積の漏洩を rho_cyc(a) = m0 (1 - rho^a) とすると、漏洩の合計 = sum_{完了した周期} m0 (1 - rho^{周期の年数}) + m0 (1 - rho^{a}) + m0 rho^{a} r w_Y（a は最終年の年初の経過年数）で、再生報酬の形になる（検算：周期が実数の場合を含めて相対差 2.2e-12）。修繕（B3-01）：修繕を計上する年数 = T - (事象の属する年の重みの和) で、周期が 1 年より長ければ T - N + (1 - w_Y)·[最終年に事象が属する] である。更新時の漏洩（B1-03）は事象の時点の報酬、廃棄時の未回収量（B1-04）は期末の経過年数で決まる終端の報酬である。以上は確定的な寿命について厳密で、滑らかな式（年割り、T/c - 1/2）は近似である。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】行ごとに（周期 c、事象 1 回の報酬 r_e、周期の中の累積の報酬 rho(a)、終端の報酬 kappa(a)）をデータとして与え、C(T) = N·(r_e + rho(c)) + rho(A) + kappa(A)、A = 経過年数、という 1 本の式にまとめる。F04 は rho = 0、F05 は c = ∞（事象なし）で rho(a) = int_0^a h、F07 は等比の rho、修繕は「率 × 経過年数 − 事象の年の穴」、B1-04 は kappa だけである。この形が厳密になるのは、周期の中の報酬が暦の年によらない場合である。独立概念モデルでは、更新・建替は初期と同じ係数を使い、年によって変わるのは電力の係数だけ（EQUATION_BRIEF の時間の取り決め）なので、周期を持つ行は暦によらず、暦による行（電力）は周期を持たない。この分かれ方のおかげで、再生報酬の形は F04・F07・修繕・建替について厳密になり得る。rho をコードではなくデータ（TH-S1-03 の原子の一覧、または TH-S1-04 の有理式の係数）で与えられれば、手順書 5 節の「単位の違いはデータだけ」を満たす。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】寿命を平均 c、ばらつき sigma の分布にすると、期待回数 m(T) は T と c について滑らかになり、sigma → 0 で階段に戻る。したがって「切り上げ」と「滑らかな近似」は 1 つの再生の演算子の 2 つの極限である。アーラン分布（次数 k）なら F^(s) = (k lam/(s + k lam))^k は有理式で、m^(s) も有理式になり、逆変換は指数関数と多項式の原子で閉じる。k → ∞ が確定的な寿命である。これは、滑らかさを 1 つのパラメータ k で調節できる変換の族で、誤差（倍数の近くでの階段のなまり。幅はおよそ c sqrt(n/k)）と滑らかさの釣り合いを測定できる。年割りの T/c - 1 は、定常な（位相が一様にばらついた）再生過程の期待回数 T/c から 1 を引いたもので、どの寿命の分布の漸近式 T/c + (sigma^2 - mu^2)/(2 mu^2)（定数項は -1/2 以上）にも当たらない（独自の見解）。

### 限界

漸近定理は建物の部材の回数（0〜6 回）の範囲では前提から外れる。確定的なデータに対して確率的な平滑化を使うと、T が c の倍数の行で基準より約 1/2 回多くなる。事象の属する年の規則（許容幅つきの ceil）と、1 年に複数の事象が入る場合の扱いを、閉じた形に正しく写す必要がある。暦によって変わる係数を周期のある行に掛ける拡張をすると、周期ごとの報酬が同じでなくなり、N × (1 周期分) の形が崩れる。

### 主張の区別

- 【文献で実証済み】再生方程式 m(t) = F_S(t) + int_0^t m(t-s) f_S(s) ds、初等再生定理 m(t)/t → 1/E[S_1]、再生報酬定理（平均率 E[W_1]/E[S_1]）（出典：S-WP-RENEWAL）
- 【文献で実証済み】建築 LCA の取替回数には、切り上げ Roundup(T/t - 1) と、年割り（端数つきの回数と同値）の 2 つの方法があり、年割りは常に切り上げ以下の結果を与える（出典：S-FRANCART2021）
- 【文献の記載（未読・要旨のみ）】非格子的で 2 次モーメント有限のとき、再生関数は t/mu + 定数 + o(1) の 2 次の展開を持つ（出典：S-RENEWAL-2ND）
- 【文献の記載（未読・要旨のみ）】Lotka 1939 と Feller 1941 が、工業の取替を含む再生理論の出発点である（出典：S-LOTKA1939、S-FELLER1941）
- 【独自仮説】年割り T/c - 1 は c が T を割り切る行で厳密、割り切らない行で 1 - psi だけ小さい。偏りのない滑らかな式は T/c - 1/2 である（走り書き検算、作成者のみ）（出典：S-FRANCART2021）
- 【独自仮説】F07・修繕・建替は、回数 N と経過年数 A の再生報酬の閉じた形で厳密に書ける（走り書き検算、作成者のみ）（出典：なし）

### 実験の案

- 行ごとのデータ（c、r_e、rho、kappa）だけから再生報酬の式で B1-02・B1-03・B1-04・B3-01・B4-02・B5-01 を作り、基準計算と相対差 1e-9 で比べる。周期が 1 年未満の行、最終年に事象が属する行、明示の事象年の一覧を持つ行を必ず含める。1 つでも合わない場合があれば、その規則を反例として記録する。
- 切り上げ、年割り（T/c - 1）、中心化した年割り（T/c - 1/2）の 3 つで更新の排出を計算し、周期が T を割り切る行の割合ごとに符号つきの誤差を測る。割り切る行で年割りの誤差が 0 でなければ反証。
- アーラン次数 k = 1、4、16、64、256 の期待回数で更新の排出を計算し、誤差の 95％点が k とともにどう減るか、T が c の倍数の行で約 U_c/2 の偏りが残るかを測る。

## TH-S1-08　ポアソン和公式（和と積分の関係、くしの双対、折り返し）

- 英語名：Poisson summation formula (sum versus integral, duality of combs, aliasing)　／　族：格子上の和の双対変換
- 関連度：中（独立の計算手段としては TH-S1-01 と同じ限界を持つが、「年割りの項＋境界の補正＋振動の補正」という誤差の内訳を与え、既存の 2 つの方法を 1 つの式に並べる説明の道具になる。）
- 扱う型：F04、F05　／　厳密か近似か：F04 は双対の項を無限に取った極限でのみ厳密（倍数の点を除く）。有限項は近似。F05 は多項式の年次量ならオイラー・マクローリンの有限項で厳密になり、ポアソン和公式は不要。

### 1 何を意味する理論・方程式か

関数 f の格子上の和を、そのフーリエ変換の双対の格子上の和に書き換える恒等式である：sum_{n} f(x+n) = sum_{n} e^{2 pi i n x} int f(t) e^{-2 pi i n t} dt（DLMF 式 1.8.14）。半直線の形は (1/2) f(0) + sum_{n>=1} f(n) = int_0^inf f(x) dx + 2 sum_{n>=1} int_0^inf f(x) cos(2 pi n x) dx である（DLMF 式 1.8.15）。右辺の n = 0 の項が積分（和を積分で置き換えた値）で、残りの項が補正である。超関数の言葉では「ディラックのくしのフーリエ変換は、間隔 1/T0 のディラックのくしである」という事実と同じである（S-WP-DIRAC）。

### 2 なぜ開発され、何を解決するか

和と積分の差、すなわち等間隔の標本による数値積分の精度を調べる中で見いだされた。台形則が周期的な解析関数に対して幾何級数的に収束する現象は、1820 年代に Poisson が最初に指摘したとされる（S-TW2014 の紹介。検索結果の記載）。解決する問題は、収束の遅い格子上の和を、収束の速い双対の和に変えること、および標本化で生じる折り返しを式で表すことである。S-TW2014 は Poisson の言葉として、オイラーの級数は初めの項では収束しても最後には発散して不正確になることがある、という趣旨を引用している。

### 3 どの分野でどう使われているか

数値解析では、台形則の値 I_h が I_h = 2 pi sum_j w^(2 pi j/h) と書け、真値 I = 2 pi w^(0) との差が j != 0 の項（折り返し）になる（S-TW2014 式(5.8)(5.9)）。信号処理では、くしを掛けることが標本化、くしとの畳み込みが周期化（折り返しの原因）になる（S-WP-DIRAC）。数論ではテータ関数の変換式に使われる（DLMF 式 1.8.16 がガウス関数の場合を与える）。メリン変換の立場では、ポアソン型の和公式とディリクレ級数の関数等式は一般に同値である（S-FGD1995 のペロンの公式の直前の段落）。

### 4 主要方程式・数学的原理・成立条件

DLMF 式 1.8.14 の条件は、f が 2 回連続微分可能で、f と |f''| が実軸全体で可積分であること。DLMF 式 1.8.15 の条件は、f が [0, ∞) で連続かつ有界変動で可積分、x → ∞ で 0 に近づくこと。S-TW2014 は、ポアソン和公式は通常もっと厳しい仮定の下で述べられると注意している。窓が階段（区間 [0, T) の指示関数）の場合はこれらの条件を満たさず、双対の和は 1/k でしか減らない。その結果が、のこぎり波のフーリエ級数 N = T'/c - 1/2 + (1/pi) sum sin(2 pi k T'/c)/k（倍数でないとき）である（独自の当てはめ）。滑らかでない被積分関数では台形則の収束は代数的で、オイラー・マクローリンの展開 I_N - I ~ h^2 (B_2/2!)[v'(2 pi) - v'(0)] + h^4 (B_4/4!)[v'''(2 pi) - v'''(0)] + … が誤差を与える（S-TW2014 式(10.1)）。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、f^ が速く減る（f が滑らか）場合で、N 項の和を「積分＋少数の双対の項」で置き換えられる。解析的な関数なら双対の項は指数的に小さい（S-TW2014 の定理 3.2 と 5 節）。窓が階段の場合は双対の項が 1/k でしか減らず、得にならない（TH-S1-01 と同じ誤差）。窓の縁を幅 eps だけ滑らかにすると双対の項は速く減るが、n c が T から eps 以内にある行の回数が端数になり、そこに誤差が集まる。誤差の原因は、双対の和の打ち切りと、窓の滑らかさと鋭さの釣り合いである。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：回数は sum_{n>=1} 1[n c < T'] という「窓を掛けた格子上の和」で、ポアソン和公式の n = 0 の項が T'/c（年割りに当たる項）、境界の補正が -1/2、双対の項が振動の補正である。双対の項を K 個で打ち切ると TH-S1-01 の近似になり、K = 0 が中心化した年割り T/c - 1/2、K → ∞ が切り上げである。F05：年次量が滑らかな関数 h(t) の整数点の値なら、sum_y h(y) と int h の差は端点の補正（オイラー・マクローリン）で、多項式の場合は有限項で厳密になる。ポアソン和公式の双対の項を使う必要はない。F06・F07 には直接の使い道が無い（F07 は等比級数で閉じる）。厳密になるのは K → ∞ の極限だけで、有限の K はすべて近似である。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】ポアソン和公式は「事象についての和 ＝ 積分（年割りの項）＋ 振動の補正」という分解を与える。したがって、建築 LCA の文献で比べられている 2 つの方法（切り上げと年割り。S-FRANCART2021）は、1 つの式の打ち切りの段数 K の両端として並べられる。F05 の年についての和も、間隔 1 年の格子上の和として同じ式の対象になる（c = 1）。すなわち F04 と F05 は「窓を掛けた関数の格子上の和」という同じ形で、格子の間隔が c_i か 1 年かが違うだけである。この見方は誤差の説明（どの項を落としたか）には使えるが、有限の K では厳密にならないので、完成モデルの変換方式にはならない。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】ポアソン和公式は、TH-S1-03 の核 1/(e^{sc}-1) の極による展開をフーリエの側から書いたものであり、オイラー・マクローリンの剰余項（周期ベルヌーイ関数）をフーリエ級数（DLMF 式 24.8.3）に展開したものでもある。3 つは同じ恒等式なので、別々の変換方式として数える必要は無い。周期について集計した和 sum_c U_c floor(T/c) に対しては、ディリクレの双曲線法が sum_{k<=x} floor(x/k) = 2 sum_{k<=sqrt x} floor(x/k) - floor(sqrt x)^2 のような厳密な書き換えを与え、演算は O(sqrt x) 回で済む（S-WP-HYPERBOLA）。ただしこれは U が一定の場合で、建物ごとに違う重み U_c には直接は使えない。集計した和にも滑らかな式では消せない振動の残りがあること（約数問題の誤差項。出典未確認（調査担当の知識））は、滑らかな近似だけでは厳密にならないことの数論の側の裏づけになる。

### 限界

階段の窓は公式の通常の条件（滑らかさ）を満たさず、双対の和は条件収束である。位相が一様にばらつくことを前提にした誤差の相殺は、周期が評価期間を割り切る行が多い母集団では起きない。倍数の点では中点に収束し、基準と 1/2 ずれる。

### 主張の区別

- 【文献で実証済み】ポアソン和公式（DLMF 式 1.8.14、1.8.15）とその成立条件（出典：S-DLMF-1.8）
- 【文献で実証済み】台形則の誤差は折り返しの和で、解析的な周期関数では指数的に、滑らかでない場合は代数的に減る。代数的な場合の展開はオイラー・マクローリンの式である（出典：S-TW2014）
- 【文献で実証済み】ディラックのくしのフーリエ変換はくしであり、標本化は折り返しを生む（出典：S-WP-DIRAC）
- 【独自仮説】切り上げと年割りは、ポアソン和公式の双対の項の打ち切りの段数 K の両端である（出典：S-FRANCART2021、S-DLMF-1.8）

### 実験の案

- 双対の項の数 K を 0 から 256 まで変えて更新の排出の誤差を測り、シナリオの種類（周期が T を割り切る行の割合）ごとに並べる。K = 0 の誤差が sum_c U_c (psi_c - 1/2)（近似 − 基準） に一致しなければ、この分解は反証される。
- 窓の縁を幅 eps = 0.01、0.1、0.5、1 年で滑らかにした回数で更新の排出を計算し、誤差の出る行の数と大きさを測る。
- 行の数 M を 10、100、1000、10000 と増やし、中心化した年割りの相対誤差が、位相がばらつく母集団で 1/sqrt(M) に近い減り方をし、位相がそろった母集団（周期が T を割り切る）で減らないことを確かめる。後者で減るなら、相殺が起きないという主張は反証される。

## TH-S1-09　オイラー・マクローリンの和公式（和と積分の差の補正項、アーベルの総和法、部分和分）

- 英語名：Euler–Maclaurin summation (sum versus integral with Bernoulli corrections; Abel summation; summation by parts)　／　族：和と積分の差の展開
- 関連度：高（F05 の閉じた形（旧研究で既知）を一般化し、F04 と周期的な事象の累積量を同じベルヌーイ多項式の原子で厳密に書けることを示す。非線形の要素を回数 N（または階段 H0）1 つに絞る議論の根拠になる。）
- 扱う型：F04、F05、F06　／　厳密か近似か：F05（一定・直線・下限つきの直線低下・段階的の組合せ）は区間ごとの冪の和で厳密。F04 と周期的な事象の累積量は切断冪の式で厳密。滑らかな打ち切り（端点の補正を有限項だけ取る近似）を F04 に使うのは近似で、誤差は psi - 1/2。年次の表は対象外。

### 1 何を意味する理論・方程式か

整数点での和と積分の差を、端点の微分係数とベルヌーイ数で表す式である：sum_{j=a}^{n} f(j) = int_a^n f(x) dx + (1/2) f(a) + (1/2) f(n) + sum_{s=1}^{m-1} (B_{2s}/(2s)!) (f^{(2s-1)}(n) - f^{(2s-1)}(a)) + int_a^n ((B_{2m} - B~_{2m}(x))/(2m)!) f^{(2m)}(x) dx（DLMF 式 2.10.1）。B~_n(x) = B_n(x - floor(x)) は周期ベルヌーイ関数で、剰余項に「のこぎり波の仲間」が現れる。1 次の形はアーベルの総和法 sum_{x<n<=y} a_n phi(n) = A(y) phi(y) - A(x) phi(x) - int_x^y A(u) phi'(u) du（A は部分和）で、リーマン・スティルチェス積分の部分積分である（S-WP-ABEL）。部分和分の式は sum_{j=1}^{n-1} u_j v_j = U_{n-1} v_n + sum_{j=1}^{n-1} U_j (v_j - v_{j+1}) である（DLMF 式 2.10.9）。

### 2 なぜ開発され、何を解決するか

収束の遅い級数の値を積分で近似する、また積分を和で近似する（数値積分）ために作られた（経緯は出典未確認（調査担当の知識））。解決する問題は、項数に比例する手間の和を、積分と少数の補正項で置き換えることである。演算子の形では、ずらしを e^D（D は微分）と書くと和の作用素が 1/(e^D - 1) = 1/D - 1/2 + D/12 - D^3/720 + D^5/30240 - … となり、これが公式を与える（S-MAHAJAN。著者は類推による導出で、厳密な証明ではないと断っている）。

### 3 どの分野でどう使われているか

和の漸近展開（S(n) = sum j ln j の展開など。DLMF 式 2.10.4〜2.10.8）、数値積分の誤差の解析（台形則。S-TW2014 式(10.1)）、数論（ゼータ関数の表示。S-WP-ABEL の例）で使われる。S-WP-ABEL は、a_n = 1 のとき zeta(s) = s int_1^inf floor(u)/u^{1+s} du を導く例を示す。冪の和の公式（等差級数、2 乗和）はこの公式の多項式の場合に当たり、旧研究で年重み付き和の閉じた形に使われた（EQUATION_BRIEF の「旧研究で分かっていること」）。

### 4 主要方程式・数学的原理・成立条件

DLMF 式 2.10.1 の条件は、a、m、n が整数で n > a、m > 0、f^{(2m)} が [a, n] で絶対可積分であること。f が 2m - 1 次以下の多項式なら f^{(2m)} = 0 で剰余項が消え、有限項で厳密になる。一般の f では漸近展開で、項を増やすと発散することがある（S-TW2014 が引く Poisson の注意）。アーベル・プラナの公式（DLMF 式 2.10.2）は、帯領域で解析的な f について剰余を積分で表す。独自の計算：切断冪の格子上の和は sum_{n>=1} (T' - n c)_+^m = c^m [B_{m+1}(x) - B_{m+1}(psi)]/(m+1)（x = T'/c、psi = x - N、N = ceil(x) - 1）で厳密に閉じる（検算：m = 0、1、2 で相対差 1.1e-13 以内）。m = 0 は B_1(x) - B_1(psi) = N である。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、年数 Y に比例する和を O(1) の閉じた形にできる場合である。誤差の原因は剰余項で、f^{(2m)} の大きさに比例する。max や最終年の按分による折れでは f が滑らかでないので、折れの位置で区間を分けて区間ごとに適用する必要がある（区分的な多項式なら区間ごとに厳密）。階段関数（事象の数え上げ）には使えない。f' がデルタ関数になり、剰余項が効果のすべてになるからである。滑らかな打ち切りを F04 に当てはめると誤差は psi - 1/2 で、これは旧研究の反例（N ≈ T/c - 1 が大きく外れた）と同じ原因である（独自の解釈）。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F05（年次量が一定または直線、係数が一定・下限つきの直線低下・段階的）：整数年の部分 sum_{k=0}^{Y-2} q_k g_k は、折れの位置 K = ceil(k*) と段の境界で区間に分ければ、各区間で 2 次以下の多項式の和になり、冪の和の公式（sum k、sum k^2）で厳密に閉じる。最終年の項 w_Y q_{Y-1} g_{Y-1} を足せば sum_y w_y q_y g_y になる。F04：上の切断冪の式（m = 0）がそのまま厳密な回数である。周期的な事象の累積量（修繕を計上しない年の数、年別の累積の系列）は m = 1、2 の式で厳密に閉じる。F07：等比の和であり、等比級数の公式で閉じる（オイラー・マクローリンの対象ではない）。厳密なのは多項式・区分多項式の場合で、年次の表（任意の値の列）は閉じた形を持たず、和をそのまま取るしかない。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】「窓を掛けた区分多項式の格子上の和 ＝ 多項式の部分 B_{m+1}(x) − 周期の部分 B_{m+1}(psi)」という 1 つの形に、F04（m = 0、格子の間隔 c）、F05 の年数と最終年の按分（m = 0、1、格子の間隔 1 年）、直線の年次量と直線の係数の積（m <= 2）が入る。1 つの閉じた形の原子 BB_m(T; c) = c^m [B_{m+1}(T'/c) - B_{m+1}(psi)]/(m+1) を m = 0、1、2 について用意し、E = sum_j alpha_j BB_{m_j}(T - tau_j; c_j)（tau_j は折れ・開始の位置、c_j = ∞ は繰り返しなし）と書く。これは TH-S1-03 の遅延×積分器の原子に周期化を入れたものの閉じた形である。部分和分（DLMF 式 2.10.9）は、年次量の差分と係数の累積を入れ替える操作で、TH-S1-03 の「率の差分を原子の重みにする」書き換え（sum_y w_y h_y = sum_k (h_{k+1} - h_k)(T - k)_+）の根拠になる。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】B_{m+1}(x) - B_{m+1}(psi) は psi = x - N を代入すると x と N の多項式になる（m = 1 なら N(2x - N - 1)/2）。したがって時間の軸の計算で多項式でない要素は回数 N(T', c) ただ 1 つで、ほかは x = T'/c と N の多項式である。F05 の Y と w_Y は N(T, 1) と T - N(T, 1)、F06 の max による折れは (k - k*)_+ = (k - k*)·[k* < k]、F11 のしきい値の判定は [tau < x] であり、どれも厳密な不等号の階段 H0 と多項式の積で書ける。N 自身も N = sum_{n>=1} H0(T' - n c) なので、非線形の原始演算は H0 の 1 種類に絞れる。この見方では、変換方式の数は「H0 を含む核の評価」と「線形の縮約」の 2 つが下限の候補になる（TH-S1-11）。

### 限界

年次の表（任意の列）は圧縮できない。3 つ以上の直線の因子の積や高次の年次量には、より高い m が要る。等比の漸化式（F07）は多項式でないので、原子に rho^n の因子を足す必要がある。折れの位置と段の境界を前もって求める処理（k* の計算、ceil）が要り、これは前処理として数える必要がある。

### 主張の区別

- 【文献で実証済み】オイラー・マクローリンの公式（DLMF 式 2.10.1）とその条件、周期ベルヌーイ関数による剰余項（出典：S-DLMF-2.10）
- 【文献で実証済み】和の作用素は 1/(e^D - 1) = 1/D - 1/2 + D/12 - D^3/720 + … と書ける（類推による導出）（出典：S-MAHAJAN）
- 【文献で実証済み】アーベルの総和法はリーマン・スティルチェス積分の部分積分であり、zeta(s) = s int_1^inf floor(u)/u^{1+s} du を導く（出典：S-WP-ABEL）
- 【独自仮説】sum_{n>=1} (T' - n c)_+^m = c^m [B_{m+1}(x) - B_{m+1}(psi)]/(m+1) が厳密に成り立ち、時間の軸で多項式でない要素は N だけになる（走り書き検算、作成者のみ）（出典：S-DLMF-2.10、S-DLMF-24.8）

### 実験の案

- 原子 BB_m（m = 0、1、2）だけで B6-01・B6-03・B7-04・X-11 を、年次量と係数が記述子（一定、直線、下限つきの直線低下、段階的）で与えられる場合について作り、基準計算と相対差 1e-9 で比べる。
- 架空シナリオで、年次量・係数が年次の表で与えられる（記述子が使えない）単位と行の数を数える。多数なら、閉じた形による統合の適用範囲は狭い。
- 端点の補正を有限項だけ取る滑らかな近似を F04 に当てはめ、誤差が psi - 1/2 に一致することを確かめる（旧研究の反例の原因の確認）。一致しなければ、この解釈は反証される。

## TH-S1-10　メリン変換・ペロンの公式（算術的な階段関数の和、調和和）

- 英語名：Mellin transform / Perron formula (sums of arithmetic step functions, harmonic sums)　／　族：乗法的な畳み込みの積分変換（拡大縮小の対角化）
- 関連度：低（行をまたいだ集計の構造（データと数え方の規約の分離）と、滑らかな近似の誤差の上界を説明できるが、厳密な計算手段にならず、F05〜F07 を扱えない。変換方式の候補としては優先度が低い。）
- 扱う型：F04　／　厳密か近似か：F04（と建替の回数）について、変換の領域での分離 E*(s) = Lam(s)·phi*(s) は厳密。有限個の極による式（T sum U_c/c - (1/2) sum U_c）は近似で、誤差は sum_c U_c (psi_c - 1/2)。F05〜F07 は対象外。

### 1 何を意味する理論・方程式か

正の実数の上の関数 f を f*(s) = int_0^inf f(x) x^{s-1} dx に写す変換で、値域は「基本帯」と呼ぶ縦の帯で解析的な関数である（S-FGD1995 式(1)）。変数変換 x = e^{-y} でラプラス変換・フーリエ変換に移る（S-FGD1995）。g(mu x) の変換は mu^{-s} g*(s) なので、調和和 G(x) = sum_k lam_k g(mu_k x) の変換は G*(s) = Lam(s) g*(s)、Lam(s) = sum_k lam_k mu_k^{-s} と、振幅と周波数の組（ディリクレ級数）と基底関数とに分かれる（S-FGD1995 式(6)、補題 2）。ペロンの公式は、数論的関数 a(n) の部分和を A(x) = sum'_{n<=x} a(n) = (1/(2 pi i)) int_{c-i inf}^{c+i inf} g(z) x^z/z dz と表す（S-WP-PERRON。g はディリクレ級数、x が整数のとき最後の項は 1/2 倍）。一般形は sum a(n) f(n/x) = (1/(2 pi i)) int F(s) G(s) x^s ds である（S-WP-PERRON）。

### 2 なぜ開発され、何を解決するか

ディリクレ級数の係数の部分和を、級数そのものの複素積分で表すために作られた（Perron 1908。S-WP-PERRON の参照文献の記載）。メリン変換は、共通の基底関数の拡大縮小の重ね合わせ（調和和）の漸近挙動を、変換の極から読むための道具として整理されている（S-FGD1995 の要旨）。解決する問題は、「変換した関数の特異点の 1 つ 1 つ」と「元の関数の漸近展開の項の 1 つ 1 つ」を対応させることである（S-FGD1995 の定理 3、4）。

### 3 どの分野でどう使われているか

解析的整数論（素数定理の証明）、算法の解析（分割統治の漸化式に現れる周期的な揺らぎ、桁和）、組合せ論、通信理論で使われる（S-FGD1995）。S-WP-PERRON は、公式の証明がアーベルの総和法から出て、x = e^t の変換でラプラス変換の逆変換になることを述べる。建築 LCA・更新回数への使用例は、この調査の検索では見つからなかった。

### 4 主要方程式・数学的原理・成立条件

逆変換は f(x) = (1/(2 pi i)) int_{c-i inf}^{c+i inf} f*(s) x^{-s} ds で、積分路は基本帯の中に取る（S-FGD1995 定理 2）。f が有界変動の点では、逆変換は (f(x+) + f(x-))/2 を返す（同 定理 2 (ii)）。調和和の漸近展開の定理（同 定理 5）は、基底関数の変換 g*(s) が縦の方向に速く減り、ディリクレ級数がゆっくりしか増えないことを条件にする。階段関数を基底に取った場合（ペロンの公式）については、変換 H*(s) = 1/s が ±i∞ の方向に良い減り方をしないので、公式の使用はしばしば繊細である、と同じ文献が注意している。zeta(s) = s int_1^inf floor(x) x^{-(s+1)} dx（Re s > 1。S-WP-PERRON、S-WP-ABEL）。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、少数の極の留数だけで漸近式が得られる場合で、行の数によらず数個の「モーメント」で値が決まる。回数関数を基底にすると、s = 1 と s = 0 に当たる 2 つの極から E ≈ T sum_c U_c/c - (1/2) sum_c U_c（中心化した年割り）が出る（独自の計算）。残りの部分は減衰しない振動で、大きさは (1/2) sum_c U_c まで達し得る（独自の計算。誤差 = sum_c U_c (psi_c - 1/2)）。ペロンの積分を高さ H で打ち切る数値計算は、x が跳びに近いほど誤差が大きい（1/s の減り方が遅いことの帰結。定量的な評価は出典未確認（調査担当の知識））。誤差の原因は、TH-S1-01 のギブス現象と同じもの（跳びを持つ基底関数の変換の減り方の遅さ）である。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：更新の排出 E(T) = sum_c U_c phi(T'/c)、phi(x) = ceil(x) - 1 は、振幅 U_c、周波数 1/c、基底関数 phi の調和和である。phi の変換は phi*(s) = int_0^inf phi(x) x^{s-1} dx = -zeta(-s)/s（Re s < -1。zeta の積分表示からの独自の導出）で、E*(s) = -(zeta(-s)/s) sum_c U_c c^{s} と分かれる。すなわち建物のデータは「周期のスペクトル」Lam(s) = sum_c U_c c^{s} にだけ入り、数え方の規約（期末を含めない、切り上げ）は基底関数の変換にだけ入る。この分離は変換の領域では厳密な恒等式である。逆変換は条件収束する積分としてのみ厳密で、有限個の極による式（中心化した年割り）は近似である。建替（B5-01）の回数も同じ phi である。F05・F06・F07 は時刻のずらし（加法的な構造）で書かれており、メリン変換の対象ではない。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】(T, c) に T/c という比だけで依存する量（F04 の回数、建替の回数、整数年の周期の F07 の完了した周期の数）は、すべて同じ基底関数の調和和で、行をまたいだ集計の法則がメリン変換の積 Lam(s)·phi*(s) で与えられる。構成：周期の値ごとの合算 U_c（旧研究で既知の、行の和の順序の入れ替え）を測度 U(dc) と見て、E(T) = int U(dc) phi(T'/c) と書く。データの圧縮という点では、滑らかな近似に要るのは 2 つのモーメント sum_c U_c/c と sum_c U_c だけである。厳密な値には Lam(s) を縦の線の全体で知る必要があり、有限個の数への圧縮はできない（否定的な結果。跳びを持つ基底関数の変換が 1/|s| でしか減らないため）。したがってメリン変換は「集計の構造の説明」と「滑らかな近似の誤差の上界 (1/2) sum_c U_c」を与えるが、厳密な計算の手段にはならない。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】u = ln T、v = ln c と置けば、メリン変換は対数の軸でのフーリエ変換であり、乗法的な畳み込みは普通の畳み込みになる（S-FGD1995 が変数変換による関係を述べる）。したがってメリン変換を別の変換方式として数える必要は無く、TH-S1-06 の「可換群の上の畳み込み」の群を (R_+, ×) に取った場合である。周期と評価期間を等比の格子（c = c_0 beta^j）に限れば対数の軸の畳み込みは離散になるが、実際の周期の値（5、10、15、20、25、30、40、50、60 年のような値）は等比の格子に乗らないので、この条件は現実的でない。加法的な格子（刻み h の整数倍）のほうが周期の値に合い、そこではランベルト級数（TH-S1-05）が加法と乗法の 2 つの構造をつなぐ。

### 限界

基底関数が跳びを持つので逆変換は条件収束で、数値計算に向かない。周期の値ごとの直接計算（U_c × N の和）より手間が増える。加法的な構造（事象の時刻、年の境界、按分）を表せない。

### 主張の区別

- 【文献で実証済み】調和和のメリン変換は、ディリクレ級数（振幅と周波数）と基底関数の変換の積に分かれる（出典：S-FGD1995）
- 【文献で実証済み】ペロンの公式は階段関数を基底に取った場合で、その変換 1/s の減り方が遅いので使用は繊細である（出典：S-FGD1995）
- 【文献で実証済み】ペロンの公式と、一般形 sum a(n) f(n/x) = (1/(2 pi i)) int F(s) G(s) x^s ds、zeta(s) = s int floor(x) x^{-s-1} dx（出典：S-WP-PERRON、S-WP-ABEL）
- 【独自仮説】更新の排出は基底 phi(x) = ceil(x) - 1 の調和和で、建物のデータは Lam(s) = sum_c U_c c^s にだけ入る。有限個の数への厳密な圧縮はできない（出典：S-FGD1995）

### 実験の案

- 2 つのモーメント（sum U_c/c と sum U_c）だけによる式で更新の排出を計算し、誤差が sum_c U_c (psi_c - 1/2) に一致することと、その絶対値が (1/2) sum_c U_c を超えないことを確かめる。超える例があれば上界の主張は反証される。
- ペロンの積分を高さ H = 10、100、1000 で打ち切って数値計算し、誤差を「T'/c の整数からの距離」の関数として測る。H <= 100 で更新の排出の誤差の 95％点が 1％ を下回れば、「数値計算に向かない」という評価は反証される。
- 評価期間を掃引して「基準 − 2 モーメントの式」の分布を作り、減衰しない振動であることを確かめる。

## TH-S1-11　排出の測度とスティルチェス積分・切断冪（階段・傾斜）の原子による表現（追加項目）

- 英語名：Emission measure, Lebesgue–Stieltjes integral and truncated-power (step / ramp) atoms (added item)　／　族：超関数・測度による時間軸の統一表現
- 関連度：高（この観点の理論のうち、F04〜F07 を厳密に、かつ単位の違いをデータだけで表す形に最も近い。変換方式を 2 種類（核の評価と縮約）または格子の上で 1 種類に絞る挑戦的な候補の土台になる。）
- 扱う型：F04、F05、F06、F07、F09、F03　／　厳密か近似か：F04・F05・F06・F07・修繕・建替・年別と累積の系列は、原子の和として厳密（恒等式）。格子版の構造テンソルは、T と周期が格子に乗る場合に厳密で、乗らない行は近似。F08・F10・F11 と、値の側の非線形（B6-04、F02）は対象外。

### 1 何を意味する理論・方程式か

時間の軸の上の排出を符号つきの測度 mu で表す：事象は時刻 tau に重み e の点の質量、年次のフローは密度 h(t) dt である。評価期間の合計は E(T) = mu([0, T)) = int 1_{[0,T)} d mu（左連続の分布関数）になる。階段 H0(t - tau) はデルタ関数の 1 回の積分、切断冪 (t - tau)_+^m/m! は m+1 回の積分で、ラプラス変換では e^{-s tau}/s^{m+1} に当たる。離散の和と連続の積分を 1 つの積分で書く枠がリーマン・スティルチェス積分で、アーベルの総和法はその部分積分である（S-WP-ABEL）。ディラックのくしは周期的な超関数で、標本化と周期化を表す（S-WP-DIRAC）。

### 2 なぜ開発され、何を解決するか

点の質量と連続な密度を同じ積分で扱うため（スティルチェス積分）、および不連続な関数の微分を正当化するため（超関数。S-WP-DIRAC の参照文献に Schwartz 1951 がある）に作られた。切断冪は、区分多項式（スプライン）を 1 つの式で書くための基底として使われる（出典未確認（調査担当の知識））。解決する問題は、「起きた瞬間に全部」（事象）と「期間に比例して」（フロー）という 2 種類の時間の入り方を、同じ対象（測度）にまとめることである。

### 3 どの分野でどう使われているか

確率論（点の質量と密度が混ざった分布関数）、信号理論（標本化）、スプライン近似、梁の点荷重の計算（切断冪の括弧記法）、保険数理・キャッシュフローの計算（離散の支払と連続の年金を 1 つの積分で書く）で使われる（一般的な用途。出典未確認（調査担当の知識））。現在価値がキャッシュフローのラプラス変換になるという指摘（S-GRUBB1967、S-BUSER1986）は、キャッシュフローを時間の軸の上の測度と見る立場である。動的 LCA の「時刻ごとのインベントリ」（S-MULLER2025、S-LEVASSEUR2010）も、排出を時間の軸の上の分布として持つ点で同じ表現である。

### 4 主要方程式・数学的原理・成立条件

E(T) = sum_{tau_j < T'} e_j + int_0^T h(t) dt。h が年ごとに一定（区間 (y-1, y] で h_y）なら int_0^T h = sum_y w_y h_y が厳密に成り立つ。w_y = min(1, T-(y-1)) は区間 (y-1, y] と (0, T] の重なりの長さだからである（独自の確認。検算：相対差 2.1e-15）。すなわち基準計算の「最後の年を按分する」規則は、年ごとに一定の密度のルベーグ積分そのものである。次数 m 以下の区分多項式は、折れの位置 tau_j での切断冪 (t - tau_j)_+^i（i <= m）の線形結合で書ける（出典未確認（調査担当の知識））。決めておく必要がある規約は、事象を期末で含めるか（基準は tau < T(1-1e-9) で含めない）と、事象の属する年（基準は ceil(tau(1-1e-9))）である。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、回数・按分つきの和・折れを 1 本の評価の式にまとめられる点で、手間は原子の数に比例する。周期化した原子の閉じた形（TH-S1-09）を使えば、行と原子の組 1 つにつき O(1) である。恒等式なので近似の誤差は無い。浮動小数点では、折れの数が多いときに切断冪の基底の桁落ちが起き得る（B スプラインの基底が安定な代替。出典未確認（調査担当の知識））。期末・年の境界の許容幅の扱いを誤ると、境界の上の行で回数が 1 ずれる。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：原子 (e_i, n c_i, m=0)。F05：h_y = q_y g_y として原子 (h_{k+1} - h_k, k, m=1)、E(T) = sum_k (h_{k+1} - h_k)(T - k)_+。F06：g(k) = g_0 H0 - d (k)_+ + d (k - k*)_+ を整数の k で読む。段階的な系列は sum_j (段の値の差) × [段の始まり <= k]。F07：年次の率 l_y = r R_y を F05 と同じ原子にする（R_y は等比の規則で作る）。修繕（B3-01）：事象の属する年で 0 になる率の差分を原子にする。年別・累積の系列（X-07）は E(T) を T = 1, …, Y で読んだものである。検算では、1 つの評価関数で更新・年次量×係数・修繕・冷媒の 4 種が相対差 2e-14 以内で再現された（作成者のみ。基準計算そのものは実行していない）。買電量の max(0, 消費 - (発電 - 売電))（B6-04）は時間ではなく値の側の切断冪で、年ごとに符号が変わるかどうかがデータに依存するので、時間の原子には入らない。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】この観点の単一演算子の候補は Phi(T; A) = sum_{(alpha, tau, m, c) in A} alpha × [周期化した切断冪の原子](T - tau; m, c) である。F04・F05・F06・F07・修繕（B3-01）・建替（B5-01）・年別と累積の系列（X-07）・周期別の集計（X-08）は、原子の一覧 A というデータの違いだけで表せる見込みである。F01・F03・F09 の和は「tau = 0 より前、m = 0 の原子」として形式的には入るが、和を和と言い換えただけで、統合の実質は無い。F08・F10（比と差）は読み出しの後の演算として残り、F11 のうちしきい値の判定は値の軸の上の H0 として書けるが、係数の検索と優先順位の解決は入らない。手順書 5 節の条件 (c)（単位の仕様がデータだけ）を満たすには、原子の一覧を作る処理（R_y の漸化式、事象の属する年の集合、折れの位置 k*）を演算子の中に入れるか、前処理として数える必要がある。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】(1) 原子の重み alpha に段階（14 段階）とガスの添字を持たせると、F09・F03 は重みの縮約になり、全体が E_{s,g}(T) = sum_j W_{j,s,g} K_j(T) という 1 つの双線形の形になる。K_j(T) は時間のデータと T だけで決まる核の値、W は数量と係数だけで決まる重みである。この「時間と数量の分離」の下で、変換方式は (i) 核の評価（T について非線形：階段と傾斜）と (ii) 線形の縮約の 2 種類になる。(2) 時間を格子に限れば、核の評価は表の参照（添字 p での読み出し）になり、回数の表 K[p, q] = ceil(p/q) - 1 は建物によらない普遍の構造テンソルとして前もって持てる。すると計算はすべて縮約（1 種類）になる。この普遍のテンソルを前処理に置くことが手順書 5 節の 4（前処理に単位ごとの計算を隠した場合は数える）に触れないかは、内部統括の判断が要る。テンソルが単位にも建物にも依存しないことが、認められる根拠になり得る。(3) 非線形の原始演算を H0 の 1 つに絞る（TH-S1-09 の q8）と、「H0 を含む核」と「縮約」が変換方式の数の下限の候補になる。

### 限界

値の側の非線形（買電量の max(0, ·)、端材率の 1/(1-r)、比）は入らない。欠損・範囲外の行を除く規則は、重み 0 のデータとして表せるが、その判定そのもの（F11）は別の演算である。原子を作る前処理が単位ごとの計算を含むと、変換方式の数え方の上で統合と認められない。1 年に複数の事象が入る行での「事象の属する年」の集合の扱いが、原子の作り方を複雑にする。

### 主張の区別

- 【文献で実証済み】アーベルの総和法はリーマン・スティルチェス積分の部分積分である（出典：S-WP-ABEL）

### 実験の案

- 「時間の核 K_j(T) × 重みのテンソル W」の試作で B の段階の全単位を作り、基準計算と相対差 1e-9 で比べる。核をわざと壊して（H0 の不等号を逆にするなど）、対象の単位の出力がすべて変わることを確かめる（手順書 5 節 2 の (b)）。変わらない単位があれば、その単位は演算子に属していない。
- 格子版：回数の表 K[p, q] を建物によらない定数として持ち、縮約だけで更新・修繕・冷媒の合計を作る。記憶量、演算回数、格子に乗らない行の数と誤差を測る。
- 架空シナリオで、買電量が一部の年だけ 0 に張り付く（発電が消費を上回る年がある）場合の数を数える。多ければ、値の側の非線形を別の演算として数える必要がある。

## TH-S1-12　有理級数・定数係数の漸化式を満たす列（C 有限列）・転送行列による線形表現（追加項目）

- 英語名：Rational series, C-finite sequences and linear representations (transfer-matrix form) (added item)　／　族：列の線形表現（重みつきオートマトン）
- 関連度：高（F07 のリセットつきの漸化式と F04 の回数を、前処理を外に残さずに 1 つの演算子（行列の積）に入れられる。閉包性の定理が合成を保証するので、挑戦的な候補（変換方式 1 種類）の実装の形として有力である。）
- 扱う型：F04、F05、F07、F06　／　厳密か近似か：格子の上で F04・F05（一定・直線の年次量、または表を入力として）・F07・修繕・建替が厳密。F06 は入力の列として厳密（低次の C 有限列ではない）。格子に乗らない周期は近似、または明示の事象として時変の積に入れれば厳密。

### 1 何を意味する理論・方程式か

定数係数の線形漸化式を満たす列（C 有限列）は、有理式の母関数を持つ列であり、a_n = u^T M^n v（M は定数の行列）という線形表現を持つ列でもある（3 つの同値は標準的な事実。出典未確認（調査担当の知識））。非可換の形式級数については、級数が有理的であることと、線形表現を持つ（重みつき有限オートマトンで認識される）ことが同値である（Schützenberger の定理。S-BR2011 に関する検索結果の記載）。C 有限列の集まりは、和、コーシー積、アダマール積（項ごとの積）で閉じている（S-KT2022 の定理 9。検索結果の記載）。この研究では、時間の格子の添字 p を n に取り、出力を p 番目の項として読む。

### 2 なぜ開発され、何を解決するか

漸化式で定まる列を、閉じた演算の体系として扱うために整理された（S-KT2022 は、列の型を仮定して式を当てる手順を、多項式・C 有限・ホロノミックの各型について解説する）。形式言語とオートマトンの理論では、重みつきの数え上げを行列の積で表すために使われる（S-BR2011）。解決する問題は、合成（和、積、項ごとの積）をしても型の外に出ないことを保証し、個別の式の導出を係数の計算に置き換えることである。

### 3 どの分野でどう使われているか

組合せ論（転送行列法）、オートマトン理論、制御（状態空間表現）、列の型を当てる計算機代数で使われる（S-KT2022、S-BR2011 と一般的な用途。後者は出典未確認（調査担当の知識））。離散時間の制御では、伝達関数 B(z)/A(z) と状態空間 (A, b, c) が同じ系の 2 つの表示である（S-WP-ZT が伝達関数を述べる）。建築 LCA への使用例は、この調査の検索では見つからなかった。

### 4 主要方程式・数学的原理・成立条件

和の次数は r + s 以下である（S-KT2022 に関する検索結果の記載）。アダマール積の次数は r·s 以下で、線形表現ではクロネッカー積に当たる（出典未確認（調査担当の知識））。極がすべて 1 の冪根である有理式の係数は準多項式で、floor(n/q) はその例である（出典未確認（調査担当の知識））。独自の構成：周期 q の位相を表す巡回シフトの行列 P_q（q×q）と、回数を数える成分を合わせた M = [[P_q, 0], [e^T, 1]] で、回数は u^T M^p v になる。P_q の固有値は 1 の q 乗根で、DFT が P_q を対角化する。固有値 1 のジョルダン細胞（大きさ 2 以上）が多項式の成長（傾向）を、単位円上のほかの固有値が周期の成分を、絶対値が 1 未満の固有値 rho が減衰を与える。成り立つ条件は、時間が格子に乗り、遷移が時刻によらないこと（時刻による場合は行列の積 prod M_n になる）である。

### 5 計算削減の仕組みと誤差の原因

計算が減るのは、p 番目の値を行列の冪（log p 回の行列の積）または固有分解の閉じた形で得られる場合と、合成を閉包性で機械的に行える場合である。誤差は有理数の演算で 0 である。浮動小数点では、単位円上の固有値と重複した固有値 1 があるので、固有分解の閉じた形は条件が悪くなり得る。周期と減衰率ごとのブロック対角の形で持つのが安全である（独自の見解。測定が要る）。状態の数は、格子に載せた周期の値 q の和の程度になる（刻み 0.1 年、周期 60 年までなら 1 周期あたり最大 600）。

### 6 建築 LCA のどの計算にどう適用できるか

【独自仮説】F04：上の M で厳密（格子上）。F07：状態を（位相、残存量）に取り、年の遷移を「残存量に rho を掛ける」、交換の位相での遷移を「残存量を m0 に戻す」とすれば、年初の残存量・年次の漏洩・交換の直前の残存量（B1-03）・期末の残存量（B1-04）が同じ行列の積から出る。F05：累積の成分を足した行列で、年次量が C 有限（一定、直線）なら状態に（1、k）を足す。F06：下限つきの直線低下は、折れの位置 K まで直線、その後一定なので、低い次数の C 有限列ではない（K 個の過渡の項を持つ）。入力の列（データ）として与えるのが妥当である。評価期間が整数でない場合は E(T) = u^T [I + w_Y (F - I)] (J F)^{Y-1} v の形になる（F は 1 年分のフローの遷移、J は年の境界での事象の遷移。蓄積も R_{Y+1} = R_Y (1 - r w) も w について 1 次であることによる独自の導出）。厳密なのは整数年（または刻み h）の格子に乗る周期の場合で、乗らない周期は近似か、明示の事象として時変の積に入れる。

### 7 方程式の再構成で共通変換へ統合できるか

【独自仮説】1 つの演算子「y = u^T (prod_{n<p} M_n) v」に、F04・F05（記述子の年次量）・F07・修繕・建替が入る。M は（周期、減衰率）ごとのブロックを対角に並べた行列で、同じ周期の行は同じブロックを共有し、行の違いは重みのベクトル u（周期ごとの合算 U_c）だけになる。年次の表は時変の入力（M_n の中の 1 成分）として入る。行についての和は直和、プロファイルとの畳み込みは直列接続、年次量と係数の積はクロネッカー積で、閉包性によりどれも同じ演算子の中に留まる。これは、TH-S1-03 の原子の方法を格子の上で書いたもので、原子を作る前処理（列挙、漸化式）が行列の積の中に入る点が違う。前処理を演算子の外に残さないという点で、手順書 5 節の数え方に対して最も素直な形である。

### 8 成立条件や変換の工夫でさらに種類数を減らせるか

【独自仮説】(1) M のスペクトルの 3 つの部分（固有値 1 のジョルダン細胞、単位円上のほかの固有値、絶対値 1 未満の固有値）は、TH-S1-03 の核の 3 つの展開（ローラン、極、等比）と TH-S1-09 の「多項式の部分＋周期の部分」に当たる。フーリエ・オイラー・マクローリン・列挙は、1 つの行列のスペクトル分解の部分の取り方として 1 つにまとまる。(2) 滑らかな近似の誤差は「単位円上の 1 以外の固有値の成分」に等しいので、その成分の大きさを測れば、どの近似の誤差も前もって見積もれる。(3) max(下限, ·) や回数を、max と + の半環の上の線形演算と見て、半環を取り替えられる 1 本の行列積の演算子にする案は、この観点の範囲の外であり、仮説として記録する。(4) 行列の積は TH-S1-11 の格子版の縮約（普遍の構造テンソル K[p, q]）と同じものの別の書き方で、K は M^p の成分を表にしたものである。

### 限界

状態の数が周期の値の種類と刻みの細かさに比例して増える。明示の事象年の一覧や年次の表は時変の積になり、冪による短縮が効かない。閉包性の定理（S-KT2022、S-BR2011）は本文を読んでおらず、次数の上界などは要旨・検索結果の水準の確認である。回数だけなら ceil 1 回のほうが速く、得になるのは統合（コードの経路の 1 本化）であって速度ではない。

### 実験の案

- シナリオの周期の集合からブロック対角の M を作り、整数年の周期と刻み 0.1 年の周期について、B の段階の合計（B1-02・B1-03・B1-04・B3-01・B4-02・B5-01）を行列の積だけで作って基準計算と比べる。整数でない T で E(T) = u^T [I + w_Y (F - I)] (J F)^{Y-1} v が合わなければ、最終年の扱いの導出は反証される。

- 合計を、固有値 1 の部分（傾向）、単位円上のほかの固有値の部分（振動）、減衰の部分に分けて報告し、振動の部分の大きさが滑らかな近似の誤差と一致することを確かめる。

### HYP-S1-01

- 主張：時間の軸の型 F04・F05・F06・F07（と修繕 B3-01、建替 B5-01、年別と累積の系列 X-07）は、1 つの核 K_c(s) = 1/(e^{sc} - 1) と遅延・積分器だけで書ける。列挙、フーリエ級数、ポアソン和公式、オイラー・マクローリンは、この核の 3 つの展開であり、別々の変換方式として数えなくてよい。
- 構成：E^(s) = sum_j alpha_j e^{-s tau_j} (beta_j + K_{c_j}(s)) / (s + lam_j)^{m_j+1}。beta_j は 1 回目を時刻 tau_j に置くか（1）置かないか（0）、c_j = ∞ は繰り返しなし（K = 0）。F04：alpha = e_i、tau = 0、beta = 0、m = 0、c = c_i、lam = 0。F05：alpha = h_{k+1} - h_k、tau = k、beta = 1、m = 1、c = ∞。F06：g(k) の変換 g_0/s - d/s^2 + d e^{-s k*}/s^2。F07：年次の率 l_y = r R_y を F05 の形に入れる（連続時間で近似するなら lam = -ln(1 - r)）。核の展開：(i) sum_{n>=1} e^{-nsc}（列挙。厳密）、(ii) 1/(sc) - 1/2 + sc/12 - …（傾向。近似）、(iii) 1/(sc) - 1/2 + sum_k 2sc/((sc)^2 + 4 pi^2 k^2)（フーリエ。打ち切れば近似）。
- 条件：事象が等間隔（周期 c）であること。周期の中の量が暦の年によらないこと（独立概念モデルでは更新・建替が初期と同じ係数を使うので満たされる）。明示の事象年の一覧は beta = 1、c = ∞ の原子として入れる。期末と年の境界の規約（tau < T(1-1e-9)、事象の年 ceil(tau(1-1e-9))）を逆変換の不等号に写すこと。
- 反証になるもの：F04〜F07 と B3-01・B5-01 のうち、上の形の変換に書けない単位が 1 つでも見つかること（候補：1 年に複数の事象が入る行の修繕の年の集合、明示の交換年と補充なしの冷媒の組合せ）。または、展開 (i) による逆変換が基準計算と相対差 1e-9 を超えて食い違うこと。
- 見込まれる誤差の原因：展開 (i) は誤差なし（丸めのみ）。(ii) は振動の成分 sum_c U_c (psi_c - 1/2) を落とす。(iii) を K 項で打ち切ると、T'/c が整数に近い行で最大 1/2 回分の誤差。連続時間の減衰で F07 を置き換えると、年単位の規則との差が出る。

### HYP-S1-02

- 主張：周期化した切断冪の原子（ベルヌーイ多項式の閉じた形）を 1 つの演算子とすれば、実数の T と c のまま、F04・F05（記述子の年次量）・F06・修繕・建替・年別の系列を、原子の一覧というデータの違いだけで厳密に計算できる。多項式でない要素は回数 N（すなわち階段 H0）1 つになる。
- 構成：BB_m(T; c) = sum_{n>=1} (T' - n c)_+^m = c^m [B_{m+1}(x) - B_{m+1}(psi)]/(m+1)、x = T'/c、N = ceil(x) - 1、psi = x - N、T' = T(1 - 1e-9)。c = ∞ のとき 0。Phi(T; A) = sum_{(alpha, tau, m, c, beta) in A} alpha [beta (T - tau)_+^m + BB_m(T - tau; c)]（m = 0 の (·)_+^0 は tau < T' のとき 1）。B_1(x) = x - 1/2、B_2(x) = x^2 - x + 1/6、B_3(x) = x^3 - (3/2) x^2 + (1/2) x。F04：(e_i, 0, 0, c_i, 0)。F05：(h_{k+1} - h_k, k, 1, ∞, 1)。年の数と最終年の重み：Y - 1 = N(T, 1)、w_Y = T - N(T, 1)。F06 の折れ：(d, k*, 1, ∞, 1)。
- 条件：年次量と係数が区分多項式（一定、直線、下限つきの直線低下、段階的）で与えられること。年次の表は原子が年数だけ要る（厳密だが圧縮されない）。F07 は年次の率を別に作る必要があり、この原子だけでは閉じない（rho^n の因子を持つ原子の追加が要る）。
- 反証になるもの：走り書き検算（作成者のみ、m <= 2、相対差 1.1e-13）と違う結果が、基準計算との比較で出ること。特に、T が整数に相対 1e-9 以内で近い場合に、Y = ceil(T)（許容幅なし）と N(T, 1)（許容幅あり）の食い違いが合計の相対差 1e-9 を超えること、または by_year の配列の長さが食い違うこと。
- 見込まれる誤差の原因：恒等式なので近似の誤差は無い。浮動小数点の桁落ち（x が大きく m が高い場合の B_{m+1}(x) - B_{m+1}(psi)）。境界の許容幅の写し間違い。

### HYP-S1-03

- 主張：時間を刻み h の格子に限れば、F04・F05・F07・修繕・建替は「有理式の母関数の係数の取り出し」＝「ブロック対角の行列の積 u^T (prod M) v」という 1 種類の演算子に入り、原子を作る前処理（列挙、漸化式）も演算子の中に入る。更新の排出は、T によらない事象の系列 b_n = sum_{q|n} U_q の前からの和になる。
- 構成：回数：sum_p N(p,q) z^p = z^{q+1}/((1-z)(1-z^q))。更新の排出：sum_p E(p) z^p = (z/(1-z)) sum_q U_q z^q/(1-z^q)、E(p) = sum_{n=1}^{p-1} sum_{q|n} U_q。冷媒（整数年の周期 c、補充なし）：sum_y l_y z^y = m0 r z (1 - rho^c z^c)/((1 - rho z)(1 - z^c))。状態空間：位相の巡回シフト P_q、累積の成分、残存量の成分を並べたブロック対角の M。整数でない T は u^T [I + w_Y (F - I)] (J F)^{Y-1} v。合成：行の和は直和、プロファイルとの畳み込みは直列接続、年次量 × 係数はクロネッカー積（C 有限列の閉包性）。
- 条件：T と周期が共通の刻み h の整数倍であること（周期が有理数 a/b なら事象の年の並びは a 年で繰り返す）。遷移が時刻によらないこと（年次の表や明示の事象は時変の積として入る）。
- 反証になるもの：架空シナリオの周期が刻み 0.1 年（または 0.01 年）の格子に乗らない行を多数含み、丸めと境界の行の個別補正を合わせても相対差 1e-9 に届かないこと。または、内部統括が「普遍の表 K[p, q] や M の組み立ては前処理に隠した単位ごとの計算である」と判断すること。
- 見込まれる誤差の原因：格子の上では誤差なし。周期を格子へ丸めると、n c が T' または年の境界から h 以内の行で回数・所属年が 1 ずれる。高次の分母を展開した場合の丸めの蓄積。

### HYP-S1-04

- 主張：原子の重みに段階とガスの添字を持たせ、時間と数量を分けると、F01・F03・F04〜F07・F09 の出力は E_{s,g}(T) = sum_j W_{j,s,g} K_j(T) という 1 つの双線形の形になる。変換方式は「核の評価 K_j(T)（階段 H0 を含む）」と「線形の縮約」の 2 種類が下限の候補で、格子の上では核の評価が表の参照になり 1 種類になる。
- 構成：W_{j,s,g} = （行の活動量 × 換算倍率 × 係数のガス別の値）を、原子 j・段階 s・ガス g ごとに合算した重み（T によらない）。K_j(T) = beta_j (T - tau_j)_+^{m_j} + BB_{m_j}(T - tau_j; c_j)（T と時間のデータだけで決まる）。合計 = sum_s 1[s が対象] sum_g E_{s,g}(T)。格子版：K[p, q] = ceil(p/q) - 1 を建物によらない定数の表として持ち、E = W · K[p, ·]。
- 条件：行の排出が活動量と係数について双線形であること（F01）。周期を持つ行の係数が暦の年によらないこと。値の側の非線形（買電量の max(0, ·)、端材率の 1/(1-r)）と比（F08、F10）、判定（F11）は、この形の外に前処理・後処理として残る。
- 反証になるもの：核を壊す故障注入で出力が変わらない単位があること（その単位は演算子に属していない）。または、前処理・後処理に残る演算の種類が多く、合わせて数えると旧研究の統合モデルより変換方式の数が減らないこと。
- 見込まれる誤差の原因：恒等式の範囲では誤差なし。欠損・範囲外の行を除く規則を重み 0 として写すときの写し間違い。B2 と B6 の振り替えのような条件つきの集約の規則。

### HYP-S1-05

- 主張：（否定的な仮説）位相 psi_c を使わない滑らかな式（年割り T/c - 1、中心化した年割り T/c - 1/2、数値ラプラス逆変換、少数項のフーリエ・メリン）は、周期が評価期間を割り切る行を多く含む母集団では、更新の排出について完成モデルの基準（近似の基準：合計の誤差の 95％点 1％ 以内、段階ごと 2％ 以内）を満たせない。位相を入れれば厳密になる。
- 構成：厳密な値：N = x - psi（x = T'/c）。中心化した年割りの誤差（近似 − 基準）：sum_c U_c (psi_c - 1/2)。c が T を割り切る行では psi = 1 で、誤差は +U_c/2。年割りの誤差：sum_c U_c (psi_c - 1)。c が T を割り切る行では 0、それ以外では負。位相が一様にばらつく母集団では前者の平均は 0、後者の平均は -(1/2) sum U_c。
- 条件：更新の排出が段階 B4 または合計に占める割合が、誤差の基準に対して無視できない大きさであること。
- 反証になるもの：架空シナリオの集合で、位相を使わない滑らかな式のどれかが、周期が T を割り切る行の割合によらず、上の基準を満たすこと。
- 見込まれる誤差の原因：誤差は振動の成分そのもの。行の数が多く位相がばらつけば相殺で減る（1/sqrt(行数) の見込み）が、位相がそろえば減らない。

### HYP-S1-06

- 主張：寿命をアーラン分布（次数 k、平均 c）とする再生の演算子は、変換が有理式になり、逆変換が指数関数と多項式の原子で閉じる。k → ∞ が基準の切り上げで、k を調節することで滑らかさと誤差の釣り合いを 1 つのパラメータで動かせる近似の変換の族になる。
- 構成：F^(s) = (k lam/(s + k lam))^k、lam = 1/c。期待回数の変換 m^(s) = F^(s)/(1 - F^(s))。更新の排出の近似：E_k(T) = sum_c U_c m_k(T; c)。k → ∞ で F^(s) → e^{-sc}、m^(s) → 1/(e^{sc} - 1)。
- 条件：近似であることを明記して使う。確定的な入力に対する平滑化なので、確率的な耐用年数という別のモデルの結果と混同しない。
- 反証になるもの：k を 256 まで上げても、周期が T を割り切る行で約 U_c/2 の偏りが残り、誤差の基準に届かないこと（その場合、この族は説明の道具にとどまる）。
- 見込まれる誤差の原因：倍数の近くでの階段のなまり（幅はおよそ c sqrt(n/k)）。倍数ちょうどでは期待回数が中点（基準 + 1/2）に近づく。

### HYP-S1-07

- 主張：F05 の時間の規則（年の数 Y と最終年の重み w_Y）は、周期 1 年の F04 と同じ原始演算で書ける：Y - 1 = N(T, 1)、w_Y = T - N(T, 1)。したがって F04 と F05 の時間の扱いは、回数 N(T, c) という 1 つの原始演算に統合できる。
- 構成：sum_y w_y h_y = sum_{y=1}^{N(T,1)} h_y + (T - N(T,1)) h_{N(T,1)+1} = (1 - w_Y) C_{Y-1} + w_Y C_Y（C は h の累積の列）。
- 条件：T が整数に相対 1e-9 以内で近くない場合は恒等式。近い場合、基準は Y = ceil(T)（許容幅なし）を使い、N は許容幅 1e-9 を使うので、Y が 1 だけ食い違う。
- 反証になるもの：T が整数のごく近く（相対 1e-9 以内で上）にあるとき、合計の相対差が 1e-9 を超えること、または by_year の配列の長さの食い違いが下流の単位の出力を変えること。
- 見込まれる誤差の原因：許容幅の食い違いによる、最終年の項 1 つ分（相対 1e-9 程度）の差。

## LCA・建築 LCA での先行例（調査担当が見つけたもの）
