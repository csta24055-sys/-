## 0. 2 つの構造と共通の約束

### 0.1 マスク付き積和

```
out[g] = Σ_{x ∈ 表} Σ_{t ∈ 項} Π_k φ_{t,k}(x)        （g ごとに足す）
```

因子 φ は 3 種類だけである：(1) 列の値（定数を含む）、(2) 0/1 の述語（値がある・範囲内・等しい・以下）とその否定、(3) 1 つの列の有理関数（1/x、1−x、1/(1−x)、x/(1−x)）。
列の指し方は、同じ表の列、参照を通した別の表の列、1 行の表の値、定数。まとめ方 g は、行ごと・合計・参照先の行ごと。
キーの照合（`match`）は「キーが等しい最初の行」を返す。順序が要るのはここだけである。
欠損は 0 と区別する：述語がすべて 1 なのに値が欠けた項は「欠損」になり、合計も欠損になる。

### 0.2 節点スペクトル

評価期間 T への依存は、T によらない振幅 a_j と、次の核の重ね合わせで表す（ε = 1e-9）。

```
Φ(T) = Σ_j a_j · h(T; s_j, ℓ_j, g_j),     h(T; s, ℓ, g) = [g < T(1−ε)] · clip((T − s)/ℓ, 0, 1)     （ℓ = 0 のとき clip は 1）
```

| 形 | s | ℓ | g | 意味 |
|---|---|---|---|---|
| 定数 | 0 | 0 | −∞ | T によらない量 |
| 原子 | τ | 0 | τ | 時刻 τ の事象。τ < T(1−ε) のとき数える |
| 年セル k | k | 1 | −∞ | 年 k+1 の年重み clip(T − k, 0, 1) |
| ゲート付き年セル | k | 1 | τ | 「事象 τ を含む年」の年重み。事象が数えられたときだけ効く |
| 密度 | 0 | H | −∞ | 一定の率 a（振幅 a·H）。T ≤ H で a·T |

評価の仕方は 3 つあり、どれも同じ Φ を計算する。

- **跳び形**（`tstudy/knots.py`）：各節点での値の跳び c0 と傾きの跳び c1 を節点の順に累積しておき、`Φ(T) = base + Σ_{節点 < T}(c0 + c1·T)` を二分探索 2 回で出す。
- **区間形**（`tstudy/interval.py`）：年セル k の内側で有効な係数 (A_k, B_k) を直接持ち、`Φ(T) = A_k + B_k(T − k) + セル内の節点の補正` を出す（D-09）。
- **ゲート付き和**（積和②の TIME）：節点の表の上で、核を「述語と一次式の積」として行ごとに評価し、行・年・係数ごとにまとめる。これはマスク付き積和そのものである。

### 0.3 基準計算の時間の規則（すべての節で使う）

```
年重み      w_y(T) = min(1, T − (y−1))       y = 1, …, Y,  Y = ceil(T)
事象の計上  時刻 τ の事象は  τ < T(1−ε)  のとき数える（評価期間の終わりちょうどは数えない）
事象の年    y(τ) = max(1, ceil(τ(1−ε)))
周期の事象  τ_n = n·c（n = 1, 2, …）。周期が欠損・非正・無限なら事象なし
```

### 0.4 共通表（2 構造の手前）

入力は表に平坦化する（`tstudy/tables.py`）。そのうえで、単位の知識を持たない一般の操作だけで次を作る（`tstudy/index.py`、何を作るかは `specs/system.py` の `INDEX_PLAN`）。

- 文字列の分割：最初の「/」の前後（`~h`、`~t`）、`名前[番号].残り` の 3 部分（`~p`、`~i`、`~s`）。すべての文字列列に一律。
- 添字集合：2 つの表の全組合せ（年×電力係数の段、機器×年、材料区分×処理経路、年×年）、0..H の連番、列の相異なる値、行の並べ替え。
- 節点の格子：周期の倍数 n·c と、明示の時刻一覧。各節点には、それが属する年セル k = y(τ) − 1 を付ける。

格子の時刻 n·c と年セルの番号は、節点スペクトルの「節点の位置」であり、振幅（排出量）の計算ではない。

## D-01 活動量×係数の総和（A1-A3・A4・A5・C1〜C4 と参考値の 22 単位）

対象：A13-01、A13-03、A13-04、A13-05、X-01、X-13、A4-01、A4-02、X-12、A5-01〜04、C1-01、C2-01、C3-01、C4-01、X-14、X-16、X-17、STO-01、STO-02。

**① 元の方程式**（例：A4-01、X-14、C3-01）

```
for 行 i:  計上できる条件を満たさなければ 0 として件数に数える
           e_i = 活動量_i × 換算倍率_i × 係数_i ;  total += e_i
C3-01:     for 行 i, 最終処分以外の経路 j:  e = 廃棄質量_i × 比率_ij × 換算倍率 × 係数_ij
```

**② 意味** 行ごとに「量×単位の換算×排出係数」を出して足す。使えない行（数量が欠損・負、係数が無い・使用許諾が無い・段階が違う・単位を換算できない）は足さずに数える。

**③ 理論** 条件分岐 `if c: x else 0` は、0/1 の指示関数との積 `[c]·x` に等しい。排他的な分岐の列は、指示関数の積の和になる。

**④ 変形**

```
total = Σ_i ( if ok_i then q_i·c_i·f_i else 0 )
      = Σ_i [ok_i]·q_i·c_i·f_i ,          ok_i = Π_m [条件 m が成り立つ]
n_skipped = Σ_i (1 − [ok_i]) = Σ_i [ok_i = 0]
```

「1 − Π 述語」を和の形で書くときは、最初に破れた述語で場合分けする：`1 − p1·p2·p3 = [¬p1] + [p1][¬p2] + [p1][p2][¬p3]`（排他的）。
発注量 `Q/(1−w)`、未数量分の上乗せ `r/(1−r)` は、1 列の有理関数である。

**⑤ 最終表現**（A4-01）

```
a41.ok[i]      = [搬入係数なし]·[係数が使える]·[質量 ≥ 0]·[距離 ≥ 0]
a41.by_item[i] = [a41.ok = 1]·mass_t·distance_km·換算倍率·係数
a41.value      = Σ_i a41.by_item[i] ,     a41.n_skipped = Σ_i [搬入係数なし]·[a41.ok = 0]
```

**⑥ 入力と係数** 数量・距離・質量は材料の行、換算倍率と係数は D-02 の照合で得る。A5-01 は、電力係数の単位文字列を「/」で分けた後半を電力量の単位として換算を引く（2026-11-13 に、既存仕様の固定の一覧をこれに置き換えた）。

**⑦ 結果・⑧ 誤差** 22 単位とも全集合で不一致 0。相対差は 5.5e-16 以下で、X-13 だけ 2.2e-12（発注量 Q/(1−w) を 1/(1−w) との積で作るための丸め。2026-11-11 の記録と同じ）。A4-01、A5-01〜04、C1-01、C3-01、C4-01、X-01、X-14、STO-01、STO-02 は 0 でない値がすべて倍精度で一致した。

**⑨ 成立条件** 値が有限であること。欠損は述語で外れる。

**⑩ 未確認・例外** 整数で入力された数量は、積和の結果が浮動小数になる（2026-11-11 の記録の制約。架空の母集団では数量は浮動小数）。C2-01 の `質量/1000` は `×0.001` で計算するので、最後の 1 ビットが違うことがある（相対差 5e-16 以下）。

## D-02 係数の検索・単位の換算・適用の優先順位（X-15、A13-02、X-03 と、全単位の係数ゲート）

**① 元の方程式**

```
lookup(係数ID, 段階, 活動量の単位):  記録がある ∧ 使用許諾あり ∧ 係数の段階 = [段階] ∧ 換算できる  →（記録, 換算倍率）
convert(from, to):  同じ単位なら 1、行固有の換算に最初に合う行、なければ全体の換算表に最初に合う行（連鎖なし）
X-15:  EPD が使えれば EPD、複合品なら A13-02 の複合係数、それ以外は汎用係数
A13-02:  Σ_j 質量比_j × 換算 × 係数_j（負の質量比・使えない構成係数・合計が 1 から 1e-6 超ずれる行は係数なし）
```

**② 意味** 活動量に掛ける係数を、権限と単位と優先順位の規則に従って 1 つ決める。

**③ 理論** キーによる検索は関係の結合である。「最初に合う行」は行の位置についての最小値で、(min, ·) 半環の演算にあたる。優先順位は排他的な指示関数の列で書ける。

**④ 変形** 優先順位 `if A: a elif B: b elif C: c` は

```
[A]·a + [¬A][B]·b + [¬A][¬B][C]·c
```

と書ける。換算倍率は `[from = to]·1 + [from ≠ to][行固有にある]·f_行 + [from ≠ to][行固有にない][全体にある]·f_全体`。
「係数の段階がちょうど [s]」は、段階の一覧の長さが 1 で、s に等しい要素が 1 個であること：`[stages# = 1]·[Σ_j [stage_j = s] = 1]`。

**⑤ 最終表現** テンプレート `STAGE`（段階ゲート）、`CONV`（換算）、`FACTOR`（検索＋ゲート）。どの単位もこの 3 つを使い回す。

**⑥ 入力と係数** 係数の表、換算の表、行固有の換算。年次量の単位「単位/year」と電力係数の単位「kgCO2e/単位」は、共通表の分割（`~h`、`~t`）を使う。

**⑦⑧** X-15・A13-02 は全集合で完全一致（0 でない値がすべてビット一致）。X-03 は 4.8e-16 以下。

**⑨ 成立条件** 換算は連鎖しない（基準計算と同じ）。同じキーの行が複数あれば最初の行を使う（基準計算と同じ）。

**⑩ 未確認・例外** 文字列の分割は積和の外（入力の符号化）で行う。分割の規則は「最初の『/』」だけで、単位の種類は知らない。

**実装** `specs/pre_a.py` の `TEMPLATES`。

## D-03 時間の核：年重み・事象の計上・事象の年

**① 元の方程式** 0.3 節の 3 つの規則。

**② 意味** 評価期間 T が整数年でないとき最後の年を按分し、事象は期間の内側のものだけ数える。

**③ 理論** T の関数を、原子（デルタ）と区分的に一定の密度からなる符号付き測度 μ の累積 `Φ(T) = μ([0, T))` と見る。区分的に一次の関数は、切断べき `(T − t)_+^0`、`(T − t)_+^1` の一次結合で書ける。

**④ 変形**

(1) 年重み付きの和。y ≤ Y では `min(1, T − (y−1)) = clip(T − (y−1), 0, 1)`（正なので下限は効かない）、y > Y では `T − (y−1) ≤ 0` なので clip は 0。よって

```
Σ_{y=1}^{ceil(T)} a_y · w_y(T) = Σ_{y ≥ 1} a_y · clip(T − (y−1), 0, 1)        （和の上限が T によらなくなる）
```

(2) 事象の和。`Σ_{τ} u · [τ < T(1−ε)]` は、そのまま原子の和である。

(3) 「事象を含む年」の年重み（修繕の除外、冷媒の更新直前の量）。その年の最初の事象 τ が数えられたときにだけ効くので、`a · [τ < T(1−ε)] · clip(T − k, 0, 1)`。

(4) 跳び形。`clip(T − k, 0, 1) = (T − k)_+ − (T − k − 1)_+` なので、年セル k（振幅 a）は節点 k に (c0, c1) = (−a·k, a)、節点 k+1 に (a(k+1), −a) を置けばよい。原子は節点 τ に (a, 0)。ゲート付き年セルは、節点 τ（事象の規則）に (−a·k, a)、節点 k+1 に (a(k+1), −a)。

```
Φ(T) = base + Σ_{事象の節点 τ_j < T(1−ε)} (c0_j + c1_j·T) + Σ_{年の節点 t_j < T} (c0_j + c1_j·T)
     = base + P0e[ke] + T·P1e[ke] + P0p[kp] + T·P1p[kp]         （P は節点の順の累積和、ke・kp は二分探索）
```

(5) ゲート付き和。核を述語で書く：`[g < T'] = ¬[T' ≤ g]`、`clip(T − k, 0, 1) = [k < T][k+1 ≤ T]·1 + [k < T][T < k+1]·(T − k)`。節点の表の上の積和になる。

**⑤ 最終表現** 0.2 節。

**⑥ 入力と係数** 振幅は積和①の列、節点の位置は格子（周期の倍数、明示の一覧）と年セル。対応は `specs/system.py` の `EMIT` に一覧で書いた。

**⑦⑧** 評価期間 0.001〜130 年、事象の時刻の ±0.000001 年を含む全集合で、時間に依存する単位の不一致 0。累積和を使う跳び形の値（B3-01、B4-02、B6-03 など）は相対差 5.7e-13 以下。MATLAB でも、年セルの重みの和が閉じた式と一致した（`results/external_engines.json`）。

**⑨ 成立条件** 0 < T ≤ H（H は年次表の長さ、架空データでは 130）。事象の時刻が T または整数年から相対 1e-10〜1e-8 の距離にある入力（判定が丸めで決まる）は比較から除外する。振幅が T によらないこと（各節の④で確かめる）。

**⑩ 未確認・例外** 「すべての T 依存がこの核で書ける」ことは、70 単位について構成で示した（各節）が、一般の定理としては述べていない。除外した入力（上の帯）は未検証。

**実装** `tstudy/rampstep.py`、`tstudy/knots.py`、`specs/at_t.py` の `TIME`。

## D-05 修繕（B3-01、B3-02）

**① 元の方程式**

```
B3-01: for 行 i（修繕率 r_i ≥ 0）: for 年 y = 1..Y:  その行の更新が年 y にあれば飛ばす;  e = e0_i·r_i·w_y(T)
B3-02: Σ_i e0_i·r_i·T
```

**② 意味** 毎年、初期の製造排出の一定割合を修繕として計上する。更新した年は修繕しない。

**③ 理論** 一定の密度から、事象を含む年セルを引く。

**④ 変形** a_i = e0_i·r_i とおく。

```
B3-01_i(T) = a_i·Σ_{y ∉ skip_i(T)} w_y(T) = a_i·Σ_{y=1}^{Y} w_y(T) − a_i·Σ_{y ∈ skip_i(T)} w_y(T)
```

第 1 項は `Σ_y w_y(T) = T`（年セルの重みの和は区間の長さ）なので密度 a_i·T。第 2 項の skip_i(T) は「T の内側の事象が属する年」の集合で、年 y が入るのは、その年の最初の事象 τ_i(y) が数えられるとき（`τ_i(y) < T(1−ε)`）に限る。よって

```
B3-01_i(T) = a_i·T − Σ_{事象を含む年 y} a_i·[τ_i(y) < T(1−ε)]·clip(T − (y−1), 0, 1)       （密度 − ゲート付き年セル）
by_year_k(T) = w_{k+1}(T)·( Σ_i a_i − Σ_{i: 年 k+1 の最初の事象が内側} a_i )
```

「その年の最初の事象」は、行と年セルをキーにした照合（先頭一致）で選ぶ。事象の表は時刻の昇順なので、先頭が最小の時刻である。

**⑤ 最終表現** 振幅 `b3.a_mat = [r ≥ 0]·(a01 + a03)·r`、`b3.a_eq = [r ≥ 0]·x01·r`。スペクトル `B3-01` は密度とゲート付き年セル（振幅 −a）。

**⑦⑧** 不一致 0。相対差は B3-01 で 5.7e-13 以下（最大規模 26,300 行）、B3-02 で 4.3e-15 以下。B3-01 が統合系で最大の相対差で、原因は「密度 a·T から多数の年セルを引く」ときの丸めである（桁落ちは軽い。行数とともに増える）。

## D-07 運用（X-06、B6-04、B6-01、B6-02、B6-03、B2-01、B7-01〜04、X-11）

**① 元の方程式**

```
年次量（年 y、添字 k = y−1）:  一定なら base、直線なら base + slope·k、どちらでもなければ年次表[k]
X-06 電力係数 γ_k:  整った記述子なら  一定: start / 直線低下: max(floor, start − decline·k) / 段階: from_index ≤ k の最後の段の値、 それ以外は年次表[k]
B6-04 買電量:  n_k = max(0, c_k − (g_k·cg − x_k·cx))        （単位が「単位/year」で換算できるとき）
B6-01:  e_k = n_k × 換算 × γ_k                              （使用許諾・換算あり・B6-04 が算出済みのとき）
B6-02:  f_k = Σ_{燃料} 量_k × 換算 × 係数
B6-03 = Σ_y w_y(T)·(e_y + f_y),   B2-01 = (Σ_y w_y(T)·e_y)·ρ（ρ は施設管理の比率、0〜1）,   B7-04 = Σ_y w_y(T)·(上水 + 下水 + 廃棄物)_y
X-11 = 延床面積 × 面積当たり電力 × 換算 × Σ_y w_y(T)·γ_y
```

**② 意味** 年ごとのエネルギー・水の量に係数を掛け、評価期間で積算する。電力の係数は年とともに変わる。

**③ 理論** max は指示関数で書ける（`max(0, d) = [d ≥ 0]·d`、`max(p, q) = [p ≤ q]·q + [p > q]·p`）。区分的に一定の関数（段階）は、区間の指示関数の和。年の和は D-03 の年セル。

**④ 変形**

(1) 年の添字。電力係数の年次表の行（k = 0, …, H−1）を暦として使う。年次量は暦の上の積和になる：

```
v_k = [一定][base がある]·base + [直線][base, slope がある]·(base + slope·k) + [どちらでもない]·table_k
```

table_k は、暦の行から年次表の行への照合（位置 k が等しい行）で引く。

(2) 段階的な電力係数。段 s の開始位置 f_s が厳密に増加し f_0 = 0 のとき、「from_index ≤ k の最後の段」は「f_s ≤ k < f_{s+1} を満たすただ 1 つの段」である（増加列なので区間 [f_s, f_{s+1}) は互いに重ならず、0 以上の整数を覆う）。よって、年×段の全組合せの表の上で

```
γ_k = Σ_s [f_s ≤ k]·([次の段がない] + [次の段がある][¬(f_{s+1} ≤ k)])·val_s
```

「次の段」は、位置 s+1 をキーにした照合。差分（val_s − val_{s−1}）を累積する形にしなかったのは、値を足し直すと丸めが入るためである（上の形は val_s をそのまま取り出す）。

(3) 整っているかの判定。`[段階][段が 1 つ以上][先頭の段の開始が 0][開始が前の段以下の段が 0 個]`。最後の個数は、位置 s−1 への照合を使った積和。

(4) 単位。「単位/year」かどうかは `[~t = "year"]`、その単位は `~h`。電力係数の電力量の単位は `[~h = "kgCO2e"][~t がある][~t ≠ ""]·~t`。

(6) 記述子と年次表の一致（`descriptors_match_tables`）。年 k の食い違い `mis_k = [v ≠ t]·[|v − t| > 1e-12·max(|v|, |t|)]` を、絶対値と最大値を指示関数で書いて作り（テンプレート `CLOSE`）、`N(T) = Σ_k mis_k·[k < T]` を原子のスペクトルで数える。判定は `[N(T) = 0]`。

**⑤ 最終表現** 暦の列 `x06.g`（γ）、`b64.net`（買電量）、`b61.e`、`b62.e`、`b71.e`〜`b73.e`、振幅 `b63.a = b61.e + b62.e`、`b74.a`。スペクトル `B6-03`、`EL`、`G`、`B7-04`、燃料ごとの活動量 `act.*`、食い違いの件数 `mis.*`。

**⑥ 入力と係数** 年次量 9 本（記述子と年次表）、電力係数（記述子・段・年次表・単位・使用許諾）、燃料と上下水の係数 ID、換算表、施設管理の比率、延床面積。**基準計算の出力は使わない**（2026-11-12 の代表値検証では年ごとの値を基準計算から取っていた。それを解消した）。

**⑦⑧** 年ごとの値（X-06、B6-04、B6-01、B6-02、B7-01〜03 の by_year）は全集合で倍精度の完全一致。積算値は B6-03 3.2e-15、B2-01 2.9e-15、B7-04 2.5e-15、X-11 4.0e-15 以下。算出可否・除外件数・一致判定・source は不一致 0。

## D-08 冷媒の漸化式から積和 8 段へ（B1-01、B1-02、B1-03）

**① 元の方程式**（機器ごと。r = 年間漏洩率、m0 = 初期充填量、λ = 交換時損失率）

```
m ← m0
for y = 1..Y:
    leak = m·r·w_y(T);  B1-02 += leak·GWP;  補充しない機器は  m ← m − leak
    年 y に属する交換 1 回ごとに:  B1-03 += m·λ·GWP;  m ← m0
B1-04 = (評価期間の終わりの m)·(1 − 回収率)·GWP
```

**② 意味** 冷媒は毎年一定割合で漏れ、機器の交換で初期量に戻る。排出は「その時点の残存量」に比例するので、状態 m を年ごとに追う必要がある。

**③ 理論** 一次の線形漸化式は、下二重対角行列の線形方程式である。べき零行列 N について `(I − N)^{-1}` は有限のノイマン級数で、項数が 2 のべきのとき因数分解できる。

**④ 変形**（途中を省かない）

**(a) 状態を T によらない列にする。** 年セル k（年 y = k+1）の年初の残存量を u_k とする。評価期間の途中の年はすべて重みが 1 なので、最後の年より前では

```
補充なし・交換なし:  u_{k} = u_{k−1} − u_{k−1}·r·1 = (1 − r)·u_{k−1}
補充あり:            u_{k} = u_{k−1}
年セル k−1 に交換がある:  u_{k} = m0
```

最後の年の端数の重み w_Y(T) は、その年の排出と期末の量にしか効かない。交換の有無 p_k（年セル k に交換が 1 回以上ある）は、T が年セル k より後にあれば T によらない（年セル k の交換はすべて T の内側。0.3 節の規則と、D-03 ⑨ の除外による）。
そこで q = [補充あり]·1 + [補充なし]·(1 − r) とおくと、

```
u_0 = m0 ,      u_k = p_{k−1}·m0 + (1 − p_{k−1})·q·u_{k−1}        (k = 1, 2, …, H−1)
```

**(b) 行列の形。** 機器×年の表の上で、

```
b_0 = m0,  b_k = p_{k−1}·m0 ;      (N u)_k = (1 − p_{k−1})·q·u_{k−1}        ⇒      u = b + N u ,   (I − N) u = b
```

N は対角の 1 つ下だけに成分を持つので、`N^H = 0`（べき零）。

**(c) 逆行列。** `(I − N)·(I + N + N² + … + N^{H−1}) = I − N^H = I` より `(I − N)^{-1} = Σ_{j=0}^{H−1} N^j`。

**(d) 因数分解。** 任意の正方行列 N と m ≥ 1 について

```
Π_{i=0}^{m−1} (I + N^{2^i}) = Σ_{j=0}^{2^m − 1} N^j
```

（帰納法：m = 1 は自明。`(Σ_{j<2^i} N^j)·(I + N^{2^i}) = Σ_{j<2^i} N^j + Σ_{j<2^i} N^{j+2^i} = Σ_{j<2^{i+1}} N^j`。）
2^m ≥ H なら右辺は (c) の和に等しい（j ≥ H の項は 0）。H ≤ 256 なので m = 8 で

```
u = (I + N)(I + N²)(I + N⁴)(I + N⁸)(I + N¹⁶)(I + N³²)(I + N⁶⁴)(I + N¹²⁸) b
```

**(e) 各因子を積和 1 段にする。** N^s は「s 年前の行から、その間に交換が無ければ q^s を掛けて持ってくる」行列で、成分は 1 行に 1 つ：`(N^s u)_k = c^{(s)}_k·u_{k−s}`、`c^{(s)}_k = Π_{i=0}^{s−1} (1 − p_{k−1−i})·q`（k < s なら 0）。すると

```
c^{(1)}_k   = [k ≥ 1]·[p_{k−1} = 0]·q
c^{(2s)}_k  = c^{(s)}_k · c^{(s)}_{k−s}                         （s 年ぶんの係数を 2 つ掛ける）
u ← u + c^{(s)}_k · u_{k−s}                                    （因子 (I + N^s) を掛ける）
```

「s 年前の行」は、（機器, k − s）をキーにした照合で引く。どの式も、機器×年の表の上のマスク付き積和である。s = 1, 2, 4, …, 128 の 8 回で u が得られる。べき乗も逐次計算も使わない。
解は `u_k = m0·q^{(最後の交換からの年数)}` で、これは (a) の漸化式を解いた値に等しい。

**(f) 排出。**

```
B1-02(T) = Σ_{d,k} u_{d,k}·r_d·GWP_d·clip(T − k, 0, 1)                                          （年セル）
B1-03(T) = Σ_{交換 e（機器 d、年セル k、時刻 τ）} [τ < T(1−ε)]·λ·GWP·( [その年の最初]·u_{d,k}·(1 − [補充なし]·r·clip(T − k, 0, 1)) + [2 回目以降]·m0 )
```

B1-03 の第 1 項は、その年の漏洩（年重みは T での値）を引いたあとの量である。原子 `λ·GWP·u` と、ゲート付き年セル `−λ·GWP·u·r`（ゲートはその交換の時刻）に分かれる。
「その年の最初の交換」は、機器×年の行から交換の表への照合（先頭一致）で選ぶ。

**⑤ 最終表現** 列 `b1.u8`（年初の残存量）、振幅 `b1.a2`、`b1.a3`、`b1.g3`。スペクトル `B1-02`（年セル）、`B1-03`（原子＋ゲート付き年セル）。B1-01 は `Σ_d [充填量 ≥ 0][GWP ≥ 0]·充填量·GWP`。

**⑥ 入力と係数** 充填量、GWP、漏洩率、損失率、補充の有無、耐用年数または交換年一覧。交換の時刻は格子（一覧があれば一覧、なければ耐用年数の倍数。選択は述語）。

**⑦⑧** 不一致 0。相対差は B1-02 で 3.5e-15、B1-03 で 2.6e-14 以下（後者の最大は同じ年に 3 回の交換を置いた特殊条件）。別エンジン：(d) の恒等式は SymPy（記号の重み、n = 8・16）と SageMath（有理数、n = 64、6 因子）で厳密に成立、漸化式と 8 因子の積は有理数で完全一致（SymPy、40 機器）、SciPy の疎な三角解と 1.9e-15、MATLAB の `\` と 2.3e-16 で一致した。

**⑨ 成立条件** 年数 H < 256（8 因子）。0 ≤ r ≤ 1。交換の時刻が D-03 ⑨ の帯に無いこと。

**⑩ 未確認・例外** H ≥ 256 の年次表では因子を 1 つ増やす必要がある（仕様の `NDBL`）。積の順序が基準計算の逐次計算と違うので、u は数 ulp 違う。

**実装** `specs/physical.py` の `REFRIGERANT`、`specs/lib.py` の `DOUBLE`。

## D-09 冷媒の期末残存量 B1-04：跳び形の桁落ちと、節点スペクトルの区間形

**① 元** `B1-04 = Σ_d (期末の m_d)·(1 − 回収率_d)·GWP_d`（D-08 ① の m）。

**② 意味** 廃棄時に回収されずに放出される量。期末の「状態」そのものに比例する。

**③ 理論** 区分的に一次の関数には、節点での跳びを並べる表現（跳び形）と、各区間の中で有効な係数を並べる表現（区間形）がある。厳密な算術では、区間形の係数は跳び形の跳びの累積和であり、2 つは同じ関数である。浮動小数では、累積和の中の桁落ちの有無が違う。

**④ 変形**

**(a) 跳び形（2026-11-12 の代表値検証の形）。** κ = (1 − 回収率)·GWP とおく。期末の量を「初期量 − 最後の交換以降の漏洩」と書くと、

```
B1-04_d(T) = κ·( m0 − Σ_k [補充なし]·u_k·r·clip(T − k, 0, 1) + Σ_{交換を含む年セル k} [τ1_k < T(1−ε)]·( (m0 − u_k) + [補充なし]·u_k·r·clip(T − k, 0, 1) ) )
```

（各年の漏洩を引き、交換のたびにそれまでの不足分を戻す。）どの項も核の形なので、節点スペクトルで評価できる。

**(b) 桁落ち。** 交換が無く漏洩が続くと、結果は `κ·m0·q^n`（n は年数）で、大きさ κ·m0 の項を足し引きして得る。相対誤差はおよそ `ε_mach / q^n`。q = 0.65・n = 60 なら q^n = 6e-12 で、相対誤差は 1e-5 程度、q = 0.4 では値として使えない（EXP-U1 で実測）。

**(c) 区間形。** T が年セル K にあるとき（K < T ≤ K+1）、機器 d の期末の量は

```
年セル K の交換がまだ数えられていない:  u_{d,K}·(1 − [補充なし]·r_d·(T − K))
数えられた（τ1 < T(1−ε)）:              m0
```

機器について足すと

```
B1-04(T) = A_K + B_K·(T − K) + Σ_{年セル K の交換, τ1 < T(1−ε)} ( a_j + g_j·(T − K) )
A_K = Σ_d κ_d·u_{d,K} ,   B_K = −Σ_d κ_d·[補充なし]·u_{d,K}·r_d ,   a_j = κ·(m0 − u) ≥ 0 ,   g_j = κ·[補充なし]·u·r ≥ 0
```

（交換した機器の項は `κu(1 − r(T−K)) + κ(m0 − u) + κ u r (T−K) = κ m0`。）
初期量からの引き算が無く、足すのは結果と同じ大きさの項だけである。A_K、B_K は積和①で年セルごとにまとめ、補正は年セルごとに時刻の順の累積和を持つ。評価は、年セルの特定（K = ceil(T) − 1）と、そのセルの中の二分探索 1 回。

**(d) 積和による局所形。** 同じ式を、機器×年の表の上で「T を含む年セル」を述語 `[k < T][T ≤ k+1]` で選ぶ積和として書ける（`t.b14`）。値は (c) と同じで、計算量が機器×年の行数に比例する。

**⑤ 最終表現** 採用したのは (c)（`tstudy/interval.py` の `IntervalSpectrum`）。(d) は照合用に毎回計算し、(a) は比較用に残した（`System(..., b14="jump")`）。

**⑥ 入力と係数** D-08 の u、回収率、GWP、交換の時刻。

**⑦⑧** EXP-U1（mpmath 60 桁の漸化式を真値とする。45 条件）：最大相対誤差は、基準計算 4.6e-16、跳び形 6e+21（漏洩率 60％・130 年で破綻）、**区間形 6.6e-15、局所形 6.7e-15**。生成器の範囲（評価用集合）では跳び形でも 2.4e-14 以下。全集合の検証（区間形）では不一致 0、相対差 4.0e-15 以下。

**⑨ 成立条件** D-08 と同じ。

## D-10 段階ベクトル・合計・指標・基準案との比較（X-02、SUM-01〜08）

**① 元の方程式**

```
X-02:  A1-A3 = A13-01 + A13-03 + A13-04 + X-01, …, B6 = B6-03 − B2-01, …（14 段階）。対象外の段階は結果に含めない。
       B2 が対象外で B6 が対象なら B6 = B6-03。 対象段階に「除外した行などを持つ単位」があれば complete = 偽、その単位を列挙。
SUM-01/02/03:  対象段階のうち所定の段階の値を順に足す。
SUM-04 = S3/面積（面積 > 0 のとき）, SUM-05 = S3/(面積·T), SUM-06 = S3/1000, SUM-07 = 段階の値/S3（S3 > 0 かつ負の段階なし）
SUM-08:  基準案があり、面積・期間・対象段階・ガスの範囲・係数の版の集合がすべて一致すれば  差 = p − b、削減率 = (b − p)/b（b > 0）
```

**② 意味** 単位の値を段階にまとめ、合計と指標を作り、完全かどうかと、基準案と比べられるかを判定する。

**③ 理論** まとめ方は、0/1 と ±1 の成分を持つ行列（段階×単位）との積。集合の一致は、互いに含まれない要素が 0 個であること。

**④ 変形**

```
full_s = Σ_u M_{s,u}·v_u(T)                      M は「段階の構成」の表（符号 ±1。B6 の行に B2-01 が −1）
bs_s   = [s が対象]·Σ_u M_{s,u}·([条件なし] + [B2 が対象のときだけ]·[B2 が対象])·v_u(T)
complete(T) = [ Σ_{(s,u) ∈ 点検表} [s が対象]·[bad_u(T) ≥ 1] = 0 ]       bad_u は単位 u の除外件数など（B4-02 だけ T に依存）
S1 = Σ_s [対象][A1-A3, A4, A5]·bs_s ,  S2 = Σ_s [対象][B6, B7 以外]·bs_s ,  S3 = Σ_s [対象]·bs_s
SUM-04 = [A > 0]·S3·(1/A) ,  SUM-05 = [A > 0]·S3·1/(A·T) ,  SUM-06 = S3·0.001
割合_s = [対象]·[S3 > 0]·[負の段階が 0 個]·bs_s·(1/S3)
集合 X, Y の一致 = [Σ_{x ∈ X} [x ∉ Y] = 0]·[Σ_{y ∈ Y} [y ∉ X] = 0]            （∉ は照合が外れること）
比較可能 = [基準案がある]·[面積が等しい]·[期間が等しい]·[段階の集合が一致]·[ガスの範囲が等しい]·[係数の版の集合が一致]
差 = p − b ,   削減率 = [b > 0]·(b − p)·(1/b)
```

単位の値 v_u(T) は、T によらない単位は積和①のスカラー、T に依存する単位は節点スペクトルの値である。これを「単位の行を持つ表 U」に並べ直してから積和②（AGG）に渡す（並べ直しに算術は無い）。
基準案の値 b は、基準案の入力に同じ系をもう一度通して得る。

**⑤ 最終表現** 静的な表 `STG`（14 段階）、`COMP`（構成、22 行）、`CHK`（点検、27 行）。

**⑥ 入力と係数** 対象段階の一覧、延床面積、基準案の ID と基準案の入力一式。

**⑦⑧** 真偽値・一覧・状態・理由は全集合で不一致 0。数値は SUM-01 2.5e-16、SUM-02〜06 1.1e-13、SUM-07 4.7e-13、SUM-08 1.3e-13 以下（どれも B3-01 の丸めを引き継いだもの）。

**⑨ 成立条件** 段階の値が有限であること。

**⑩ 未確認・例外** 除算は逆数との積で行うので、最後の 1 ビットが基準計算と違うことがある。基準案の合計が不完全でも比べる点は基準計算と同じ（有効範囲の条件 9）。

## D-11 排出の行による再集計（X-04、X-05、X-07、QA-01 (a)、QA-03）

**① 元の方程式**

```
段階ごとの「行」＝（係数 ID, 活動量）の一覧。A・C 段階は行の結果の内訳、B3 は 製造の行×修繕率×修繕年数、B4 は 行×更新回数、
B5 は A・C 段階のすべての行×(建替回数×範囲比)、B6・B7 は 年重み付きの活動量、買電と冷媒は係数を持たない擬似の行。
X-04:  by_gas[g] = Σ_行 活動量×係数のガス g の量 ;  値 = Σ_g GWP_g·by_gas[g] + 買電 + 冷媒 ;  段階ごとの足し直し = Σ_行 活動量×係数の値
X-05:  段階ごとに Σ_行 活動量×係数の CO2 の量（買電は CO2、冷媒は 0）
X-07:  時点 0 に初期段階、各年に年次の排出と事象の排出、最終年に廃棄段階と B1-04。累積を作る。
QA-01 (a):  段階の値と足し直しが 1e-9·max(|段階|, 1) 以内で一致
QA-03:  行で実際に使われた係数がすべて使用許諾あり・出典あり
```

**② 意味** 同じ排出を、係数のガス別の内訳・CO2 だけ・年ごと、という別の切り口で集計し直す。

**③ 理論** 排出は「活動量×係数」の双一次形式なので、係数の側の値（CO2e、ガス別、CO2）を取り替えれば別の集計になる。

**④ 変形**

(1) 行の種類（スロット）を 20 個の表として書く（`LINE_SLOTS`）：マスク、活動量の因子、係数への参照、段階。A・C 段階の「係数ごとの活動量」は

```
L_s[f] = Σ_{スロット σ ∈ 段階 s} Σ_{行 x} [マスク_σ(x)]·活動量_σ(x)·[係数_σ(x) = f]           （係数への参照でまとめる積和）
```

(2) 繰り返される行。行ごとの時間の量を TIME で作る：更新回数 `n_i(T) = Σ_事象 [τ < T(1−ε)]`、修繕年数 `Y_i(T) = T − Σ_{事象を含む年} [最初の事象が内側]·clip(T − k, 0, 1)`。すると

```
L_B3[f](T) = Σ_σ Σ_x [マスク][修繕の行がある]·活動量·r_i·Y_i(T)·[係数 = f]
L_B4[f](T) = Σ_σ Σ_x [マスク]·活動量·n_i(T)·[係数 = f]
L_B5[f](T) = k(T)·Σ_{s ∈ A, C} L_s[f] ,   k(T) = 建替回数(T)·範囲比
L_B6[f](T) = [燃料 f が使える]·(燃料の活動量のスペクトル)(T)          （B7 も同じ）
```

(3) 集計。

```
足し直し_s = Σ_f L_s[f]·値_f + 擬似の行 ,   CO2_s = Σ_f L_s[f]·CO2_f + 買電の行
by_gas[g] = Σ_f (Σ_s L_s[f])·ガス量[f, g] ,   値 = Σ_g GWP_g·by_gas[g] + 買電 + 冷媒
使用_f(T) = [ 存在する行の数_f(T) ≥ 1 ] ,   QA-03 の違反 = 使用_f·[使用許諾なし または 出典が空]
```

「存在する行の数」は活動量が 0 の行も数える（数量 0 の行も係数を使ったことになる。基準計算と同じ）。更新のときだけ現れる行（据付、設備の搬入・据付）は、その行に更新が 1 回以上数えられたときに限り存在する：`[行がある]·[n_i(T) ≥ 1]`。

(4) X-07。年の表 Y0（0, 1, …, H）の上で、時点 0・各年・最終年の項を並べる。各年の値は TIME の年ごとの列（`t.b42_y` など）と年次の列（`b61.e` など）×年重み。最終年は述語 `[k < T][T ≤ k+1]`。累積は、年×年の全組合せの表の上の `cum_y = Σ_{y' ≤ y} series_{y'}`。

(5) QA-01 (a)。`|d| ≤ tol ⟺ [d ≤ tol]·[−d ≤ tol]`、`tol = 1e-9·([|s| ≥ 1]·|s| + [|s| < 1]·1)`。

**⑤ 最終表現** `specs/physical.py` の `LINES`（静的な段階）、`specs/at_t.py` の `TIME`（L.B3〜L.B7、使用）と `AGG`（集計、X-07、QA-01）。

**⑥ 入力と係数** D-01〜D-08 の活動量の列、係数のガス別の量、ガスの GWP、対象段階。

**⑦⑧** 不一致 0。X-04 7.1e-14、X-05 2.4e-14、X-07 3.0e-15 以下。QA-03 の違反一覧と使用件数は完全一致（出典が空の係数、更新前後での件数の変化を含む）。

## D-12 検査・品質（C-05、QA-01、QA-02、QA-04、SYS-01〜04）

**① 元の方程式**（共通の形）：対象を 1 つずつ調べ、条件を破ったものの場所を一覧にし、一覧が空なら合格。

**② 意味** 入力と結果の整合を調べる。数値ではなく、真偽値・件数・場所の一覧を返す。

**③ 理論** 検査は述語の積、件数は和、合否は「件数が 0」という述語、一覧は印の付いた行の集合である。

**④ 変形**

```
違反の印 v[x] = Σ（排他的な）Π 述語       件数 n = Σ_x v[x]       ok = [n = 0]       一覧 = { x : v[x] = 1 }
```

- **C-05**：経路の比率の和 `tot_i = Σ_j 比率`、負の個数 `neg_i = Σ_j [比率 < 0]`。`v1 = [neg ≥ 1] + [neg = 0][¬(tot ≤ 1 + 1e-6)]`、未配分 `= [v1 = 0][tot < 1 − 1e-6]`、質量 `v2 = [点検できる]·[¬(廃棄質量 ≤ 据付質量·換算·(1 + 1e-6))]`。
- **QA-02**（T に依存）：一覧の時刻 t ごとに `[¬(t ≥ 0)] + [t ≥ 0][T(1−ε) ≤ t]` を行にまとめる。ゲートは節点と同じ述語。
- **SYS-04／QA-04**：用途別面積を用途名の昇順に足す（足す順序は定義の一部なので、並べ替えた表の上で足す）。`r = A − S`、`|r| ≤ c·A ⟺ [r ≤ c·A][−r ≤ c·A]`。
- **SYS-01**：入力値ごとの状態。宣言された状態は「所有者の上書き、なければ出所の記録、なければ欠損」：`d_s = [上書きがある][上書き = s] + [上書きがない][記録がある][記録の状態 = s]（+ s が欠損のとき [どちらもない]）`。状態は `欠損 = [値がない] + [値がある][導出でない][0 でない]·d_欠損`、`導出 = [値がある]·d_導出`、`明示の 0 = [値がある][導出でない]·([0] + [0 でない]·d_明示の0)`、ほかも同様。上書きのキーは、行が所有者なら項目名、一覧の要素なら `一覧名[番号].項目名` なので、共通表の分割（`~p`、`~i`、`~s`）で照合する。項目は 26 種類（テンプレート `STATE` を 26 回）。
- **SYS-02**：活動量と係数が出会う 24 種類の場所と、単位だけの換算 5 種類。`違反 = [適用][単位がない] + [適用][単位がある][記録がある][換算できない]`、段階の不一致は係数ごとに `Σ_場所 [適用][単位がある][記録がある][段階ゲート ≠ 1]` を数える。
- **SYS-03**：係数の参照 24 種類。`参照なし = [適用][ID がない]`、`記録なし = [適用][ID がある][照合が外れる]`、使用許諾は係数ごとの参照数 `cnt_f` と `[許諾なし または 出典が空]` の積。電力係数シナリオを 1 件加える。
- **QA-01 (b)(c)**：`[a01 ≠ 0][a03 ≠ 0]`、`[a41 ≠ 0][a42 ≠ 0]`。

**QA-01 が入力では破れないこと。** (b)：a01 は `[EPD でない]`、a03 は `[EPD である]` を因子に持つので、同じ行で両方が 0 でないことはない。(c)：a41 は `[搬入係数なし]`、a42 は `[搬入係数あり]` を因子に持つ。(a)：段階の値と足し直しは同じ活動量と同じ係数の値から作る。したがって、違反が出るのは上流の計算が壊れたときだけである。そこで、上流の結果（A13-03 と A4-02 の行の値、段階の値）を**基準計算の側と統合系の側で同じように偽り**、QA-01 の出力が一致し、どちらも不合格になることを確かめた。

**⑤ 最終表現** `specs/gates.py`（`CHECKS`、`SYS_01`、`SYS_02`、`SYS_03`）、`specs/at_t.py`（QA-01 (a)、QA-02）。場所の文字列（`materials[3].end_of_life.routes` など）は、印の付いた行の番号から読み出しで作る。重複の除去と整列は読み出しで行う（算術ではない）。

**⑥ 入力と係数** 入力のすべての数値項目、状態の上書き、出所の記録、係数の記録（使用許諾・出典・段階）、単位。

**⑦⑧** 真偽値・件数・一覧・状態は全集合で不一致 0。基準計算の側で検査が実際に働いた回数は `VERIFICATION.md` の 4 節（例：SYS-01 不合格、SYS-02 の違反あり、C-05 の違反ありなどが、欠陥入りと特殊条件で発生）。QA-01 の故障注入は 4 件とも一致。SYS-04 の残差は、並べ替えを入れる前は 4 組で食い違い（足す順序の違い）、入れた後は完全一致。
