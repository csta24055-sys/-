# マスク付き積和の統一計算仕様

実装：`research_code/tstudy/msp.py`（2026-11-11 にコミットした版から無変更）。仕様：`research_code/specs/`（データのみ。関数や式の文字列を含まない）。

## 1. 形

```
out[g] = Σ_{行 x} Σ_{項 t} Π_k φ_{t,k}(x)
```

仕様の 1 ステップは、表（添字集合）、項の一覧（因子の一覧の一覧）、まとめ方、結果の列名からなる辞書である。エンジンは評価単位の ID で分岐しない。

| 要素 | 種類 |
|---|---|
| ステップ | `sp`（積和）、`match`（キーが等しい最初の行への参照）。`use` はテンプレートの展開（計算ではない） |
| 因子 | 列（定数を含む）／述語 `present`・`range`・`eq`・`le` とその否定／1 列の関数 `inv`・`one_minus`・`inv_one_minus`・`ratio_one_minus` |
| 列の指し方 | 同じ表の列／参照を通した列（`via`）／1 行の表の値（`of`）／定数 |
| まとめ方 | 行ごと（`none`）／合計（`total`）／参照先の行ごと（`by`） |

統合系が使っている関数は `inv`、`one_minus`、`inv_one_minus`、`ratio_one_minus` の 4 つで、2026-11-11 の語彙のままである（`results/controls.json` の `structure`）。

## 2. 欠損の規則

列ごとに「値がある」という印を持つ。述語がすべて 1 なのに値が欠けた項は欠損、欠損の行を含む群は欠損、読み出しは欠損を None にする。
述語が 1 つでも 0 の項は、値が欠けていても厳密に 0 を寄与する（これがマスクである）。欠損を 0 とみなすことはない。

## 3. 書き換えの型（どの単位もこの組合せ）

| 元の書き方 | 積和での書き方 |
|---|---|
| `if c: x else 0` | `[c]·x` |
| `if A: a elif B: b else c` | `[A]·a + [¬A][B]·b + [¬A][¬B]·c`（排他的な項） |
| `1 − p1·p2·…`（どれかが破れた） | `[¬p1] + [p1][¬p2] + [p1][p2][¬p3] + …` |
| `max(0, d)`、`max(p, q)`、`|d|` | `[d ≥ 0]·d`、`[p ≤ q]·q + [¬(p ≤ q)]·p`、`[d ≥ 0]·d + [d < 0]·(−1)·d` |
| `|d| ≤ tol` | `[d ≤ tol]·[−d ≤ tol]` |
| `a / b` | `a·inv(b)`（b が 0 のときは述語で外す） |
| キーによる検索、優先順位つきの検索 | `match` と、排他的な述語の和 |
| 2 つのキーでまとめる | 全組合せの表への `match` で参照を作り、`by` でまとめる |
| 集合の一致 | 互いに `match` が外れる要素の個数が両方 0 |
| 件数・真偽値・一覧 | `Σ 印`、`[件数 = 0]`、印が 1 の行（読み出し） |
| 前の行・s 個前の行 | 位置−s をキーにした `match` |
| 線形漸化式 `u = b + N u`（N はべき零のずらし） | `u ← u + c·u[k−s]`、`c ← c·c[k−s]` を s = 1, 2, 4, … で繰り返す（D-08） |
| 時刻 T でのゲート | `[τ < T']` を `¬[T' ≤ τ]`、年重みを `[k+1 ≤ T] + [k < T][¬(k+1 ≤ T)]·(T − k)` |

## 4. 3 つのプログラム

| プログラム | 仕様 | ステップ | 役割 |
|---|---|---|---|
| P1（積和①） | `specs/system.py` の `SPEC1` | 1,528（sp 1,358・match 170） | T によらない量：行の排出、係数の検索、振幅、行の検査、状態、係数ごとの活動量 |
| TIME（積和②a） | `specs/at_t.py` の `TIME` | 95（sp 95） | 時刻 T での節点の表の評価：回数、行ごと・年ごとの値、B1-04 の局所形、繰り返される行の活動量 |
| AGG（積和②b） | `specs/at_t.py` の `AGG` | 166（sp 156・match 10） | 段階ベクトル、合計、指標、基準案との比較、ガス別・CO2、年次系列、時間境界検査 |

P1 の単位の並び：既存の 18 単位（A5-01 だけ単位の読み取りを入れ替え）→ 解体・廃棄 → 振幅 → 事象の表 → 運用 → 冷媒 → 検査 → 排出の行 → SYS-01〜03 → 添字の参照。

## 6. 読み出し

読み出しは整形だけを行う（一覧・辞書・場所の文字列・型の変換・重複の除去と整列）。既存の 18 単位は仕様の `outputs`（データ）で、
それ以外は `tstudy/unified.py` の `_static_results`・`_results` で書いた。読み出しが使った列は実行時に記録され、`UNIT_MAP.md` の元になる。
