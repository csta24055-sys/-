# 節点スペクトルの時間計算仕様

実装：`research_code/tstudy/rampstep.py`（核と格子）、`tstudy/knots.py`（跳び形）、`tstudy/interval.py`（区間形）。
`rampstep.py` と `knots.py` は 2026-11-11 にコミットした版から無変更、`interval.py` は 2026-11-13 に追加した。

## 1. 核

```
h(T; s, ℓ, g) = [g < T(1−ε)] · clip((T − s)/ℓ, 0, 1)        ε = 1e-9,  ℓ = 0 のとき clip は 1
Φ(T) = Σ_j a_j · h(T; s_j, ℓ_j, g_j)                          a_j は T によらない
```

| 形 | (s, ℓ, g) | 使う場面 |
|---|---|---|
| 定数 | (0, 0, −∞) | 初期量など |
| 原子 | (τ, 0, τ) | 更新・交換・建替の 1 回、件数（振幅 1） |
| 年セル k | (k, 1, −∞) | 年ごとの量 × 年重み |
| ゲート付き年セル | (k, 1, τ) | 修繕の除外、交換直前の量 |
| 密度 | (0, H, −∞)、振幅 a·H | 毎年一定の量（T ≤ H で a·T） |

基準計算の規則との対応：年重み `min(1, T − (y−1))`（y ≤ ceil(T)）は年セル y−1、事象の計上 `τ < T(1−ε)` は原子のゲート、事象の年 `max(1, ceil(τ(1−ε)))` は節点が属する年セル。

## 2. 節点の位置

| 位置 | 作り方 | 所在 |
|---|---|---|
| 周期の倍数 n·c | n = 1, 2, … で `n·c < H(1−ε)` の間。周期が欠損・非正・無限なら無し | `rampstep.periodic_times`、`index.add_events` |
| 明示の一覧 | `0 < t < H(1−ε)` のもの | `rampstep.explicit_times`、`index.add_events` |
| 年の境界 | 0, 1, …, H（H は年次表の長さ） | 電力係数の年次表の行 |
| 節点が属する年セル | `k = max(1, ceil(τ(1−ε))) − 1` | `rampstep.event_year` |

事象の表（材料・設備・冷媒機器・建物・周期の値）は、周期の格子と一覧の格子の両方を持ち、どちらを使うかは積和の述語で決める。表の中では時刻の昇順に並べる（「その年の最初の事象」を先頭一致で選ぶため）。

## 3. 評価

**跳び形（`KnotSpectrum`）。** 各節点に、値の跳び c0 と傾きの跳び c1 を置く。

```
年セル k（振幅 a）:           節点 k に (−a·k, a)、節点 k+1 に (a(k+1), −a)        〔年の規則 t < T〕
原子（τ, 振幅 a）:            節点 τ に (a, 0)                                    〔事象の規則 τ < T(1−ε)〕
ゲート付き年セル（k, τ, a）:  節点 τ に (−a·k, a)〔事象の規則〕、節点 k+1 に (a(k+1), −a)〔年の規則〕
Φ(T) = base + P0e[ke] + T·P1e[ke] + P0p[kp] + T·P1p[kp]
```

P は節点の昇順の累積和（ノイマイヤーの補正つき）、ke・kp は二分探索。1 回の評価は節点の数によらない（二分探索 2 回）。

**区間形（`IntervalSpectrum`）。** 年セル k の内側で有効な係数を直接持つ。

```
Φ(T) = A[k] + B[k]·(T − k) + Σ_{セル k の節点, τ_j < T(1−ε)} (a_j + g_j·(T − k)),      k = ceil(T) − 1
```

セル内の補正は時刻の昇順の累積和（セルごとに 0 から）。状態量（冷媒の期末残存量）に使う。厳密な算術では跳び形と同じ関数で、浮動小数では初期量からの引き算が無い（DERIVATIONS D-09、EXP-U1）。

**ゲート付き和（積和②の TIME）。** 節点の表の上で核を述語と一次式の積として評価し、行・年・係数ごとにまとめる。

```
[τ < T'] = ¬[T' ≤ τ],   T' = T·(1 − 1e-9)
w_k(T)   = [k < T]·([k+1 ≤ T] + [¬(k+1 ≤ T)]·(T − k))
T を含む年セル = [k < T]·[T ≤ k+1]
```

行ごとの回数、年ごとの値、係数ごとの活動量のように、群の数が多い出力に使う。計算量は節点の表の行数に比例する。

## 5. 成立条件

- 0 < T ≤ H。H を超える T は受け付けない（基準計算は年次表が足りないと例外で止まる）。
- 事象の時刻が、T または整数年から相対 1e-10〜1e-8 の距離にある入力は、判定が丸めで決まるので比較から除外する（`scenarios.valid_domain`）。
- 跳び形は、結果が項の大きさに比べて極端に小さくなる量（強く減衰する状態）には使わない（区間形を使う）。
