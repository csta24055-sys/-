# 第3章：計算の前提・入力項目

[inputs.json](inputs.json) は **124件**の独立アプリ用入力仕様草案。ID / 種類 / 単位 / 条件付き必須 / 出典 / 権限を記録している。これは公式J-CAT全入力セルの認証済み転記ではない。

## 扱う項目群
- **PROJECT**: 22項目（建物名称、新築・既存・増改築、建物所在地・地域、地域・気候条件 など）
- **BOUNDARY**: 9項目（評価期間、建物の建替周期、評価開始年度、計算対象A1〜C4 など）
- **MATERIAL**: 20項目（材料行ID、工種（基礎・躯体・外装・内装等）、資材の分類（コンクリート等）、材種・規格・強度・厚さ・樹種 など）
- **FACTOR**: 11項目（独立係数ID、独立係数数値、係数の分母単位、係数が含む段階 など）
- **TRANSPORT**: 5項目（資材輸送質量、輸送距離、輸送手段・車種、積載率 など）
- **CONSTRUCTION**: 6項目（工事燃料の年間・工期総量、仮設電力使用量、工事用ガス使用量、工事廃棄物の数量 など）
- **EQUIPMENT**: 9項目（設備行ID、電気・空調・給排水・昇降機、製品・機器仕様、設備数量 など）
- **REFRIGERANT**: 8項目（冷媒・発泡剤・消火剤・絶縁ガスの種類、用途（断熱・空調・消火・絶縁）、機器充填質量、GWP（採用版指定） など）
- **OPERATION**: 11項目（新築・既存区分、年間買電量、延床面積当たり年間電力、年間ガス消費量 など）
- **WATER_WASTE**: 6項目（年間上水使用量、年間下水量、年間一般廃棄物量、上水原単位の独立ID など）
- **END_OF_LIFE**: 9項目（解体・撤去活動量、解体原単位、廃材輸送量、廃材搬出距離 など）
- **PROVENANCE**: 8項目（測定・設計・推定・文献の種別、入力項目の一次資料・証拠URL、使用許諾の状態、データ品質・不確実性 など）

## 運用上の最重要ルール
- 単位を必ず持たせる：kg, t, m2, m3, km, kWh, L、kgCO2e・tCO2eを混ぜない。
- 入力値の状態：MISSING / EXPLICIT_ZERO / OBSERVED / USER_ESTIMATE / LICENSED_DEFAULT / DERIVED。
- 資材単位の不一致や未許諾原単位は **計算を停止** する。
- `required_in_context` は全面必須ではない。実際の必須条件はステージ・算定目的・使用データで変化。
- 公開アプリは公式J-CAT原版の登録者情報や個人案件の例示値を流用しない。
- 専門の人が数値を上書きしたら元値・上書き理由・根拠を残す。
- GHG/CO2の結果単位と排出係数の意味を確認する。
- 関連説明：[第4章（計算）](../04_FORMULAS/README.md) → [第6章（入出力対応）](../06_LINEAGE/README.md)。

## 原版との対照（公開できるレベル）
- 標準算定の主要入力群：A1〜A5/B2〜B5/C1〜C4・B1・B6/B7の3群。
- 建物概要には所在地、用途、構造、延べ床面積、竣工年、用途別面積、評価期間、建替周期等。
- 資材の入力には工事細目、コード、数量、単位、更新周期、修繕率、材種など。
- 冷媒等には物質、使用用途、充填量、GWP、漏洩・回収の前提。
- 運用には電力、ガス、石油、水、一般廃棄物等の年間使用量。
