# 02 工程の定義、時間変数、70 単位との対応

対象：独立概念モデル（70 評価単位、架空データ）。第 17 章の正準形（核の項）を、建物のライフサイクルの**工程**に割り当てる。工程の数は固定しない（入力の行が工程の実体になる）。

## 1. 時間変数（混同しない）

| 記号 | 名前 | 定義 | モデルでの所在 |
|---|---|---|---|
| $t_{\mathrm{cal}}$ | 暦年 | $t_{\mathrm{cal}} = Y_0 + t$、$Y_0$ = `boundary.study_start_year`（評価の 1 年目の暦年） | 入力にあるが、70 単位の計算には使われない（第 2 段階で初めて使う） |
| $t$ | 供用開始からの経過時間（実時間） | 0 が供用の開始。施工は $t<0$ の側（拡張でだけ扱う） | 第 17 章 TH-4 の実時間の分解 |
| $T$ | 評価期間 | 算定に含める期間の長さ。$C(T)$ の引数 | 全単位 |
| $\tau_i = t - t_{i,0}$ | 工程の局所時間 | 工程 $i$ の開始 $t_{i,0}$ からの経過時間 | 下の 2 節 |
| $c_i$ | 更新周期 | 品目 $i$ の耐用年数（周期の倍数 $n c_i$ が事象の時刻） | 第 11 章の格子 |
| $t_e$ | 排出の時刻 | 排出（質量）が実時間の上で置かれる時刻 | 工程関数の原子の位置 |
| $t_{\mathrm{end}}$、$H_c$ | 気候影響の終点・時間範囲 | 動的な特性化で影響を数える終わりの時刻、またはその長さ | 06（拡張。モデルには無い） |
| $H$ | 年次表の長さ | 130 年 | $T\le H$ |
| $D_c$ | 施工期間 | `construction.duration_months / 12` | 入力にあるが 70 単位の計算には使われない |

**評価期間 $T$ と実時間 $t$ の関係**（第 17 章 TH-4）：$C(T) = M([0,T]) + Z(T)$。$M$ は $T$ によらない実時間の測度、$Z(T)$ は評価期間の終わり $t=T$ に置かれる項（C 段階と冷媒の期末残存量）。したがって $T$ を 1 年延ばしたときの $C$ の増分は、その 1 年の実際の排出と、終わりの項の変化の和であり、実際の排出そのものではない。

## 2. 工程（族と実体）

工程の**族**（17 個）は単位の意味から決まる。族の中の**実体**は入力の行（冷媒の機器、資材・設備の品目、改修の事象）で、数は建物ごとに違う。

| 族 | 名前 | 単位 | 実時間での形（導出） | 局所時間の原点 $t_{i,0}$ |
|---|---|---|---|---|
| P01 | 資材の製造 | A13-01、A13-03、A13-04 | $t=0$ の原子 | 0 |
| P02 | 設備機器の製造 | X-01 | $t=0$ の原子 | 0 |
| P03 | 現場への輸送 | A4-01、A4-02 | $t=0$ の原子 | 0 |
| P04 | 施工 | A5-04 | $t=0$ の原子 | 0 |
| P05 | 冷媒の漏洩 | B1-02 | 機器×年セルの一様な率 $r\,\mathrm{GWP}\,u_{d,k}$ | 0（状態は交換で初期化） |
| P06 | 冷媒の交換時の損失 | B1-03 | 交換の時刻の原子＋交換後の負の率（その年の漏洩分の差し引き） | 交換の時刻 |
| P07 | 施設管理のエネルギー | B2-01（段階 B2） | 年セルの率 $\rho_{\mathrm{B2}}\,e_k$ | 0 |
| P08 | 修繕 | B3-01 | $[0,H)$ の一様な率、更新の年に負の原子と負の率（年単位の除外） | 0 |
| P09 | 更新 | B4-02 | 更新の時刻 $n c_i$ の原子 | 各更新の時刻 |
| P10 | 大型改修・建替 | B5-01 | $nC_{\mathrm{ren}}$ の原子 | 各改修の時刻 |
| P11 | 運用エネルギー | B6-03、−B2-01（段階 B6） | 年セルの率 $e_k + f_k - \beta\rho_{\mathrm{B2}}\,e_k$ | 0 |
| P12 | 水・一般廃棄物 | B7-04 | 年セルの率 | 0 |
| P13 | 解体 | C1-01 | $t=T$ の原子 | $T$ |
| P14 | 廃棄物の輸送 | C2-01 | $t=T$ の原子 | $T$ |
| P15 | 廃棄物の処理 | C3-01、X-14 | $t=T$ の原子 | $T$ |
| P16 | 最終処分 | C4-01 | $t=T$ の原子 | $T$ |
| P17 | 冷媒の廃棄時の放出 | B1-04 | $t=T$ の原子（量は $T$ での状態 $R(T)$） | $T$ |

- **割り当ての一意性**：正準形のすべての核の項は、ちょうど 1 つの族に入る（単位と段階で決まる。B2-01 は段階 B2 なら P07、段階 B6 の差し引きなら P11）。検証は 07（R-1）。
- **実体**：P05・P06・P17 は冷媒の機器、P08・P09 は資材・設備の品目、P10 は改修の事象ごと。P01〜P04、P07、P11〜P16 は建物全体で 1 つの実体（行に分かれない集計値）。P17 の区間形の係数は年セルごとの機器の和なので、機器の実体に分けられない部分がある（07 に件数）。

## 3. 時間の意味をそのまま保つ規則

- 年セル $k$ の量は $[k, k{+}1)$ に一様に置く（モデルの年重み $w_k(T)$ が一次なので、これが唯一の整合する置き方）。
- 事象は浮動小数の規則の切り替え点 $\mathrm{sw}(\tau)$ に置く（第 17 章 L-2：$\tau/(1-\varepsilon)$ の数 ulp 以内）。
- ゲート付き年セル（事象の年の補正）は、事象の時刻の原子 $a(\mathrm{sw}-k)$ と、$[\mathrm{sw}, k{+}1)$ の率 $a$ に分ける（TH-4 の証明）。率が負なら負の排出として残す（符号を隠さない）。
- C 段階と冷媒の期末残存量は $t=T$ に置く。モデルは、その後の解体の期間・廃棄物の処理の時間を定義しない（05 の拡張）。
- 施工（A 段階）は $t=0$ に置く。モデルは施工期間の中の配分・製造の時期を定義しない（05 の拡張）。
