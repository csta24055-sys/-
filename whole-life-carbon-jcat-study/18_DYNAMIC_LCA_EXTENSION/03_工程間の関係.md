# 03 工程間の関係：順序・重なり・共有量・事象による結合・畳み込みの成否

対象は 02 の 17 族（独立概念モデル、架空データ）。関係は**モデルの式から導いたもの**（証明つき）と、**年の系列での測定**（07 の 3 節）を分けて書く。指示どおり、関係を畳み込みに統一しない。

## 1. 順序と重なり

| 区間 | 族 | 根拠 |
|---|---|---|
| $t=0$ | P01〜P04（A 段階） | 定数は $t=0$ の原子（02 の 3 節） |
| $[0,T)$ | P05、P07、P08、P11、P12 の流れ、P06・P08・P09・P10 の事象 | 年セル・密度・事象の時刻 |
| $t=T$ | P13〜P17 | 廃棄時の定数と冷媒の期末残存量 |

供用中の族は互いに全期間で重なる（07 の 3 節）。A 段階と C 段階は供用中の族と時間を共有しない（モデルの配置では原子）。

## 2. 共有量（同じ量を複数の工程が使う）

**P07 と P11（買電）。** 年セル $k$ の買電排出を $e_k$ とすると、P07 の率は $\rho_{\mathrm{B2}}\,e_k$、P11 の率は $e_k + f_k - \beta\rho_{\mathrm{B2}}\,e_k$（$f_k$ は燃料、$\beta = \iota_{\mathrm{B2}}$）。

$$ e_{07}(t) = \rho_{\mathrm{B2}}\,e_{\mathrm{el}}(t),\qquad e_{07}(t) + e_{11}(t) = e_{\mathrm{el}}(t) + e_{\mathrm{fuel}}(t)\quad(\iota_{\mathrm{B2}} = 1). $$

P07 は買電排出との**瞬時の比例**（核 $\rho_{\mathrm{B2}}\,\delta(\tau)$ の時不変の畳み込み）で厳密に表せる（07：全シナリオの全年セルで厳密に一致）。B2 を数えるとき、B6 から同じ量を引くので、合計は付け替えで変わらない。

**P10（改修・建替）。** 1 回の量は $\varphi\,(E_{\mathrm{A1\text{-}A3}} + E_{\mathrm{A4}} + E_{\mathrm{A5}} + E_{\mathrm{C1\text{-}C4}})$（初期の量の合計への**比例**）。時間関数としては

$$ e_{10}(t) = \varphi\,\big(E_{\mathrm{A}} + E_{\mathrm{C}}\big)\sum_{n\ge1}\delta(t - nC_{\mathrm{ren}}). $$

時刻の形は改修周期の櫛で決まり、量は他の工程の**合計**で決まる。他の工程の時間関数との畳み込みではない（C 段階の量は $t=T$ に置かれるが、改修の量はそれを $nC_{\mathrm{ren}}$ で使う）。

## 3. 事象による結合（更新の時刻が複数の工程を動かす）

品目 $i$ の更新の時刻 $\tau_{i,n}$（周期の倍数または一覧）は、次の工程に同時に効く。

| 工程 | 更新の時刻での働き | 数学的な形 |
|---|---|---|
| P09 更新 | 量 $u_i$ の原子 | $u_i\,\delta(t - \tau_{i,n})$（線形） |
| P08 修繕 | その年の残りの修繕を止め、その年の始めからの分を取り消す | $a_i\big(1 - \mathbf 1_{[\tau, k+1)}(t)\big)$ と $-a_i(\tau - k)\,\delta(t-\tau)$（**ゲート**：時刻について非線形、振幅について線形） |
| P06 冷媒の交換 | 交換時の損失、交換後のその年の漏洩の差し引き | 原子 $\lambda_{\mathrm{loss}}\mathrm{GWP}u$ と率 $-\lambda_{\mathrm{loss}}\mathrm{GWP}u r$ |
| P05 冷媒の漏洩 | 状態の初期化（翌年から $m_0$） | 下の 4 節 |
| P17 冷媒の廃棄時 | 期末の状態が初期化の後の値になる | 下の 4 節 |

事象の時刻の一致の数（07 の 3 節）：P08 と P09 は同じ品目の同じ時刻を共有する（修繕の除外は更新が起きた年だけ）。年の系列の相関も P08–P09 は強い負（更新の年に修繕が減る）。

## 4. 状態を持つ結合：冷媒（線形だが時不変ではない）

機器の年初の残存量 $u_k$ は、第 11 章 D-08 の漸化式

$$ u_k = \chi_{k-1}\,m_0 + (1 - \chi_{k-1})\,q\,u_{k-1},\qquad u_0 = m_0 $$

に従う（$\chi_{k-1}$ は年セル $k-1$ に交換があるか、$q = 1 - r$ または補充ありで 1）。解は $u_k = m_0\,q^{\,k - k_{\mathrm{last}}}$（$k_{\mathrm{last}}$ は最後の初期化の年）。漏洩の率は

$$ e_{05}(t) = r\,\mathrm{GWP}\sum_k u_k\,\mathbf 1_{[k,k+1)}(t) = \int h(t, s)\,dP(s),\qquad h(t, s) = r\,\mathrm{GWP}\,m_0\,q^{\lfloor t\rfloor - \lfloor s\rfloor - 1}\,[\,s \text{ が } t \text{ より前の最後の交換}\,], $$

と**二時刻の核** $h(t,s)$ で書ける（$P$ は交換の時刻の点過程、$s=0$ に初期の充填）。$h$ は「$s$ と $t$ の間に交換がない」という条件を含むので、$t - s$ だけの関数ではない（時不変でない）。しかも核そのものが後の事象で切られるので、交換の列については非線形（充填量 $m_0$ については線形）である。

- 交換が整数の周期 $c$ で起きるときは、$u_k$ は周期 $c$ の列になり、年増分に 1 の $c$ 乗根のモードが現れる（第 17 章 TH-9、07 の 4 節：周期 17 年で次数 16〜17）。
- 期末の状態 $R(T) = \kappa_R\,m(T)$（P17）は $t=T$ に置かれるが、その値は $[0,T)$ の交換の列で決まる（03 の 5 節の非一意性も参照）。

## 5. 畳み込みが成り立つか（年の系列での検査）

年の系列 $x_y, y_y$ に、因果的な長さ 12 年の時不変の核を最小二乗で当てはめ（$y \approx h * x$）、相対残差を測った（07 の 3 節）。残差 0 なら厳密な時不変の畳み込み。

- P07 ← P11：残差は多くのシナリオで小さいが 0 ではない（P11 に燃料と B2 の差し引きが入るため）。**真の関係は P07 ＝ $\rho_{\mathrm{B2}}\times$ 買電で、P11 との畳み込みではない**。
- P06 ← P05、P08 ← P09、P10 ← P09、P06 ← P09：残差は大きい（多くは 0.5 以上）。事象による**ゲート**と**状態の初期化**は時不変の畳み込みで表せない。
- これは文献の指摘（Pigné ら 2020：畳み込みは供給側に需要側の時間形を押しつける。Beloin-Saint-Pierre ら 2014：時間の平行移動に対する不変性はすべての場合には成り立たない）と同じ向きの結果である（01 の 4 節）。

## 6. 因果の構造（モデルの式から）

```
入力（数量・係数・周期・表・比率）
 ├─ 更新の時刻 τ_{i,n} ──→ P09（原子） ──┐
 │                     ├─→ P08（ゲート、負の補正）
 │                     ├─→ P06（交換時の損失）
 │                     └─→ 冷媒の状態 u_k ─→ P05（漏洩の率） ─→ P17（期末の状態、t = T）
 ├─ 買電 e_k ─────────────→ P07（ρ e_k）、P11（e_k + f_k − βρ e_k）
 ├─ 初期の量（A）と廃棄時の量（C） ─→ P10 の量（φ 倍）
 └─ 年次表 ──────────────→ P11、P12
```

矢印は「左の量が右の工程の時刻または量を決める」の意味。逆向きの依存（右から左）はない。年の系列の相関（07）は、共通の周期や傾向による見かけの相関を含むので、因果の判定には使わない。
