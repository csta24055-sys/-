# 18 動的 LCA への拡張：70 評価単位の骨格を保った工程関数・相互関係・再構成（第 2 段階）

指示書「ホールライフカーボン統一数学理論の確立」の第 2 段階の成果（2026-11-14）。

- 対象：独立概念モデル（70 評価単位、架空データ）。第 17 章の正準形（核の項）と実時間の分解（TH-4）を出発点にし、70 単位の骨格は変えていない。J-CAT 原版の式・係数・値は含まない。
- 導出したもの（モデルの式から）と、仮定したもの（文献に基づく時間配分）を分けて書く。導けない分布を導出結果としては扱わない。
- 証拠の水準：P＝証明、E＝有理数での厳密な照合（標本の点で）、F＝浮動小数での測定、L＝文献（読んだ水準つき）。
