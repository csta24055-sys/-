# 05 70 単位から導けない時間分布：仮定としての拡張と、非一意性

## 1. 導けるものと導けないもの

| 量 | 70 単位から導けるか | 理由 |
|---|---|---|
| 供用中の年ごとの量の配分（年セルの中で一様） | 導ける | 年重み $w_k(T)$ が一次。ほかの配分では年の途中の $T$ で $C_{70}(T)$ が変わる |
| 更新・交換・改修の時刻 | 導ける | 周期の倍数・一覧（第 11 章の格子） |
| 冷媒の状態の時間変化 | 導ける | 漸化式（03 の 4 節） |
| 施工期間の中での A 段階の配分、製造の時期 | **導けない** | A 段階は $t=0$ の定数。入力に施工期間 `construction.duration_months` があるが、どの単位も使わない |
| 更新に伴う製造・輸送・撤去の内訳の時期 | **導けない** | B4-02 は 1 回の更新の量 $u_i$ だけを持つ |
| 解体・廃棄物処理の期間、最終処分後の排出 | **導けない** | C 段階は $t=T$ の定数 |
| 年の中の季節変動 | **導けない** | 年次表しかない |

導けない分布は、以下の**仮定**（拡張）としてだけ扱い、導出結果とは書かない。

## 2. 変種（いずれも工程ごとの合計を変えない）

$D_c$ = 施工期間（入力の月数 / 12）、$D_e$ = 解体の期間（入力に無いので $D_e = D_c$ と仮定）。

| 変種 | 内容 | 根拠の種類 |
|---|---|---|
| M0 | モデルの配置（02） | 導出 |
| X1 | A 段階（P01〜P04）を $[-D_c, 0)$ に一様に配分 | 仮定（Negishi ら 2018・2019 の「施工は $[-1, 0]$」と同じ型） |
| X2 | 製造（P01、P02）を施工の始め $-D_c$ の原子、輸送と施工（P03、P04）を $[-D_c, 0)$ に一様 | 仮定（DyPLCA の「製造は使用の前」の型） |
| X3 | 廃棄（P13〜P17）を $[T, T + D_e)$ に一様に配分 | 仮定（Negishi の「廃棄は $[50, 51]$」の型） |
| X4 | X1 と X3 | 仮定 |

## 3. 非一意性の定理

**定理 1（配分の非一意性）.** 工程ごとの合計を保つ任意の配分の変更は、$C_{70}(T)$ を変えない（$C_{70}$ は合計と $T$ での状態だけで決まり、$t<0$ や $t\ge T$ の位置を区別しない）。したがって $C_{70}$ から実時間の分布を一意に戻すことはできない。

*証明.* $C_{70}(T) = M([0,T]) + Z(T)$ で、A 段階の原子を $[-D_c, 0)$ に動かしても $M([0,T])$ の中のその寄与は合計のまま（$T>0$ ならすべて $T$ より前）、C 段階を $[T, T + D_e)$ に動かしても $Z(T)$ は合計のまま。∎ 〔検証：07 の 4 節、全変種で合計が厳密に一致〕

**定理 2（終わりの項の読み替え）.** 冷媒の期末残存量 $R(T)$ は、跳び形（第 11 章 D-09）では
$$ R(T) = \kappa_R\Big(m_0 - \sum_k [\text{補充なし}]\,u_k r\,w_k(T) + \sum_{\text{交換}} \theta_\varepsilon(T;\tau)\big((m_0 - u_k) + [\text{補充なし}]\,u_k r\,w_k(T)\big)\Big) $$
で、これは $T$ によらない実時間の測度 $M_R$（$t=0$ に $\kappa_R m_0$、負の漏洩の率、交換の時刻に正の原子）について $R(T) = M_R([0,T])$ と書ける。つまり「廃棄時に放出する $R(T)$」を「供用中に少しずつ負の排出があり、交換で戻る」と読んでも、すべての $T$ で同じ $C(T)$ になる。

*証明.* 跳び形の各項は核の形なので、第 17 章 TH-4 の構成がそのまま使える。∎ 〔検証：`code/altdecomp.py`、`results/altdecomp.json`：$M_R([0,T]) = R_{\mathrm{jump}}(T)$ が全標本で有理数として一致。区間形との差は丸めの大きさ〕

この 2 つの読み方は、関数 $C(T)$ としては区別できない。本章は単位の意味（B1-04 は「廃棄時の未回収」）に従って $t=T$ に置いた。動的な特性化（06）では、どちらを採るかで結果が変わる。

## 4. 結論

- 70 単位から導ける時間構造は、年セルの一様な配分・事象の時刻・冷媒の状態まで。
- 施工・製造・解体の時期は入力にも単位の式にも無く、**仮定でしか決まらない**。変種ごとに結果を示し、どれも導出結果とは扱わない。
- $C(T)$ という関数そのものが、実時間の分布を一意に決めない（定理 1、2）。
