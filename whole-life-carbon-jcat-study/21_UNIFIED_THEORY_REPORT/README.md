# 21 研究報告書：70 評価単位を基礎とした時間特性・動的 LCA 統一理論

指示書「Claude Code研究指示書 ホールライフカーボン統一数学理論の確立 — 70評価単位の完全時間解析・動的LCAへの拡張・全体再構成・大規模確率検証」の最終報告（2026-11-14）。第 17〜20 章の成果をまとめる。`code/make_report.py` が各章の結果ファイルから数値（件数・不一致・上限）を読み込んで書き出した。判定の語句と、扱いの記述（除外 0 など）は本文として書いた。

- 対象：第 1・2・4 段階は独立概念モデル（70 評価単位、架空データ）。第 3 段階だけが J-CAT 原版の式を扱い、原版の式本文・係数・値・セル番地は公開しない（非公開の資料として直接渡した）。
- 本研究は J-CAT と同じ結果を出す製品・互換ソフトを主張しない（`01_COMPLIANCE`）。
- 証拠の水準：**P** 証明、**E** 有理数での厳密な照合（標本の点）、**F** 浮動小数での測定、**S** 宣言した分布での統計的な確認、**L** 文献。

## 1. 要旨

1. **建物全体の理想方程式.** 70 単位の合計 $C(T)$ を核の項の 1 本の和と節点形 $C(T) = A_0 + \sum_t[t<T](P_t+Q_tT) + \sum_g\theta_\varepsilon(T;g)(p_g+q_gT)$ に展開した（17 章 01）。どの係数も単位・段階・入力の行へ戻せる。基準計算と 1,293 組（定義域の外 2 を除く）で相対 1e-9 以内、不一致 0。節点形と核の和は 1,293 組の評価期間で有理数として比べ、不一致 0。
2. **時間特性.** $C(T)$ は評価期間 $T$ の区分一次関数で、跳びは事象の切り替え点、年の境では連続（丸めの大きさと、切り替え点が年セルの終わりを越える事象による初期化を除く）。$C(T) = M([0,T]) + Z(T)$（実時間の測度＋終わりの項）で、$dC/dT$ は排出率ではない。ラプラス変換と有限の台のフーリエ変換は厳密、フーリエ級数の部分和は近似（512 項でも最大誤差の中央値 2.8％）。DMD の前提（時不変の線形系）は成り立たない（17 章 03〜05）。
3. **動的 LCA.** 70 単位の骨格を保ったまま 17 の工程関数 $e_i(t)$ に分け、$C_{\mathrm{dyn}}(T) = \int_{[0,T]}e_{\mathrm{total}} + Z(T) = C_{70}(T)$ を証明し、79 シナリオ・4,248 点で有理数として照合した（不一致 0）。施工・製造・解体の時期は 70 単位から導けず、仮定の変種でだけ扱う。工程間の関係は比例・ゲート・二時刻の核で、時不変の畳み込みは比例の場合だけ（18 章）。
4. **原版の残り 12 式.** すべて 2 構造で厳密に変換し、除外は 0（「変換できなかったから不要」とした式はない）。全セル 2,247／2,247、境界条件 6,800／6,800、無作為ケース 61,390／61,390 値が一致（19 章）。
5. **大規模ランダム検証.** 宣言した分布から 20,000 シナリオ・100,000 ケース。定義域の内側の 90,055 ケース（18,011 シナリオ）で失敗 0。失敗の確率の 95％ 片側上限は、シナリオあたり（したがってケースあたりにも成り立つ）1.7e-04。ケースを独立とみなした値 3.3e-05 は、同じシナリオの 5 ケースが独立でないので参考にとどめる。帯 $(K,\mathrm{sw}(\tau)]$ に入りうる 0 ケースを除いた $\mathcal{D}'$ では、シナリオあたり 1.7e-04。継承した第 11 章の 10 集合の再実行：1,295 ケースのうち定義域の外として除いた 2 を除く 1,293 ケース（定義域の外の欠陥集合のケースは絞り込みなしで比べた）で失敗 0（上限は付けない：宣言した分布の標本ではない。20 章）。
6. **見つかった限界.** 第 11 章の定義域 `valid_domain` は、切り替え点が年セルの終わり $K$ を越える事象（整数の時刻と、整数の相対 1e-9 程度の近く（すぐ下・すぐ上）の浮動小数の時刻）の直後の細い帯 $(K,\mathrm{sw}(\tau)]$ を除かない。その帯で正準形と統一系は基準計算と異なりうる（整数の時刻での実測：（シナリオ、$K$）の 9 組のうち 2 組で異なった。17 章 07 の 6 節）。主張はこの帯を除いた $\mathcal{D}'$ に限る。

## 3. 主張の区別

### 3.1 数学的に証明できたこと（P）

- 正準形（核の和）と節点形は、すべての $T\in(0,H]$ で有理数として等しい（TH-0 (i)）。各核は切断べきの有限和（L-1）。
- 区分一次・跳び・超関数としての導関数・累積の閉じた形・ラプラス変換の閉じた形（TH-1〜TH-3、TH-6、TH-7）。有限の台のフーリエ変換 $=\mathcal{L}_H[C](i\omega)$、延長した関数の超関数としての変換（TH-8b）。
- 実時間の分解 $C(T) = M([0,T]) + Z(T)$ とその非一意性、符号の構造（TH-4）。年増分の式（TH-5）。
- 浮動小数の事象の規則の切り替え点が $g/\mathrm{fl}(1-\varepsilon)$ の数 ulp 以内（L-2）。
- 年増分の線形漸化式とモード分解の同値、DMD の前提が成り立たないこと（冷媒の状態は切り替わるアフィンの漸化式）（TH-9）。FRI は厳密な算術で厳密（TH-10）。
- 周期の事象の準周期の部分の有界性と上界、周期になる十分条件（TH-11）。$T\le H$ での $H$ への非依存（TH-13）。
- 動的 LCA の再構成定理 $C_{\mathrm{dyn}} = C_{70}$、配分の非一意性の定理 2 つ（18 章 04・05）。
- 12 式のテキストの規則の 2 構造による構成（宣言した定義域、19 章 02）。

### 3.3 統計的に高い信頼度で確認できたこと（S）

宣言した抽出分布（20 章 01）で、定義域の内側の 90,055 ケース（18,011 シナリオ）に失敗 0。失敗の確率の 95％ 片側上限は、シナリオあたり 1.7e-04（ケースあたりの確率はこれ以下なので、ケースあたりにも成り立つ）。ケースを独立とみなした値 3.3e-05 は参考（同じシナリオの 5 ケースは独立でない）。これは宣言した分布についての保証で、全入力の証明ではない。分布は帯 $(K,\mathrm{sw}(\tau)]$ にほとんど確率を置かない（0 ではない）。帯に入りうるケース 0 を除いた $\mathcal{D}'$ の上限はシナリオあたり 1.7e-04。G 層は数量の一部だけに倍率を掛けた（20 章 01 の 1 節）。

負の対照（意図的に誤った式、宣言した分布の定義域の内側のケース）：NC1 21,748/21,754、NC2 87,000/87,000、NC3 2,040/2,040、NC4 73,781/73,793、NC5 0/0、NC6 89,980/89,980、NC7 90,050/90,050、NC8 90,030/90,030（検出／適用できるケース）。NC5（B1-04 の跳び形）は SUM-03 で判定するので作り方から検出の力を持たず、検出できた誤りの型に数えない（20 章 02 の 3 節）。

### 3.4 追加の時間データ・仮定が必要なこと

- 施工期間の中の A 段階の配分、製造の時期、更新に伴う製造・輸送・撤去の内訳の時期、解体・廃棄物処理の期間、季節変動：70 単位からは導けない。18 章 05 の変種（X1〜X4）は文献の型に沿った仮定で、データに基づく値ではない。
- ガス別の時間分解された目録：動的な特性化は CO2e を CO2 とみなす近似（18 章 06）。
- $T>H$ の延長：モデルが定めない（ラプラス・フーリエ変換の延長はその選び方に依る）。

### 3.5 未解決のこと

- **定義域の穴**：切り替え点が年セルの終わりを越える事象の直後の帯 $(K,\mathrm{sw}(\tau)]$ で、区間形の B1-04（と第 11 章の統一系）は基準計算と異なりうる。第 11 章（完了済み）は変更せず、主張を $\mathcal{D}'$ に縮めた（17 章 03 の 0 節、07 の 6 節）。整数の近く（すぐ下・すぐ上）の浮動小数の時刻の後の帯は、照合では確かめていない（整数の時刻だけ）。
- 浮動小数の係数では、冷媒の期末残存量の厳密な連続性（跳び形）と桁落ちのない値（区間形）を同時に満たせない（17 章 05 の 3 節）。
- TH-11 の傾向の傾き $\beta$ は数値で求めていない。X-04 の `by_gas`・X-05 の内訳は区分一次であることだけを確かめ、重みごとの式は照合していない。X-10 は照合していない。
- 節点形は保存した係数のままでは最小でない。$C$ が定める量の数は、区切りの位置を別にして $2+\sum([\text{傾きの変化}\ne0]+[\text{跳び}\ne0])$（17 章 05 の 3 節）。これが最小であることは、節点ごとに係数を持つ表現の中でも、周期ブロック形を含めても、証明していない。
- 冷媒の補充なしの減衰は、モデルの浮動小数の状態では低い次数の漸化式にならない（17 章 04 の 2.5）。
- 12 式の必要性の解析は静的な参照の範囲で、`OFFSET` の動的な参照・マクロ・グラフ・条件付き書式・入力の検証規則は扱っていない。8 式を表示専用とは証明していない（除外もしていない）。必要性の検査は基準の入力（原版の雛形の値）での結果。EQ-0417 では 32 セルがテキストの変更でだけ 8 ulp 以内で変わり、その仕組みは特定していない（19 章 01 の 3 節）。
- 大規模検証で、同じシナリオの 5 つの評価期間のケースは独立でない（成り立つ上限はシナリオ単位）。負の対照 NC5 は検出の力を持たない。G 層は数量の一部だけに倍率を掛けた（20 章 01・02）。
- 大規模検証の基準計算と理想方程式は別のコードだが、理想方程式の振幅は第 11 章の仕様から取るので、仕様と基準計算に共通の誤解があれば照合では見つからない。
- 冷媒の結合は二時刻の核で書けるが、交換の列について非線形（18 章 03）。
