# 01 宣言した抽出分布と検証の方法（第 4 段階）

対象：独立概念モデル（70 評価単位、架空データ）。第 09 章の凍結したシナリオ生成器を無変更で使う（`code/gen4.py` は引数と評価期間の選び方だけを決める）。J-CAT 原版の式・係数・値は使わない。

## 1. ケースと抽出分布

**ケース** ＝（シナリオ $i$、評価期間 $T$）の組。シナリオ $i = 0, 1, 2, \dots$ の引数は `random.Random(SEED4 * 1_000_003 + i)`（`SEED4 = 20261114`）からすべて決まる（実行の順序や分割によらない）。各シナリオで評価期間を 5 つ取る。目標は 20,000 シナリオ × 5 = **100,000 ケース**。100 シナリオごとの塊（チャンク）に保存し、途中から再開できる（`results/chunks/c*.json`）。

| 層 | 確率 | 内容 | 評価期間の選び方 |
|---|---|---|---|
| N 通常 | 0.40 | 検証用の母集団と同じ形の正常なシナリオ（規模 S 0.8／M 0.2） | 自分の評価期間、$U(0.5,H)$ を 2 つ、対数一様 $10^{U(-2,\log_{10}H)}$、整数 $\{1..130\}$ |
| B 境界重視 | 0.20 | 正常なシナリオ | 整数とその $\pm10^{-5}$、事象の時刻とその $\pm10^{-5}$、$(0.001, 1)$、$T=H$、自分の評価期間 |
| G 桁 | 0.10 | 資材・設備の数量、輸送と廃棄の質量、冷媒の充填量、運用（電力・ガス・油・地域熱・自家発電・売電）と水・下水・一般廃棄物の年次の量を $10^{U(-6,6)}$ 倍（非負の倍率なので物理的な制約を保つ）。**倍率を掛けていない入力**：施工現場（A5）の電力・燃料・廃棄物、解体（C1）の活動量、廃棄物の運搬、集計の数量、床面積・費用。したがって G 層の SUM-03 は $10^{\pm6}$ の全幅には広がらない | N と同じ |
| E 同時事象 | 0.10 | 耐用年数を $\{10,20,30\}$ などの整数・約数に、改修周期 30、明示の一覧、冷媒の交換一覧 | N と同じ（自分の評価期間は 30・60・90・120） |
| S 特別な設定 | 0.10 | 評価に含める段階の無作為の部分集合、CO2 のみ、明示の事象の一覧、冷媒の交換一覧、補充の有無、表と電力係数の種類 | N と同じ |
| D 欠損・異常 | 0.10 | 生成器の `dirty=True`（欠損・異常値の注入） | N と同じ。基準計算の定義域の外なので、定義域の絞り込みなしで比べ、別に報告する |

すべての評価期間は $T\le H = 130$。物理的な制約（非負の数量、0〜1 の割合、正の周期）は生成器が保つ。

**この分布がほとんど確率を置かない場所**：切り替え点が年セルの終わり $K$ を越える事象（整数の時刻と、整数の相対 1e-9 程度の近く（すぐ下・すぐ上）の浮動小数の時刻）の直後の細い帯 $(K, \mathrm{sw}(\tau)]$（幅は $K$ の相対 $10^{-9}$ 程度。第 17 章で見つけた定義域の穴）には、B 層の $\pm10^{-5}$ のずれでは入らない。ただし確率は 0 ではない：連続の評価期間（$U(0.5,H)$、対数一様）はケースあたりおよそ $10^{-8}$ の確率で帯に入り、B 層で事象の時刻そのものに置く評価期間は、整数のすぐ上の浮動小数の事象（例 $\mathrm{fl}(25\times0.56)=14.000000000000002$）で帯に入る。帯に入りうるケースは $T$ だけから数え（$T\in(K, K(1+3\times10^{-9})]$、$K$ は整数：帯はこの中にある）、$\mathcal{D}'$ の上限から除く（02 の 1 節）。統計的な上限はこの帯について何も言わない。

## 3. 負の対照（意図的に誤った式。NC5 を除き、それぞれ検出されなければならない）

| 記号 | 誤り |
|---|---|
| NC1 | 事象を $\tau \le T$ で数える（厳密な規則 $\tau < T(1-\varepsilon)$ でない） |
| NC2 | 密度の振幅 $aH$ をそのまま率として使う |
| NC3 | B6 から常に B2-01 を引く（段階の述語 $\beta$ なし） |
| NC4 | 事象の年の補正の符号を逆にする |
| NC5 | B1-04 を跳び形で計算する（区間形でなく）。**SUM-03 で判定するので作り方から検出の力を持たない**（跳び形の誤りは B1-04 を絶対値で 1e-12 程度しか変えず、$10^{-12}\times$ SUM-03 よりずっと小さい：最終の独立レビューの指摘。跳び形の誤りは第 17 章 07 の 1.3 で単位の値として記録） |
| NC6 | 年セルを 1 年ずらす |
| NC7 | 64 項のフーリエ部分和を値として使う |
| NC8 | 終わりの項 $Z(T)$ を落とす |

各負の対照は、その誤った式の値が正しい値（浮動小数で評価した正準形）と相対 1e-12 を超えて異なる組（「適用できる」組）について、V1 と同じ比較（相対 1e-9）で基準計算と食い違えば「検出」とする。適用できるのに検出されない組は、誤りが 1e-9 より小さい影響しか持たない組である。

## 4. 統計的な記述

独立な $N$ 回の試行で失敗 0 件のとき、失敗の確率 $p$ について 95％ 片側の信頼上限は $p \le 1 - 0.05^{1/N}$（二項分布、0 件のときのクロッパー・ピアソン。およそ $3/N$）。失敗が $k>0$ 件なら二項分布の上側の確率から求める（`code/agg4.py`）。**これは宣言した分布についての統計的な保証であり、全入力についての数学的な証明ではない**。シナリオは独立に引くが、同じシナリオの 5 つの評価期間のケースは独立でない。そこで**主の上限はシナリオ単位**とする（$N$ = 定義域の内側のケースを持つシナリオの数、シナリオの失敗 ＝ そのケースのどれかの失敗）。ケースあたりの失敗の確率はシナリオあたりの確率以下なので、この上限はケースあたりにも成り立つ。ケースを独立とみなした上限は参考として併記し、成り立つ上限としては使わない。継承した第 11 章の集合（`R:`）は宣言した分布の標本ではないので、上限を計算しない。

## 5. 基準計算と新方式が同じ不具合を共有していないか

- 理想方程式（第 17 章の正準形）は、基準計算を読まずに、積和①の列（第 11 章）から作る。基準計算は凍結した第 09 章の実装（`baseline.assert_frozen()` で確認）。両者は別のコードで、比較は浮動小数の基準計算と有理数の正準形の間で行う。
- ただし、正準形の振幅は第 11 章の統一系の積和①の列から取るので、第 11 章の仕様と基準計算が同じ誤解（たとえば入力の意味の取り違え）を持てば、照合では見つからない。負の対照はその種の誤りのうち 7 つの型（NC1〜NC4、NC6〜NC8）を検出できることを示すだけである（NC5 は検出の力を持たない）。
- 継承した 1,293 組（第 11 章の 10 集合）も同じ照合で再実行した（`results/chunks/set_*.json`、層 `R:`）。
