# 20 70 評価単位の大規模ランダム検証（第 4 段階）

指示書「ホールライフカーボン統一数学理論の確立」の第 4 段階の成果（2026-11-14）。第 1 段階（17 章）の理想方程式と第 2 段階（18 章）の工程関数を、宣言した抽出分布からの多数のケースで、凍結した基準計算と照合した。

- 対象：独立概念モデル（70 評価単位、架空データ）。第 09 章の凍結した生成器・基準計算を無変更で使う。J-CAT 原版の式・係数・値は使わない。
- 主張の範囲：失敗 0 件は**宣言した分布についての統計的な上限**であり、全入力での数学的な一致の主張ではない（[02_結果.md](02_結果.md) の 5 節）。

## 2. 再実行

`code/` で `python3 -B`（`__pycache__` を作らない）。

| プログラム | 内容 |
|---|---|
| `run4.py <最初> <最後（含まない）> [塊の大きさ]` | シナリオ $i$ の範囲を照合し、塊ごとに保存（既にある塊は飛ばす：途中から再開できる） |
| `run4.py --sets` | 継承した第 11 章の 10 集合（1,293 組）を同じ照合で |
| `agg4.py` | 集計（`results/stage4_summary.json`） |
| `make_docs4.py` | 02 と図の書き出し |

本検証は 4 コアの環境で 5 つの処理に分けて実行した（0〜4,000、4,000〜8,000、8,000〜12,000、12,000〜16,000、16,000〜20,000）。最後の塊（15,200〜16,000）は空いたコアで 3 つの処理を追加して分けた。既にある塊は飛ばし、塊の内容はシナリオ番号だけで決まる（実行の順序・分割によらない）ので、分け方は結果を変えない。全 200 塊・20,000 シナリオを読み込めることを集計の前に確かめた。

## 3. 未解決・制約（隠さない）

- 抽出分布は切り替え点が年セルの終わりを越える事象の直後の細い帯 $(K,\mathrm{sw}(\tau)]$ にほとんど確率を置かない（0 ではない。帯に入りうるケースは数えて $\mathcal{D}'$ の上限から除いた）。この帯での不一致（第 17 章 07 の 6 節）は、この検証の対象外。
- 同じシナリオの 5 つのケースは独立でない。成り立つ上限はシナリオ単位のもので、ケースを独立とみなした上限は参考にとどめる。継承した集合（`R:`）には上限を付けない。
- 基準計算と理想方程式は別のコードだが、理想方程式の振幅は第 11 章の仕様（積和①の列）から取るので、仕様と基準計算が同じ誤解を持てば照合では見つからない（01 の 5 節）。
- 負の対照 NC5（B1-04 の跳び形）は、SUM-03 で判定するので作り方から検出の力を持たない（02 の 3 節）。
- G 層は数量の一部（資材・設備・冷媒・運用・水と廃棄物）だけに倍率を掛け、施工現場・解体の活動量・集計の数量などには掛けていない（01 の 1 節）。
