- **非公開の検証資料**（J-CAT 原版（以下「原版」）の式本文・値を含むもの）は、ここには載せない。所在だけを [NONPUBLIC_INDEX.md](NONPUBLIC_INDEX.md) に記録した。
- 数式と記号は [03_数式と記号の完全仕様.md](03_数式と記号の完全仕様.md)、主張と原典・コードの対応は [12_原典とコード対応表.md](12_原典とコード対応表.md)（機械可読：`data/claims.csv`）、証明と検証の件数は [08_証明と検証結果.md](08_証明と検証結果.md) を見ること。本書は「どのファイルを、どう動かせば、何が得られるか」に絞る。

## 0. 読み方

### 0.1 証拠の区分

主張には次の区分を付ける（本基盤の他の文書と同じ）。

| 区分 | 意味 |
|---|---|
| [P] | 数学的に証明済み |
| [E] | 厳密な算術（有理数）で標本の点を照合済み |
| [F] | 浮動小数の計算で照合・測定済み（第 9・10 章の原典が「数値の一致（N）」と書くものは [F] と読む） |
| [S] | 宣言した分布について統計的に確認済み |
| [L] | 文献で支持される |
| [H] | 未検証の新しい仮説（推定を含む） |

ファイルの所在・大きさ・コミット・件数そのもの（何があるか）は記録であり、区分を付けない。CSV の `evidence` 列は「そのファイルが根拠になる主張の区分」で、ファイルの存在の確かさではない。

### 0.2 いつも区別すること

- **マスク付き積和で表せたこと**と、**それが最小の表現であること**は別である。統一系の節点形は、保存した係数のままでは最小でない（`17_WHOLE_BUILDING_TIME_THEORY/05_最良表現.md`@46781f2 の 3 節）。自由度の最小性は示されていない。
- **計算結果の一致**は、**現実の建物の CO2 の予測精度ではない**。この研究の係数・原単位はすべて架空（凍結した生成器がシードから作る）であり、実在の建物についての精度は一度も確かめていない。ここに挙げるどのデータも、実建物の精度の根拠にならない。
- **評価期間 $T$ への依存**と**実際の排出時刻 $t$** は別である。第 17 章の $C(T)$ は累積排出ではなく、$C(T) = M([0,T]) + Z(T)$（実時間の測度＋終わりの項）と分解される [P]（`17_WHOLE_BUILDING_TIME_THEORY/03_時間特性の定理と証明.md`@46781f2 の TH-4。分解は一意でない：TH-4(c)）。
- **数学的な厳密さ**と**浮動小数の誤差**は別である。照合の合格条件は「数値は相対 $10^{-9}$ 以下、基準が厳密に 0 なら厳密に 0、型・キーも一致」である：
  $$|a-b| \le 10^{-9}\,|b| \quad (b \ne 0), \qquad a = 0 \quad (b = 0).$$
  これは浮動小数での一致 [F] であり、有理数での厳密な照合 [E] や証明 [P] とは別に数える。
- **定義域**：第 11 章の統一系の照合は `valid_domain`（`tstudy/scenarios.py`）の内側の組について行った。第 17 章は、その内側にあるのに一致しないことがある帯 $(K,\mathrm{sw}(\tau))$（切り替え点が年セルの終わり $K$ を越える事象の直後、幅は $K$ の相対 $10^{-9}$ 程度）を見つけ、主張をこの帯を除いた $\mathcal{D}'$ に縮めた（`17_WHOLE_BUILDING_TIME_THEORY/README.md`@46781f2 の 2 節の 2・4 節）。本書の $\mathcal{D}'$ はこの意味である。
- **$T$ について区分一次で表せる範囲**（SUM-03 と 14 段階の値 [P]、TH-0・TH-1）と、**そうでない範囲**（冷媒の期末残存量は浮動小数の係数のもとで厳密な連続性と数値の安定を同時に満たせない：17 章 05 の 3 節。区間形の B1-04 は帯 $(K,\mathrm{sw}(\tau))$ で基準計算と異なりうる [F]：17 章 README の 2 節の 2）を分ける。
- **原版の変換実験**（第 14〜16・19 章：原版の式を 2 構造で書けるか）と、**独立した 70 評価単位の研究**（第 9〜11・17・18・20 章：独自の概念モデルと架空データ）は別の系統で、つながっていない（`14_EQUATION_DISCLOSURE/README.md`@4c38df6 の 0 節）。
- **文献の原理** [L]（第 18 章の動的 LCA の文献調査）と、**この研究や利用者の新しい仮説** [H]（`10_新しい研究仮説.md`）を混ぜない。

### 0.3 70 評価単位について

70 評価単位は 70 個の独立な物理法則ではない。ホールライフ合計に直接寄与する単位と、補助・判定・内訳の単位がある（区別は [02_70評価単位の完全台帳.md](02_70評価単位の完全台帳.md) と `data/units70.csv` の `role` 列）。本書のデータの多くは「全 70 単位の全出力」を照合しているが、その件数は独立な法則の数ではなく、出力キーの数（190）と組の数の積である。

環境変数と引数：

```bash
export PYTHONDONTWRITEBYTECODE=1   # 凍結したフォルダに __pycache__ を作らない（-B と併用）
export GIT_OPTIONAL_LOCKS=0        # assert_frozen の git status がインデックスを書き換えない
export WLCSTUDIO_OFFLINE=1         # アプリ（23 章）の外部取得を止める。研究コードには影響しない
export WLC_REPO="$(git rev-parse --show-toplevel)"   # 取り出したリポジトリの絶対パス（リポジトリの中で実行。下の STUDY に使う）
mkdir -p /tmp/wlc_out              # 作業用の出力先（リポジトリの外。名前は任意）。先に作る：無いと出力の書き込みで止まる
python3 -B ...                      # 常に -B
```

**第 15 章の `compile2.py` を読み込むコマンド（第 19 章の `test12.py`、第 16 章の `synth_all.py` など。4.4 節）には `STUDY="$WLC_REPO/whole-life-carbon-jcat-study"` を付ける。** `compile2.py` はエンジン（第 10 章の `research_code`）の場所を環境変数 `STUDY` から取り、無ければ研究時の絶対パス（`/home/user/-/whole-life-carbon-jcat-study`）を使う。`STUDY` を付けないと、その場所が無い環境では読み込みで止まり、ある環境では**別の取り出し先のエンジン**を黙って使う（2026-11-17 の点検で実際に起きた。13 §5.2 の 10）。

**`-B` を付けずに第 9 章のコードを読み込むと、凍結したフォルダに `__pycache__` ができ、`git status --porcelain` が汚れを報告して `assert_frozen` が `BaselineChanged` で止まる**（`baseline.py` の判定。第 9 章 `research_code/README.md`@66186a8 の再現の手順のコマンドには `-B` が書かれていないので注意）。

原典は 4 コアで 5 つの処理に分けて 20,000 シナリオを実行した（20 章 README の 2 節）。

**主張の区分**：20,347 シナリオ・101,295 組で失敗 0。これは**宣言した抽出分布についての統計的な上限** [S] であり、すべての入力での数学的な一致ではない。上限の式は、独立な $N$ 回で失敗 0 のときの 95% 片側の信頼上限（クロッパー・ピアソン）

$$p \le 1 - 0.05^{1/N} \approx \frac{3}{N}$$

で（`01_抽出分布と方法.md`@3a30103 の 4 節。式そのものは二項分布の事実 [P]）、主の上限は**シナリオ単位**（$N$ = 18,011、$p \le 1.66\times10^{-4}$）。ケースを独立とみなした値（$N$ = 90,055、$p \le 3.33\times10^{-5}$）は参考で、同じシナリオの 5 ケースは独立でない（本書で `stage4_summary.json` の値を上の式で検算した）。帯 $(K,\mathrm{sw}(\tau)]$ には分布がほとんど確率を置かず、上限は帯について何も言わない。負の対照 NC5 は作り方から検出の力を持たない（20 章 README の 3 節）。
