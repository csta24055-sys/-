# 00 README：ホールライフカーボン（WLC）理論研究基盤

`whole-life-carbon-jcat-study/WLC_THEORY_RESEARCH_BASE/` は、これまでの WLC 研究のうち**数理の部分**（70 評価単位、マスク付き積和、節点スペクトル、建物全体の理想方程式 $C(T)$、時間特性の定理、動的 LCA、証明と検証の結果、J-CAT 原版の 667 式の変換実験の公開できる部分）を、別のチャットで研究を続けられる形に整理した**研究基盤**である。

- **アプリ（WLC Studio、第 23 章）とは独立している。** 本基盤はアプリのコードを読まず、アプリから読まれることも想定しない。アプリの研究上の位置は §6 の表に「指し示すだけ」と書いた。
- **70 評価単位の理論の続きを研究するための出発点**であり、新しい理論の完成や成立の宣言ではない。仮説 A〜J（[10_新しい研究仮説.md](10_新しい研究仮説.md)）はすべて未検証 [H] である。
- 既存の研究資料・研究コードは**変更していない**。本基盤は原典を読み、その内容を原典の記法のまま整理し直したものである。新しく計算したものは、その旨と方法を各文書に書いた（§7）。
- **すべての係数は架空である。** 計算結果どうしの一致は、現実の建物の CO2 予測精度を意味しない。

作成時点：2026-11-17。原典は研究ブランチ `claude/jcat-lca-app-foundation-c33936` のコミット `f2ea616`（2026-11-16 23:37 UTC）。リポジトリ `csta24055-sys/-`。資料一覧・版・SHA-256 は [manifest.json](manifest.json)（[tools/make_manifest.py](tools/make_manifest.py) で作る）。

文書の約束（全ファイル共通）：

- 主張には証拠の区分（§4）を角括弧で付け、[P]・[E]・[F]・[S] には成立範囲（定義域）を書く。定義・記録（何を作ったか、件数そのもの）には付けない。
- 出典は `パス@コミット §節` で書く。パスは `whole-life-carbon-jcat-study/` からの相対、コミットはそのファイルを最後に変更したコミット（`git log -1 --format=%h -- <パス>`）。
- 記号は原典（`17_WHOLE_BUILDING_TIME_THEORY/01_理想方程式.md`、`10_TRANSFORM_STUDY/11_UNIFIED_SYSTEM/SPEC_MSP.md`・`SPEC_KNOTS.md`、`14_EQUATION_DISCLOSURE/07_建物全体の統一方程式_完全版.md`）のまま使う。本基盤で足した記号は「本基盤で追加」「本台帳で導入」などと明記し、定義した場所を示す（03 §2・§9、10 §0.3、15 §0.3）。
- 式は LaTeX（`$$…$$`、`$…$`）で、そのまま再利用できる形で書いた。

## 4. 証拠の区分

| 区分 | 意味 | 読み方の注意 |

| **[P]** | 数学的に証明済み | 原典に証明があるもの。本基盤で新しく書いた証明は「本資料の証明。独立の確認なし」と書き分けた（例：15 §5.4）。成立範囲を必ず読む（例：第 17 章の定理は「浮動小数で与えられた振幅・時刻を有理数とみなしたとき」の主張） |

| **[L]** | 文献で支持される | 読んだ水準（全文・要旨のみ・二次資料・未確認）を併記する（07 §0.1、15 §0.1） |
| **[H]** | 未検証の新しい仮説 | 仮説 A〜J、作成者だけが確かめた証明の案、見積もり、本基盤で足した主張（例：04 §4.2 の逆向きの表現定理） |
