# 02 70 評価単位の完全台帳

対象：独立概念モデルの 70 評価単位（第 09 章で定義し、第 10 章で 2 つの構造（マスク付き積和・節点スペクトル）に統一した計算体系）。データはすべて架空で、J-CAT 原版の式・係数・セル・値は含まない（原版の 667 式の変換実験は 15・16・19 章の別の研究で、本台帳の単位とは独立。19 章までの公開の記述以上のことは書かない）。本台帳の一致・照合は計算結果どうしの一致であり、**現実の建物の CO2 予測精度の主張ではない**。

**70 単位は 70 個の独立な物理法則ではない。** ホールライフ合計 $C(T)$ に直接寄与するのは 21 単位（DIRECT）で、残りは補助の量・判定・内訳・合計と指標・参考値である（3 節）。

機械可読の台帳：`data/units70.json`（全項目。`eval_py` は各単位の式の実行形）、`data/units70.csv`（1 単位 1 行の要約）、`data/unit_dependencies.csv`（依存の辺）。作り方：`tools/extract_units70.py`（原典の JSON・コード・表から抽出し、手で書いた式・役割と合わせる）。照合：`tools/check_units70.py`（6 節）。基準のコミット：作業木の HEAD `f2ea616`。

### 2.2 入力の項目（各単位の式が直接読むもの）

単位ごとの入力は JSON の 3 つの一覧：`inputs_direct`（その単位の式が直接読む項目。149 項目）、`inputs_notation`（2.1 節の共通の部分式 $\mathrm{cv}$・$\mathrm{G}_s$・$\mathcal{F}_s$・$v_k$・$\mathrm{aunit}$・$\mathrm{gunit}$・状態 $\delta$・GWP が読む項目。統一系の記録から機械的に集めた）、`inputs_reached`（統一系の記録 unit_map.json の inputs と、事象の格子などの索引の表の元の項目）。依存の閉包の単位の入力も、その単位の値に効く（6 節 (f) の入力の感度で照合）。項目ごとの記号・単位・定義域（式が値を使う範囲。範囲外・欠損は述語で外して件数に数える）・意味は、各単位の節の「入力」の表と JSON の `inputs_direct`、項目ごとの一覧（直接読む単位つき）は `data/units70_inputs.csv`（`tools/extract_units70.py --write-inputs-csv` で JSON から作り、JSON と一致する）。架空データの生成器のデータモデル（MODEL@0db5c77）と式の述語から書いた。行の添字は $i$＝資材、$j$＝設備、$d$＝冷媒の機器、$x$＝施工・解体・費用の小さな表の行。判定の単位が調べる箇所の表と X-04 の行の表は JSON の `sites`。

## 7. この台帳でできていないこと・限界

- 照合はすべて浮動小数どうしの標本照合〔F〕（厳密な算術でも統計的な上限でもない）。架空データで、現実の建物の CO2 予測精度は意味しない。最小の表現かどうかは調べていない。$T$ について区分一次であることは、排出の実時間 $t$ への配分を一意に決めない（17 章 03 の TH-4(c)）。
- LaTeX の式は機械的には評価していない。照合したのは、式と 1 対 1 に書いた実行形 eval_py（基準計算と同じ計算順序）と、式を手で写した独立の評価 IND。SYS-01〜03 の箇所の表・X-04 の行・QA-03 の使用・B4-02 の n_partial・X-02 の CHK は本照合で統一系の仕様を読んで書き足した定義なので、それらの IND は仕様から完全には独立していない。
- 未解決の切り替え境界：整数の時刻 $K$ の交換の直後の帯 $T\in(K,\mathrm{sw}(K))$ では統一系（区間形）が台帳の式・基準計算と異なる（6 節 (e)）。整数の相対 1e-9 程度の近くの浮動小数の時刻の帯、$H\ge256$、定義域の刃の帯は調べていない（統一系の成立範囲の外）。
- 入力の感度 (f) は値のある所を型に合わせて動かす摂動だけ（⊥ にする・型を変える・非有限にする摂動は無い）。変化を起こせなかった宣言の項目（`ledger_check_summary.sensitivity.declared_not_exercised`）は、値の有無・0 かどうかだけを見る項目などで、読まれないことを意味しない。
- 依存の記録は 3 つ（本台帳の式 kind=formula：受け渡しのキー `_parts`・`_row_lines` を含む、基準計算の宣言、第 09 章の台帳）で、A13-03・X-05・X-07 で異なる（JSON・CSV）。A13-01・X-03 の A13-02 は受け渡しのキーだけを読む。
