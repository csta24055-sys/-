非公開資料を使えるのは、**原版の利用者登録を行い、権利者の使用条件に従う研究者**だけである。使用条件にない使い方（他の算定ツールへの係数の流用、原版を使った他の著作物の創作、改変・頒布、比較結果の公表など）は、権利者に書面で許諾を求める（`01_COMPLIANCE/README.md`@79d1ff8 の 1-A・1-F、`01_COMPLIANCE/PERMISSION_REQUEST.md`）。公式の使用条件は https://www.ibecs.or.jp/zero-carbon_building/jcat/licenseterms.html と FAQ https://www.ibecs.or.jp/zero-carbon_building/jcat/faq.html（最新の版を読み直すこと）。

1. **写しを受け取る・保管する**：Git の管理下にも、Dropbox などの共有クラウドにも置かない。置き場所は、`.gitignore` が除外する名前の型（`**/local-only/**`、`**/restricted-originals/**`、`**/raw-licensed-data/**`、`**/raw-formula-extraction/**`、`*JCAT*.zip` など。`whole-life-carbon-jcat-study/.gitignore`@94cb585）の中か、リポジトリの外にする。
2. **指紋を確かめる**（NP-01・NP-02）：
   ```bash
   stat -c '%n %s' JCAT_非公開_667式の変換と検証.zip JCAT_非公開_数式と値_小.zip
   sha256sum JCAT_非公開_667式の変換と検証.zip JCAT_非公開_数式と値_小.zip
   # 期待値：14235139 / 2cb6b68965d9cc70accce65f28984f2f3258d7831a0a8e32ee4a94a30d7e3517
   #         8329231  / 2da25179fabcdf45f4d6833028aeb2855c634f6d88638163574617ecb430b33a
   ```
   NP-10 は SHA-256 を記録していないので、受け取った時点の値を各自で記録する。
3. **公開のコードと組み合わせる**（いずれも公開リポジトリにあり、原版のデータを含まない。出力はリポジトリの外のフォルダへ）：
   - 第 13 章：原版を Git の外の作業フォルダ `W` に置き、`13_INPUT_CLASSIFICATION/tools/` の `unpack.py`→`scan.py`→`regions.py`→`classify.py`→`export.py` を順に実行する（手順と引数は `JCAT_input_classification_report.md` の 10 節）。`scan.sqlite3` は原版の値を含む。
   - 第 14 章：`14_EQUATION_DISCLOSURE/tools/node_map.py <patterns.pkl> <out dir>`（非公開の走査結果から、分類との対応の件数だけを書く）。
   - 第 15 章：`15_JCAT_CONVERSION/tools/` の `instances.py`→`validate_ref.py`→`run_compile.py`→`verify_boundary.py`→`random_cases.py`（LibreOffice の headless の UNO が必要。`lo_engine.py`）→`chain_eval.py`→`aggregate.py`→`make_docs.py <chapter_dir>`・`make_private.py <out_dir>`。この順序は各ファイルの説明文から読み取った目安で、原典に順序の記載は無い。原典は「`tools/` のプログラムと非公開の台帳（原版の走査結果）で再現できる。乱数はすべて上のシードから決まる。」とだけ書く（`15_JCAT_CONVERSION/04_検証の方法と結果.md`@7df1fdd の 5 節）。
   - 第 16 章：`run8.py <out.pkl>`、`rc_eval8.py`、`down8.py`、`down8b.py`、`agg8.py <public_json> <private_md>`。
   - 第 19 章：`python3 -B agg12.py <rc12_*.pkl と down12.pkl のある非公開フォルダ> <19 章のフォルダ>`（件数のファイルだけを書く）。
4. **結果を公開するとき**は、公開章と同じく件数・分類・方法だけにし（`agg8.py`・`agg12.py`・`make_docs.py` の方式）、式本文・係数・値・セル番地・見出しを含めない。方法の説明や比較の公表は `RULES.json` の R06（`PERMISSION_REVIEW`）に当たるので、範囲を確かめてから行う。
5. **非公開資料から作った成果物は、研究の独立概念モデル（70 評価単位）とは別の系統である。** 70 評価単位・統一系・理想方程式 $C(T)$・動的 LCA・大規模検証（第 9〜11・17・18・20 章）は架空データと独自のモデルで作られ、非公開資料を使っていない（`14_EQUATION_DISCLOSURE/README.md`@4c38df6 の 0 節）。原版の式と 70 評価単位の突き合わせは行われていない。

## 6. 分からないこと・確かめていないこと

- NP-01・NP-02・NP-10 の中身（どのファイルが入っているか）。2・3 節の対応は推定で、**開いて確かめていない**。
- NP-01・NP-02 の SHA-256 の再計算（指示に従い開かなかったため。5 節の 2 で各自が確かめる）。NP-10 の SHA-256。

- 第 15 章の中間ファイル（`instances.pkl` など）、第 14 章の `抽出プログラム/` の所在と、NP-01・NP-02 に含まれるかどうか。
