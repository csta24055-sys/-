## 0. すべての実験に共通の約束

### 0.1 作業の規則

- `python3 -B` で実行し、`__pycache__` を作らない（スクリプトの先頭で `sys.dont_write_bytecode = True` も置く）。外部への通信をしない（`WLCSTUDIO_OFFLINE=1`）。
- 既存の研究コード（`10_TRANSFORM_STUDY/research_code/`、`17_*/code/`、`18_*/code/`、`20_*/code/`）は**読み取り専用で読み込む**。変更しない。凍結した基準計算は `baseline.assert_frozen()` で確かめてから使う（`20_LARGE_RANDOM_VERIFICATION/01_抽出分布と方法.md`@3a30103 §5）。
- **既存のファイルを上書きするプログラムをそのまま走らせない。** たとえば `10_TRANSFORM_STUDY/research_code/tools_unit_map.py` は `11_UNIFIED_SYSTEM/UNIT_MAP.md` と `results/unit_map.json` を、`tools_units_doc.py`・`tools_verification_report.py`・`tools_example.py` も `11_UNIFIED_SYSTEM/` の中を書き換える（`10_TRANSFORM_STUDY/11_UNIFIED_SYSTEM/REPRODUCE.md`@b93201e）。これらは複製して出力先を作業領域に変えてから使う。第 17・18・20 章のプログラムは出力先を引数で受け取るので、作業領域のパスを渡す。

### 0.2 事前登録

各実験の記録の冒頭に、実行の前に次を書く：(1) 検査する仮説と形（強い形・弱い形）、(2) 測る量とその尺度、(3) **反証の基準**（この結果が出たら仮説を捨てる、または弱い形に下げる）、(4) 停止の基準、(5) 結果に付ける証拠の区分の見込み。実行後に基準を変えたときは、変えた理由と元の基準を残す。

### 0.4 権利と非公開の資料

- J-CAT 原版の資料（数式本文・係数・値・セル番地・シート名・マクロ・有償の資料）は、**利用の権利を確かめた非公開の環境でだけ**扱う。公開の基盤に載せてよいのは、件数・割合・分類の名前・方法・結果の要約だけで、第 14・15・16・19 章の公開分と同じ水準に限る。非公開の保存物を公開のリポジトリに置かない。
- 規格・データ集・有償の刊行物の表や式を転載しない（構造と出典の書誌だけを書く）。公開のデータでも利用条件（再配布・出典表示）を確かめる（[15_劣化・寿命・交換モデル研究開始資料.md](15_劣化・寿命・交換モデル研究開始資料.md)（以下 [B15]）§10.2）。
- 非公開資料の所在・指紋は [NONPUBLIC_INDEX.md](NONPUBLIC_INDEX.md)（中身は載せない索引）、公開データの所在・実行方法・取得可否・権利は [14_研究用データ索引.md](14_研究用データ索引.md) を見る。
- 個人の名前・連絡先を記録に書かない。

保存場所と命名の規則は [13_別チャット引継ぎ文.md](13_別チャット引継ぎ文.md) に従う。そこに定めが無い事項の既定として、実験の記録は実験 ID ごとの 1 つのフォルダ（例：`EX-I1_<短い名前>/`）に、記録（事前登録・結果・区分）、コード、機械可読の結果（JSON・CSV、UTF-8）を置き、1 つの Markdown を 80 KB 程度以下に保つ。乱数の種・ソフトウェアの版・入力のコミット ID を結果に書く。

### 0.6 停止の基準の型

各実験の停止の基準は次の 4 つの型の組み合わせで書く。

| 型 | 意味 |
|---|---|

### EX-D1 述語の因子の数え上げ（HYP-D・A の材料。済、再実行の手順）

本基盤の作成時に 1 回実行した（結果は [10_新しい研究仮説.md](10_新しい研究仮説.md) §HYP-D の表）。仕様のモジュールの大域変数から辿れる辞書を巡回し、述語の種類と定数を数える。**テンプレートは展開前に 1 回だけ数える**（展開後の数は EX-F1 で数える）。読み取り専用で、モデルの値は何も計算しない。

```python
"""EX-D1: count predicate factors and their constant thresholds in the unified specification (read-only)."""
import sys, json, collections, importlib
sys.dont_write_bytecode = True
RC = "<worktree>/whole-life-carbon-jcat-study/10_TRANSFORM_STUDY/research_code"   # 実際のパスに置き換える
sys.path.insert(0, RC)
mods = {m: importlib.import_module("specs." + m) for m in ("lib", "pre_a", "physical", "gates", "at_t", "system")}
seen, preds, bounds, eqc, steps = set(), collections.Counter(), collections.Counter(), collections.Counter(), collections.Counter()
def walk(o):
    if isinstance(o, (dict, list, tuple)):
        if id(o) in seen: return
        seen.add(id(o))
    if isinstance(o, dict):
        if o.get("op") in ("sp", "match"): steps[o["op"]] += 1
        p = o.get("pred")
        if p:
            preds[(p, bool(o.get("not")))] += 1
            if p == "range": bounds[("lo", repr(o.get("lo")))] += 1; bounds[("hi", repr(o.get("hi")))] += 1
            if p == "eq" and isinstance(o.get("b"), dict) and "const" in o["b"]: eqc[repr(o["b"]["const"])] += 1
        for v in o.values(): walk(v)
    elif isinstance(o, (list, tuple)):
        for v in o: walk(v)
for m in mods.values():
    for k, v in vars(m).items():
        if k.startswith("_") and not k.isupper(): continue
        if isinstance(v, (dict, list, tuple)): walk(v)
print(json.dumps({"steps_seen": dict(steps),
                  "predicates": {f"{p}{'(not)' if n else ''}": c for (p, n), c in sorted(preds.items())},
                  "range_bounds": {f"{a}={b}": c for (a, b), c in bounds.most_common()},
                  "eq_constants": dict(eqc.most_common())}, ensure_ascii=False, indent=1))
```

実行：`WLCSTUDIO_OFFLINE=1 python3 -B ex_d1.py > ex_d1.json`（作業領域で）。本基盤の作成時の結果（コミット f2ea616 の仕様、`specs/`@2f5200d）：辿れたステップ 積和 1,005・検索 81、述語 `eq` 688（否定 100）・`present` 204（95）・`range` 116（11）・`le` 22（17）、`range` の端は $\{0,1,\pm\infty\}$ と許容幅 $\pm10^{-6}$・$1\pm10^{-6}$ だけ [E]（数え上げ）。**次の作業**：各述語を単位と出力に結びつけ（`UNIT_MAP.md` の追跡を作業領域で再実行）、[10_新しい研究仮説.md](10_新しい研究仮説.md) §HYP-D の由来の区分 V・K・Θ・B・R・N を 1 つずつ付ける。

### HYP-B 共通評価行為

| 項目 | 内容 |
|---|---|
| 比較の方法 | 大きさの比 $\mathrm{SR}=\lvert\mathcal P\rvert_{\mathrm{step}}/\mathrm{DL}(\text{元の規則の記述})$ を、(i) 70 単位、(ii) 手続きが同じで対象の物理が違う会計（2〜3 分野）、(iii) 同じ建物の物理モデル（2〜3 種）で比べる |
| 反証の方法 | 事前登録の案：(ii) の $\mathrm{SR}$ が (i) の 1/3〜3 倍の範囲に入らない（手続きが同じでも簡潔さがそろわない）、**または** (iii) の $\mathrm{SR}$ が (i) の 3 倍未満（物理モデルも同じく簡潔：反-B1 の支持）。どちらかで B を捨てる。両方とも B の向きなら支持 |
| 実験の順序 | **EX-B1**（別分野の会計）：公開されている算定の手引きの構造（区分・係数の掛け方・集計の規則）だけを使い、建物の積算（数量×単価の集計）と製品のカーボンフットプリントの算定を架空の数値でマスク付き積和に書く。**EX-B2**（物理モデル）：1 室の熱収支（陽的な時間刻み）、効率の指数的な低下とリセット、連続の冷媒の漏洩 $\dot m=-rm$ を同じ語彙で書く（時間刻みごとのステップか、状態の倍化が要るかを記録）。**EX-B3**：$\mathrm{SR}$ を比べ、どの語彙の要素（述語・`match`・倍化）が差を生んだかを分解する |

| 新しく書くコード | 別分野の会計と物理モデルの仕様、$\mathrm{SR}$ の測定（EX-F1 の尺度） |

### EX-X1 B 対 G 対 C：マスク付き積和の構造はどこから来たか

**問い.** 70 単位と原版の算定規則がマスク付き積和で簡潔に書けたのは、(B) 評価の手続き（分類・乗算・集計）のためか、(G) 計算の依存の形のためか、(C) 表計算の実装の形のためか。3 つは排他ではないので、それぞれの寄与を分けて測る。

**設計.** 同じ規則の集合 $\mathcal R$ を 3 つの形で書く：(r1) 規則の記述から直接書いたマスク付き積和（仕様）、(r2) 表計算の形の実装（IF・LOOKUP・INDEX・MATCH・参照・転記を使う。EX-C2）、(r3) ふつうの手続き型のコード（ループと条件文）。これを 2 つの領域で行う：(d1) 建物の WLC（70 単位の 5〜10 単位）、(d2) 手続きは同じで物理が違う会計（EX-B1 の積算など）。加えて対照 (d3) に、手続きの違う計算（EX-B2 の物理モデル）を置く。各組で、EX-F1 の大きさ（骨格の数・ステップ数・$\mathrm{DL}$）と、EX-G の正準な商 $\bar{\mathcal G}$ の不変量を測る。

**判定表**（事前登録の案。「大」「同」は EX-F1 の尺度で 2 倍以上・2 倍未満の差）：

| 観察 | 支持される仮説 |
|---|---|
| (r2) の骨格の数は (r1) より大だが、$\mathcal N$ で正規化すると (r1) と同、かつ $\bar{\mathcal G}$ は (r1)・(r2)・(r3) で同 | C（数の増加は実装由来）と G（グラフは実装によらない） |
| 正規化の後も (r2) が (r1) より大 | 反-C1 の否定ではなく、正規化 $\mathcal N$ の不足か、表計算に固有の構造（循環・動的参照）の存在。原因を特定する |
| (d1) と (d2) で $\mathrm{SR}$ が同、(d3) で大 | B |
| (d1)・(d2)・(d3) で $\mathrm{SR}$ が同 | 反-B1（物理の加法性）か §2 の表現の汎用性。B は支持されない |
| $\bar{\mathcal G}$ が (d1) と (d2) で同、(d3) と異 | G（手続きの共通性がグラフに現れる）と B の両方 |
| $\bar{\mathcal G}$ が (d1)・(d2)・(d3) ですべて同 | 反-G2（グラフは粗すぎる） |

**コード・データ.** EX-B1・B2・C2・F1・G1・G3 の成果を使う。原版は使わない（権利の要らない形で完結させる）。原版での確認は EX-C1・G4 として別に行い、件数だけを公開する。

**停止.** 判定表のどれかの行に当たったら記録して止める。どの行にも当たらなければ、尺度か正規化の定義を見直す（予算の範囲で）。

### EX-X2 E 対 I 対 H：時間の原理はどこまで共通か

**問い.** 時間構造（E）の中身は、確率的な寿命（I）と連続の状態（H）を加えても、少数の核の種類と振幅の分離で書けるか。

**設計.** モデルの梯子を作る：(m0) 既存の固定周期（決定論）、(m1) 期待値の更新過程（$m_F$）、(m2) 年齢に依る量の期待値（効率低下・冷媒の残存。年齢の分布が要る）、(m3) 状態に依る故障の強度を持つ PDMP（期待値は生成作用素の方程式）。各段で、(a) 必要な核の種類（[10_新しい研究仮説.md](10_新しい研究仮説.md) §HYP-E の時間の原始＋新しい種類）、(b) $C=\langle\mathbf a,\boldsymbol\kappa\rangle$ の分離の成否、(c) $T$ についての区分一次性の成否、(d) 実時間の分解 $M([0,T])+Z(T)$ の成否を表にする。

| 段 | 見込み（[H]） | 確かめ方 |
|---|---|---|
| m0 | (a) 5 形＋窓、(b) 冷媒を除き成立、(c) 成立 [P]、(d) 成立 [P] | 既存（TH-0、TH-1、TH-4） |
| m1 | (a) 期待更新測度との畳み込みが 1 種類増える、(b) 成立、(c) 不成立（[B15] §5.7 (c)）、(d) 成立の見込み | EX-I2 |
| m2 | (a) 年齢の分布の汎関数が増える、(b) 振幅が寿命分布に依る、(c) 不成立、(d) 見込み | [B15] §7、EX-H2 |
| m3 | (a)〜(d) 不明 | EX-H3 の拡張 |

**反証.** m1〜m3 で核の種類が段ごとに増え続け、(d) が m1 で既に壊れれば、E の強い形（E3）を捨てる。

### EX-X3 A 対 J：種別のパラメータか、部材の和か

**設計.** EX-A2 の架空の 4 種別を、(i) 共通の $\Psi$ に種別のパラメータを入れる形と、(ii) 部材の記述 $\mathcal L_i$ の和と相互作用の形で書き、大きさと、種別を加えたとき・部材を加えたときの増え方を比べる。**判定**：(i) が種別の数に比例して大きくなり (ii) が部材の数に比例するだけなら J の形が自然、(i) が増えず (ii) が部材の種類ごとに新しい相互作用を要するなら A の形が自然。両立する場合（$\mathcal L_i$ のパラメータが種別で決まる）は、その旨を記録する。

### EX-X4 D 対 C：分岐は人の閾値か、表計算の防御か

**設計.** EX-C2 の表計算の形の実装 (r2) と、仕様 (r1) の述語を EX-D1 の方法で由来の区分に分け、(r2) にだけ現れる述語（エラーの捕捉、空欄の扱い、検索の失敗）の割合を測る。**判定**：(r2) に V・N の述語が大きく増え、Θ・K・B は (r1) と同じなら、分岐の増加は実装由来（C、反-D2）。原版について同じことを行う場合は EX-D3（非公開の環境、件数だけ公開）。
