# 非整数乗・常用対数：実数としての厳密表現の不可能性と、有限精度での正確な実現

この文書は、整数でない定数指数 a の実数べき x^a と常用対数 log10 x について、
(1) 2 構造（マスク付き積和・最初の一致の検索）と節点スペクトルの**有限の合成**では、実数演算として厳密に表せないこと（数学的な不可能性）、
(2) それでも、倍精度（IEEE 754 binary64）の入出力としては「真値に最も近い倍精度数」（正しい丸め）を、証明書つきで返せること、
を区別して述べる。(1) は実装の不足ではなく数学的な事実、(2) は有限精度での正確な実現であって、(1) と矛盾しない。

## 1. 2 構造が実数演算として計算する関数の形

**計算モデル（実数版）。** 列の値を実数とし、1 つの手順（プログラム）は次のステップの有限列とする。

- `sp`：各行で、項ごとに「因子の積」をとり、項を足す。因子は、列の値・定数・1 列の有理関数（1/x、1−x、1/(1−x)、x/(1−x)）・述語（a = b、a ≤ b、値がある／ない、およびその否定。値は 0 か 1）。行の集まり（グループ）ごとの和もとれる。
- `match`：キー（いくつかの列の値の組）が等しい、相手の表の最初の行を指す参照列を作る。
- 節点スペクトル：Σ_k c_k [t_k ≤ x] の形。手順の中では、定数 t_k, c_k をもつ有限個の項からなる `sp` そのものである。

入力を実数の組 x ∈ R^m とする。索引集合（表の行の集まり）は入力のデータ配置として与えられ、手順の実行中には変わらない。

**補題 1（区分的有理性）。** 上のモデルの任意の手順の任意の出力列の値 f(x) について、R^m を有限個の半代数的集合 A_1, …, A_N に分け、各 A_j 上で f = P_j/Q_j（P_j, Q_j は多項式、A_j 上で Q_j ≠ 0）と書ける分割が存在する。「値がない」（欠損）も 1 つの値として扱えば、欠損になる入力の集合も半代数的である。

*証明（ステップ数に関する帰納法）。* 入力列と定数は自明に満たす。仮定として、それまでの全列が共通の有限半代数分割の各部分で有理関数（または欠損）であるとする。

- 積と和：有理関数の積と和は有理関数。1 列の有理関数（1/x など）も有理関数で、分母が 0 になる集合（零点集合。半代数的）で分割を細かくすれば、各部分で有理関数または「有限でない値」（欠損として扱う）になる。
- 述語 [a ≤ b]、[a = b]：各部分で a − b = R(x) は有理関数なので、{R > 0}、{R = 0}、{R < 0} で分割を細かくすれば述語は各部分で定数（0 または 1）。これらの集合は多項式の符号条件で定まるので半代数的。
- `match`：相手の行 y が選ばれる条件は「キーの等式 (有理関数) = (有理関数) が y で成り立ち、y より前の行では成り立たない」で、有限個の等式・否定の論理結合なので半代数的。各部分で参照先は一定の行になり、参照を通した値はその行の列の値（有理関数）。
- グループごとの和：グループの所属は入力のデータ配置か、参照列（上の `match` で定まる、各部分で一定の行）で決まるので、各部分で有限個の有理関数の和。
- 欠損の伝播：値がない・述語が偽という条件はすべて上の半代数的条件の論理結合。

有限回の細分で分割は有限のままであり、各部分で出力は有理関数か欠損である。∎

節点スペクトルを何個（有限個）使っても、それは `sp` の項の数が増えるだけで補題 1 の範囲に入る。

**系 1。** 1 変数の入力 x（他の入力は固定）について、手順が規則と一致すると主張する開区間 J の中に、f(x) = P(x)/Q(x) が成り立つ開区間 I ⊂ J がある。
（J を補題 1 の有限個の部分で覆うと、各部分と J の交わりは有限個の点と区間の和なので、正の長さの区間を含む部分が必ずある。）

**節点が無限個の場合についての注意。** 補題 1 は**有限の**手順（有限個のステップと項）に対するものである。項が無限個になると、1 つの `sp` でべき級数（例：2 進の分解のあとの Σ_k C(a, k)(f − 1)^k）や Σ_k 1/(x − t_k) のような超越関数を作れるので、結論は成り立たない。ただし「どの点の近くでも 0 でない項が有限個しかない」（局所有限）場合は、各点の近くで有限の手順と同じになり、系 1 がそのまま成り立つ。したがって不可能性の根拠は、2 構造の語彙ではなく**有限性（または局所有限性）**にある。

## 2. x^a（a は整数でない）と log10 x は、どの開区間でも有理関数でない

**定理 1。** a が整数でないとき、どの開区間 I ⊂ (0, ∞) でも x^a = P(x)/Q(x)（多項式 P, Q、Q ≢ 0）にはならない。

*証明。* I 上で x^a Q(x) = P(x) が成り立つとする。両辺は (0, ∞) で実解析的なので、一致の定理により (0, ∞) 全体で成り立つ。Q の最高次を q 次（係数 c ≠ 0）、P を p 次（係数 d ≠ 0）とすると、x → ∞ で左辺は c x^{a+q}、右辺は d x^p に漸近するので a + q = p、すなわち a は整数となり矛盾。（P ≡ 0 なら x^a Q ≡ 0 から Q ≡ 0 で矛盾。）∎

**定理 2。** どの開区間 I ⊂ (0, ∞) でも log10 x = P(x)/Q(x) にはならない。

*証明。* 同様に (0, ∞) 全体で Q(x) log10 x = P(x)。x → ∞ で P/Q は c x^{p−q} に漸近する。p − q > 0 なら P/Q は多項式の速さで増えるが log10 x はどんな正のべきより遅い。p − q ≤ 0 なら P/Q は有界だが log10 x → ∞。いずれも矛盾。∎

**結論（数学的不可能性）。** 補題 1・系 1 と定理 1・2 から、2 構造と節点スペクトルの有限の（または局所有限の）合成で、x^a（a は整数でない）や log10 x を、**どの開区間の上でも、実数演算として厳密に**表すことはできない。これは手順の工夫（ステップ数、索引集合、補助列、節点の設計）では越えられない。

**区間でなく有限集合の上では。** 入力が有限個の値（たとえばすべての倍精度数）に限られるなら、項 [x = d_k]·c_k（c_k = d_k^a という実数の定数）の有限和で、実数としての値そのものを再現できる。不可能性は「区間の上の関数として」の主張であり、倍精度の入力に対する正確な実現（次節）とは矛盾しない（ただしこの表は 2^{64} 行の規模で、実現可能ではない）。

注意：a が整数の場合は x^a は有理関数なので、2 構造で厳密に書ける（2 進展開による反復乗算）。

## 3. 有限精度（倍精度）としての正確な実現

倍精度数の集合は有限なので、「倍精度の入力 x に対して、真値 x^a（実数）に最も近い倍精度数 fl(x^a) を返す」関数は有限集合から有限集合への関数であり、2 構造で書けない理由は数学的には存在しない。問題は**実現可能な大きさで、確実に**書けるかである。方式 A は次のように実現する。

1. **2 進の分解（厳密）。** x = 2^e f、f ∈ [0.6875, 1.4375)。e は 2 進格子の節点スペクトル Σ_k [2^k ≤ x]、f = x·2^{−e} は 2 のべきによる倍率なので誤差がない。
2. **区分多項式。** f の区間を幅 1/64 の 48 区間に分け、各区間で t = 128 (f − c_i) ∈ [−1, 1]（Sterbenz の補題により厳密）について次数 13 の多項式を、60 桁の 10 進演算で求めた係数（2 倍長の定数として保持）で評価する。log10 は Q(f) = log10 f / (f − 1) を近似して (f − 1) を掛けることで、x = 1 付近の**相対**精度を保つ。
3. **2 倍長の Horner 法。** 誤差のない変換（two-sum、Veltkamp の分割、two-product）は 1 回 1 回の IEEE 演算の固定列であり、それぞれ 1 つの `sp` ステップで書ける。結果 y = yh + yl の誤差上限 ε（近似誤差 + 演算誤差）は 2^{−90} 相対以下になるよう次数・区間を選んだ。
4. **次数と誤差上限、範囲。** 区分多項式の次数は指数ごとに、補間剰余の厳密な上限 |a(a−1)⋯(a−n)|/(n+1)!·f_min^{−(n+1)}·max|Π(t − t_j)|·h^{n+1} が 2^{−100} 以下になる最小の n（13〜40）とし、さらに 2 倍長の Horner 法の演算誤差 (2n + 8)·cond·2^{−104}（cond = Σ|c_k| / 区間での g の最小値）を加えた合計が 2^{−91} 以下であることを確かめる。満たせない指数（例 |a| = 300.5）は方式 A の対象外として変換しない。2^{e·a} の定数は 2^{600n} で倍率を変えて [2^{−300}, 2^{300}] に入れ、証明書を出してから倍率を戻す（途中の値がすべて正規化数になる）。結果が倍精度の最大値を超えれば #NUM!（参照評価器と同じ）、正規化数より小さい（非正規化数・0）ときは欠損。（レビューで、|a| が大きいときに固定の次数 13 では上限を満たさず誤った値を証明していたこと、結果が 2^{−1000} 付近では途中の値が非正規化数になり上限が崩れていたこと、2^{996} 以上では定数の分割が溢れていたことが見つかり、この形に改めた。）
5. **証明書つきの丸め。** 2 倍長の結果を fast two-sum で (yh, yl)、yh = fl(yh + yl) に正規化する。真値 τ は |τ − (yh + yl)| ≤ ε|τ| を満たす。yh の両隣の倍精度数との中点までの距離は ulp(yh)/2（yh が 2 のべきで yl が 0 に向かう側なら ulp(yh)/4）なので、|yl| + ε|yh| がそれより小さければ τ も同じ区間にあり、yh が τ の正しい丸めである。これを述語で判定し、判定できない入力は**欠損**（値を返さない）にする。誤った値は返さない。

**判定できない入力の大きさ。** 真値が中点から相対 2^{−90} 以内に来る x の割合は、真値の下位ビットが一様とみなせる入力では約 2^{−37} である（いわゆる「表作成者のジレンマ」）。ただし構造をもつ入力では一様性が成り立たない。
- **ちょうど中点になる x^a**：a = p/q（既約）で x が完全べきのとき（例：a = 2.5 と x = m^2·4^j、289^{6.5} = 17^{13}）、x^a が隣り合う倍精度数のちょうど中点になることがある。証明書はこれを判定できないので欠損になる（誤った値は返さない）。8 件の式の指数（分母が 12,500・50,000）では、x = 1 以外にこのような x は倍精度の範囲にない。
- **1 や 2 のべきのすぐ近くの x**：(1 + 2^{−52})^{0.5} などは真値が代数的に中点の近くに来るので、欠損が増える。

実測（合成データ、正規化数の結果）では、指数 0.05〜±100.5 の 23 種で欠損 0、誤り 0 だった（04_検証の方法と結果.md）。

**元の規則との一致について。** 方式 A は「数学的な真値の正しい丸め」を返す。表計算ソフトの POWER・LOG10 が常に正しく丸めるとは限らない（参照評価器が使う C 標準ライブラリの pow・log10 も、合成データで正しい丸めと一致しない入力があった）。したがって方式 A は「実数としての厳密一致」ではなく「有限精度として最良の値」であり、原版ソフトの内部実装との**ビット単位の一致は、キャッシュ値がある入力でのみ確認できる**。確認できた範囲（原版のキャッシュ値）では全件一致した。
