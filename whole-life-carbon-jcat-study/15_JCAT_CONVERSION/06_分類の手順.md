# 分類の手順（667 件）

1. 独立方程式ごとに、代表の式、変種、使用関数、現れるシート、結果の型の件数、数値の範囲、近くの見出し、参照先の見出しをまとめた資料を作った（非公開）。
2. 2 組の読み手（各 8 エージェント）が、同じ 667 件を**別の区切り方**（A：連続した 84 件ずつ、B：8 件おきの抜き出し）で独立に分類した。どの読み手も、自分の区切りの資料だけを読み、ほかの読み手の結果は見ていない。
3. 大分類が一致した 629 件はその分類、割れた 38 件は判定者（本研究の実行者）が式の構造と見出しから決めた。判定の基準：SUMIF・AVERAGE・総和が本体の式は集計、評価期間内の年に値を置く式は時間条件、選択に使う番号を求める式は条件分岐・選択、工程の原単位を作る式は係数、グラフ作成欄からの検索は表示、参照切れで常にエラーになる式はその他。
4. 「本質的な算定規則か」は、2 組のどちらかが「はい」とした式と、分類 1〜3 のすべてを「はい」とした（算定規則を落とさない側に倒す）。
5. 667 件すべてに分類が付き、未確認は 0 件。

## 読み手への指示（原文）

```
You classify formulas of a building life-cycle CO2/GHG calculation tool (J-CAT, Excel workbooks).
The input file is a JSON list of "independent equations" (one per element). Fields: eq (id), cells (how many cells use it),
formula (representative Excel formula), variants, skeleton (references abstracted), functions, kind, sheets (book:sheet=count),
process (sheet-role classification), result_types (counts of number/text/error results in the cells), number_range/examples,
text_examples, col_header/row_header/top_header (labels near the representative cell), ref_headers (labels near referenced cells).
The data is PRIVATE: read only the one file named below, do not copy it anywhere, do not write files, do not use the network.

Assign exactly one category to EVERY element (no element may be skipped):
 "1" 実際のLCA排出量算定式 : the result is an emission amount (CO2/GHG, e.g. kg-CO2e, t-CO2, kg-CO2/m2, per year) obtained from an
     activity amount and an emission factor / unit, or the emission of an item/stage/year (including conditional or looked-up
     variants whose output is an emission amount).
 "2" 数量・係数・時間・条件分岐に関する計算式 : computes quantities (material amounts, masses, areas, energy, water, refrigerant),
     coefficients/factors/rates (composite unit factors, ratios, losses, reuse rates, conversion factors), time (years, cycles,
     number of replacements, year flags with MOD), or selects a value by a condition or a look-up (IF/VLOOKUP/INDEX choosing a
     number) when the output is not itself an emission amount or a pure aggregate.
 "3" 集計式 : aggregation: SUM/SUMIF/SUMPRODUCT/AVERAGE/MAX/COUNTIF over items, subtotals and totals, additive combination of many
     cells of the same kind (a+b+c...), including totals of emissions.
 "4" 単なるセル転記・表示・補助処理 : a plain copy of another cell (=X, OFFSET with constant offsets, IF(x="","",x) display guards whose
     value is just a copy), labels and display texts, text building (&, SUBSTITUTE, LEFT), look-up keys/codes/names built or copied
     for display or for keys, row numbering, flags that only control display.
 "5" その他 : anything that fits none of the above (state the reason).
Also give:
 subtype: a short Japanese label (e.g. "資材別排出量", "複合原単位", "更新回数", "年次フラグ", "部門小計", "名称の転記", "検索キー生成").
 essential_rule: true when the formula is a real calculation rule of the assessment (categories 1,2,3 normally; also a
   category-4/5 formula if its result changes a number used in the calculation, e.g. a key that selects a coefficient);
   false only for pure display/copy/label work.
 reason: one Japanese sentence (<= 80 characters) citing the formula structure and labels you relied on.
Judge from the formula, the labels and the result types. When the output is a number copied unchanged from one cell, choose "4".
When a formula multiplies an amount by a factor and the labels or sheet indicate emissions (排出, CO2, GHG, kg-CO2), choose "1".
Return every element of the file in the same order.
```
