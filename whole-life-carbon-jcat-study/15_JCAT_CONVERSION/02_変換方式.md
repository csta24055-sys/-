# 02 変換方式：表計算の式から「節点スペクトル＋マスク付き積和」へ

この文書は**一般的な変換規則**だけを書く。J-CAT 原版の式本文・係数・値は含まない（原版の式に当てはめた結果は非公開ファイル）。

## 1. 原則

- 計算はすべて、既存の研究エンジン `10_TRANSFORM_STUDY/research_code/tstudy/msp.py`（**変更なし**）の 2 種類のステップで行う。
  - `sp`（マスク付き積和）：$\mathrm{out}(g) = \sum_{x:\,\rho(x)=g} \sum_{t} \prod_{k} \phi_{t,k}(x)$。因子 $\phi$ は列の値、述語（$[a=b]$、$[a\le b]$、$[a\ \text{が存在}]$ とその否定）、1 変数の有理関数（$1/x$ など）。
  - `match`（最初の一致）：$\rho(x) = \min\{\, y : \mathrm{key}(y) = \mathrm{key}(x) \,\}$。研究のエンジンに最初からある語彙で、新しく足していない。
- 節点スペクトルは跳び形（ランプ・ステップ核で $\ell = 0$）の格子和で、これも `sp` の列として評価する。
- 式の外で計算するのは次の 2 つだけである。どちらも、データに対する算術ではない。
  1. **静的な配置**：式が位置で指すセル（相対参照・絶対参照・定数の OFFSET・範囲）を表の列や子表に並べること（式の幾何）。
  2. **係数**：セルを含まない部分式（例：定数どうしの積）を、参照評価器で 1 回だけ評価した定数。
- 条件分岐を別の名前で隠すことはしない。IF は排他的なマスクの和、検索は `match`、丸めは整数格子の節点スペクトルとして、すべてのステップを書き出す（非公開ファイルの各節 3）。

## 2. 値の表し方（すべてのセルで共通）

| 成分 | 意味 |
|---|---|
| $t$ | 型：0 空欄、1 数値、2 文字列、3 論理値、4 エラー |
| $n$ | 数値（$t=1$）、論理値の 1/0（$t=3$） |
| $s$ | 文字列の識別符号（文字列が完全に等しいとき等しい） |
| $k$ | 文字列の照合順位（大文字小文字を区別しない。Shift_JIS の符号順。等号比較と大小比較の両方に使う） |
| $e$ | エラー符号（1 #NULL!、2 #DIV/0!、3 #VALUE!、4 #REF!、5 #NAME?、6 #NUM!、7 #N/A） |
| $p, q$ | 文字列が数値として読めるときの値と、その有無（表計算の文字列→数値の強制） |
| $w, o$ | 文字列がワイルドカード文字を含むか、比較演算子で始まるか |

照合順位の決め方（Shift_JIS 順・等しい値で探索を止める二分探索）は、原版の検索セル 514,007 個の保存値をすべて再現することで確かめた（照合順位を Unicode 順にすると 17 セルが合わない）。

## 3. 構文ごとの変換規則

| 構文 | 変換 |
|---|---|
| セル参照 | 静的配置 → 9 成分の列。範囲は「範囲ごとの行」と「セルごとの子表」（索引集合） |
| `+ - *` | 両辺を数値へ強制（マスク：$[t=1]n + [t=3]n + [t=2][q=1]p$）、最初のエラーを伝播（マスクの連鎖）、$[\text{エラーなし}]\cdot(a \circ b)$ |
| `/` | 基本方式：$a \cdot (1/b)$。改良方式：正しく丸めた商（5 節）。$b=0$ は #DIV/0! のマスク |
| 比較 | （型の類、キー）の辞書式比較：数値 < 文字列 < 論理値、空欄は相手の類の 0 または空文字列 |
| IF | $[c=1]\,y + [c=0]\,z + [\text{条件がエラー}]\,\mathrm{err}$（成分ごと）。選ばれない枝の値は寄与しない |
| IFERROR, ISNUMBER など | 型 $t$ の述語 |
| AND, OR | 引数ごとの真偽・「数えるか」・エラーの和と、その数の述語 |
| SUM, AVERAGE | 範囲を子表にし、親（範囲）ごとの分類和 $\sum_{x:\rho(x)=g}[t_x=1]\,n_x$。最初のエラーは `match` |
| MAX | 範囲内の対の索引集合で「より大きい数がない」セルを数え、`match` で最初の 1 つ |
| ROUND, ROUNDDOWN, ROUNDUP | $y=\lvert x\rvert 10^{d}$ に、15 桁丸めの半単位 $h(y)$（10 進格子）を加えた値の床（整数格子）。符号はマスク |
| INT, MOD | 整数格子の床。MOD は $a - b\lfloor a/b \rfloor$ と、表計算の「$\lvert r-b\rvert < 10^{-15}\lvert b\rvert$ なら 0」のマスク |
| VLOOKUP, HLOOKUP, MATCH（完全一致） | 検索列を子表にし、（範囲, 類, キー）での `match` |
| 同（近似一致）, LOOKUP | 表計算の二分探索そのものを固定回数のステップで書く。中点は整数格子の床、空欄は「左の最も近い空欄でないセル」（走行カウントと `match`）、等しい値で停止 |
| INDEX, OFFSET | 定数の位置 → 静的配置。データで決まる位置 → シートのセル表への（行, 列）の `match` |
| SUMIF, COUNTIF | 条件をマスクに展開（数値・数値として読める文字列・空・文字列の照合順位）。条件が定数でない場合は（写し × セル）の積の索引集合 |
| SUMPRODUCT | 子表の行ごとの積の分類和 |
| RANK | （写し × セル）の積の索引集合での大小の数え上げ |
| AGGREGATE(15,…) | 条件を満たすセルの走行カウントと `match`（k 番目の行） |

## 4. 節点スペクトル

| 名前 | 式 | 使いどころ |
|---|---|---|
| 整数格子 | $F(x) = \sum_{m\ge 1}[\,m \le x\,] = \lfloor x \rfloor$（$x \ge 0$） | 丸め、INT、MOD、二分探索の中点、整数の桁の切り出し |
| 10 進格子 | $E(y) = \sum_{k}[\,10^{k} \le y\,] - \mathrm{const} = \lfloor \log_{10} y \rfloor$ | 15 桁丸めの半単位 $h(y) = \tfrac12 10^{E(y)-14}$、桁数 |
| 2 進格子 | $\sum_{k}[\,2^{k} \le \lvert q\rvert < 2^{k+1}\,]\,2^{k-52}$ | 商の最下位桁の重み（改良方式の割り算） |
| 走行カウント | $O(p) = \sum_{q \le p}[\,\text{空欄でない}(q)\,]$ | 近似一致検索の空欄の扱い、AGGREGATE |

整数格子の和は無限和だが、二進の区切りで正確に評価する：$r_0 = x$、$r_{j+1} = r_j - 2^{51-j}[\,2^{51-j} \le r_j\,]$（$j=0,\dots,51$）、$\lfloor x\rfloor = x - r_{52}$。各引き算は Sterbenz の補題により誤差がない（$x \ge 2^{52}$ はすでに整数）。

## 5. 改良方式（既存の研究成果を変えずに追加したもの。検証済みの基本方式と区別して数える）

| 改良 | 内容 | 位置づけ |
|---|---|---|
| 正しく丸めた割り算 | $q_0 = a\cdot(1/b)$ のあと、Dekker の誤差なし積による剰余 $r = a - bq$ の符号と大きさで、2 進格子の ulp だけ 2 回補正 | 厳密（無作為 20 万組のうち $b=0$ の 14 組を除く 199,986 組で IEEE の $a/b$ とビット単位で一致。元の $a\cdot(1/b)$ は 52,484 組でずれた） |
| 文字の付随情報 | 文字列の長さと各位置の文字符号（`tstudy.index.tokenise` と同じ「語彙の付随列」） | ワイルドカード「?」の照合を述語の積に、数字の読み取りを桁の和にする（定義域を明記） |
| 実数べき・常用対数 | $x^{m} = 10^{E(x)m}\cdot P(\text{仮数})$、$\log_{10}x = E(x) + P(\text{仮数})$。$P$ は仮数 $[1,10)$ の 24 区間それぞれの 12 次チェビシェフ補間（区間形の節点スペクトル） | **近似**。相対誤差の上限を測った値で示し、厳密な成功とは数えない |

## 6. 範囲外の扱い

変換した式の定義域の外（例：データの条件に比較演算子が付いている、ワイルドカード「*」、INDEX の 0 番目の行）は、値を出さずに**欠損**として返す。照合ではそれを不一致として数える（成功に見せない）。
