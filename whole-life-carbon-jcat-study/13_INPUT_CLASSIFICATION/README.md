2026-11-12 に受領した入力分類ツリー（v0.1）と、追加指示「J-CAT原版の全入力項目・数値の完全分類」による成果物を置く。

| ファイル | 内容 |
|---|---|

| `tools/` | 走査・領域化・分類・照合・出力のプログラム（原版のデータは含まない） |

## 守っていること

- **原版の値は入れていない。** 排出原単位・係数・標準値・選択肢の文言・コード表・データ表の見出しは、どのファイルにも書いていない
  （[第1章](../01_COMPLIANCE/README.md)）。台帳にあるのは、場所・種類・型・単位・個数・分類である。入力シートと設定表の短い見出しだけは、項目を特定するために載せている。
- 原版のファイルは読み取り専用で扱い、リポジトリには入れていない。走査の中間データ（原版の値を含む）もリポジトリの外にある。
- 分類は規則による機械的な割り当てで、確認者は作業者のみ。件数の照合は機械的に行った（報告書 5 節、`12_APP_BASE/apptests/test_classification.py`）。
- これは入力項目の分類であり、原版の計算の再現でも、互換性の主張でもない。

## 使い方

- 入力仕様を作るとき：`JCAT_input_categories_complete.json` の各節の `input_entries`（表示されている入力シートの入力欄 218 件）を出発点にする。
- 原版のどこにあるかを調べるとき：`JCAT_input_inventory.csv` を分類 ID やシート名で絞る。
- アプリで使うとき：`12_APP_BASE` は、この 5 大分類で入力文書を受け取る（`python3 -B -m lcaapp binding` で結び付けを確認できる）。
- 作り直すとき：報告書 10 節の手順。原版は各自が正規に入手したものを Git の外に置く。
