# 第3章 原理 P2：条件は 0/1 の掛け算

## 3.1 何を求めたいのか

実際の算定には条件がつく。「この段階は範囲に含めるか」「この材料に値は入っているか」「交換はもう起きたか」「自家発電が消費を上回ったら買電は 0」「規則 A が使えなければ規則 B」。条件ごとに別の式を書くと、式の数が条件の組合せの数だけ増える。この章では、**条件をすべて 0 か 1 の数にして掛ける**ことで、算定全体を P1 の形のまま一つの式に書く方法を学ぶ。これが研究の第 1 の構造「マスク付き積和」である。

## 3.2 いちばん簡単な例

段階 A4 を範囲に含めるなら運搬の排出を数え、含めないなら数えない。

$$ C_{\mathrm{A4}} = \mu \, f\, m , \qquad \mu = \begin{cases} 1 & \text{A4 を範囲に含める} \\ 0 & \text{含めない} \end{cases} $$

$\mu$ を**マスク**という。$\mu = 1$ なら P1 の積がそのまま残り、$\mu = 0$ なら 0 になる。式は一つで、条件は数として入っている。

## 3.3 条件を数にする記号

条件 $c$ が成り立てば 1、成り立たなければ 0 になる記号を $[c]$ と書く（アイバーソンの括弧）。

$$ [3 < 5] = 1, \qquad [L > 0] = \begin{cases} 1 & L > 0 \\ 0 & L \le 0 \end{cases}, \qquad [s \in \mathcal{S}] = \text{段階 } s \text{ が範囲 } \mathcal{S} \text{ に入れば } 1 $$

この記号を使うと、条件の組合せはすべて掛け算と足し算で書ける。

| 条件 | 0/1 の式 | 理由 |
|---|---|---|
| A かつ B | $[A][B]$ | 両方 1 のときだけ 1 |
| A でない | $1 - [A]$ | 0 と 1 が入れ替わる |
| A または B | $[A] + [\lnot A][B]$ | 重ならない二つに分けてから足す |
| もし A なら $a$、そうでなく B なら $b$、どちらでもなければ $c$ | $[A]\,a + [\lnot A][B]\,b + [\lnot A][\lnot B]\,c$ | 互いに重ならない項の和 |
| $\max(0, d)$ | $[d \ge 0]\, d$ | 正のときだけ残す |
| $\max(p, q)$ | $[p \le q]\, q + [p > q]\, p$ | 大きい方の枝だけが 1 |
| $\lvert d \rvert \le \delta$（許容差の中） | $[d \le \delta][-d \le \delta]$ | 両側の条件の AND |
| $a / b$（$b \ne 0$ のときだけ） | $[b \ne 0]\, a \cdot \tfrac{1}{b}$ | 0 で割る場合を外す |

> **注意：「または」は単純に足さない**
> $[A] + [B]$ は、A と B が両方成り立つと 2 になり、同じものを二度数える。足す前に、$[A] + [\lnot A][B]$ のように**重ならない項に分ける**。第 2 章の「重複しない」と同じ考え方である。

> **例題 3.1　正味の買電**
> 年間の消費電力 $E$、自家発電で自分で使う量 $G$ のとき、買う電力は $\max(0, E - G)$。これを 0/1 で書き、$E = 80{,}000$、$G = 100{,}000$（kWh）のときの値を求めよ。
>
> $d = E - G$ として $[d \ge 0]\,d$。$d = -20{,}000$ なので $[d \ge 0] = 0$、買電は 0 kWh。$G$ が $E$ より小さければ $d$ がそのまま残る。

## 3.4 マスク付き積和

P1 の和の各項に、条件の 0/1 を掛けたものが**マスク付き積和**である。研究は次の形で書いた。

$$[3.1] \mathrm{out}[g] = \sum_{x \in \text{表}} [\,x \text{ が } g \text{ に入る}\,] \ \sum_{\text{項 } j} \ \prod_{k} \varphi_{j,k}(x) $$

- $x$：表の行（材料・設備・年など）。$g$：結果のまとめ方（段階ごと、材料ごと、全体の合計など）。
- 項 $j$：一つの行から出る寄与（if・elif・else の各枝など）。
- 因子 $\varphi_{j,k}(x)$：次の三種類だけ。
  1. 列の値（活動量、係数、割合など。定数も含む）
  2. 条件の 0/1（値があるか、範囲の中か、キーが等しいか、大小）
  3. 1 列だけの簡単な関数：$1/a$、$1 - a$、$1/(1-a)$ など

条件を含まない積和 $\sum_i f_i m_i$ は、因子が「係数」と「活動量」の二つで項が一つの、いちばん簡単な場合である。

> **例題 3.2　運搬の式をマスク付き積和にする**
> 材料の各行 $x$ に、段階・重量 $m_x$・距離 $d_x$・係数 $f_x$ がある。A4 の排出は「段階が A4 で、重量と距離が入っている行の $m_x d_x f_x$ の和」。
>
> $$ C_{\mathrm{A4}} = \sum_{x} [\text{段階}(x) = \mathrm{A4}]\,[m_x \text{ がある}]\,[d_x \text{ がある}] \cdot m_x\, d_x\, f_x $$
>
> 条件の 0/1 が三つ、列の値が三つの、項が一つの積和である。

**検索（表引き）も同じ形になる。** 係数をキーで探して最初に一致した行の値を使うことは、「キーが等しい、かつ、それより前に一致した行が無い」という 0/1 を掛けて足すことと同じである。研究ではこれを専用の手順（`match`）で実装した。キーが一意なら純粋な積和になるが、「最初の一致」を選ぶ操作をこの一つの形に含めて数えるかは、研究でも決めていない（厳密に数えれば、積和とは別の基本操作が一つ要る）。

**評価期間 $T$ での条件も 0/1 になる。** 「時刻 $\tau$ の交換は $T$ までに起きたか」は $[\tau < T]$、年の重み（最後の年の端数）も $[k < T]$ などの 0/1 と一次式の積で書ける（第 4 章）。

## 3.5 不明は 0 ではない

活動量が入力されていない（不明）とき、それを 0 として計算すると、排出を**黙って少なく見積もる**。研究の約束は次の二つである。

1. 条件の 0/1 が一つでも 0 の項は、値が欠けていても**厳密に 0** を寄与する（そもそも数えない項だから）。
2. 条件がすべて 1 なのに値が欠けた項は、結果を**欠損（不明）**にする。不明を 0 とみなすことはない。

条件そのもの（輸入かどうか、など）が不明なときは、その 0/1 を 0 と 1 の両方で計算してみるとよい（本書の勧める扱い。研究のエンジンは、値の無い入力への条件を 0、その否定を 1 として計算し、両方での計算はしていない）。結果が同じなら（たとえば OR の他の条件が確かに 1 なら）結果は決まり、違えば結果は**不明**（二つの値のどちらか）として扱う。OR の書き方を $1 - (1-[A])(1-[B])$ にすると、$[B] = 1$ のときに不明な $[A]$ を含む項が厳密に 0 になり、この判断が式の形のまま行える。

なお、研究のモデルの合計（SUM の単位）では、使えない・欠けた入力の行を 0 にせずに合計から除いて件数を数え、合計に「不完全」の印を付ける（付録 D）。

マスクの 0 は「数えない」という意味の 0 であり、「量が 0」という意味ではない。この区別が、不明な入力を明示する算定（初心者が使う画面で「不明」「推定」を表示する、など）の土台になる。

## 3.6 研究では何をしたか

> **研究では**
> 独立概念モデルの 70 の評価単位のうち、評価期間 $T$ によらない部分（係数の検索、数量、条件、検査の印、時間の項の振幅（第 4 章））は、すべて式 (3.1) の**データ**として書かれ、一つの計算プログラム（`msp.py`）で計算された。プログラムは評価単位の名前で分岐せず、仕様（表・項・因子の一覧）だけを読む。1 列の関数は $1/a$、$1-a$、$1/(1-a)$、$a/(1-a)$ の 4 種類に絞られた。ただし、因子と関数の種類（語彙）は単位を書く途中で少しずつ追加され、全 70 単位の統一系では表の前処理（文字の分解・並べ替え・事象の格子づくりなど）の共通の操作も加えた。〔測定〕（数値の一致は実装者自身の確認で、独立の確認者はいない。）
>
> 全 70 単位の全出力は、時間の構造（第 4 章の節点スペクトル）と合わせて、1,293 組（シナリオ × 評価期間）・約 2,270 万個の値で、**基準計算**（定義の文章どおりに行ごと・年ごとに素朴に計算し、以後変更しないで凍結した物差しのプログラム）と一致した（不一致 0）。ただしこれは標本での数値の一致であり、全入力の証明ではない。

J-CAT 原版の独立方程式 667 件も、この形（と第 4 章の節点スペクトル）に書き直して照合した（第 9 章）。原版の式そのものは非公開である。

## 3.7 行列で見る

第 2 章の 0/1 の表 $S$（項目が段階に入るか）は、マスクを並べたものである。範囲の選択はさらにマスクのベクトル $\boldsymbol{\mu}$（段階 $s$ を含めるなら 1）を掛けて

$$ C = \boldsymbol{\mu}^{\top} S\, (\mathbf{f} \circ \mathbf{m}) $$

と書ける。$\circ$（成分ごとの積）は、0/1 の条件と値を掛け合わせる操作そのものである。

## 3.8 初めて見る問題への使い方

1. 文章の条件を、ひとつずつ $[\ \cdot\ ]$ に直す（「〜なら」「〜のとき」「〜を超えたら」）。
2. 「または」「if–elif–else」は、重ならない項に分けてから足す。
3. 各項を「条件の積 × 値の積」にし、行について足す。
4. 値が欠けているときは、その項の条件が 0 か 1 かで、0 にするか不明にするかを決める。

## 3.9 よくある誤解

- 「または」を $[A] + [B]$ と書いて二重に数える。
- 不明な値を 0 として計算する（マスクの 0 と量の 0 は意味が違う）。
- 0 で割る場合を外し忘れる（面積 0 の原単位など）。

## この章のまとめ

- **P2：条件 $c$ は $[c] \in \{0, 1\}$ として掛ける。** AND は積、NOT は $1 - [c]$、OR と if–else は重ならない項の和、max・min・絶対値も 0/1 で書ける。
- P1 に P2 を掛けた**マスク付き積和** $\sum_x \sum_j \prod_k \varphi_{j,k}(x)$ が、算定の $T$ によらない部分のすべてを表す（研究の第 1 の構造）。
- マスクの 0 は「数えない」。不明は 0 ではなく欠損として扱う。
- 覚えること：$[c]$ の意味、AND は積・NOT は $1 - [c]$・OR は重ならない和、不明は 0 ではない。導けること：max・絶対値・割り算・表引き・段階の範囲の書き方（すべて 0/1 の積と和）。
