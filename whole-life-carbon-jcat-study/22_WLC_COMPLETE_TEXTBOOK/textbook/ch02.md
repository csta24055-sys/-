# 第2章 原理 P1：量 × 係数 の和

## 2.1 何を求めたいのか

建物の WLC は、何百もの材料・設備・工事・年ごとの電力などの排出の合計である。項目は多いが、計算の形は一つしかない。この章で、その形と、それを使うときの注意（単位・集計・重複）を身につける。

## 2.2 いちばん簡単な例

コンクリートを 12 t 使い、その排出係数が 300 kgCO2e/t だとする（架空の値）。

$$ C = f\,m = 300\ \tfrac{\mathrm{kgCO_2e}}{\mathrm{t}} \times 12\ \mathrm{t} = 3600\ \mathrm{kgCO_2e} = 3.6\ \mathrm{tCO_2e} $$

ここで $m$ は**活動量**（使った量、単位は t）、$f$ は**排出係数**（1 t あたりの排出量）、$C$ は排出量である。係数の分母の単位（/t）と活動量の単位（t）が打ち消し合い、kgCO2e だけが残る。**単位が打ち消し合わない式は、どこかが間違っている。**

## 2.3 項目が多いとき

材料が $n$ 種類あれば、それぞれの積を足す。

$$[2.1] C = \sum_{i=1}^{n} f_i\, m_i $$

| 材料 $i$ | 活動量 $m_i$ | 係数 $f_i$ | 積 $f_i m_i$ |
|---|---|---|---|
| コンクリート | 12 t | 300 kgCO2e/t | 3,600 kgCO2e |
| 鉄筋 | 1.5 t | 2,000 kgCO2e/t | 3,000 kgCO2e |
| 合板 | 0.8 t | 500 kgCO2e/t | 400 kgCO2e |
| **合計** | | | **7,000 kgCO2e** |

式 (2.1) が P1 のすべてである。以下は、この形がどこにでも現れること、そして足し方を変えても答えが変わらないことの説明である。

## 2.4 すべての段階が同じ形

活動量と係数の「中身」を変えれば、どの段階も式 (2.1) になる。

| 段階 | 活動量 $m$ | 係数 $f$ | 時間の性質 |
|---|---|---|---|
| A1–A3 製造 | 材料の量（t、m³） | kgCO2e/t | 一度 |
| A4 運搬 | 重量 × 距離（t·km） | kgCO2e/(t·km) | 一度 |
| A5 施工 | 現場の電力量・燃料の量・廃棄物の量 | 電力・燃料・処理の係数 | 一度 |
| B6 運用 | その年の電力量・ガスの量 | その年の係数 | **毎年** |
| B7 水 | その年の上水・下水の量 | 係数 | **毎年** |
| C1–C4 解体・処理 | 解体の活動量・運ぶ量・処理する量 | 係数 | 一度 |

運用のように毎年起きるものは、「（項目、年）の組」ごとに積を作って足す。

$$[2.2] C_{\mathrm{B6}} = \sum_{y=1}^{Y} \sum_{k} f_{k,y}\, m_{k,y} $$

$m_{k,y}$ は $y$ 年目のエネルギー $k$ の量、$f_{k,y}$ はその年の係数である。年ごとに係数が変わる（電力の排出係数が年々下がる、など）場合も、この形のまま扱える。年が $y = 1, \dots, Y$ で係数と量が毎年同じなら、和は単純に $Y f m$ になる。

> **注意：形が同じでも意味は違う**
> 運搬の「t·km」と運用の「kWh」は、どちらも式 (2.1) の $m$ だが、運搬は建てるときに一度、運用は毎年である。この違いは、評価期間 $T$ を変えたときの振る舞い（第 4 章）を決める。数学の形をまとめるときも、物理的な意味（いつ・何度起きるか）は区別しておく。

**少しだけ形が変わる例**（どれも P1 の中で導ける）：

- **複合材料の係数**：成分 $j$ の質量の割合 $w_j$（$\sum_j w_j = 1$）なら $f = \sum_j w_j f_j$。材料全体では $f m = \sum_j f_j (w_j m)$ で、成分ごとの P1 と同じ。
- **端材のロス**：取り付ける量 $m_{\mathrm{inst}}$、ロス率 $r$ なら、注文する量は $m = m_{\mathrm{inst}}/(1-r)$。活動量を先に正しく求めてから掛ける。
- **温室効果ガスの換算**：$C = \sum_k m_k \mathrm{GWP}_k$（第 1 章）も、$f = \mathrm{GWP}$ とした P1 である。

## 2.5 和の分け方は自由（線形性）

P1 の前提は、排出が活動量に**比例**すること（係数 $f$ が量によらない一定の値で、しきい値や量による割引が無いこと）である。この前提のもとで $C$ は**線形**、つまり (i) 活動量をすべて $\lambda$ 倍すると $C$ も $\lambda$ 倍になり、(ii) 二つの活動の排出は足し算になる。量によって係数が変わる規則は、量の範囲ごとの 0/1 で分けて（第 3 章）、範囲ごとに P1 を使う。

足し算は順番やまとめ方を変えても結果が同じである。だから、同じ項目の集まりを、**段階別・材料別・年別・部位別**のどれでまとめても総量は変わらない。

$$ C = \sum_{\text{段階 } s} C_s = \sum_{\text{材料 } i} C_i = \sum_{\text{年 } y} C_y $$

これが集計の根拠である。

- アップフロント $C_{\mathrm{UF}} = C_{\mathrm{A1\text{–}A3}} + C_{\mathrm{A4}} + C_{\mathrm{A5}}$
- エンボディド $C_{\mathrm{EC}} = C_{\mathrm{UF}} + C_{\mathrm{B1\text{–}B5}} + C_{\mathrm{C1\text{–}C4}}$
- WLC $C = \sum_{s \in S} C_s$（$S$ は範囲に含めた段階の集まり）

> **注意：同じものを二度数えない（重複）**
> 分け方が自由なのは、**どの項目も一度だけ**どこかに入っているときに限る。よくある重複：材料の係数がすでに工場までの輸送を含むのに A4 でも数える／施工の廃棄物を A5 と C の両方で数える／リサイクルの効果を C3 と D の両方で数える。研究の概念モデルでは、買電の排出 $E_{\mathrm{el}}$ のうち施設管理の分（割合 $\rho_{\mathrm{B2}}$）を B2 に移し、B2 を数えるときだけそのぶん B6 から引いている：$C_{\mathrm{B2}} = \rho_{\mathrm{B2}}\,E_{\mathrm{el}}$、$C_{\mathrm{B6}} = E_{\mathrm{el}} + E_{\mathrm{fuel}} - \rho_{\mathrm{B2}}\,E_{\mathrm{el}}$（燃料 $E_{\mathrm{fuel}}$ には割合を掛けない）。合計は $E_{\mathrm{el}} + E_{\mathrm{fuel}}$ のままで、重複も漏れもない。

**同じ係数の項目をまとめる**（分配法則）：同じ係数 $f_k$ を使う行がいくつもあれば、先に活動量を足してから一度だけ掛けてよい。

$$[2.3] C = \sum_{\text{行 } r} f_{k(r)}\, m_r = \sum_{k} f_k \Big(\sum_{r:\ k(r) = k} m_r\Big) = \sum_k f_k\, M_k $$

研究の初期の段階（第 9 章の統一モデル）は、この形で何百行の計算を「係数ごとの合計量 $M_k$」と係数の積和にまとめ、評価期間に依存する部分を後から掛ける形に整理した。

## 2.6 比べるための指標

- 面積あたり：$C/A$（kgCO2e/m²）、面積・年あたり：$C/(A T)$（kgCO2e/(m²·年)）、t 換算：kg を 1000 で割る
- 段階の割合：$C_s / C$
- 二つの案の比較：差 $\Delta = C_{\text{案}} - C_{\text{基準}}$、削減率 $(C_{\text{基準}} - C_{\text{案}})/C_{\text{基準}}$

面積・年あたりの値は、$C(T)$ が一次式 $\alpha + \beta T$ の区間では $C/(AT) = \beta/A + \alpha/(AT)$ となり、$T$ に反比例する部分を持つ（初期の排出 $\alpha$ を年数で割るので、短い期間ほど大きく、長い期間では $\beta/A$ に近づく。$T \to 0$ では限りなく大きくなる）。割合 $C_s/C$ も一次式どうしの比なので、$T$ とともに変わる（第 5 章の役割ごとの割合の表）。

比べてよいのは、面積・評価期間・範囲・係数の版がそろっているときだけである。面積や期間が 0 のとき、合計が 0 や負のときは割合を計算しない（意味のない数が出る）。

## 2.7 行列で書く

項目を縦に並べたベクトル $\mathbf{m}$（活動量）と $\mathbf{f}$（係数）を使うと、式 (2.1) は内積になる。

$$ C = \mathbf{f}^{\top} \mathbf{m} = \sum_i f_i m_i $$

段階別の値をまとめて求めるには、「項目 $i$ が段階 $s$ に入るなら 1、入らないなら 0」という表（行列）$S$ を使う。

$$[2.4] \mathbf{c} = S\,(\mathbf{f} \circ \mathbf{m}), \qquad C = \mathbf{1}^{\top} \mathbf{c} $$

$\mathbf{f} \circ \mathbf{m}$ は成分ごとの積（$f_i m_i$ を並べたもの）、$\mathbf{c}$ は段階別の値のベクトルである。$S$ の各列に 1 がちょうど一つあれば、重複も漏れもない。この「0/1 の表を掛ける」考え方は、第 3 章の原理 P2 そのものである。

## 2.8 初めて見る問題への使い方

1. 項目ごとに **活動量** と **係数** を表にする（何の量か、単位は何か）。
2. 係数の分母の単位と活動量の単位をそろえる（t と kg、kWh と MJ、t·km など）。
3. 掛けて足す。毎年のものは年ごとに足す（係数が毎年同じなら年数を掛ける）。
4. 範囲と重複を確かめる（どの段階に入れたか、二度数えていないか）。

> **例題 2.1（値を変えても同じ手順）**
> 鉄骨 30 t（係数 1,800 kgCO2e/t）を 120 km 運ぶ（係数 0.1 kgCO2e/(t·km)）。製造（A1–A3）と運搬（A4）の排出量は？
>
> 製造：$1800 \times 30 = 54000$ kgCO2e。運搬：活動量は $30\ \mathrm{t} \times 120\ \mathrm{km} = 3600$ t·km なので $0.1 \times 3600 = 360$ kgCO2e。合計 54,360 kgCO2e（製造の係数に工場から現場への運搬が含まれていないことを確かめてから足す）。

## 2.9 よくある誤解

- kg と t、kWh と MJ を取り違える（単位の打ち消しを確かめれば防げる）。
- 冷媒の充填量 × GWP を排出として足す（在庫であって排出ではない）。
- 面積・期間・範囲の違う建物どうしを、そのまま比べる。
- 「CO2」と「CO2e」を混同する（CO2e は他のガスを含めた換算値）。

## この章のまとめ

- **P1：$C = \sum_i f_i m_i$**。どの段階も、活動量と係数の中身が違うだけでこの形。
- 足し方は自由（段階別・材料別・年別でも総量は同じ）。ただし各項目は一度だけ数える。
- 同じ係数の項目は、先に量を足してから掛けてよい（分配法則）。
- 行列では $C = \mathbf{f}^{\top}\mathbf{m}$、段階別は 0/1 の表を掛ける（第 3 章へ）。
- 覚えること：$C = \sum_i f_i m_i$ と、係数と活動量の単位をそろえること。導けること：段階の合計、指標、複合の係数、ロス、行列の形（すべて P1 の和の分け方）。
