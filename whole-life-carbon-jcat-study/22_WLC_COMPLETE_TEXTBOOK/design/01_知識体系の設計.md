# 01 知識体系の設計（教材の骨格）

教材の目的は、例題の暗記ではなく、**少数の基本原理から個別の式を導き直せる状態**に読者を連れて行くこと。この文書は、執筆の前に決めた骨格（原理・章の順・記号・証拠の表示）を記録する。研究の再調査（第 1 工程、`design/02_研究全体図.md`）の結果に合わせて改訂する。

## 1. 学習目標（指示書の合格基準 A〜F を、読者ができることとして書き直したもの）

| 基準 | 読者ができること |
|---|---|
| A | 建物の WLC の算定から、研究の数学的成果（全体方程式・時間特性・動的 LCA・検証）までを、一つの筋で説明できる |
| B | 全体方程式・時間関数・再合成の式などを、基本原理から自分で導ける |
| C | 値・周期・条件を変えた、初めて見る計算問題・応用問題を解ける |
| D | 製造・運搬・施工・運用・更新・解体の時間の性質と、それらの数学的な関係を説明できる |
| E | 研究で「証明されたこと」「有理数で照合したこと」「浮動小数で測ったこと」「統計的に確かめたこと」「仮定」「未解決」を区別できる |
| F | 以上に必要な文章量が、理解を損なわない範囲で少ない |

## 2. 基本原理（覚えるのはこれだけ。個別の式はここから導く）

| 原理 | 内容 | ここから導くもの |
|---|---|---|
| **P1 量 × 係数 の和（線形性）** | 排出量は「活動量 × 1 単位あたりの排出量」の和。和は分け方を変えても同じ（段階別・材料別・年別に分けて足しても総量は変わらない） | 製造・運搬・施工・運用・水・廃棄の全段階の式、集計（初期・エンボディド・WLC）、原単位（面積あたり・年あたり）、行列の形 |
| **P2 条件は 0/1 の掛け算（マスク）** | 「含める／含めない」「起きる／起きない」「どちらの枝か」を 0 か 1 の数で表して掛ける。条件の AND は掛け算、OR・最大・最小も 0/1 で書ける | 算定範囲（境界）、段階の選択、条件分岐、正味の買電 max(0, ·)、マスク付き積和（研究の第 1 の構造）、「不明は 0 ではない」の扱い |
| **P3 時間は節点で区切る（事象の数え上げ）** | 評価期間 $T$ の関数は、毎年の流れ（傾き）と、更新などの事象（跳び）でできている。事象の回数は「$nL < T$ を満たす $n$ の数」 | 更新回数、階段関数、区分一次関数、跳び・傾き・微分・積分、節点スペクトル（研究の第 2 の構造）、建物全体の方程式 $C(T)$、周期性と長期の傾向 |
| **P4 状態を持つ量だけは漸化式（記憶）** | ほとんどの工程は「今年の量 × 係数」で記憶を持たない。冷媒の残存量だけは前年の状態に依存し、交換で初期化される | 冷媒の漏洩・交換・期末残存、比例関係と畳み込みが使える場合／使えない場合、DMD などの前提の成否 |
| **P5 評価期間 $T$ と実時間 $t$ を区別する（会計と排出の時刻）** | $C(T)$ は「$T$ 年で評価したら合計いくら」で、累積排出の曲線ではない。実時間の排出 $e(t)$ と期末の項 $Z(T)$ の和に分かれる | 動的 LCA の工程関数、再合成 $C_{\mathrm{dyn}}=C_{70}$、時間配分の非一意性、動的な特性化、$dC/dT \ne$ 排出率 |
| （横断）**E 主張の強さを区別する** | 証明・有理数での照合・浮動小数の測定・統計的確認・仮定・未解決 | 研究成果の読み方、検証の方法の選び方、限界の説明 |

数学的に同じ形でも、物理的な意味が同じとは限らない（例：運搬の「重量×距離」と運用の「年間電力量」は P1 の同じ形だが、片方は一度きり、片方は毎年の流れ）。教材では「形が同じ」と「意味が同じ」を分けて書く。

## 4. 記号（全章で共通。研究の記号との対応は付録）

| 記号 | 意味 | 単位の例 |
|---|---|---|
| $m$ | 活動量（材料の量・輸送量・電力量など、1 単位の量） | t、m³、t·km、kWh |
| $f$ | 排出係数（活動量 1 単位あたりの排出量） | kgCO2e/t、kgCO2e/kWh |
| $C$ | 排出量（CO2 換算） | kgCO2e、tCO2e |
| $\mu$ | マスク（0 か 1） | なし |
| $T$ | 評価期間（何年で評価するか） | 年 |
| $t$ | 実時間（建物の完成からの経過年数） | 年 |
| $L$ | 耐用年数・更新周期 | 年 |
| $N(T)$ | 評価期間 $T$ の中の更新回数 | 回 |
| $\theta$ | 事象が数えられるかの 0/1（階段関数） | なし |
| $A_0, P_t, Q_t, p_g, q_g$ | 第 17 章の全体方程式の係数（節点ごとの切片と傾き） | kgCO2e、kgCO2e/年 |
| $e(t)$ | 実時間の排出の率または原子（工程関数） | kgCO2e/年 |
| $Z(T)$ | 期末の項（評価期間の終わりに残る量の評価） | kgCO2e |

研究の記号（第 4 章の $Q_i, EF_i$、第 17 章の $\kappa$ など）とは付録で対応させる。

## 5. 証拠の表示（研究成果に付けるラベル）

| ラベル | 意味 |
|---|---|
| 〔一般〕 | WLC・LCA の一般的な知識（この研究の成果ではない） |
| 〔証明〕 | 研究の文書に数学的な証明がある |
| 〔照合〕 | 有理数（厳密な算術）で標本の点を照合した（全入力の証明ではない） |
| 〔測定〕 | 浮動小数で測った |
| 〔統計〕 | 宣言した分布からの無作為の標本で、統計的な上限を得た |
| 〔仮定〕 | データが無いので置いた仮定 |
| 〔未解決〕 | 未解決・未確認 |

研究の主張は、独立概念モデル（70 評価単位・架空データ）についてのものであり、J-CAT 原版や実在の建物すべてについて証明されたものではない。この区別を各章で明示する。

## 6. 圧縮の方針

- 同じ数学的構造は一度だけ説明し、後の章では参照する（例：P1 の「和の分け方の自由」は集計・行列・工程別の再合成のすべてで使う）。
- 圧縮してはいけないもの：前提、記号の意味、導出の重要な段、適用条件、例外、結果の解釈、他の概念との関係。
- 「暗記する事項」（段階の名前、記号の約束など）と「導ける事項」（個別の式）を分けて示す。
- 各章の終わりに「この章の式はどの原理から出るか」を 1 行で示す。
