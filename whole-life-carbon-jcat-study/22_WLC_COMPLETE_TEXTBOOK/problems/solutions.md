### 解答 1.3　節点スペクトルの用語

- **核**：評価期間 $T$ への依存だけを受け持つ決まった形の関数 $\kappa(T; s, \ell, g) = [g < T]\cdot \min(\ell, \max(0, T - s))$（$\ell = 0$ なら $[g<T]$）。始まり $s$、長さ $\ell$、ゲート $g$ で、定数・原子・年セル・ゲート付き年セル・密度の 5 つの形になる。
- **振幅**：核に掛ける数で、$T$ によらない。マスク付き積和で計算する。
- **節点**：関数の値や傾きが変わる時刻（事象の時刻と年の境目）。
- **跳び形**：核を「節点 $u$ で始まる一次式 $[u<T](c_0 + c_1 T)$」の和に分けた表現。節点での値の跳びは $c_0 + c_1 u$、傾きの変化は $c_1$。

関係：全体は $\Phi(T) = \sum_j a_j \kappa_j(T)$ で、各核を節点ごとの $(c_0, c_1)$ に分けて同じ節点を足し合わせると、$T$ より前の節点の累積和で値が求まる。

**考え方**：4.7 節の式 (4.4)・(4.5) と 4.8 節の表を使う。

> **検算（1/1 通過）**
> - ✓ 解答が使う教材の節がすべて実在する（4.7、4.8）

**採点の観点**：（1）振幅が T によらず、T の依存は核だけ、と書く　（2）跳び c0 + c1 u と傾きの変化 c1 を書く　（3）節点が事象の時刻と年の境目だと書く

## 2. 原理の説明

### 解答 2.1　運搬も「量 × 係数」

(1) 活動量は $20 \times 75 = 1{,}500$ t·km。$C = 0.12 \times 1{,}500 = 180$ kgCO2e。
(2) どの段階も「何かをどれだけ使ったか（活動量 $m$）」と「1 単位あたりの排出（係数 $f$）」で決まり、排出は活動量に比例する（2 倍使えば 2 倍出す）。比例の量を足し合わせるので $C = \sum_i f_i m_i$ になり、段階ごとに違うのは $m$ と $f$ の中身（t、t·km、kWh など）だけである。

**考え方**：単位：t × km = t·km。係数の分母 t·km と打ち消し合って kgCO2e が残る。

> **検算（3/3 通過）**
> - ✓ 20 t × 75 km × 0.12 kgCO2e/(t·km) = 180 kgCO2e
> - ✓ 次元が CO2e だけになる
> - ✓ 解答が使う教材の節がすべて実在する（2.2、2.4）

### 解答 2.2　「または」と不明の扱い

(1) 両方当てはまる行で 2 になり、同じ $e$ を二度数える。重ならない項に分けて $[A] + [\lnot A][B]$（$A$：輸入、$B$：長距離）、または $1 - (1-[A])(1-[B])$ と書く。
(2) 不明は「輸入でない」ではない。0 にすると、輸入だった場合の分を黙って落とす（**不明は 0 ではない**）。不明を別の状態として扱い、確認するか、範囲と仮定を明示する。
(3) 誤り：$(1 + 1) \times 30 = 60$。正しい：$(1 + 0 \cdot 1) \times 30 = 30$。

**考え方**：3.3 節の表（または）と 3.5 節（不明は 0 ではない）を使う。

> **検算（6/6 通過）**
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=0, B=0）
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=0, B=1）
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=1, B=0）
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=1, B=1）
> - ✓ (3) 誤り 60、正しい 30
> - ✓ 解答が使う教材の節がすべて実在する（3.3、3.5）

### 解答 2.3　傾きは排出率ではない

(1) $C(31) - C(30) = (M([0,31]) - M([0,30])) + (Z(31) - Z(30)) = 4 + (8 - 9) = 3$ tCO2e。
(2) $C$ の増分は「その年の実際の排出」と「期末の項の変化」の和である（$dC/dT = \rho + Z'$）。$Z$ が $T$ とともに変わると、傾きは実際の排出率と一致しない。この例では実際は 4 出たのに、$C$ は 3 しか増えない。

**考え方**：7.3 節の式 (7.1) と $dC/dT = \rho(T) + Z'(T)$ を使う。

> **検算（3/3 通過）**
> - ✓ C の増分 = 4 + (8 − 9) = 3
> - ✓ 実際の排出（4）と C の増分（3）が違う
> - ✓ 解答が使う教材の節がすべて実在する（7.3、4.9）

### 解答 3.2　年セルの跳び形

(1) $T \le k$：両方の 0/1 が 0 で 0。左辺も $\max(0, T-k) = 0$。$k < T \le k+1$：右辺 $= a(T - k)$、左辺 $= a(T-k)$。$T > k+1$：右辺 $= -ak + aT + a(k+1) - aT = a$、左辺 $= a$。
(2) 節点 $u$ での跳びは $c_0 + c_1 u$。節点 $k$：$-ak + ak = 0$、傾きの変化 $+a$。節点 $k+1$：$a(k+1) - a(k+1) = 0$、傾きの変化 $-a$。跳びが 0 なので連続。
(3) $T = 2.4$：$30 \times 0.4 = 12$、跳び形 $-60 + 72 = 12$。$T = 5$：$30$、跳び形 $-60 + 150 + 90 - 150 = 30$。

**考え方**：4.8 節の表（年セルの行）と 4.9 節の跳びの式を使う。

> **検算（4/4 通過）**
> - ✓ 跳び形 = 年セル（T = 0〜6 の 0.1 刻みの 61 点、有理数で）
> - ✓ T = 2.4 で 12、T = 5 で 30
> - ✓ 両節点の跳び c0 + c1·u = 0
> - ✓ 解答が使う教材の節がすべて実在する（4.6、4.8、4.9）

### 解答 3.3　節点の一次式のラプラス変換

(1) $T = u + x$ と置くと $\int_0^\infty (c_0 + c_1 u + c_1 x)\, e^{-s(u+x)}\, dx = e^{-us}\Big((c_0 + c_1 u)\int_0^\infty e^{-sx}dx + c_1 \int_0^\infty x e^{-sx} dx\Big) = e^{-us}\Big(\frac{c_0 + c_1 u}{s} + \frac{c_1}{s^2}\Big)$（$\int_0^\infty x e^{-sx}dx = 1/s^2$ は部分積分）。
(2) 節点形は、節点 $0$ に $(a, b)$、節点 $L$ に $(R, 0)$。よって $\mathcal{L}[C](s) = \frac{a}{s} + \frac{b}{s^2} + \frac{R\, e^{-Ls}}{s}$。
(3) 指数 $e^{-us}$ の $u$ が節点の時刻、$1/s$ の係数 $c_0 + c_1 u$ がその節点での跳び、$1/s^2$ の係数 $c_1$ が傾きの変化。

**考え方**：8.2 節の式 (8.1)。$\int_0^\infty e^{-sx}dx = 1/s$ と $\int_0^\infty x e^{-sx} dx = 1/s^2$ を使う（部分積分）。

> **検算（3/3 通過）**
> - ✓ (2) の閉じた式と数値の積分（台形則、刻み 0.0025、1,500 年で打ち切り）が一致（s = 0.05、相対 1.3e-06 < 1e-5）
> - ✓ (2) の閉じた式と数値の積分（台形則、刻み 0.0025、1,500 年で打ち切り）が一致（s = 0.2、相対 8.1e-07 < 1e-5）
> - ✓ 解答が使う教材の節がすべて実在する（8.2、4.8）

### 解答 12.3　表せないことと、有限の精度での実現

(1) 2 構造の有限の組合せで計算できる関数は、入力の空間を有限個に分けると各部分で有理関数（多項式 ÷ 多項式）になる（区分的有理性）。$x^{0.5}$ や $\log_{10} x$ はどんな小さな区間でも有理関数にならないので、実数の関数として一致できない。
(2) 倍精度の入力は有限個で、「真の値に最も近い倍精度数」を返す対応は有限の表や区分で作れる。実数の関数として等しいこと（不可能）と、有限の精度で同じ出力を返すこと（可能）は別の主張なので矛盾しない。
(3) 上限は宣言した分布についての確率で、その分布が細い帯をほとんど選ばないので、帯の中の入力の振る舞いは標本にほとんど現れない。研究は主張を帯を除いた $\mathcal{D}'$ に縮めた。

**考え方**：9.5 節（表せないことの証明）と 9.4・9.6 節。

> - ✓ 解答が使う教材の節がすべて実在する（9.4、9.5、9.6）
