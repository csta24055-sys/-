### 解答 1.2　CO2e と GWP、在庫と排出

(1) CO2e はガスの質量 × GWP の和（CO2 に換算した量）。GWP は同じ質量の CO2 を 1 としたときの温める力の比（ふつう 100 年間で比べた GWP100）。

(3) 漏洩量 $8 \times 0.05 = 0.4$ kg、排出 $0.4 \times 700 = 280$ kgCO2e/年。

**考え方**：(2) と (3) は P1 の形 $C = f m$ で、$f = \mathrm{GWP}$。 排出は「大気に出た量」だけ。充填量は在庫（1.6 節の注意）。

> **検算（4/4 通過）**
> - ✓ 充填量 × GWP = 5,600 kgCO2e（単位 kgCO2e）
> - ✓ 漏洩の排出 = 280 kgCO2e/年
> - ✓ 漏洩率は 0〜1 の範囲
> - ✓ 解答が使う教材の節がすべて実在する（1.6、2.4）

**採点の観点**：（1）CO2e ＝ 質量 × GWP の和、GWP は CO2 を 1 とした比（単位なし）と書く　（2）充填量は在庫で排出ではないと書く　（3）(3) 漏洩量 × GWP を kgCO2e/年で答える

### 解答 1.3　節点スペクトルの用語

- **核**：評価期間 $T$ への依存だけを受け持つ決まった形の関数 $\kappa(T; s, \ell, g) = [g < T]\cdot \min(\ell, \max(0, T - s))$（$\ell = 0$ なら $[g<T]$）。始まり $s$、長さ $\ell$、ゲート $g$ で、定数・原子・年セル・ゲート付き年セル・密度の 5 つの形になる。
- **振幅**：核に掛ける数で、$T$ によらない。マスク付き積和で計算する。
- **節点**：関数の値や傾きが変わる時刻（事象の時刻と年の境目）。
- **跳び形**：核を「節点 $u$ で始まる一次式 $[u<T](c_0 + c_1 T)$」の和に分けた表現。節点での値の跳びは $c_0 + c_1 u$、傾きの変化は $c_1$。

関係：全体は $\Phi(T) = \sum_j a_j \kappa_j(T)$ で、各核を節点ごとの $(c_0, c_1)$ に分けて同じ節点を足し合わせると、$T$ より前の節点の累積和で値が求まる。

**考え方**：4.7 節の式 (4.4)・(4.5) と 4.8 節の表を使う。

> **検算（1/1 通過）**
> - ✓ 解答が使う教材の節がすべて実在する（4.7、4.8）

**採点の観点**：（1）核の引数 s・ℓ・g の意味と 5 つの形を書く　（2）振幅が T によらず、T の依存は核だけ、と書く　（3）跳び c0 + c1 u と傾きの変化 c1 を書く　（4）節点が事象の時刻と年の境目だと書く　（5）Φ = Σ a κ を節点ごとに集めると累積和で値が出る、という関係を一文で書く

## 2. 原理の説明

### 解答 2.1　運搬も「量 × 係数」

(1) 活動量は $20 \times 75 = 1{,}500$ t·km。$C = 0.12 \times 1{,}500 = 180$ kgCO2e。
(2) どの段階も「何かをどれだけ使ったか（活動量 $m$）」と「1 単位あたりの排出（係数 $f$）」で決まり、P1 の前提（係数が量によらない）のもとで排出は活動量に比例する（2 倍使えば 2 倍出す）。比例の量を足し合わせるので $C = \sum_i f_i m_i$ になり、段階ごとに違うのは $m$ と $f$ の中身（t、t·km、kWh など）だけである。

**考え方**：単位：t × km = t·km。係数の分母 t·km と打ち消し合って kgCO2e が残る。

> **検算（3/3 通過）**
> - ✓ 20 t × 75 km × 0.12 kgCO2e/(t·km) = 180 kgCO2e
> - ✓ 次元が CO2e だけになる
> - ✓ 解答が使う教材の節がすべて実在する（2.2、2.4）

**採点の観点**：（1）活動量と係数の比例を根拠にする　（2）段階ごとに違うのは m と f の中身（単位）だけと書く

### 解答 2.2　「または」と不明の扱い

(1) 両方当てはまる行で 2 になり、同じ $e$ を二度数える。重ならない項に分けて $[A] + [\lnot A][B]$（$A$：輸入、$B$：長距離）、または $1 - (1-[A])(1-[B])$ と書く。
(2) 不明は「輸入でない」ではない。この行は長距離でない（$[B] = 0$）ので、結果は輸入かどうかだけで決まり、0 にすると輸入だった場合の $e$ を黙って落とす（**不明は 0 ではない**）。0 と 1 の両方で計算すると $0$ と $e$ で違うので、結果は不明（$0$ か $e$ のどちらか）として扱い、確認するか仮定を明示する。（もし長距離なら OR は輸入によらず 1 なので、不明でも結果は決まる。）
(3) 誤り：$(1 + 1) \times 30 = 60$。正しい：$(1 + 0 \cdot 1) \times 30 = 30$。

**考え方**：3.3 節の表（または）と 3.5 節（不明は 0 ではない、条件が不明なときは 0 と 1 の両方で計算）を使う。

> **検算（7/7 通過）**
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=0, B=0）
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=0, B=1）
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=1, B=0）
> - ✓ [A]+[¬A][B] = 1−(1−A)(1−B) = OR（A=1, B=1）
> - ✓ (3) 誤り 60、正しい 30
> - ✓ (2) 長距離でない行：[A] = 0 と 1 で 0 と 30（違うので不明）、長距離の行なら両方 30（確定）
> - ✓ 解答が使う教材の節がすべて実在する（3.3、3.5）

**採点の観点**：（1）[A] + [B] が両方 1 で 2 になる（二重計上）と指摘し、重ならない形を書く　（2）不明を 0 にしない理由と、0 と 1 の両方で計算する扱いを書く

### 解答 2.3　傾きは排出率ではない

(1) $C(31) - C(30) = (M([0,31]) - M([0,30])) + (Z(31) - Z(30)) = 4 + (8 - 9) = 3$ tCO2e。
(2) $C$ の増分は「その年の実際の排出」と「期末の項の変化」の和である（$dC/dT = \rho + Z'$）。$Z$ が $T$ とともに変わると、傾きは実際の排出率と一致しない。この例では実際は 4 出たのに、$C$ は 3 しか増えない。

**考え方**：7.3 節の式 (7.1) と $dC/dT = \rho(T) + Z'(T)$ を使う。

> **検算（3/3 通過）**
> - ✓ C の増分 = 4 + (8 − 9) = 3
> - ✓ 実際の排出（4）と C の増分（3）が違う
> - ✓ 解答が使う教材の節がすべて実在する（7.3、4.9、7.2）

**採点の観点**：（1）C の増分 ＝ 実際の排出 ＋ Z の変化（dC/dT = ρ + Z'）を書く　（2）Z が T で変わると傾き ≠ 排出率と結論する

## 3. 数式の導出

### 解答 3.1　交換の回数の式

(1) 数える交換は $n = 1, 2, \dots$ のうち $nL < T$、つまり $n < T/L$ を満たすもの（$T > 0$）。$x \le \lceil x \rceil < x + 1$ なので、$\lceil x \rceil - 1$ は $x$ より小さい最大の整数である。よって $x = T/L$ より小さい正の整数 $1, 2, \dots, \lceil T/L \rceil - 1$ の個数は $\lceil T/L \rceil - 1$（$T/L$ が整数でもそうでなくても成り立つ）。
(2) $N(36) = \lceil 3 \rceil - 1 = 2$（36 年の交換は数えない）、$N(36.5) = \lceil 3.04\ldots \rceil - 1 = 3$、$N(11) = \lceil 0.91\ldots \rceil - 1 = 0$。

**考え方**：4.3 節の式 (4.2) と約束（4.3 節の囲み）を使う。

> **検算（4/4 通過）**
> - ✓ N(36) = 2（閉じた式と数え上げが一致）
> - ✓ N(73/2（≈ 36.5）) = 3（閉じた式と数え上げが一致）
> - ✓ N(11) = 0（閉じた式と数え上げが一致）
> - ✓ 解答が使う教材の節がすべて実在する（4.3）

**採点の観点**：（1）nL < T を n < T/L に直す　（2）⌈x⌉ − 1 が x より小さい最大の整数であることを使う

### 解答 3.2　年セルの跳び形

(1) $T \le k$：両方の 0/1 が 0 で 0。左辺も $\max(0, T-k) = 0$。$k < T \le k+1$：右辺 $= a(T - k)$、左辺 $= a(T-k)$。$T > k+1$：右辺 $= -ak + aT + a(k+1) - aT = a$、左辺 $= a$。
(2) 節点 $u$ での跳びは $c_0 + c_1 u$。節点 $k$：$-ak + ak = 0$、傾きの変化 $+a$。節点 $k+1$：$a(k+1) - a(k+1) = 0$、傾きの変化 $-a$。跳びが 0 なので連続。
(3) $T = 2.4$：$30 \times 0.4 = 12$、跳び形 $-60 + 72 = 12$。$T = 5$：$30$、跳び形 $-60 + 150 + 90 - 150 = 30$。

**考え方**：4.8 節の表（年セルの行）と 4.9 節の跳びの式を使う。

> **検算（4/4 通過）**
> - ✓ 跳び形 = 年セル（T = 0〜6 の 0.1 刻みの 61 点、有理数で）
> - ✓ T = 2.4 で 12、T = 5 で 30
> - ✓ 両節点の跳び c0 + c1·u = 0
> - ✓ 解答が使う教材の節がすべて実在する（4.6、4.8、4.9）

**採点の観点**：（1）3 つの場合のそれぞれで両辺が等しいことを示す　（2）跳び c0 + c1·u = 0 から連続と結論する

### 解答 3.3　節点の一次式のラプラス変換

(1) $T = u + x$ と置くと $\int_0^\infty (c_0 + c_1 u + c_1 x)\, e^{-s(u+x)}\, dx = e^{-us}\Big((c_0 + c_1 u)\int_0^\infty e^{-sx}dx + c_1 \int_0^\infty x e^{-sx} dx\Big) = e^{-us}\Big(\frac{c_0 + c_1 u}{s} + \frac{c_1}{s^2}\Big)$（$\int_0^\infty x e^{-sx}dx = 1/s^2$ は部分積分）。
(2) 節点形は、初期値（定数）$A_0 = a$、節点 $0$ に $(0, b)$、節点 $L$ に $(R, 0)$。定数の変換は $\int_0^\infty a\, e^{-sT} dT = a/s$。よって $\mathcal{L}[C](s) = \frac{a}{s} + \frac{b}{s^2} + \frac{R\, e^{-Ls}}{s}$。
(3) 指数 $e^{-us}$ の $u$ が節点の時刻、$e^{-us}/s$ の係数 $c_0 + c_1 u$ がその節点での跳び、$e^{-us}/s^2$ の係数 $c_1$ が傾きの変化。

**考え方**：8.2 節の式 (8.1)。$\int_0^\infty e^{-sx}dx = 1/s$ と $\int_0^\infty x e^{-sx} dx = 1/s^2$ を使う（部分積分）。

> **検算（7/7 通過）**
> - ✓ (1) の一般式と数値の積分が一致（u = 3.0、c0 = -60.0、c1 = 20.0、s = 0.1、差 1.2e-06）
> - ✓ (1) の一般式と数値の積分が一致（u = 3.0、c0 = -60.0、c1 = 20.0、s = 0.4、差 4.9e-07）
> - ✓ (1) の一般式と数値の積分が一致（u = 7.5、c0 = 10.0、c1 = -2.0、s = 0.1、差 5.7e-08）
> - ✓ (1) の一般式と数値の積分が一致（u = 7.5、c0 = 10.0、c1 = -2.0、s = 0.4、差 4.4e-16）
> - ✓ (2) の閉じた式と数値の積分（台形則、刻み 0.0025、1,500 年で打ち切り）が一致（s = 0.05、相対 1.3e-06 < 1e-5）
> - ✓ (2) の閉じた式と数値の積分（台形則、刻み 0.0025、1,500 年で打ち切り）が一致（s = 0.2、相対 8.1e-07 < 1e-5）
> - ✓ 解答が使う教材の節がすべて実在する（8.2、4.8）

**採点の観点**：（1）(8.1) を正しく導く（置き換えでも部分積分でもよい）　（2）(2) で a/s + b/s² + R e^{−Ls}/s を得る　（3）e^{−us}・跳び・傾きの変化の対応を書く

### 解答 12.2　動的 LCA に何が足りないか

(1) 導ける：毎年の量の年の中の配分（一様）、更新・交換・改修の時刻、冷媒の状態の時間変化（いずれか 2 つ）。導けない：施工期間の中の配分・製造の時期、解体・処理の期間、更新の内訳の時期、季節変動（いずれか 2 つ）。

### 解答 12.3　表せないことと、有限の精度での実現

(1) 2 構造の有限の組合せで計算できる関数は、入力の空間を有限個に分けると各部分で有理関数（多項式 ÷ 多項式）になる（区分的有理性）。$x^{0.5}$ や $\log_{10} x$ はどんな小さな区間でも有理関数にならないので、実数の関数として一致できない。
(2) 倍精度の入力は有限個なので、「入力 → 真の値に最も近い倍精度数」という対応は、原理的には有限の表で、実際には有限個の区間に分けてマスクで切り替える区分的な有理式（誤差を保証して丸め、保証できないごくまれな入力は欠損にする）で作れる。実数の関数として等しいこと（不可能）と、有限の精度で同じ出力を返すこと（可能）は別の主張なので矛盾しない。
(3) 上限は宣言した分布についての確率で、その分布が細い帯をほとんど選ばないので、帯の中の入力の振る舞いは標本にほとんど現れない。研究は主張を帯を除いた $\mathcal{D}'$ に縮めた。

**考え方**：9.5 節（表せないことの証明と、有限の精度での実現が両立する理由）と 9.4・9.6 節。

> - ✓ 解答が使う教材の節がすべて実在する（9.4、9.5、9.6、5.7、9.8）

**採点の観点**：（1）区分的有理性と、べき・対数がどの区間でも有理関数でないことを書く　（2）倍精度の数が有限個であることから、有限個の区分で作れると説明し、主張が別物だと書く　（3）宣言した分布が帯をほとんど選ばないことを理由にする
