# 重要原理シート

教材を読み終えた人が、短時間で全体を思い出すための資料。左の列だけを覚え、右の列は自分で導けることを確かめる。〔 〕は主張の強さ（教材 0.3 節）。

## 五つの原理と一つの規律

| 原理 | 覚えること | 導けること（教材の節） |
|---|---|---|
| **P1 量 × 係数 の和** | $C = \sum_i f_i m_i$。どの段階も同じ形 | 段階の合計、指標 $C/A$・$C/(AT)$、行列 $\mathbf{c} = S(\mathbf{f} \circ \mathbf{m})$、和の分け方は自由（重複・漏れが無ければ）（2.2〜2.7） |
| **P2 条件は 0/1 の掛け算** | $[c] \in \{0, 1\}$。AND は積、NOT は $1 - [c]$、OR は重ならない和 $[A] + [\lnot A][B]$。不明は 0 ではない | マスク付き積和 $\mathrm{out}[g] = \sum_x \sum_j \prod_k \varphi_{j,k}(x)$、max・絶対値・割り算の場合分け（3.3〜3.5） |
| **P3 時間は節点で区切る** | 事象は $[\tau < T]$（$T$ ちょうどは数えない）。$N(T) = \lceil T/L \rceil - 1$。年の重み $w_k(T) = \min(1, \max(0, T - k))$ | 核 $\kappa(T; s, \ell, g)$ の 5 つの形、跳び形 $(c_0, c_1)$、建物全体の方程式、区分一次であることの証明、跳び $c_0 + c_1 u$・傾き・積分・ラプラス変換、長期の傾き $b + R/L$（4.3〜4.10、5.1〜5.5、8.2） |
| **P4 状態を持つ量は漸化式** | $u_k = \chi_{k-1} m_0 + (1 - \chi_{k-1})\, q\, u_{k-1}$（冷媒だけ） | 畳み込み $y_t = \sum_s x_s h_{t-s}$ は線形かつ時不変のときだけ。ゲート・状態は書けない。二時刻の核 $h(t, s)$（6.3〜6.6） |
| **P5 評価期間と実時間を分ける** | $C(T) = M([0, T]) + Z(T)$ | $dC/dT = \rho + Z'$（傾き ≠ 排出率）、$C(0+) \ne 0$、再合成、時期は $C$ から一意に決まらない、動的な特性化（7.2〜7.7） |
| **E 主張の強さを区別する** | 証明・有理数の照合・浮動小数の一致・統計・仮定・未解決 | 失敗 0 件の上限 $p \le 1 - 0.05^{1/N} \approx 3/N$（独立な単位で数える）。0 件は証明ではない（9.6〜9.7） |

## 中心の式

$$ C(T) = A_0 + \sum_{t \in \Lambda} [\,t < T\,]\,(P_t + Q_t T) + \sum_{g \in E} \theta_\varepsilon(T; g)\,(p_g + q_g T) $$

- $\Lambda$：年の境目（毎年の量が切り替わる）、$E$：事象の時刻（交換・更新・改修）。$\theta_\varepsilon(T; g) = [\,g < T(1 - \varepsilon)\,]$。
- 係数 $A_0, P_t, Q_t, p_g, q_g$ は $T$ によらない。マスク付き積和で作った振幅を、核の分解（下の表）で節点ごとに集めたもの。
- 節点の間では $T$ の一次式なので、$C(T)$ は**区分一次関数**〔証明〕。跳びは事象の節点だけ（年セルは跳ばない）。

| 部品（振幅 $a$） | 核 | 節点 $u$ に置く $(c_0, c_1)$ |
|---|---|---|
| 定数 | $1$ | 初期値に $a$ |
| 原子（時刻 $\tau$） | $[\tau < T]$ | $u = \tau$ に $(a, 0)$ |
| 年セル $k$ | $w_k(T)$ | $u = k$ に $(-ak, a)$、$u = k+1$ に $(a(k+1), -a)$ |
| ゲート付き年セル $(k, \tau)$ | $[\tau < T]\, w_k(T)$ | $u = \tau$ に $(-ak, a)$、$u = k+1$ に $(a(k+1), -a)$ |
| 密度 $(0, H, -\infty)$ | $\min(H, T)$ | $u = 0$ に $(0, a)$（$T \le H$ の範囲。$u = H$ に $(aH, -a)$） |

## 問題の型と最初の一手

| 問われたこと | 最初の一手 |
|---|---|
| 排出量の計算 | 単位をそろえて $f \times m$ を足す。範囲（マスク）・期間・係数の版を確かめる |
| 条件付きの規則 | 条件を 0/1 にして掛ける。OR は重ならない和。不明を 0 にしない |
| $C(T)$ の値 | 定数・毎年・事象・期末に分け、$T$ より前の事象だけ数える。最後の年は重み |
| 逆問題・比較（$C = $ 目標、二案の差） | 区間ごとに一次式を解き、解が区間に入るか確かめる。跳びで値が飛ぶ |
| 跳び・傾き・積分 | 節点の表を作る。跳び $c_0 + c_1 u$、傾き $\sum_{u<T} c_1$ |
| 長期の傾向 | $N(T) = T/L + \Pi$、$-1 \le \Pi < 0$ から $C/T \to b + \sum R/L$ |
| 関係が畳み込みで書けるか | 線形か、時不変か（応答が経過時間だけで決まるか）を確かめる |
| 動的 LCA | 実時間に置く（$t = 0$、毎年、事象の時刻、$t = T$）。足りない時期は仮定として明示 |
| 研究の主張の読み方 | 対象（独立概念モデル・架空データ）と主張の強さを確かめる |

## 覚えておく研究の事実

- 対象：独立概念モデル（70 評価単位 ＝ 算定式 53 ＋ 構造 17、14 段階、架空データ）。J-CAT 原版の結果・互換性ではない。
- 2 つの構造（マスク付き積和・節点スペクトル）で全 70 単位を計算し、凍結した基準計算と 1,293 組で不一致 0（相対 $10^{-9}$ の基準、最大の相対差 $1.0 \times 10^{-13}$、帯を除く範囲 $\mathcal{D}'$）〔照合〕。
- 原版の独立方程式 667 個は、すべて 2 構造で表現できる（改良方式 647 ＋ 個別研究 8 ＋ 12）〔照合〕。$x^a$（$a$ が整数でない）・$\log_{10}$ は実数として厳密には表せない（区分的有理性）〔証明〕。
- 100,000 ケース（20,000 建物）の検証で、定義域の 90,055 ケース（18,011 建物）に食い違い 0。建物単位の上限 $1.7 \times 10^{-4}$〔統計〕。
- 表現として採用しないもの：フーリエ級数（512 項でも最大誤差の中央値 約 2.8％）、POD（32 モードで誤差の 95％ 点 9.5％）、DMD（時不変の線形の前提が成り立たない）。
- 未解決：整数の年の近くの交換の直後の細い帯、冷媒の期末残存量の数値の安定性と連続性の両立、節点形の最小性、時期の分布のデータ、ガス別の時間の目録。

## 間違えやすい点

- $N(T) = T/L$、$T$ ちょうどの事象を数える、最後の年を丸ごと数える。
- 冷媒の充填量 × GWP を排出として足す（在庫であって排出ではない）。
- OR を $[A] + [B]$ と書く。不明な入力を 0 にする。
- $C(T)$ の傾きを排出率と読む。負の原子を物理的な負の排出と読む。
- 照合や統計の一致を「証明」と言う。独立概念モデルの結果を J-CAT や実在の建物の結果と言う。
