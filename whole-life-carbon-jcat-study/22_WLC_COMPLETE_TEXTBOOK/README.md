# 第 22 章　ホールライフカーボン完全理解教材

研究全体（第 1〜21 章）を読み直し、初学者が最初から順に読めば、建築 LCA の基礎から研究の数学的成果（建物全体の方程式・時間特性・動的 LCA・検証）までを理解し、初めて見る計算・理論・説明の問題を解けるようにした教材である。試験の出題予想ではない。覚える項目の数ではなく、理解すべき原理の数を減らすことを目的にした。

## 五つの原理と一つの規律

P1 量 × 係数の和、P2 条件は 0/1 の掛け算（マスク付き積和）、P3 時間は節点で区切る（節点スペクトル・建物全体の方程式）、P4 状態を持つ量は漸化式、P5 評価期間と実時間を分ける（動的 LCA）、E 主張の強さを区別する（証明・有理数の照合・浮動小数の測定・統計・仮定・未解決）。

## 作り方と確かめ方

- **再調査**：9 つの独立した読み手で第 1〜21 章・保存資料・コード・結果・他のブランチ・接続ストレージを読み直し、照合した（⑤）。
- **問題**：12 種類 × 初級・中級・上級と追加の問題。計算はすべて有理数で厳密に解き、独立な 2 通りの計算、答えの代入、単位、定義域を自動で検算する（`python3 -B code/problems.py`）。
- **教材だけで解けるかの監査**：制作者とは別の解き手が、解答を見る前に教材だけで解き、不足を報告した。不足を教材に加え、もう一度解き直した（⑥）。網羅の点検者が研究の論点の抜けと事実の食い違いを調べた。
- **組版と品質検査**：Markdown の原稿から PDF と Word を作る（`python3 -B code/build.py`）。数式は MathML で組んで画像にし、文中の式は数式用フォントで組む。PDF のフォントの埋め込み・空ページ・文字化け・ページ番号・期待する語・どのフォントにも無い文字、Word の画像の数を自動で検査し、ページを画像にして目で確かめた（output/品質検査.json）。
- **試験対策システムの応用**：利用者の試験対策システム（第 3・4 部）の組版・品質検査・検算の考え方を引き継ぎ、「出題されそうか」の等級を「何種類の問題を支えるか・後の節からどれだけ参照されるか」に置き換えた（code/coverage.py）。等級による削除はしていない。有料の外部 AI の API は使っていない。

## 公開の範囲

J-CAT 原版の数式の文・係数・値・セル番地・シート名、非公開の資料、授業の動画などは含めない。数値の例はすべて説明用の架空の値で、研究の結果は独立概念モデル（70 評価単位・架空データ）についてのものである。J-CAT との互換性や同じ結果を主張しない。公開の原稿に原版の式の番号やセル番地の形の文字列が無いことを機械的に点検している（⑥の 6 節）。

## 再生成

```
cd code
python3 -B figs.py        # 図
python3 -B problems.py    # 問題・解答・検算
python3 -B coverage.py    # 節ごとの対応と用語の初出
python3 -B make_audit.py  # 監査表
python3 -B build.py       # PDF・Word と品質検査
```

必要なもの：Python 3（reportlab、python-docx、pypdf）、Node.js の Playwright と Chromium（数式と図の描画）、poppler-utils、IPA ゴシックと FreeFont。
