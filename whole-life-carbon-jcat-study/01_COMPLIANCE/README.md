| **禁止** | J-CATソフトとマニュアルを無断複製・頒布 | **原ZIP／xlsx／xlsm／PDFはGitHub公開しない** |

## 1-B. 必ずすべきこと（MUST）
1. このフォルダにJ-CAT原ファイル、ベタ書きした原単位・マクロ、スクリーンショット全文、Excel式の大量転記を置かない。
2. 独立した算定規則と、許諾が確認できる係数データを使う。公開規格自体の文面も無断で全文コピーしない。
3. 原単位ごとに出典・版・適用地域・時点・単位・ライセンス・監査日・利用許諾を登録する。
4. サードパーティの値と独立算定で得た値の差を比較する前に、比較・公表の許諾条件を確認する。
5. 「公式J-CAT完全互換」「認証済み」「同じ結果」と誤認させない。
6. すべての入力に UNKNOWN / USER_SUPPLIED / OBSERVED / LICENSED_DEFAULT / DERIVED と証拠区分を付ける。
7. 検証済み・未検証・保留・使用禁止を混同しない。公開前に独立検算、単位試験、境界試験、セキュリティ試験を実施する。
8. 設計前に利用許諾の範囲を明らかにし、権利者に書面で問い合わせる。許諾がないものは独立実装で置き換える。

## 1-C. やるべきこと（SHOULD）
- 一般に利用できるLCA概念（材料数量 × 正当に取得した排出係数など）から開発を開始。
- バウンダリA1～C4の全段階、建物用途・ライフサイクルの時点を明示。
- 「未入力」は0と分け、不明値・欠損・補完値・感度分析を併記。
- UIは「かんたん」と「専門」の両モードで同じ検算コアを使う。
- 出力の根拠、変更履歴、バージョン、単位と丸め方を保存。
- 公式FAQから利用条件の**要点を自分の文章で整理**し、転載でなくリンクで根拠を示す。

## 1-D. しないほうがよいこと（SHOULD NOT）
- 3.8百万セルのExcel式をそのままWebで再実行させる設計。
- 入力不足を0に自動補完すること、統計推計を実測と称すること。
- 参照済みだが未再計算の式を「検証済み」とすること。
- ダウンロードしたマクロを無検証で実行すること。
- 将来排出係数の使用年・単位・排出境界を混ぜること。
- 木材の炭素貯蔵を排出削減と無条件に相殺すること。
- 既存の別研究フォルダや main に直接追記すること。

## 1-E. 権限判断の状態機械
`PERMITTED_PUBLIC` = 公開資料で権利クリア / `PERMISSION_REQUIRED` = 書面許諾待ち / `RESTRICTED` = 現条件で他ツールへ転用不可 / `UNKNOWN` = 追加確認要。
実数の係数や元の数式を `PERMITTED_PUBLIC` にする証拠がない限りGitへのコミットを拒否する。
