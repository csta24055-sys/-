# 03 検証の方法と結果

数値はすべて `results/` の件数ファイルから書き写した（原版の式・値は含まない）。参照評価器は第 15 章の Excel 意味論の評価器、LibreOffice は無作為ケースの再計算に使った別の実装。

## 1. 方法

| 照合 | 内容 |
|---|---|
| 全セル | 12 式の全セル（同じ形のパターンごと）を変換し、原版のキャッシュ値と参照評価器の値の両方と、テキストは完全一致、数値は第 15 章の規則で比べた |
| 境界条件 | 第 15・16 章と同じ生成器（空白・0・±1・実在の大きさ・整数・式の閾値 ± 微小量・丸めの中点・テキスト・エラー・論理値・検索表の値・混合の 40 変種）で、実例（各シート最大 8）の参照セルを置き換え、同じ入力の参照評価器と比べた |
| 無作為の建物ケース | 4 冊（簡易・標準・詳細・集計）に無作為の建物の入力を入れて LibreOffice で再計算した 670 ケース（DET 110、SIM 200、STD 60、SUM 300）。ケースで値が変わったセルを、方式 A・参照評価器・LibreOffice の 3 者で比べた |
| 合成データ | 原版に依存しない合成のシートで、同じ演算（SUBSTITUTE・IFERROR・IF・検索結果の文字・連結）の 32 通りの式を 1,500 行ずつ（種 20261126）。旧テキストの重なり、空、長さ 255 の前後、数値の一般形式などを意図的に含む |
| 下流への影響 | 01 の 2 節（静的な閉包、方式 A の値の差し替え、必要性の検査） |

- 「照合の対象なし」：前提のセル（式が参照するセル）が無作為ケースのどれでも変わらず、式の値がキャッシュ値と同じなので、比べる新しい値がない（EQ-0090、0185、0317、0373、0417、0553、0621）。これらの式の新しい入力での正しさは、境界条件と合成データで確かめた。
- 方式 B の欠損：第 16 章の方式 B（テキストの指紋と辞書）は、ブックの文字列辞書にない新しい結果を表せないので欠損を返す。誤った値を返したことはない（誤り 0）。SUBSTITUTE の 2 式（EQ-0181、0185）には方式 B を定義していない（未定義）。

## 3. 合成データ（原版に依存しない）

32 通りの式×1,500 行 = 48000 件で、誤った値 0、欠損 107。欠損はすべて宣言した定義域の外（元のテキストが 255 文字を超える行）で、誤った値の代わりに欠損を返した。式ごとの件数は `results/02_合成データの検証.json`。

## 4. 下流への影響

01 の 3 節。方式 A の値はキャッシュ値と全セルで同じなので、差し替えで下流は変わらない。必要性の検査（テキストを替える）では、静的な下流を持つ 4 式とも、段の上限なしの閉包で 8 ulp を超えて変わった下流のセルは 0。8 ulp 以内の違いは EQ-0090 で 16、EQ-0417 で 48、EQ-0471 で 12、EQ-0317 で 0 セル。変更なしの再評価（対照）でも EQ-0090 の 16、EQ-0471 の 12 は同じセルに現れ、EQ-0417 の 48 のうち 16 も同じ。EQ-0417 の残り 32 セルだけがテキストの変更による（`results/04_依存関係と下流への影響.json`）。

## 5. 共有する不具合の確認

- 方式 A は参照評価器を使わずに作る（2 構造の手順を実行するだけ）。照合の相手は、原版のキャッシュ値（Excel が計算した値）、参照評価器、LibreOffice の 3 つで、互いに独立に作られている。3 者の一致は、方式 A と参照評価器が同じ誤りを共有している可能性を下げるが、Excel の仕様の解釈（一般形式の数値の文字など）を 3 者が同じ形で誤る可能性は残る。
- 合成データは、旧テキストの重なり（定義域の外）と長さ 255 の境目を意図的に含め、定義域の外で欠損になることを確かめた（負の対照の役割）。
