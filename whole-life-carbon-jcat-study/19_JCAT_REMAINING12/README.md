# 19 J-CAT 原版の残り 12 式：依存関係の分析と、2 構造による厳密な変換（第 3 段階）

指示書「ホールライフカーボン統一数学理論の確立」の第 3 段階の成果（2026-11-14）。第 15 章（667 式の変換）・第 16 章（未解決 8 件）を引き継ぐ。

- 対象：15 章で基本方式・改良方式とも変換できなかった 12 式 EQ-0090、EQ-0181、EQ-0185、EQ-0317、EQ-0373、EQ-0377、EQ-0417、EQ-0471、EQ-0553、EQ-0587、EQ-0621、EQ-0643（15 章の分類はいずれも「単なるセル転記・表示・補助処理」）。
- 原版の式の本文・係数・値・セル番地・見出しは**公開しない**。それらを含む資料（各式の本文、変換前後の式、パターン別の照合の詳細、依存先のセルの一覧）は非公開ファイルとして直接渡した。
- 既存の 2 構造（マスク付き積和／最初の一致、節点スペクトル）だけを使う。エンジン `msp.py` は無変更。第 16 章の方式 A（テキストを文字の索引集合として持つ）を引き継ぎ、テキストの IF・IFERROR・SUBSTITUTE・検索結果の文字を同じ表現の上に加えた（[02_変換方式.md](02_変換方式.md)、`tools/exact12.py`）。
- この研究は原版の計算規則の表現可能性を調べたもので、J-CAT と同じ結果を出す製品・互換ソフトを主張するものではない（`01_COMPLIANCE`）。

## 1. 結論

| 項目 | 結果 |
|---|---|
| 12 式の扱い | **12 式すべてを方式 A（厳密）で変換**。除外した式はない（「変換できなかったから不要」とした式は 0） |
| 原版のキャッシュ値との一致（全セル） | 方式 A：2,247 セルすべて一致（参照評価器とも全セル一致） |
| 境界条件（40 通り×標本の実体） | 方式 A：6,800 件すべて一致（誤り 0、欠損 0） |
| 無作為の建物ケース（LibreOffice で再計算した 670 ケース） | 方式 A：評価した 61,390 値すべてで LibreOffice・参照評価器と一致。前提のセルがどのケースでも変わらない 7 式（EQ-0090、0185、0317、0373、0417、0553、0621）は、ケースの値がキャッシュ値と同じなので照合の対象にならない（[03_検証の方法と結果.md](03_検証の方法と結果.md)） |
| 合成データ（原版に依存しない） | 32 通りの式×1,500 行＝48,000 件で誤り 0。欠損 107 件はすべて宣言した定義域（元のテキストが 255 文字以下）の外 |
| 依存関係（必要性） | 下流の数式から参照されない式 8（表示だけ：静的な参照の範囲で）、参照される式 4（EQ-0090、EQ-0417、EQ-0471、EQ-0317）。後者は表示用に見えるが計算の連鎖に入る（[01_依存関係と必要性.md](01_依存関係と必要性.md)） |
| 方式 B（高精度近似） | 連結だけの 9 式はキャッシュ値では全セル一致するが、新しい入力（境界条件）では大部分が欠損。テキストの IF の 1 式（EQ-0587）はキャッシュ値でも欠損。SUBSTITUTE の 2 式には方式 B を定義していない。いずれも誤った値は 0 |

## 2. 数値的な完全性と全機能の再現の区別

[04_扱いと適用範囲.md](04_扱いと適用範囲.md)。12 式の変換で、原版のテキストを作る規則が、宣言した範囲（元のテキストが 255 文字以下、SUBSTITUTE の旧テキストが重ならない形）で**値として**完全に再現される。表示の書式（フォント・色・セルの書式）、マクロ、グラフ、入力の検証規則などの**機能**は対象外で、再現したとは主張しない。
