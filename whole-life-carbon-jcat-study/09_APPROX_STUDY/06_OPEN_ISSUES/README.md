## B. 独立モデルの定義として本研究が決めた点（変えれば結果も変わる）

基準計算は、概念式が決めていない点を次のように定めた。統合モデルは同じ定義を前提にしており、定義を変える場合は基準計算と統合モデルの両方を直して検証し直す必要がある。

| 番号 | 定めた内容 | 別の選択肢 | 影響する単位 |
|---|---|---|---|
| B-1 | 評価期間 T は実数。非整数のときは最終年を按分する | T を整数に限る | 年次の積算すべて |
| B-2 | 周期の事象は n×周期 < T のものだけ数える（T ちょうどは数えない） | T ちょうどを数える | B4-01、B4-03、B5-01、B1 |
| B-3 | 事象は、それが属する評価年（切り上げ）に置く | 期首に置く、按分する | X-07、B3-01、B1-02 |
| B-4 | 更新が属する年は修繕を計上しない | 更新年も計上する（B3-02 と同じ） | B3-01 |
| B-5 | 冷媒機器の交換は、属する年の年末に残存量へ反映する | 年の途中で反映する | B1-02、B1-03、B1-04 |
| B-6 | 廃棄時の未回収分（B1-04）は B1 段階に入れる | C 段階に入れる | X-02、SUM-02 |
| B-7 | 建替・大規模改修（B5）があっても、部材の更新周期を初期化しない | 建替時点で初期化する | B4、B3、B5 |
| B-8 | 更新・建替時の排出は、初期と同じ係数で計算する（係数は時点によらず固定） | 更新時点の係数を使う | B4-02、B5-01、B3 |
| B-9 | 未数量分（A13-04）は、行ごとの費用比率 r による上乗せ r/(1−r) とする（本研究の独立設計） | 費用×費用当たり係数 | A13-04 |
| B-10 | 施設管理分（B2）は買電排出の定率で、同額を B6 から引く | エネルギー量の比で切り出す | B2-01、X-02 |
| B-11 | 設備機器の初期の搬入・据付は計上しない（更新時だけ計上） | 初期も A4・A5 に計上する | X-01、A5-04 |
| B-12 | ガスの範囲（全ガス・CO2 のみ）は結果のラベルで、合計は常に全ガス。CO2 のみは X-05 が別に出す | 範囲に応じて合計を切り替える | SUM、X-05 |
| B-13 | 経路比率の合計が 1 未満は違反にせず「未配分」として数える | 違反にする | C-05 |
| B-14 | 製品固有値（EPD）は、対象段階が A1-A3 のみ、単位が換算可能、算定日に有効、使用許諾あり、のときだけ使う | 段階の一部適用を認める | X-15、A13-03 |

特に **B-8** は統合の前提として重要である。更新時点の係数（たとえば将来の電力係数の低下を製造係数に反映したもの）を使う場合、更新の排出は「回数×1 回当たり」ではなく「事象の年ごとの係数の和」になる。回数関数の代わりに事象年の係数の累積を使えば同じ枠組みに入ると見込まれるが、**実装も検証もしていない。**

## C. 実データがないために保留している検証

| 番号 | 保留している候補 | 分かっていること | 必要なデータ |
|---|---|---|---|
| C-1 | AP-10：6 区分の要約数量×代表係数（構造×用途） | 代表係数をその建物の加重平均にすれば恒等式。外部の代表値を使う場合の誤差は未知 | 実建物の数量内訳（資材行）と、利用許諾のある係数。構造・用途ごとに複数棟 |
| C-2 | AP-11・AP-15・AP-16：延床面積・評価年数・構造・用途からの代理モデル | 架空の母集団では誤差が非常に大きいが、架空データのばらつきは実建物を表していない | 同上（建物全体の計算結果を複数棟） |
| C-3 | AP-12：質量上位の行だけ詳細計算し、残りを比率で補う | 架空の母集団では過小側に偏った | 同上（質量と係数の関係が分かる内訳） |
| C-4 | AP-13・X-11：面積当たり使用量による運用段階の推定 | 式は 1 行だが、精度は統計値の質で決まる | 実建物の年間エネルギー使用量と延床面積、利用許諾のある面積当たり統計値 |

実データは、利用条件を確認したうえで、原単位などの流用禁止（RULES R03）に触れないものに限る。

## D. 精度について検証できていないこと

1. **実建物での実用精度。** 一致を確認したのは、独立に設計した基準計算と統合モデルの間だけである。基準計算そのものが現実の排出量をどれだけ正しく表すかは、この研究の対象外である。
2. **他のツールの結果との一致。** 比較していない。比較や結果の公表には権利者の確認が要る（第1章 1-B の 4）。
3. **基準計算の正しさの独立な確認。** 基準計算と統合モデルはどちらも主担当が書いた。両者は書き方が違う（逐次計算と、単一走査＋閉形式）ので互いの誤りは検出しやすいが、同じ定義の読み違いは両方に入り得る。手計算との照合は一部の式だけである。
4. **数値の丸め。** 相対 1e-9 を許容差とした。表示上の丸め（桁数、端数処理）は扱っていない。
5. **規模の外挿。** 資材 2 万行までしか測っていない。

## E. 測定についての注意

- 計算時間・命令数・メモリは、純粋な Python の実装どうしを同じ機械で比べた値である。実装言語や実行環境が変われば絶対値は変わる。
- 軸 A の順位は、架空ベンチマークの行数の比率（資材 : 設備 : 冷媒機器 = 200 : 60 : 5 など）に依存する。
- 軸 B は 3 名の評価者の判断で、評価が割れた単位（X-17、X-13、X-15、X-10、SUM-08、B2-01）がある。順位は着手順の参考にだけ使った。
- 原版ブックの計算時間は測っていない（実行していない）。数式ノード数は繰り返しの多さの代理指標にすぎない。

## F. 権利について残っていること

- 権利者への照会（[01_COMPLIANCE/PERMISSION_REQUEST.md](../../01_COMPLIANCE/PERMISSION_REQUEST.md)）の結果は、この研究には反映されていない。
- 独立した係数データ（出典、版、単位、対象段階、利用許諾が明らかなもの）は未入手。架空データ以外での計算はしていない。
- シート名を使った構造の整理を公開資料に含めることの可否は、既存の第2章と同じ扱い（名称とノード数のみ）としたが、最終的な判断は権利者の確認による。
