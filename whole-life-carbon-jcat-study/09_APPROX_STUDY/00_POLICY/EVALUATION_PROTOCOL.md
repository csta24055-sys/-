## P2. 評価単位（計算式・式群）の定義

評価単位 = 独立概念モデルにおける固有の計算構造 1 件。次の 2 種類からなる。

1. **既存単位**：[formulas.json](../../04_FORMULAS/formulas.json) の 53 概念式。ID はそのまま使う（例 `A13-01`）。
2. **追加単位**：53 式に含まれないが、(a) シート族メタデータ、(b) 未接続の入力項目・出力項目、(c) 既存資料の記述から存在が読み取れる計算構造。ID は `X-01` から付番する。

追加単位には必ず根拠区分を付ける。

| 根拠区分 | 意味 |
|---|---|
| `EXISTING_CONCEPT` | 既存 53 式 |
| `INFERRED_FROM_SHEET_METADATA` | シート名・ノード数から存在を推定。原版の式本文は未確認 |
| `INFERRED_FROM_UNLINKED_INPUT` | 式に未接続の入力項目から、必要な計算構造を推定 |
| `INFERRED_FROM_EXISTING_DOCS` | 01〜08章の記述から推定 |

追加単位は「独立モデルに必要と考えられる計算構造の設計案」であって、原版の式の再現ではない。
シート族のうち計算構造を特定できないものは評価単位にせず、`NOT_INSPECTED`（未調査）として台帳に残す。

## P3. 分類台帳の様式（成果物1）

`01_LEDGER/units.json` の 1 単位は次の項目を持つ（指示書 2-1 の 10 観点に対応）。

| 項目 | 内容 |
|---|---|
| `id` / `name` / `stage` | ID、名称、ライフサイクル段階 |
| `origin` / `evidence_level` | `EXISTING_53` か `ADDITIONAL`、および P2 の根拠区分 |
| `purpose` | 計算内容と目的 |
| `inputs` / `n_inputs` | 必要な入力変数（inputs.json の ID、未定義のものは `NEW:` を前置） |
| `output` | 出力（outputs.json の ID または中間量） |
| `structure_class` | 数学的構造の分類（下表から 1 つ、必要なら副分類） |
| `canonical_form` | 構造を表す正規形（記号式） |
| `loop_dims` / `branches` | 反復の次元（例 `items`、`items×years`）と条件分岐 |
| `complexity` | 計算量（例 `O(N)`、`O(N·T)`） |
| `depends_on` / `feeds` | 依存する単位、結果を渡す単位 |
| `similar_units` | 同じ構造を持つ単位 |
| `unification_potential` | 共通化・統合の可能性 |
| `approximation_potential` | 近似式への置き換え可能性 |
| `expected_precision_loss` | 想定される精度低下 |
| `boundary_unit_caveats` | 統合時に同一視してはならない算定境界・単位 |
| `sheet_family_links` | 対応すると推定されるシート族（`SF-xx`）。対応は推定であり未検証 |
| `computable_in_reference` | 基準計算として実装できるか（モデル未定義なら `false` と理由） |

構造分類の語彙：

| `structure_class` | 意味 |
|---|---|
| `LINEAR_SUM_PRODUCT` | 活動量 × 係数の総和 Σ a·f |
| `WEIGHTED_AVERAGE` | 構成比による加重和 |
| `MATRIX_EXPANSION` | 構成行列による展開（複合品 → 構成資材） |
| `TIME_SERIES_SUM` | 年次の積算 Σ_y a_y·f_y |
| `RECURRENCE` | 年ごとの状態更新（残存量など） |
| `EVENT_SCHEDULE` | 周期イベント年の生成 |
| `COUNT_FLOOR` | 回数の計数（床・天井関数） |
| `SUM_OF_STAGES` | 段階結果の合計 |
| `RATIO` | 比・原単位化・単位換算 |
| `MAX_CLAMP` | max/min による打ち切り |
| `PREDICATE_GATE` | 判定・検証（真偽を返す） |
| `MASS_BALANCE_CONSTRAINT` | 質量収支の制約 |
| `LOOKUP_JOIN` | コード・分類表の検索結合 |
| `UNDEFINED_MODEL` | 概念はあるがモデル式が未定義 |

## P4. 評価軸A：計算負荷・複雑性（成果物2）

**測定値を優先する。** 測定対象は「独立した基準計算」（P7）であり、J-CAT 原版ではない。原版は本環境に存在せず実行もしないため、原版側は数式ノード数を代理指標として併記するにとどめる。

| 指標 | 内容 | 取得方法 | 重み |
|---|---|---|---:|
| a1 | 実行時間シェア（基準計算の総時間に占める割合） | 実測。規模 S/M/L の中央値 | 0.35 |
| a2 | 基本演算回数（内側ループの反復回数） | 実測（計数） | 0.15 |
| a3 | ピークメモリ増分 | 実測（tracemalloc） | 0.10 |
| a4 | 入力変数数＋処理段数 | 台帳から算出 | 0.10 |
| a5 | 条件分岐・反復の複雑さ | 台帳から算出 | 0.10 |
| a6 | 他式との依存（入次数＋出次数） | 台帳の依存グラフ | 0.10 |
| a7 | 対応シート族の数式ノード占有率（原版側の代理指標、対応は推定） | sheet_families.json | 0.10 |

- 各指標を全単位内の百分位順位（0〜1）に直し、重み付き和を A スコアとする。
- モデル未定義で測定できない単位は a1〜a3 を欠測とし、残りの指標の重みを正規化して順位付けする（`measured=false` と明記）。
- **感度分析**：(i) 実行時間のみ、(ii) 全指標等重み、(iii) 代理指標 a7 を除外、の 3 通りでも上位30％を求める。主スコアの上位30％に加え、いずれかの代替重みで上位30％に入る単位も検証対象に含める（取りこぼし防止。`A_SENSITIVITY` と表示）。

## P5. 評価軸B：簡略化・近似化・統合の余地（成果物3）

指示書の 8 観点を各 0〜3 点で採点する（合計 0〜24 点）。

| 観点 | 内容 |
|---|---|
| b1 | 数式が必要以上に複雑 |
| b2 | 本来まとめられる計算が別々に存在する |
| b3 | 入力条件が似ているのに異なる式を使っている |
| b4 | 複数の式を共通のパラメータモデルで表現できそう |
| b5 | 複雑な条件分岐を近似で置き換えられそう |
| b6 | 簡単な線形・多項式・補間モデルで代替できそう |
| b7 | 入力変数を減らせそう |
| b8 | 異なる式を共通の代理モデルへ統合できそう |

- 採点基準：0 = 該当しない、1 = わずかに該当、2 = 明確に該当、3 = 強く該当し具体的な置き換え案を示せる。
- 互いの採点を見ない 3 名の評価者（代数的統合／数値近似／入力・データモデル削減の各観点）が採点し、観点ごとの中央値の合計を B スコアとする。
- 評価者間の差が大きい単位（合計の最大差 6 点以上）は `B_DISPUTED` と表示し、理由を残す。

## P6. 選定規則（成果物4）

- 評価単位数を N とし、各軸の選定数を `k = ceil(0.30 × N)` とする。
- 境界で同点の単位はすべて含める（選定数が k を超えてよい）。
- A と B の和集合を検証対象とする。両方に入る単位は 1 件として数え、両方の理由を記録する。
- 選定後に対象を省略しない。検証不能な対象は理由と不足データを記録し `NOT_VERIFIED` とする。

## P7. 検証プロトコル（成果物5〜8）

### 基準計算
- 概念式の定義どおりに、行ごと・年ごとに逐次計算する実装（`research_code/refcalc/`）。簡略化を一切入れない。
- 候補モデル（`research_code/fastcalc/`）とは別の担当が書き、互いのコードを共有しない部分を持たせて独立性を確保する。
- 入力検証（単位・境界・欠損）は基準計算でも候補でも同一規則で行い、近似の対象にしない。

### 架空データ
- 係数・数量・耐用年数・修繕率・漏洩率などはすべて乱数で生成した**架空値**（`SYNTHETIC_FICTIONAL`）。J-CAT その他の実データベースの値は使わない。
- 構造種別・用途・規模の違いは架空の生成パラメータで表す。したがって「構造別・用途別の誤差」は架空母集団上の値であり、実建物での精度を示すものではない。
- 乱数シードを固定し、再現可能にする。

### 誤差の評価
- 相対誤差 = (候補 − 基準) / 基準。符号を保持し、**過小評価（負の誤差）を別途集計**する。
- 集計：平均、95パーセンタイル、最大、最小（最大の過小評価）。建物全体、段階別、材料区分別、用途別、構造別。
- 暫定目標：建物全体 1％以内、主要段階 2％以内、重大な過小評価なし、適用範囲外では厳密計算へ戻せること。
- 厳密同値をうたう候補は、浮動小数点の丸め差（相対 1e-9 以内）を超える差が 1 件でもあれば不合格。

### 性能の評価
- 同一言語・同一実行方式どうしで比較する（ベクトル化の効果と数式置換の効果を混同しない）。
- 計算時間（反復の中央値）、ピークメモリ、基本演算回数、数式の種類数、必要入力項目数、共通化できた式群の数。

### 検証状態の語彙

| 状態 | 意味 |
|---|---|
| `VERIFIED_ANALYTIC_AND_SYNTHETIC` | 数学的導出があり、架空データでも基準計算と一致または誤差上界内 |
| `VERIFIED_SYNTHETIC_ONLY` | 架空データ上でのみ確認。実用精度は未検証 |
| `NOT_VERIFIED` | 検証不能または未実施（理由と不足データを記録） |

### 採否の語彙

| 判定 | 意味 |
|---|---|
| `ADOPT_EXACT` | 厳密同値の簡略化・統合として採用候補 |
| `ADOPT_WITH_GUARD` | 適用範囲の条件付きで採用候補（範囲外は厳密計算へ戻す） |
| `KEEP_EXACT` | 近似しない（厳密計算を維持する理由を記録） |
| `REJECT` | 不採用（誤差・過小評価・物理的意味の喪失など） |
| `HOLD_DATA_NEEDED` | 検証保留（必要なデータを記録） |

## P8. 検討手順（指示書第4章）

選定された全対象について、次の順で検討し、各段階の結論を記録する。

1. 厳密同値の簡略化（計算順序の変更、共通項の抽出、重複の削除、共通関数化、前計算の再利用）
2. 単純な近似（線形、区分線形、多項式、補間）
3. 異なる式をまとめる共通モデル（重点）
4. 高度な近似（回帰、応答曲面、代理モデル）。元の計算より重くなる・入力が増える場合は利点を再評価
5. 厳密計算と近似計算の併用

採用できる近似が見つからない場合も、その結論と理由を記録する。
