# 第9章：計算式の近似化・統合研究

独立計算モデルの式群を、必要な精度を保ったまま、できるだけ少数の簡単な計算式へ置き換えられるかを調べる研究フォルダ。
**アプリ・UI・製品用エンジンは作らない。** J-CAT の原版ファイル・式本文・原単位等は含まない（[第1章](../01_COMPLIANCE/README.md)）。

## 統制文書
- [00_POLICY/DIRECTIVE.md](00_POLICY/DIRECTIVE.md)：開発方針指示書（受領した全文）
- [00_POLICY/DIRECTIVE_AMENDMENT_01.md](00_POLICY/DIRECTIVE_AMENDMENT_01.md)：追加・変更指示 第1号（上位30％制限の撤廃。受領した全文）
- [00_POLICY/EVALUATION_PROTOCOL.md](00_POLICY/EVALUATION_PROTOCOL.md)：評価単位、2軸評価、着手順序、検討手順、検証手順、進捗台帳の定義

## 研究範囲
確定できた評価単位の**すべて**が研究対象。2軸評価（A：計算負荷・複雑性、B：簡略化・近似化・統合の余地）は着手順序を決めるためだけに使い、対象の絞り込みには使わない。
