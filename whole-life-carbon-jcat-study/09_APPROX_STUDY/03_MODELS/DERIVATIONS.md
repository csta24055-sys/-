# 統合モデルの導出

統合モデル（`research_code/fastcalc`）が基準計算（`research_code/refcalc`）と同じ結果になる理由を、式で示す。
研究記録（`records/units.json`）の `derivation` 欄は、この文書の節番号を指す。

ここで扱うのは、本研究が独立に定義した概念モデルの式である。J-CAT 原版の式を導出・再現したものではない。
記号：T は評価期間（年、正の実数）、Y = ceil(T) は評価年の数、w_y は年 y の重み（w_y = 1、最後の年だけ w_Y = T − (Y − 1)）、
k = y − 1 は年の添字。事象の時刻 τ は τ < T·(1 − 10⁻⁹) のとき評価期間の内側とし、年 max(1, ceil(τ·(1 − 10⁻⁹))) に属する。

導出は式の変形だけである。丸め誤差は演算の順序が変わる分だけ生じ、検証では相対 10⁻⁹ を一致の基準にした
（実測の最大差は `04_VERIFICATION/unified_model_exactness.json`）。

## D1 行テーブル（和の順序の入れ替え）

行 i の排出が e_i = a_i · v_{k(i)}（a_i は活動量に換算と行の乗数を掛けたもの、k(i) はその行の係数キー、v は係数の値）のとき、

    Σ_i a_i · v_{k(i)} = Σ_k ( Σ_{i : k(i)=k} a_i ) · v_k = Σ_k A_k · v_k

である。左辺は行の数だけ乗算し、右辺は係数キーの数だけ乗算する。統合モデルは 1 回の走査で A_k を表ごとに作り、値を右辺で読む。

同じ A_k に別の列を掛ければ、別の結果が得られる。

- ガス別内訳（X-04）：Σ_k A_k · (係数 k のガス g の量)
- CO2 のみ（X-05）：Σ_k A_k · (係数 k の CO2 の量)
- 段階の値（X-02）：その段階に属する表の値の和
- 区分別・経路別の集計（X-17、X-09）：集約キーを（区分、係数キー）や（区分、経路、係数キー）にした表の値

行の乗数は a_i の中に入る。端材の倍率（A13-05：設計数量なら 1/(1 − w)）、未数量分の上乗せ（A13-04：r/(1 − r)）、
物価の比（X-16：P_base/P_cost）、積載率の補正（X-12：1/積載率）はいずれもこの形である。
複合品の行は、係数キーを「配合の内容」にして同じ表に載せる（D8）。

買電と冷媒は、活動量の時点ですでに排出量になっている（係数の値を 1 とする特別なキー）。この 2 つはガス別の量を持たない。

参考値（X-12、STO-02、X-16）は、段階に属さない表として同じ形に載せ、段階の値には足さない。

X-17 は、要約数量 Q_k に代表係数 f̄_k = (区分 k の製造排出) / Q_k を掛ける定義なので、Q_k · f̄_k = (区分 k の製造排出) という恒等式である。
統合モデルは区分別の表の値を返すだけで、簡略化として得るものはない（区分別への並べ替えである）。

## D2 回数関数と、周期ごとの合算

周期 c > 0 の更新が評価期間の内側で起きる回数は

    N(T, c) = #{ n ≥ 1 : n·c が内側 }

で、規約の許容幅を除けば ceil(T/c) − 1 に等しい（n·c < T ⇔ n < T/c）。統合モデルは T/c から出発し、
基準計算と同じ判定式「n·c が内側」で前後を確かめて n を決めるので、浮動小数点の端でも基準計算の数え上げと同じ回数になる。
周期が欠損・0 以下・無限大のときは 0 回。

更新の排出は、行 i の 1 回分の排出を u_i とすると

    Σ_i N(T, c_i) · u_i = Σ_c N(T, c) · U_c ,   U_c = Σ_{i : c_i = c} u_i

である。U_c は T に依存しないので、1 回の走査で周期の値ごとに（係数キー別に）合算しておけば、別の評価期間の結果は
N(T, c) を計算し直すだけで得られる（X-08 の周期別集計はこの U_c と回数そのもの）。
明示の更新年一覧を持つ設備は、一覧のうち 0 < t かつ内側のものの数を回数とする（合算せず、行ごとに扱う）。

資源量・廃棄物量（X-10）は、係数の代わりに質量を持つ同じ形で、乗数が (1 + N) になる。

年次系列（X-07）は、U_c を事象の年に置いて作る。置く年は周期と n だけで決まるので、行ごとに置く必要はない。

## D3 修繕（除外年の重み）

行 i の修繕は、更新が属する年を除いた年について e0_i · r_i · w_y を足す。除外する年の集合を S_i とすると

    Σ_{y ∉ S_i} w_y = T − Σ_{y ∈ S_i} w_y

（Σ_y w_y = T）。周期 c の更新では、S は事象 n·c（n = 1..N）の属する年の集合である。c ≥ 1 なら事象ごとに年が違い、
c < 1 なら年 1 から最後の事象の年までがすべて含まれる。重みが 1 でないのは最後の年 Y だけなので、

    Σ_{y ∈ S} w_y = (S の年の数) − (Y ∈ S なら 1 − w_Y、そうでなければ 0)

となる。修繕の排出は Σ_c (T − 除外年の重み(T, c)) · R_c、R_c = Σ_{i : c_i = c} a_i · r_i の形になり、D2 と同じく周期ごとの合算に乗数を掛ければよい。
簡易式 B3-02 は乗数を T にしたものである。

## D4 建替・大型改修

事象ごとに 範囲比 φ × (初期段階 A1-A3・A4・A5・C1〜C4 の和) を足すので、事象の数を N(T, C) として N · φ · (初期段階の和) である。
初期段階の和は表の値なので、表の活動量に共通の乗数 N·φ を掛けたものが B5 の表になる。

## D5 年重み付き和

**年次量（一定・直線）。** 年 k の値が b + s·k のとき

    Σ_{k=0}^{Y−1} w_{k+1} · (b + s·k) = b·T + s·( (Y−2)(Y−1)/2 + w_Y·(Y−1) )

である（重み 1 の年が k = 0..Y−2、最後の年が重み w_Y）。年次表で与えられる量は表を 1 回走査する。

**電力係数（区分的に直線）。** 一定、直線低下（下限つき）、段階の 3 種類は、いずれも添字の区間 [a, b) ごとに g_k = α + β·k と書ける
（直線低下は下限に達する添字で 2 区間に分かれる。その添字は基準計算と同じ比較で決める）。区間ごとに

    Σ_{k=a}^{b−1} (α + β·k) = α·n + β·s1 ,          Σ_{k=a}^{b−1} k·(α + β·k) = α·s1 + β·s2
    n = b − a ,   s1 = (a + b − 1)·n/2 ,   s2 = Σ_{k=a}^{b−1} k²

を足し、最後の年の分だけ重みを w_Y に直すと、G = Σ_k w_{k+1}·g_k と H = Σ_k w_{k+1}·k·g_k が得られる。
記述子が整っていない場合（低下量が負、初期値が下限より小さい、段の添字が 0 から厳密に増えていない）は、基準計算と同じく年次表を使い、表を走査する。

**買電排出。** 消費・発電・売電が一定または直線なら、正味の買電量は B + S·k（B、S は 3 つの量の切片と傾きを換算して合成したもの）で、
k について直線だから、両端 k = 0 と k = Y − 1 で 0 以上なら全区間で 0 以上となり、打ち切り max(0, ·) は働かない。このとき

    Σ_k w_{k+1} · (B + S·k) · g_k = B·G + S·H

である。両端のどちらかで負になる場合、または年次表で与えられる場合は、年ごとに max(0, ·) を評価する。

施設管理分（B2-01）は買電排出の定数倍、面積当たりの推定（X-11）は 面積 × 原単位 × 換算 × G である。

**入力の冗長さについて。** 年次量と電力係数は、記述子（種類とパラメータ）と年次表の両方を持つ。基準計算は、整った記述子があればそれを正とし、
年次表は写しとして扱う。統合モデルも同じ規則に従う。両者が食い違う入力は、どちらの計算も同じ値を返したうえで、食い違いを報告する
（X-06 の `matches_table`、B6-04 などの `descriptors_match_tables`）。

## D6 冷媒の充填サイクル

補充しない機器では、年初の残存量 m に対して年末の残存量は m·(1 − r)（重み 1 の年）。交換のない j 年のあとの残存量は m·(1 − r)^j、
その間の漏洩は m·(1 − (1 − r)^j) である。評価期間を交換の年で区切り、区間ごとにこの式を使う。最後の年が端数のときは、
その年の漏洩だけ m·r·w_Y とする。交換の直前の残存量が交換時損失（B1-03）に、評価期間の終わりの残存量が廃棄時未回収（B1-04）に使われる。
毎年補充する機器は残存量が常に初期充填量なので、漏洩は m0·r·T、交換の直前も終わりも m0 である。

漏洩率がごく小さいときに桁落ちしないよう、1 − (1 − r)^j は −expm1(j·log1p(−r)) で計算する。

充填量×GWP（B1-01）は、この式の m0 に GWP を掛けたもので、同じ走査で求まる。

## D7 指標と残差判定

アップフロント・エンボディド・ホールライフは段階の値の部分和、原単位はそれを面積や面積×年数で割ったもの、割合は段階÷合計、
基準案との比較は合計の差と比である。いずれも段階の値の一次式（または比）で、段階の値が一致すれば一致する。
B2 が対象外で B6 が対象のときは、B6 = B6-03 とする（B2 の分を B6 に戻す）規則を、基準計算と同じく適用する。

面積の整合（SYS-04・QA-04）と段階合計の突合（QA-01）は、残差 ρ と尺度 σ に対する同じ判定 |ρ| ≤ 許容差·σ で、許容差と尺度だけが違う。
面積の残差は 1 回だけ求め、2 つの許容差で判定する。

## D8 係数解決

ある係数を、ある段階の、ある単位の活動量に使えるかどうかと、そのときの換算倍率は、（係数、段階、単位）の組だけで決まる
（行ごとの換算を持つ行は、その換算を先に見る）。同じ組は何度解決しても同じ結果なので、1 回だけ解決して覚えておけばよい。
単位と段階の検査（SYS-02）、参照の検査（SYS-03）、使用した係数の検査（QA-03）は、この解決の結果から読める。

複合係数は Σ_j (質量比_j × 換算_j × 係数_j) で、配合の内容（構成材と質量比の並び）だけで決まる。同じ配合の行はいくつあっても同じ値なので、
配合ごとに 1 回計算する。構成材への展開（X-03）は、配合ごとに行の質量を合算してから行えば、展開の回数は配合の種類数になる。

## 導出が当てはまらない範囲

- 評価期間 T が有限の正の数でないとき（どちらの計算もエラーにする）。
- 出力に行別の値や年次の系列を求めるとき。値は同じだが、行ごと・年ごとの計算が必要になり、上の「乗算は係数キーの数だけ」
  「年ごとの繰り返しをしない」は当てはまらない（`mechanism_counts` の `full_outputs`）。
- 近似候補（AP-…）。これらは等式ではなく、誤差を `04_VERIFICATION/approximation_study.json` に測定値として記録している。
