# Route B — formula network → circuit grammar (Ψ reading)

**Status: G2 batch 2 executed. This is synthetic, fictional-data research. Matching the frozen oracle says nothing about the emission accuracy of a real building. We claim no novelty. All agreements are float agreements [F] (relative tolerance 1e-9), not equalities.**

## Question
Which **kinds** of formulas in the independent 70-unit model (`WLC_THEORY_RESEARCH_BASE` 03/04/06) can be generated *exactly* by a small circuit grammar, with the evaluation horizon **T** as the sweep variable (Ψ reading, architecture §1.4)? Which kinds need active, switched-hybrid or external digital parts? Which cannot be represented at all? Route B does not force every formula into a passive capacitor.

## Grammar 𝒢 (`code/grammar.py`)
`sweep` (independent source with value T), `src` (DC source), `gain` (linear controlled source with a T-independent coefficient), `sum` (summing node / KCL), `gate` (0/1 switch), `clip` (saturation), `cmp` (comparator `[a<b]`), `table` (external table), `int` (ideal integrator; its input is piecewise constant between declared breakpoints), `sh` (sample-hold / reset, used in the refrigerant hybrid automaton).
The grammar has **no** multiplier of two signals, no divider, no keyed look-up and no string handling. Kinds that need these are class **d** (external digital). We did not approximate them.

Classes: **a** passive (ideal sources + R/C/KCL), **b** active (comparator, clip, amplifier), **c** switched-hybrid (an integrator or sample-hold switched by comparators or counters), **d** external digital, **e** not representable.

## Conventions (the original model's rules, not the P0 pilot's)
- An event at τ counts iff `τ < T(1−ε)`, with ε = 1e-9. This is the same float operation as refcalc: `T*(1.0-EPS)`.
- Year cell k covers `(k, k+1]`, with `w_k(T) = clip(T−k, 0, 1)`. An event belongs to cell `k_τ = max(1, ⌈τ(1−ε)⌉) − 1`.
- Domain: `0 < T ≤ H = 130` (the table length of the generator) and `H < 256`.
- Units: kgCO2e for values, kgCO2e/yr for cell and density amplitudes, years for T. The circuit quantities are dimensionless stand-ins. No carbon–electric conversion is implied.

## What feeds the kernels
- **P1 amplitudes as an external table.** `unified.System(scn).pieces` holds the T-independent output of masked sum-product ① placed on kernel shapes (EMIT). Route B never uses the knot spectra or the TIME/AGG results as inputs; those are oracle outputs only.
- **Raw scenario inputs.** The refrigerant hybrid automaton (B1-02/03/04) and the equipment event counter (B4-01) are built directly from the generator's scenario fields and are independent of msp.

## Oracles
- `refcalc`, frozen, run once per T via `scenarios.with_period`. This is the primary oracle.
- `msp`/`unified.System.at(T)`. This is the second oracle.
- `tstudy.baseline.assert_frozen()` is checked before each run, and no `__pycache__` may appear in the frozen trees.
