# Shared topology (stages A, B, C) — rails, time base, event groups, buses, crossbar, core

Status: implemented and executed for CF1–CF3 (stage A, sections 1–6), the full synthetic building
(stage B, sections B.*), and the final crossbar v2 / core changes (stage C, sections C.*). Every
statement here is [E] for the executed finite cases listed in `STATUS.md`, otherwise [H]. Not drawn
as the 70-unit partition. The circuit is a fixed cell catalogue instantiated per input row (W4) and
joined to shared rails, one time base and one bus per observed stage.

Cell-type count, final state (counted from the `cell` tags of the dumped netlists):
- stage-A model (`adapter.py`): **10 cell types** (section 2);
- building model (`adapter_building.py`, `results/stageB_netlists_{S,E1}.json`): **22 cell tags**,
  identical on S and E1:
  - 8 crossbar tags: rails, factor_rail, composite, stage, eol_routes, group_sum, repair_sum, stage_sum;
  - 15 core tags: rails, timebase, clock, logic, bus, packet, yearcell, yearbank, explicit, grid, elec,
    split, refrigerant, tap, readout;
  - `rails` is shared by both, and `tap` / `readout` are interface cells;
  - one untagged element (the power-on `por`).
Base commit `e4c6d20`. Model actually run: self-reported `claude-opus-5-5`; effort not observable.

## 1. Element laws used (engine, WLC-agnostic)
| element | law | level |
|---|---|---|
| resistor `G` | `i = G (v_a − v_b)`; heat `E_R = ∫ v i dt` metered (resistor holds no energy state) | P0 |
| capacitor `C` | `i = C du/dt`, `q = C u`; state `u` | P0 |
| inductor `L` | `v = L di/dt` (benches only) | P0 |
| independent DC V/I source | `v_a − v_b = V` / `i = I` | P0 |
| ideal op-amp (nullor) | `v_+ = v_−`, zero input current, free output current | P1 |
| VCVS/VCCS/CCCS/CCVS | linear controlled sources | P1 |
| ideal switch | closed `v = 0`, open `i = 0`; controlled by a boolean | P0 (time-driven) / H (state-driven) |
| ideal diode | on `v = 0, i ≥ 0`; off `i = 0, v ≤ 0` | P0 |
| comparator | boolean `[v_+ − v_− ≥ 0]`; transitions are events with a priority | H |
| gates, SR latch, D flip-flop, counter, phase sequencer, power-on | booleans only | H |

Between events each mode is linear: MNA `M z = r0 + R s` (capacitors as voltage-defined
branches of value `u`, inductors as current-defined branches). Left null vectors of `M` are
algebraic constraints on `s` (C‖V, C loops through virtual grounds); loop currents follow
from `d/dt(constraint) = 0`. Result `z = F s + f0`, `s' = A s + b`. Integrator-only modes are
nilpotent → states are polynomials in `t`, solved exactly with `Fraction`, threshold roots
exact (degree ≤ 2 rational). At a switch change: impulse charges `Q` on current-unknown
branches satisfy KCL at every node and bring `s` onto the new constraint set (charge
conservation); impulsive energy on the linear transfer path `W_k = ½(v⁻+v⁺) Q_k`.

## 3. Hybrid state, events and transition maps
State `x = (u_C for all capacitors; latches, D-FF, counter bits, comparator outputs; sequencer phase)`.
Simultaneous events at one instant are processed in priority classes, each class as a SET:

`readout(left, 0) → power-on (5) → lookahead P (10) → year tick (20) → event fires (30) → readout(right, 100)`

Conventions (§5.4) by mechanism only: **right** `ε=0`, readout priority 100; **left** `ε=0`, priority 0;
**original** `ε=10⁻⁹` (clock/global ramp slope `1−ε`), priority 0 ⇒ an event at `τ` is counted iff
`τ/(1−ε) < T` ⇔ `τ < T(1−ε)`.

Transition map of a firing set (all sequencers in lockstep, zero-length phases):
1. all fired packet caps leave their sources (sample = pre-event state);
2. all dumps into buses / reset packets into clock integrators / shorts close;
3. dumps / shorts open; 4. caps reconnect to sources (recharge from the rail).
Then comparators are re-evaluated (ramps reset → fire falls, explicit comparators disarmed).

Year tick (commit of a year cell): gate off → `C_h` leaves the feedback → `C_h` onto `X_s` (charge
transferred) → back into feedback (empty) → gate on. `S′ ← S`, `S ← 0`.

Repair-year exclusion per group (§5.5 as implemented):
* event with `P=0` (belongs to the current year) and `S=0`: short `C_h` (discard the partial year), `S←1` (gate stays off until the tick);
* event with `P=1` (belongs to the year that just closed, i.e. last tick `K ≥ τ(1−ε)`) and `S′=0`: negative packet of one year's flow, `S′←1`;
* `P` is the level of the shared lookahead comparator at the firing instant.

## 4. Readout (only arithmetic on results)
`S_s(T) = γ Σ_{taps of s} C·u` (bus capacitor + flying year-cell capacitor), `C(T) = Σ_s S_s`.
In stage A there is no terminal term: `Z(T) = 0`, `M([0,T]) = C(T)`. `G(t)` (right-continuous
pilot) and `C(T)` (original convention) are separate runs/conventions, not one quantity.

## 6. Energy readouts and where E = V₀Q holds
Data-path dissipation = flow-resistor heat (metered) + packet switch losses (impulsive, linear path).
Single rail, positive amounts (pilot): `E = V₀ Q` exactly at every T (both flows and packets). With
amplitudes carried as voltages (repair `N_A`) and negative packets (year exclusion) it fails —
measured in `results/cf3_full_solution_original.json` (`joule_audit_fails_here`). Heat is an audit
quantity, not the emission observable.

| cell | elements | law | level |
|---|---|---|---|

| initial packets | three packets sampling N.A1-A3/A4/A5 at power-on, `C = 1/(γV0)` | Δq = C v | P1/H |
| terminal readout | packets from N.C1..C4 into readout integrators `z_s` at the readout pulse; `z_s` shorted at the start of each readout | Δq = C v, never fed back into the stage buses | P1/H |
| group renewal | clock (period) or explicit comparators; packet from N_U into the B4 bus | integrate-and-fire, Δq | H |
| year cell (B3) | stage-A year cell fed from N_A; negative one-year packet; copy capacitor sampled only at the readout into `z_B3` | flying C, packets | H |
| repair without events | resistor from N_A(free) into the B3 bus | Ohm | P0/P1 |
| B5 | clock (replacement cycle) + packet from N.B5 | H | |
| year bank | per annual profile: CONSTANT → one branch; LINEAR_TREND → base branch + 8-bit MDAC of the slope on the counter bits; TABLE → one switched branch per entry (shared 8-bit decoders) | Ohm, KCL, boolean decode | H |
| electricity | KCL summer of consumption − generation·cg + export·cx → VCCS → R_p ∥ ideal diode (max(0,·)) → follower → conversion stage → grid bank (CONSTANT / STEPWISE latches / TABLE / LINEAR_DECLINE: start − MDAC decline, comparator against the floor) | KCL, diode, Ohm | P1/H |
| ρ split | F → B6; stage ρ → −ρF into B6; inverter → +ρF steered by a static ι_B2 switch to B2 (or back to B6) | charge conservation: B2 + B6 unchanged | P1 |
| refrigerant device (B1) | charge integrator (u = V0·m), year-start sample-hold, leak `r·gwp·m_start` into B1, drain `r·m_start` (no top-up, before a replacement), loss packets (mid-year live sample + correction flow; tick-time pending sample for events of the closed year), reset to m0 (short + m0 packet), terminal packet `(1−η)·gwp·m(T)` into `z_B1` | integration, sample-hold, Δq | H |

Ordering of one instant: readout(left) → power-on → look-ahead / early comparators → year tick → firings (as a
set) → readout(right) → post phase (comparators falling just after the instant switch now, D11).
Readout: `S_s = γ (q_bus,s + q_z,s)` for s ∈ ι, `C = Σ S_s`, `Z = γ Σ q_z` over C1–C4 and B1, `M = C − Z`.

# Stage C: final crossbar (v2) and changes to the core

## C.1 Crossbar v2 (`LazyAmpNet`, default; v1 selectable with `crossbar="v1"`)
Each amplitude term is a product of data factors. The realisation rules are D21:
* the factor rail is a ±V source;
* conversion, the second-to-last row factor, DESIGN q/(1−w) and r/(1−r) become stages only if the product must
  be a voltage;
* the last factor is the junction input conductance.

Equations: stage `v_out = −(R_f/R_in)·v_in`; junction `v_out = −R_f·Σ_k G_k v_k`; source `v = x·V0`.

What is shared:
* factor rails, one per factor id, across materials, equipment, site, demolition and operation;
* derived rails, one per (factor, conversion);
* the composite factor junction per row;
* route sums per row;
* each row amplitude node, created once and used by the initial sum (t = 0), the renewal group sum (every
  firing), the repair sum (flow) and, through the stage sums, the B5 base and the terminal readout;
* one clock per distinct period across materials and equipment (core).

Sharing key, as built: structural, not value.
- factor id for rails;
- (factor id, conversion value) for derived rails;
- object identity `id(x)` of the tracked input for row factors;
- a fresh junction per `sum` call.

Equal values from different rows are therefore not merged. On S, 66 op-amp outputs duplicate another output's
value, mostly identical composite recipes (51 composite rows, 15 distinct recipes; `results/closing_timing_and_duplicates.json`,
DESIGN_DEVIATIONS D21).

## C.3 Operations that do not commute
These are preserved:
* validity masks before any sum;
* rectifier before multiplication and integration;
* leak before replacement and reset within a year;
* readout before tick before firings, and the post phase last;
* terminal packets never into the integrators;
* ι only at the readout (and the static ρ steering);
* per-stage junctions kept separate.

## C.4 Core changes
* An undilated absolute-time ramp `tb.u` is always present. STEPWISE grid steps are comparators against it (D23).
* Explicit-list groups have one renewal packet per listed year (D24).
* The refrigerant residual branch is omitted for η = 1 (D22).
