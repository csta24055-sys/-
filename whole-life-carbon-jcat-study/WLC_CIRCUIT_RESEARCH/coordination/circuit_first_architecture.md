## 1. 回路法則が無料で行う演算／行えない演算
| 法則 | 無料で行う演算 | 行えないこと |
|---|---|---|
| オーム `i=Gv` | 信号×素子値（1回の積）。`G` を切り替えれば信号×選択値 | 2つの**信号**の積。`p=v²G` は2乗で、電流の重ね合わせに対して加法的でない |
| KCL／並列 | 符号付き加算。並列コンダクタンスは和（同一品 n 個＝n 本並列） | — |
| 直列・分圧・ポテンショメータ | `a/(a+b)`、`w` と `1−w` の同時生成（`R₁+R₂=R₀`） | 一般の除算 |
| 回路網の求解（KCL連立）・負帰還 | 線形方程式の解。帰還分圧で `1/(1−w)`、`r/(1−r)` | 信号による除算（比の読出しが必要） |
| コンデンサ `q=Cv, i=C dv/dt` | 時間積分（`rate×clip(T−k,0,1)` はゲート付き流れを T まで流せば出る）、1実数の記憶 | 蓄積エネルギー `q²/2C` は電荷ではない |
| 電荷共有・SCパケット | 比 `C₁/(C₁+C₂)`、パケット `Δq=C_sV`（電荷は保存、エネルギーは失う） | — |
| 理想スイッチ／理想ダイオード | 0/1 マスク／`max(0,x)`・クランプ（`max(下限,·)`） | 表引き、キー一致、欠損の論理 |
| 比較器＋コンデンサ | しきい値事象、積分発火（周期 ∝ `C·V_th/I`） | — |
| インダクタ | 電流の保持・2次振動 | WLC に対応する2次動特性はなく、使わない（ベンチと S3 反証のみ） |
| 固定レール | 枝ごとに「供給エネルギー＝`V₀×電荷`」 | §3(ii) の条件が崩れると比例しない |

**限界の補題（いずれも [H]、検証者の査読対象）**
- **L1 同次性**：独立源と受動2端子抵抗だけの網では、枝電流は源の値について線形、コンダクタンスについて**高々1次の同次式**（電圧源駆動なら全 `G` を λ 倍すると全電流が λ 倍、電流源駆動なら不変）。よって、コンダクタンスで与えた2入力の積 `G₁G₂`（2次）は受動網では作れない。積を1つ増やすには、因子を**源の電圧**として与えるか、トランス抵抗段（制御源／ナレータ＋帰還抵抗）を1つ足すか、アダプタで事前に掛ける（＝隠蔽）しかない。
- **L2 解析性**：固定時刻で切り替わる源だけを持つ線形時不変 R/L/C 網の応答は、源の不連続点の間で実解析的。折れ・跳びを状態に依存する時刻（周期の倍数、リセット後の経過）に作るには、しきい値と切替が要る。
- **L3 積分**：レール→抵抗→接地コンデンサは `V₀(1−e^{−t/RC})` であり、厳密な積分器ではない。厳密な積算には仮想接地（能動1個）か、供給線のクーロン計（計器）が要る。抵抗の累積熱にも計器が要るのと同じ事情である。

## 2. 3方向の比較と選定
| 方向 | 方程式から見た中身 | 判定 |
|---|---|---|
| ① 共通回路モデル（法則先行） | 係数レール×数量コンダクタンスの抵抗網を KCL で解く。資材・設備・工事・運用・解体の振幅がすべて同じ形 | **採用（振幅層）** |
| ② 段階カスケード | レール→コンダクタンス→トランス抵抗→バス→積分→読出し、という**同一時刻内の信号経路** | **独立案としては不採用、①③の内部経路として吸収**。純粋な前向きカスケードには状態の帰還（時計のリセット、`u_{k+1}=f(u_k,χ_k)`）の置き場がなく、旧 P1→TIME→AGG の順を再現するだけになる |
| ③ ライフサイクル切替回路 | 時間基準・事象時計・パケット・冷媒セル・読出しスイッチのハイブリッド状態方程式を実時間 `t` で 0 から T まで走らせる | **採用（時間・状態層）** |
| S3 受動直列 R–L–C | `Lq″+Rq′+q/C=v_s(t)`、状態は (q,i) の2つ | **不採用（反証）** |

**S3 が表せないこと**：(a) 定電圧では `q→CV` に飽和し、無限に続く線形増加を作れない。目標 `q(t)` を出すには `v_s=Lq″+Rq′+q/C` を外で作る必要があり、答えを源に入れるレベル F になる。(b) L2 により、源が事象時刻を知らない限り折れ・跳びが出ない。(c) 状態が2つなので、互いに無理数比の周期 n 本の位相（§5.7）を保持できない。(d) ステップ応答の抵抗熱は `½CV²` で一定（R によらない）であり、時間に比例しない。(e) `Z(T)` は時間発展ではなく読出しである。S3 はエンジンのベンチ（解析解・エネルギー収支）にだけ使う。

**選定＝①＋③の合成**。構造は3つだけ：**(α) 振幅クロスバー**（静的・抵抗性・DC）、**(β) 時間・状態コア**、**(γ) 読出し**。

## 4. 層・許可演算・隠蔽率・レベル
**層（別モジュール、互いに import を一方向に）**
1. **回路エンジン**（WLC を知らない）：R/G、C、L、独立DC源、線形制御源・ナレータ、ポテンショメータ、理想スイッチ、理想ダイオード、比較器、ブールのラッチ・カウンタ。区間内は線形 DAE（MNA）、切替時は電荷保存による再初期化、しきい値交差は解析解。積分器だけの網（状態が t の多項式）は有理数で厳密に、一般の RC/RLC は浮動小数で解く。教科書回路だけで試験できること。
2. **ネットリスト生成器（アダプタ）**：原始入力→素子値・配線・初期スイッチ位置。**許可演算は次の4つだけ**。
   - W1 代入：素子値＝原始入力×建物によらない単位定数（`γ`、`V₀`、`τ_y`、kg→t の 1/1000、MDAC の 2ᵇ）。
   - W2 キー照合→配線（係数ID→レール、(単位,単位)→派生レール、等しい周期→同じ時計）。数値を返さない。
   - W3 単一入力の妥当性述語（欠損・範囲・列挙値・許諾・段階一致）→枝の有無。
   - W4 列挙：入力の行・一覧の要素・表の要素ごとにセルを1つ置く。
   **禁止**：データ値どうしの四則・min/max・床/天井・べき、年や `n·c` のループ、事象時刻・回数・年番号・振幅・`u_{d,k}` の計算、記述子からの表の生成、`refcalc`/`msp`/`canon`/`tstudy` の import。やむを得ず使う算術（例 `q×換算`、`1−x`）は灰色演算として実行回数を数える。算術を含む述語（質量比の合計≈1、EPD の期限比較）も数える。
3. **読出し**：解体スイッチ、`ι`、合計、`γ` の単位換算だけ。

**隠蔽率（建物ごと、機械的に測る）**：アダプタ内の原始値を計数付き数値型で包み、演算のたびに数える。
`h = W_out /(W_in + W_out)`。
`W_out` ＝ 灰色・禁止演算の実行回数 ＋ 原始入力でない値を持つ源のサンプル数（任意波形源）＋ 制御内の非ブール演算数 ＋ 読出し内の許可外演算数。
`W_in` ＝ 値が原始入力である受動素子・独立源の数（各1演算）＋ Σ(KCL節点の入力枝数−1) ＋ ダイオード数 ＋ 比較器数 ＋ データ経路のスイッチ数。
内訳（振幅層 `h_amp`、時間層 `h_time`）と、算術でない構成操作の件数（W2 照合、W3 述語、W4 列挙）を別掲する。照合は回路法則ではないので 0 にはならない。これは隠さず限界として報告する。

**レベルの操作的定義（機能ブロックごとに判定、全体は最も低い格付け）**
- **P0**：R・C・独立DC源・ポット・理想ダイオード・年ティック由来の時間駆動スイッチ・供給線計器。
- **P1**：P0＋線形制御源／ナレータ。事象間は線形 MNA のまま。
- **H**：P1＋比較器・ラッチ・カウンタ・状態依存スイッチ。**制御はブール信号だけを読み書きし、データ値はデジタル領域に入らない**（例外は年カウンタ `k` による転流アドレス）。比較器数・ビット数を数える。
- **F**：データ値が素子法則の外で演算される、任意波形源を使う、または原WLCコードを呼ぶ。
- 予測 [H]：振幅層 P0〜P1、流れと積算 P1、事象・冷媒 H、照合と欠損の扱いは回路外の構成、AGG の比は外部。全体は **H**。

**「同じ回路、パラメータ変更のみ」**：トポロジーを**セル型の有限集合＋固定の接続規則**（全セルが共有レール・バス・時間基準につながる）と定義する。建物は各セル型の個数と素子値だけが違う。判定は2つ：(a) 生成器が出すスキーマ署名（セル型と端子の接続パターン、個数を除く）が全建物で一致、(b) 最大寸法 `N_max` で作った**同一のネットリスト**に、未使用セルを開スイッチで無効にして各建物の値を入れた結果が、詰めたネットリストと一致。

| パケット採取／流れゲート | SC サンプル（振幅ノード電圧→`C_s`→バス）、ゲート付き枝 | `Δq=C_sV`、マスク | P1／H |
| 積算・読出し | 段階バスの積分器 14、終端用 `z_s`、`ι` スイッチ、合計 | 積分、KCL | P1 |

一つの振幅網を、初期（t=0）、更新（発火ごと）、修繕（流れ）、大規模改修（B5 時計）、解体（読出し）が時間をずらして共用する。これが旧分解に対する共有計算の中心である。行ノードは電圧なので、複数の行き先へコンダクタンスで分配できる（電流の複製は不要）。

### 5.3 方程式と単位
- 枝 `i=G(v_a−v_b)`、各節点 `Σi=0`、仮想接地 `v_out=−R_f Σ_j G_j v_j`、積算 `C_s·dv_s/dt=−Σ i_in`、パケット `Δq=C_s·v_N`。
- 換算：`V₀`=1 V、`τ_y`＝1年に対応する模擬秒、`γ` [kgCO2e/C]。流れ `B` [kgCO2e/年]↔電流 `B/(γτ_y)`、原子 `A`↔電荷 `A/γ`、周期 `c`↔`C_j=c·I₀τ_y/V_th`。`γ` は模擬上の定義で、物理的な炭素–電気換算ではない。結果は (`γ`,`V₀`,`τ_y`) の取り直しで変わらないこと（変成試験）。
- ハイブリッド状態 `x=(q_s, v_t, k, {v_j,E_j,P_j,S_j,S′_j}, {C_m,C_h,F}_d, 保留コンデンサ)`。

### 5.4 時刻と境界の規約
- **読出しは左極限**：時刻 T の処理順は「読出し → 年ティック → 発火（集合）」。原典の `[t<T]`、`τ<T(1−ε)` と一致する。右連続のパイロットは ε=0、順序を「発火 → 読出し」に替えるだけで同じ回路。
- **数える時刻**：時計のランプ勾配を (1−ε) にし、しきい値 `V_th` で発火（遅）。`t_f=τ/(1−ε)`。リセットは `V_th` 分の電荷の引抜き（`n·c` が累積誤差なく出る）。
- **属する年**：同じランプのしきい値 `V_th(1−ε)²` で早い比較器が働く（`t_m=τ(1−ε)`）。`年(τ)=⌈t_m⌉`。早い比較器が働いてから遅い発火までの間に年ティックが入った事象（整数時刻とその近傍）は、**閉じたばかりの年セルに属する**（`P=1`）。早い比較器と年ティックが同時刻なら早い比較器を先に処理する（`t_m=K` は年 K）。
- **同時事象は集合**：同時刻の発火は、すべて発火前の状態からパケットを採ってから、まとめてリセットする。
- **定義域**：`0<T≤H`、`H<256`、周期 > 10⁻⁶ 年。原典の 𝒟′（帯 `(K, sw(τ)]` と刃先を除く）で等価性を主張する。帯内では本設計は正準形の意味（年ティックで初期化）に従い、`refcalc` と異なる（原典自身が除外）。帯内の値は別掲で報告する。

### 5.5 遷移写像（原典の測度 M の形。走り書き検算済みの規則）
- **流れ**：年セル内、流れゲートが閉じた枝の電流が段階バスへ流れ込む。
- **更新（B4）・改修（B5）**：遅い発火でパケット `C_s·v(N_U,j)`、`C_s·v(N_B5)`。
- **修繕の年除外（B3、時計ごと。行ごとではない）**：`P=0` の発火で `S=0` なら、その年セルにここまで積んだ分を取り消し、年ティックまで流れを止め、`S←1`。`P=1` の発火で `S′=0` なら、閉じた年セル1年分を取り消し、`S′←1`。年ティックで `S′←S`、`S←0`。取消しは「年セル保留コンデンサを確定せず捨てる」ことで実現でき、信号どうしの乗算は要らない（原典の負の原子・負の密度と同値）。
- **冷媒（機器 d）**：年初に `C_h←C_m`（保持）。漏洩電流 `i=v(C_h)·G_r` が年セル全体で B1 バスへ流れ（×GWP）、補充なしで `F=0` の間は同じ電流が `C_m` を排出する。`P=0` の発火：`F=0` なら B1 へ `λ·GWP·q(C_m)` のパケット、`C_m←m₀`、`F←1`、以後年ティックまで `−λ·GWP·u·r`（補充なしのみ）の負の流れ。`F=1` なら `λ·GWP·m₀` のパケット。年ティック：年末値 `m_end=q(C_m)` を確定し、`P=1` の事象があれば最初の1件に `m_end`（`F=1` なら `m₀`）、残りに `m₀` を保留量として採り、次の年初を `m₀` にする。`P=1` も `F=1` もなければ次の年初は `m_end`。`F←0`。`P=1` の発火は保留量×`λ·GWP` のパケットだけで、状態を変えない。読出し：`R(T)=Σ_d(1−η_d)GWP_d·q(C_m,d)`。
- **読出し**：C1〜C4 の終端振幅と `R(T)` を `z_s` に採る。積算器 `q_s` には戻さない（複数の T を1回の走行で読める）。

### 5.6 交換してはならない順序
1. 正味買電の形成（KCL）→ダイオード→係数との積→時間積分。整流と積分、積と積分は入れ替えない。
2. 年初の保持→漏洩→年末確定→交換による初期化（`refcalc` の「漏洩してから事象」）。
3. 同時刻は「読出し→年ティック→発火の集合」。発火内は「全パケット採取→全リセット」。
4. `ι` は読出し側だけ。振幅網の上流に置くと B4 の単価と B5 の基礎額が欠ける。
5. `ρ` の分流は積とダイオードの後。`ι_B2` は `ρ` 側の行き先だけを切り替える。
6. 妥当性マスクは加算の前。
7. 熱の計量は加算の前の枝ごと（共有抵抗で測ると交差項が出る）。
8. 終端パケットは最後で、状態を変えない。

### 5.7 保存する観測量と状態数
- **保存**：`C(T)`、14段階値、`Z(T)`、`M([0,T])`（＝積算器の総電荷×γ。実時間側の量として `C(T)` と別に出す）、事象列（時計ID・`t_f`・属する年・回数）、交換直前・直後の冷媒量、年初状態 `u_{d,k}`。補助として枝ごとの供給エネルギー（総通過量の監査用）。
- **状態数**（`N_c`＝相異なる周期の時計数、`N_x`＝明示一覧の要素数、`N_r`＝冷媒の (漏洩率, 補充, 予定) の類の数、`H`＝年数）：連続状態 ≈ `14 + 5(z) + 1 + N_c(1〜3) + N_r(2〜3)`、ビット ≈ `8 + 4N_c + N_x + N_r`。静的素子は行数に比例（資材1行あたり枝 6〜8、設備 4 前後）＋年バンク `H×(表形式のプロファイル数)`。
- **避けられないもの [H]**：(a) 互いに無理数比の周期 n 本には位相の連続状態 n 個（到達集合が n 次元トーラスで稠密なので、未来の全事象を保つ状態の写像は単射でなければならない。サイクル1の D-9 と同じ未査読の主張）。等しい周期の行を1つの時計にまとめるのは事象を失わない正当な削減で、行数ではなく周期の種類数に比例する。(b) 冷媒は類ごとに量と年初保持の2つ。(c) 観測する段階値の数だけ積算器。
- 正準形は T までの全節点を係数として持ち、任意の T を直接評価する。本回路は動的状態が少ない代わりに T までの事象数だけ時間を進める。時間と記憶の交換であり、**速度の主張はしない**。

## 8. リスクと未確定
