## §1 目的と、何を固定し何を自由にしたか
- **目的**（13 §0、15 §1）：70評価単位を1つずつ回路部品へ言い換えるのではなく、電気回路の普通の法則（KCL/KVL、オーム則、`i=C dv/dt`、スイッチ、比較器）から共有トポロジーを作り、WLC 全体系をそれに落とし込めるかを調べる。成功基準（ユーザー指定、拘束力あり）は「70回路で70単位を再現」ではなく、**入力と最終出力を固定し内部を自由にして、電気回路の法則に自然な、より統一的な系へ再編成できたか**。優先順位は回路としての妥当性 → 入出力の保存 → 必要な内部状態 → 共有計算の範囲。速度は二次的。純粋な回路で再現できないものは数学的に限界を示す（13 §5、§2）。
- **固定した入力**（設計書 §0）：`Scenario` の原始入力（係数記録、換算表、資材・設備・冷媒機器・工事・運用年次プロファイル・解体の数量と率、周期・明示事象年、境界 ι、T）。70単位の計算済み値は入力にしない。
- **固定した出力**：`C(T)`、14段階値（ι で含めたもの）、`Z(T)=A^term+ι_B1·R(T)`、`M([0,T])=C−Z`、事象列（発火時刻・属する年・回数）、交換後の状態。
- **自由にしたもの（捨てた構造）**：70単位、21 DIRECT、単位→段階の表、資材/設備の区切り、I→P1→TIME→AGG の順、節点と跳びの事前列挙、冷媒の8段倍加。14個の積算器は「出力に14段階値が要る」ためだけに置いた観測用である。
- **固定した意味上の制約**（15 §2、設計書 §5.6）：整流→積→積分の順、漏洩→交換、同時刻は「読出し→年ティック→発火の集合」、ι は読出し側のみ、ρ 分流は積とダイオードの後、妥当性マスクは加算の前、終端パケットは積算器に戻さない。

## §2 設計：3方向の比較と選定（設計書 §2・§3）
| 方向 | 中身 | 判定 |
|---|---|---|
| ① 法則先行の共通回路 | 係数レール×数量コンダクタンスの抵抗網を KCL で解く | **採用（振幅層）** |
| ② 段階カスケード（14 S1） | 同一時刻内のレール→コンダクタンス→トランス抵抗→バス→積分→読出し | **独立案としては不採用、①③の内部経路として吸収** |
| ③ ライフサイクル切替回路（14 S2） | 時間基準・事象時計・パケット・冷媒セル・読出しスイッチを実時間 0→T で走らせるハイブリッド | **採用（時間・状態層）** |
| 受動直列 R–L–C（14 S3） | `Lq″+Rq′+q/C=v_s(t)`、状態2つ | **不採用（反証）** |

- **カスケードを吸収した理由**：純粋な前向きカスケードには状態の帰還（時計のリセット、`u_{k+1}=f(u_k,χ_k)`）を置く場所がなく、旧 P1→TIME→AGG の順を回路名で再現するだけになる。同一時刻内の信号経路としては①③の中に残る。
- **受動直列 RLC を棄却した理由**（V1 で確認）：(a) 定電圧では `q→CV` に飽和し線形増加が作れない（目標 q を出すには `v_s` を外で作る＝レベル F）；(b) L2 により、源が事象時刻を知らなければ折れ・跳びが出ない；(c) 状態2つでは互いに無理数比の周期 n 本の位相を保てない；(d) ステップ応答の抵抗熱は ½CV² で時間に比例しない；(e) Z(T) は読出しで時間発展ではない。(a)(b)(d)(e) は CONFIRMED、(c) は S3 について CONFIRMED（`circuit_first/verification/VERDICTS.md` V1「Lemma and claim verdicts」）。
- **選定**：①＋③の合成で、構造は (α) 振幅クロスバー、(β) 時間・状態コア、(γ) 読出しの3つ。
- **統括の種 (i)〜(vi)**：(i) 修正して採用（係数レール、L1）、(ii) **全体では反証**（§6）、(iii) 採用（境界の先読み規則を追加）、(iv) 等価だが簡単にならない（保持＋定電流排出を採用）、(v) 採用、(vi) 採用（B2 はポテンショメータの電流分流に置換）。

## §3 最終的に作った式と共有回路構造（詳細は `circuit_first/topology.md` B・C 節、`adapter.md`）
**素子法則**（エンジンは WLC の語を含まない）：抵抗 `i=G(v_a−v_b)`（熱は計器で ∫vi dt、抵抗は記憶を持たない）、コンデンサ `i=C du/dt`・`q=Cu`、独立 DC 源、理想オペアンプ（ナレータ：`v₊=v₋`）、線形制御源、理想スイッチ、理想ダイオード、比較器 `[v₊−v₋≥0]`、ブールのゲート・ラッチ・D-FF・カウンタ・位相シーケンサ・パワーオン。事象間は各モード線形の MNA/DAE、切替時は電荷保存による再初期化（インパルス電荷が全節点で KCL を満たす）。

**(α) 振幅クロスバー（静的 DC、`engine/dc.py` で厳密に1回解く）**
- 源 `v=x·V0`（± 係数レール、係数 ID ごとに1本を資材・設備・工事・解体・運用で共有）。
- 段 `v_out=−(R_f/R_in)v_in`（データ値は抵抗値として入る）、接合点 `v_out=−R_f Σ_k G_k v_k`。
- **受動2因子形**：項の最後のデータ因子を接合点の入力コンダクタンスにする（レール電圧×数量コンダクタンス＝オーム＋KCL、オペアンプ不要）。S で 2,134 本（`v3_crossbar.json`）。
- 電圧として要る積（さらに掛けられる、または最後の因子をコンダクタンスにできない）にだけ能動出力を1つ置き、(式, 極性) ごとに1回作って共有。反転器 0。
- ポテンショメータの両区間で `1/(1−w)`、`r/(1−r)`、`(1−η)`。組成係数・ルート和・段階和・群和・B5 基礎額は KCL 接合点。

**(β) ライフサイクル・コア（ハイブリッド、`engine/hybrid.py`）**
- タップ：クロスバーの出力電圧を接地理想源としてコアに置く（置換定理。共有節点なし、V3 の統合ネットリストで一致）。
- 段階バス：仮想接地＋帰還 C の積算器。`C_s dv_s/dt=−Σi_in`。
- パケット：`Δq=C_s·v`（初期 3、更新、B5、終端、負の1年分）。
- 時間基準：年ランプ（年ティック、8ビットカウンタ）、大域ランプ（傾き 1−ε、リセットなし）、非伸長の絶対時刻ランプ `tb.u`、共有先読み比較器 `P=[v_year ≤ ρ·v_global]`、`ρ=ε(2−ε)/(1−ε)`。
- 事象時計（W2 キー＝周期等ごとに1つ）：`(1−ε)` の傾きのランプ、遅い比較器で `nc/(1−ε)` に発火、`C_jV_th` 分の電荷を引き抜いてリセット（累積誤差なし）。明示年は参照源 `τ_e·V0` と大域ランプの比較器（発火後に `V_hi=256V0` へ切り替えて無効化）。
- 年セル（B3）：フライングコンデンサ、`P=0` で当年分を捨てる、`P=1` で負の1年分パケット（群の修繕率が年内一定であることが条件、D3/D14）。
- 年バンク：一定＝1枝、線形＝基礎枝＋カウンタビット上の8ビット MDAC、表＝デコーダで切り替える枝列。系統：段階状は `tb.u` の比較器、下限付き減少は下限比較器。
- 電力系：KCL 加算 → VCCS → `R_p ∥ 理想ダイオード`（max(0,·)）→ 換算 → 系統バンク → ρ 分流（ι_B2 の静的スイッチで B2/B6 へ。電荷保存で二重計上を防ぐ）。
- 冷媒機器（B1）：電荷積算器 `u=V0·m`、年初の保持、漏洩 `r·gwp·m_start`、排出、損失パケット（年内の生値＋補正流、または閉じた年の保留値）、`m0` へのリセット、終端パケット `(1−η)gwp·m(T)` を `z_B1` へ。

**ハイブリッド状態と遷移**：`x=(全コンデンサの u；ラッチ・D-FF・カウンタビット・比較器出力；シーケンサ位相)`。1時刻の処理順：`読出し(左) → パワーオン → 先読み・早い比較器 → 年ティック → 発火（集合） → 読出し(右) → 後処理相`。発火の集合は「全パケットが発火前の状態を採取 → 全放出・リセット → 開放 → 再充電」をシーケンサの同期した零長位相で行う。後処理相で、時刻の直後に下降する y=0 の比較器をその時刻で切り替える（V1-D1 の修正）。
**規約**：右 ε=0・読出し優先度100、左 ε=0・優先度0、原典 ε=1e-9・優先度0（事象 τ は `τ/(1−ε)<T ⇔ τ<T(1−ε)` のとき数える。発火時刻を伸長して実現、年ティック・流れ・漏洩は伸長しない：D16）。単位 `γ`（kgCO2e/C）、`V0`=1 V、`τ_y`、`G_u` は模擬上の換算で、物理的な炭素–電気換算ではない。
**読出し**：`S_s=γ(q_bus,s+q_z,s)`（s∈ι）、`C=Σ S_s`、`Z=γΣq_z`（C1〜C4、B1）、`M=C−Z`。終端パケットは段階バスに入らないので1走行で複数の T を読める。
**接続規則**（「同じ回路、パラメータ変更のみ」の意味）：有限個のセル型＋固定の接続規則（全セルが共有レール・時間基準・段階バスにつながる）。建物は各セル型の個数と素子値だけが違う（W4 で行ごとにセルを置き、W2 で等しいキーを同じ時計にまとめる）。セル型は検証者の集計で約26種（V2：クロスバー9＋新しいコア11＋段階Aの再利用6）。
