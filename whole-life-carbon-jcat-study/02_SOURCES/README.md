## 2.2 主要シート群
- 画面：表紙、更新履歴、注意事項、チェックリスト。
- 入力：入力シート(A1～5,B2～5,C1～4)、入力シート(B1)、入力シート(B6,7)。GHG/CO2の表示版・隠し版あり。
- 内部計算：原単位、複合原単位、資材構成、資材製造・輸送・施工、工種別設備（電・空・衛・昇）。
- 時間：更新周期・修繕率、経年表示、排出係数と年次シナリオ。
- 付帯：EPD組込、木材炭素貯蔵、コンクリートCO2固定、発生品目・廃棄分析。
- 出力：詳細算定結果、Upfront Carbon、WLC、報告用シート。
- 詳細方式は外部AIJ-LCA計算ソフトとの連携に依存。ZIPだけではすべての計算経路を動かせない。

## 2.3 構造解析の確認レベル
- `OBSERVED`: ファイル名、シート枚数、概数式数、主要入力と表示方法、関数種別。
- `SAMPLED`: 大量セルの個別式、参照元・計算意図の抽出（標本として扱う）。
- `NOT_VERIFIED`: VBA動作、全数式の意味分類、全セルの再計算、原版と独立エンジンの数値一致。
- `RESTRICTED`: 原データの直接公開・原単位/原式の転載。
