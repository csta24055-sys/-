# 検証記録: 2022年度 多室シミュレーション（中間粒径 5〜45 μm の行方）

最終更新: 2026-11-03 / 検証状態: **数値再現済み・結論検証済み**（MIN/MAX 出力CSV 35件のうち、行方の集計に使われた計算シート20件を全件検証。CSVは1件のみ直接確認）

## 1. 研究概要
2022年度卒論（S-2022-01/02）。実験住宅（床吹出型全館空調）の回路網で、LDKで発生させた 5〜45 μm 粉塵が30分間にどこへ行くか（各室沈着・電気集塵機・換気・浮遊残存）を計算し、『まとめ』表（S-2022-05）と学会論文 その42（S-REF-18）の図7に掲載した。

## 2. 原資料
- 入力値: S-2022-04『00 シミュレーション入力値.xlsx』（風量 弱923/強1408 m³/h、室別β、発生量MIN/MAX）
- 計算: S-2022-05『01 沈着計算＆まとめ.xlsx』— 10秒刻み16シート（条件2〜5 × 4粒径）、1秒刻み4シート（30–45 μm）
- 出力CSV: S-2022-06（35件, 1件直接確認）
- 学会論文: S-REF-18（2023 その42）

## 4. 数式と仮定
dC_i/dt = M_i/V_i − β_i C_i + (1/V_i)[Σ_j (1−η_ij) C_j Q_ij⁺ − C_i Σ_j Q_ij⁻]（S-REF-18 表5）。β は重力沈降の理論値（室高さ別）。各室完全混合。沈着量はシート上で β·V·C·Δt を時間積算。

`verification/Y2022_simulation/verify_2022_sim.py`（入力は private_data のみ）。本アプリの多室モデルによる独立再計算は `scripts/validate_fate_2022.py`。

## 6. 再現結果（results.md 全表）
- 20シートすべてで、発生量 M に対して「室別沈着＋集塵機＋換気＋30分後の浮遊残存＋未計上」が100%となる（収支は閉じる）。
- 『まとめ』右表の LDK（例 53.9%）は **LDK＋吹抜** の沈着と一致（全16条件）。
- 『その他（沈着しなかった量）』は **30分後の浮遊残存＋未計上（数値上の残差）** の和と一致（例 条件2・5–10 μm: 9.04＋3.64＝12.7%）。
- 30–45 μm の行は **1秒刻みシート** の値（LDK＋吹抜 98.0/97.2%）で、10秒刻みシート（87.6/86.8%）ではない。

## 7. 原資料との比較（主な不一致）
| 項目 | 原資料 | 再計算 | 判定 |
|---|---|---|---|
| 『LDK』の定義 | LDK | LDK＋吹抜 | 表記の不一致（数値は一致） |
| 『その他』の意味 | 沈着しなかった量 | 浮遊残存＋数値残差（30–45 μmでは浮遊残存0、残差1.2%） | 定義の不一致 |
| 集塵機（EP OFF条件） | 0.0%（多くの行） | シートの集塵機欄は EP OFF でも 0.1〜40.9% を計上 | 表は大半を0に置換、30–45 μm・条件4のみ0.3%が残る |
| 時間刻み | 1つの表 | 10–30 μm は10秒刻み、30–45 μm は1秒刻みの結果が混在 | 表の作成方法が未記載 |

## 8. 原因候補と追加検証
- **未計上（残差）**: 初回ステップで室内に入る量が C₁·V = M·(1−e^(−βΔt))/(βΔt) となり（全20シートで小数第2位まで一致）、初回ステップ内の沈着分が沈着の積算に入らない。20–45 μm では残差＝初回ステップ損失（10秒: 5.35%・11.49%、1秒: 1.24%）。5–20 μm の弱運転ではこれに他室の矩形積算の差が加わる（3.0〜3.6%）。→ **時間刻みに依存する数値誤差**であり、βΔt が大きいほど大きい（fig_residual.png）。
- 当初の仮説 F-SIM-10（β·Δt>1 の不安定）は機構としては誤りだが、「時間刻みに依存する数値誤差」という点は支持される（2026-11-03 再訂正）。

## 9. 研究上の意味
- 30–45 μm の「約98%が発生室に沈着」は1秒刻みでは成立（LDK単独94.2%、吹抜3.8%）。10秒刻みの値をそのまま使うと約11%が行方不明になる。
- EP の捕集割合（5–10 μm で32.0/47.3%）は EP ON 条件のシートと一致し、結論に影響する誤りはない。
- EP OFF 条件の集塵機欄（最大41%）は表に転記されていないため結論には影響しないが、シートを再利用する際の落とし穴である。

## 10. 最終評価
2022年度の行方の結論（粗大粒子は発生室に沈着、5–10 μm は EP で3〜5割捕集）は数値的に支持される。ただし表の『LDK』『その他』の定義と時間刻みの混在を明記する必要がある。
