## 3. 発見と検証を分けた全件収集の仕様

各新規候補には、必ず次の情報を追跡可能な形式で保存する。

`new_candidate_id`, `discovery_run_id`, `discovery_datetime_utc`, `original_query_id`（旧896に該当する場合）, `actual_search_call_id`, `source_title`, `source_url`, `canonical_url`, `doi_or_report_id`, `publisher`, `publication_date`, `retrieved_at`, `source_type`, `research_axis_ids`, `research_topic_ids`, `competitor_ids`, `required_evidence_route`（PRIMARY/INDEPENDENT/COUNTER/QUANT/COMPETITOR）, `original_page_attempted`, `fetch_status`, `original_text_read`, `quote_checked`, `quote_location`, `dependency_or_same_origin_group`, `distinct_from_existing`, `screening_decision`, `blocker`, `reviewer_or_worker_run_id`。

**4種類の数は別掲すること:** (A) 新たに発見した候補URL件数、(B) 全既存台帳との差し引き後の新規正規化URL件数、(C) 原文本文に実アクセスできた件数、(D) 指定テーマの主張に対する原文引用・独立性まで確認して正式に使える件数（S1とS2の判定を混同しない）。これと別に実行済みWeb検索操作数、拒否操作数、独立した資料起源数、資料とテーマの対応件数を示す。

- URLだけの検索結果は `DISCOVERED_NOT_READ` とし、原資料を開いたことにしない。HTTP取得成功だけなら `FETCHED_NOT_VERIFIED`。
- 公式文書・開発元本人の一次発言・学術原著・方法明記の調査、公的データ、実際の利用者証言、競合の価格・規約などを用途別に分類。企業宣伝は企業がそう主張している証拠にとどめる。反例・批判的検証・独立した研究を欠かさない。
- 同一記事のモバイル版・印刷版・PDF/HTML違い、arXivのabs/pdf、翻訳・転載・ニュース再配信、同じ母集団の複数記事を独立資料と数えない。
- CAPTCHA/403/429/規約上禁止やツール上限の場合は `BLOCKED` と原因を明記し、アクセス制限を迂回せず、適法な別の一次URLや他の原資料を探索。見つからなければ欠損のままとする。
- 年月・価格・性能値は最新か再確認し、適用日と地域を記録。推測で数値や引用・頁を作成しない。

## 4. 欠落を埋める探索順序（件数偏重禁止）

1. **現時点の未達IDを再計算する。** 旧896検索IDの未実行488件は原則指定文字列のまま本当に検索を実行し、実行マニフェストに証跡を残す。旧検索実行と追加1,000件収集を同じ検索操作で満たせる場合は効率的に同時達成する。検索結果の再索引だけでは実行済みにしない。
2. 325テーマの残200件について、まず一次資料探索・独立資料探索・反例探索・定義・観測単位・記号式/計算候補の欠落を解消する。未処理のAXIS_01/03/05/06/15/16/18等を放置せず、全軸に探索を配分。既存のテーマに関連するURLの読み込みと新規探索を両立させる。
3. 残48競合について、公式一次サイト・料金制限・PPTX編集可否・引用品質・処理速度・保持/送信・非AI無料代替・独立した利用者の反証を収集。事業者公表値と実測値を混同しない。
4. 追加7テーマ（高速化・小規模高性能エンジン・買収/提携など）にも探索を配分し、0/7のまま置かない。
5. **検索語を広げるのは不足根拠を特定したあと。** 学校／研究室／就職準備／営業／設計／専門職の用途差、作業工数、スライド品質、編集可能PPTX、生成時間と処理費、価格支払い意欲、無料代替、広告、収益・M&A、法令・プライバシーなど原指示の全対象について、欠落している原文種別を順に狙う。製品の評価に有利な資料だけを収集しない。
6. 各バッチで `new valid source candidates per under-covered topic` と `remaining S1 blockers` を比較し、S1の空白を埋められない偏った資料群をさらに増やさない。優先度は順序の調整のみで、対象IDの削除は認めない。
