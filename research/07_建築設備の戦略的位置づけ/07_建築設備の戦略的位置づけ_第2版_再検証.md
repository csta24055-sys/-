# 07 建築設備の戦略的位置づけ（第2版：再検証）

- 調査基準日：2026年11月1日／第2版（2026-11-01）
- 第1版（`07_建築設備の戦略的位置づけ.md`）は構造からの推論が中心で、職務分掌は【不明】だった。本版は、東電の採用サイトの一次記述（S051：求人96件の一覧、S053：建築系の求人詳細、S052：新卒のフィールドと社員紹介）、2026年度中間期の決算説明資料（S032）、各社の有価証券報告書を使って、第1版の判断を一つずつ検証し、修正する。
- 指令への対応：①建築の採用区分、②建築技術、③建築設備の業務、④原子力施設の空調、⑤需要家向けの設備事業、⑥データセンターの冷却を**混同せずに分けて**扱う。重要性が高い領域と低い領域の両方を示す。

## 2. 第1版の判断の検証と修正

| 第1版の判断 | 検証結果 | 修正後の判断 |
|---|---|---|
| 「全社的には支援技術である」 | **維持**。建築部門は確認できた範囲で約265名（連結の0.7%程度）。第五次総特は「建物管理・工事・修繕」を割高な費目として抑制した（S001） | 維持 |
| 「原子力・廃炉施設の換気空調は、建築設備が特定分野の中核技術となる領域」 | **過度な一般化だった**。技術として安全上の中核であることは正しい。しかし、その担い手が建築設備の技術者であることは確認できず、プラントの換気系は機械（原子力）部門の所管と推定される。建築部門の原子力関連の業務として一次資料で確認できたのは、溢水対策、緊急時対策施設、耐震評価、許認可、廃炉関連の建物（燃料・デブリ取り出し、廃棄物、水対策）、構内建物の保全である | **「技術の重要性」と「職種の担当」を分ける**。原子力施設の空調は「重要性が高いが、建築設備職の主管とは確認できない隣接領域」に分類し直す |
| 「制御室・通信室の環境維持は特定分野の中核」 | **部分的に支持**。送配電の建築部門の対象に「超高圧変電所、通信用無線中継所」があり、建物の総合マネジメントを担う（S053）。ただし、機器室の環境の要求条件を誰が決めるか（電気・通信部門か）は未確認 | 「建築部門が建物として管理する、供給信頼度に関わる建物」として維持。確度は中 |
| 「DCの受電・冷却は特定分野の中核」 | **修正**。受電は電気・送変電計画（PG-2）と特高受変電の技術営業（AEI-1）、冷却は研究開発（TRI-4）が担う。建築設備の名を冠した担い手はない。ただし、DC廃熱の利用やコンテナ型DCは、建築設備の知識と直結する新事業である | 「建築設備の知識が応用されるが、現在の担い手は電気・研究開発・営業」という**参入可能な隣接領域**に分類する |
| 「需要家側のエネルギー設備（調整力）は特定分野の中核」 | **支持（確度が上がった）**。EPのサービス企画（空調・給湯）、設備サービスの運用、JFSでのESCOの機械設備設計が一次資料で確認できた | 維持。東電グループの中で、建築設備の専門性が**収益事業の中核として明示的に使われている唯一の領域** |
| 「建築設備技術者の関与範囲は【不明】」 | **更新**。建築部門の職域に建築設備が含まれることを確認した（S053） | 「建築部門の中の設備分野」として存在する |

## 3. 重要性の高い領域と低い領域（両方を示す）

### 3.1 重要性が高い領域
| 領域 | 重要性の根拠 | 建築設備の担当関係 |
|---|---|---|
| 福島第一の廃炉関連の建物（取り出し・廃棄物・水対策の建屋） | 「福島最優先」で財務の制約を受けにくい。30年以上続く（S001, S053）。建築部門は約75名で最大規模の一つ | **直接担当**（建築部門の職域。建築設備の経験が入り口として明示されている） |
| 柏崎刈羽の安全対策（溢水対策・緊急時対策施設）と特重施設 | 再稼働の条件。特重の期限（7号機は期限超過、6号機は2031年4月）がある（S032） | 建築部門が担当。設備（空調・電源）の比重は【不明】 |
| 送配電の建物（超高圧変電所・通信用無線中継所・事業所） | 供給信頼度。建物の更新・災害対策 | **直接担当**（建築部門 約110名。建物の総合マネジメント） |
| 需要家向けの設備サービス（空調・給湯・蓄電・ESCO） | EPの収益多様化・調整力の創出（S001）。DRの実証（S032） | **直接担当**（EP・JFS） |

### 3.2 重要性が中程度または隣接する領域
| 領域 | 理由 | 担当関係 |
|---|---|---|
| 原子力のプラント換気空調系 | 安全上は極めて重要 | **隣接**（機械・原子力部門が主管と推定。建築は取り合い） |
| DCの冷却・廃熱利用・コンテナ型DC | 成長戦略。ただし担い手は研究開発・PG | **参入可能な隣接領域** |
| 大規模再開発（AEI） | 7名の小組織。建築設備士が資格要件に明記されている | 直接担当だが規模は小さい |

### 3.3 重要性が低い領域
| 領域 | 理由 |
|---|---|
| 一般の事務所・社宅の維持管理 | 第五次総特で「建物管理・工事・修繕」が割高と判定された。事務所建屋の定例工事は頻度の緩和・繰延の対象（S001）。資産売却（約2,000億円）で不動産の集約が進む可能性がある |
| JERAへ移った火力発電所の建屋・付帯設備（東電・中部にとって） | 職域ごとJERAへ移っている（S047） |
| 標準的な施工・保守の実作業 | 子会社・外部の施工会社に委託されている（S030）。本体の職務は発注・監理 |

## 4. 他社との比較（建築設備の職域は会社の資産構成で決まる）【分析】
- 火力を自社で保有する関西・東北・九州・北海道では、火力発電所の建屋・付帯設備が職域に残る。関西の南港・姫路第一の更新、北海道の石狩湾新港2・3号機、東北の東新潟6号機など、大型の建設案件がある（S040, S042, S046）。
- 送配電の建築職は、各社で「変電所・事業所の建物のライフサイクル管理（発注者）」という同じ型をとる。中部PGの建築職の求人も同型だった（検索要約 C20）。
- JERAでは、火力の建屋・付帯設備はJERAの国内火力・ガス事業（従業員3,895人）に属する（S047）。
- したがって「電力会社の建築設備職の将来」は会社によって異なる。原子力・廃炉を持つ会社（東電・関西・九州など）、火力を持つ会社、ネットワーク専業の会社で、需要の中身が違う。

## 6. 建築設備技術者が代替困難になる条件（第1版の修正版）
第1版では四条件（原子力安全規制、電力系統の要件、リスクベース保全、データ・AI）のうち二つ以上を組み合わせることを挙げた。一次資料に照らして、次のように修正する。

1. **発注者としての総合力**（企画・設計・許認可・工事監理・保全の一貫管理。積算・コスト・工程・安全）：すべての建築系の求人に共通する中核の要件である（S053）。設備の専門性は、この発注者能力の上に載る形で評価される。
2. **原子力・廃炉の建屋の要求条件の理解**（溢水・区画・耐震・許認可）：建築部門の中途需要の重心である（S051）。
3. **リスクベースの説明能力**：財務の再精査の論理（影響度×発生確率）で、保全の必要性を説明できること（S001）。
4. **需要側の設備と電力系統・市場をつなぐ能力**（DR、調整力、ESCO）：EPの設備サービスで直接求められている（S051, S052）。

【反証の検討】「建築設備は機械・電気の知識で代替できる」という反論は、プラントの空調（④）については当てはまる可能性が高い。一方、建物の総合マネジメント（③）では、建築の発注者能力と一体となった設備の知識が求められており、機械・電気だけでは代替しにくいと判断する。
