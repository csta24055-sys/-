## 1. 物理システムの基本構造

### 1.1 電源構成（2024年度速報、S010）【確認事実】
| 電源 | 比率 |
|---|---|
| LNG（天然ガス） | 約32% |
| 石炭 | 約29% |
| 石油等 | 約7% |
| 火力計 | 約68% |
| 再エネ | 約23% |
| 原子力 | 約9% |

LNG輸入量（2025年）は約6,498万トンで、豪州が39.7%、マレーシアが14.8%、ロシアが8.9%、米国が6.9%などを占める。中東依存度は10.8%、ホルムズ海峡依存度は6.3%（年間約400万トン）（S010）。電力部門は年間約3,700万トン、都市ガス部門は約2,500万トンを消費する（2024年度、S010）。

【分析】LNGのホルムズ依存度が6.3%と低いにもかかわらず、2026年の中東危機で日本の電力コストが大きく上がった。その理由は量ではなく価格にある。①カタールの供給停止（世界の輸出の約2割、S010）で世界のスポット価格が上がる。②欧州との冬季カーゴの争奪（S015）が起きる。③原油連動の長期契約価格が、原油高（JCC 117ドル/バレル、2026年6月、S011）を通じて上がる。「調達先の多角化」は量の安全保障を高めたが、価格の安全保障までは確保しない。これが、原子力・再エネ（燃料費のかからない電源）の政策的価値を再び押し上げた構造である。

### 1.2 系統の物理的制約
- **周波数の東西分断**：50Hzと60Hzの境界は周波数変換所でしか越えられず、東西の融通能力が限られる（一般史実）。
- **同期安定性と慣性**：火力・原子力・水力の同期発電機は回転慣性で周波数を支える。インバータ型の再エネ（太陽光・風力・蓄電池）が増えると慣性が減り、周波数の変動が大きくなる。対策として、同期調相機、グリッドフォーミング型インバータ、需給調整市場での調整力の調達が必要になる（技術一般論）。
- **長距離送電と立地の偏在**：再エネの適地（北海道・東北・九州）と需要地（首都圏・関西）が離れている。広域連系系統のマスタープランに基づく北海道・本州間の海底直流送電などが国家プロジェクトとして位置づけられている（S003）。
- **データセンターの集積**：首都圏では印西・白井（千葉）、相模原など、特定の変電所の周辺に需要が集中する。東電PGが「ウェルカムゾーンマップ」で適地へ誘導し、変電所用地を事業者に提供させる「パートナー参加型」の手法をとるのは、この物理的な集中を緩和するためである（S001）。

## 2. 需要の構造変化

### 2.1 OCCTO需要想定（2026年1月、S012）【確認事実】
| | 2026年度 | 2030年度 | 2035年度 | 年平均（2025〜35年度） |
|---|---:|---:|---:|---:|
| 全国の需要電力量（使用端、億kWh） | 8,034 | 8,243 | 8,461 | +0.5% |
| 東京エリアの需要電力量（億kWh） | 2,578 | 2,722 | 2,871 | +1.1% |
| 東京エリアの産業用その他（億kWh） | 872 | 1,018 | 1,167 | — |
| 東京エリアの家庭用その他（億kWh） | 965 | 953 | 940 | 減少 |
| 全国の最大需要電力（万kW） | 15,963 | 16,244 | 16,460 | +0.4% |
| 東京エリアの最大需要電力（万kW） | 5,501 | 5,699 | 5,888 | +0.8% |

データセンターの新増設分（個別計上・全国）：最大需要は2026年度0.64GW、2030年度3.28GW、2035年度6.61GW。電力量は2035年度494億kWh。半導体工場分は2035年度74億kWh（S012、検索要約と照合）。

【分析】
- 全国の需要は「家庭用の減少（人口減・省エネ）」と「産業用の増加（DC・半導体）」が打ち消し合い、緩やかに増える。増加分は地理的に偏在しており、東京エリアの伸びは全国の約2倍になる。
- 需要の増加は「kWh（電力量）」より「特定地点の受電容量（kW）と接続の時期」の問題として現れる。電力会社の技術的な課題は、発電量の確保から、ネットワークの局所的な増強（変電所・送電線）と接続の早期化へ移っている。
- 別の仮説：DCの需要は、AI投資のサイクル、チップの電力効率の改善、海外への立地流出によって大きく下振れしうる。OCCTO自身も、系統制約により需要が実現する時期は遅れうると指摘している（検索結果の二次分析による）。

### 2.2 政策見通しとの乖離
エネ基は2040年度の発電電力量を1.1〜1.2兆kWh程度とする（S003/S004）。OCCTOの2035年度の需要電力量（使用端）は8,461億kWhである。定義の違い（発電端か使用端か、送配電損失、自家発自家消費）を補正してもなお開きがあるかは【不明】（Q-P02）。【分析】エネ基は「需要が大きく増えるのに脱炭素電源が足りない」というリスクを強調する政治的な文書である。OCCTOは事業者の計画を積み上げる実務的な文書である。投資判断の前提としては、後者を基準に、前者を上振れケースとして扱うのが妥当である。

## 3. 経済・市場・資本の構造

### 3.1 制度の層構造【分析】
```
[規制収入層]  託送料金（レベニューキャップ）……一般送配電事業者の収入をほぼ確定させる
[準規制層]    容量市場／長期脱炭素電源オークション／需給調整市場……電源の固定費回収を制度で補う
[市場層]      JEPXスポット・先渡し・先物、相対契約……kWh価格の形成
[小売層]      自由料金、（経過措置の）規制料金……需要家への転嫁
[公的支援層]  電気・ガス料金支援（予備費）、GX経済移行債、政府系金融……価格の急騰と投資資金を補う
```
- 中東危機で、JKMは2026年2月27日の11.06ドルから3月9日に24.80ドルとなった。一方、JEPXのスポット価格は3月9日時点で11.43円/kWhと、前年並みにとどまった（S010）。【分析】燃料価格の急騰が卸電力価格にすぐには波及しないのは、在庫（大手電力のLNG在庫は219万トンで過去5年平均並み、S010）、長期契約の価格の時間遅れ（原油連動の長期契約は通常数か月遅れて価格に反映される）、需要の季節性による。その後、東電の2026年度第1四半期では「燃料・卸電力市場価格の高騰」が減益要因として明記された（決算概要、検索経由）。時間差をおいて小売と送配電（調整力・インバランス）の費用に転嫁されていったと推定される。

### 3.2 企業の収益構造の類型【分析】
| 類型 | 代表 | 収益の源泉 | 主なリスク |
|---|---|---|---|
| 規制ネットワーク型 | 一般送配電10社（東電PGなど） | 託送料金（レベニューキャップ） | 設備投資の前倒しと料金審査の時期差、DC需要の不確実性 |
| 燃料・発電ポートフォリオ型 | JERA、J-POWER | 燃料調達・トレーディング、発電 | 燃料価格、炭素規制、資産の座礁 |
| 垂直統合残存型 | 関電・九電・中部（JERA除く）・東北など | 原子力・水力・小売の一体運用 | 原子力の稼働率、規制、不祥事 |
| 国家関与型 | 東電HD | 原子力・小売・規制ネットワークの合算、国の資金援助 | 廃炉費用の顕在化、国の関与条件 |
| 総合エネルギー型 | 東京ガス・大阪ガス | ガスと電力のセット、海外上流、LNG | LNG価格、電化による需要侵食 |
| 上流資源型 | INPEX | 原油・LNGの権益（イクシスなど） | 原油価格、地政学（価格上昇はむしろ利益） |

### 3.3 中東危機による利害の再配分【分析】
| 主体 | 影響 | 方向 |
|---|---|---|
| INPEX・上流権益保有者 | 原油・LNGの価格上昇は収益増 | 正 |
| JERA（トレーディング機能あり） | 調達コストは増えるが、「有事でも利益を獲得できるビジネスモデル」を志向（S001） | 両義的 |
| 小売（市場連動型メニュー） | 調達費の増加と顧客の流出 | 負 |
| 原子力の比率が高い電力（関電・九電） | 燃料費のかからない電源の価値が上がる | 正 |
| 原子力の稼働が少ない電力（東電・中部・北海道など） | 燃料費・購入電力料の増加 | 負 |
| 国（財務） | 料金支援で財政負担が増える | 負 |
| 需要家（DC・製造業） | 電力コストの上昇と立地判断の見直し | 負 |

## 4. 主要企業間の関係（概観）

詳細は04章と08章の図4。要点は以下である。
- **東電—中部**：JERAで50:50の合弁（燃料・火力の統合）。その他の分野（小売の首都圏・中部圏の越境）では競合する。
- **東電—関電工・東光高岳・東京エネシス**：資本関係（35.3%・35.2%・18.1%）に基づく施工力・機器供給の確保（S030）。関電工は東電以外からの受注（一般の建築設備工事）も多い独立した上場企業でもあり、資本関係は協調と独立の両面を持つ【分析】。
- **東電—NTT系**：DCの共同開発（印西白井、50MW、2026年度下期の開設計画。2023年の発表時点、現況は【不明】）。アット東京（33.3%）を通じたDC事業。
- **東電—東芝ES**：柏崎刈羽6号機の安全対策共同事業（KS6、2025年11月に解散）。
- **規制当局—事業者**：中部電力の浜岡の基準地震動データ不正（2026年1月に発覚、9月に社長・会長が辞任、3・4号機の審査申請を取り下げ。報道）。規制委は年内に処分を決める方針とされる。【分析】一社の不祥事は業界全体の規制の厳格化（審査の長期化）を通じて他社の再稼働の時期にも影響しうる、外部性を持つ。

## 5. 設備の老朽化・保守・災害対応（第1版での論点の提示）
- 高度成長期（1960〜70年代）に建設された送変電設備・建物の更新の波が、2020〜2040年代に集中する（一般論。各社の設備年齢の分布データは未取得、Q-I01）。
- 第五次総特の再精査は「実施しない場合のリスクの影響度×発生確率」による繰延を基本とする（S001）。【予測】更新の繰延が続くと、保全は事後保全・状態監視保全へ比重を移す。センサー・データ分析（TEPCO Data Hub、AIの活用、S001）が保全計画の正当化の根拠として重要になる。
- 災害：首都直下地震・大規模水害を想定した変電所の浸水対策、建物の耐震、非常用電源、通信設備室の環境維持は、法令対応・信頼度の維持として繰延の対象になりにくい領域である【分析】。
