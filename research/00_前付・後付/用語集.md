# 用語集

| 用語 | 説明 |
|---|---|
| ABW | Activity Based Working。業務内容に応じて働く場所を選ぶ働き方。東電の建築部門の設計手法の一つ（S091） |
| AEI室 | 東電HDのエリアエネルギーイノベーション事業室。分散型電源・再エネ・DC誘致などをグループ横断で扱う |
| BELS | 建築物省エネルギー性能表示制度 |
| CfD（双方向） | 差額決済契約。市場価格が低いと補填し、高いと差額を返還させる。EUの2024年改革で新設の電源に義務化 |
| CRO・CHRO・CIO | 最高リスク責任者・最高人事責任者・最高情報責任者 |
| DC | データセンター |
| DR | ディマンドリスポンス（需要家側の電力消費の調整） |
| EP | 東京電力エナジーパートナー（小売） |
| FCF | フリーキャッシュフロー（営業CF＋投資CF） |
| FM推進センター | 東電PG用地部の、建物の施設管理を担う組織（S091） |
| FP | 東京電力フュエル＆パワー（JERA株式を保有） |
| HD | 東京電力ホールディングス |
| JEPX | 日本卸電力取引所 |
| JERA | 東電FPと中部電力の50:50の合弁。燃料・火力 |
| JERAGM | JERA Global Markets。JERAの燃料トレーディング会社 |
| JKM | 北東アジアのLNGスポット価格の指標 |
| JCC | 全日本原油輸入CIF価格 |
| KK | 柏崎刈羽原子力発電所 |
| NDF | 原子力損害賠償・廃炉等支援機構。東電HDの議決権の過半を保有 |
| OCCTO | 電力広域的運営推進機関 |
| PG | 東京電力パワーグリッド（一般送配電） |
| PJM | 米国東部の地域送電機関（RTO） |
| ROIC | 投下資本利益率 |
| RP | 東京電力リニューアブルパワー（再エネ） |
| SPI・玉手箱 | 新卒採用で使われるWeb適性検査の種類 |
| TTF | 欧州（オランダ）の天然ガス価格の指標 |
| ZEB | ネット・ゼロ・エネルギー・ビル。ZEB Readyはその前段階の水準 |
| オーナー能力 | 事業者が自ら戦略策定・設計・PM・協力企業との協働・現場安全を担う能力（第五次総特） |
| 期ずれ | 燃料価格の変動が販売価格に反映されるまでの時間差による損益 |
| 件名単位の再精査 | 設備投資・費用の各件名を、法令上の必要性と、実施しない場合のリスク（影響度×発生確率）で評価する手法（第五次総特） |
| 資産回転型 | 資産を保有し続けず、早期に売却して資金を回収・再投資する事業モデル |
| 準規制市場 | 本研究の用語。市場に、容量市場・長期脱炭素電源オークション・レベニューキャップなどの制度的な回収の仕組みが重なった状態 |
| 総特（総合特別事業計画） | 東電とNDFが策定し、国が認定する再建計画。第五次は2026年1月認定 |
| 長期脱炭素電源オークション | 脱炭素電源の固定費を長期で回収させる制度 |
| 特重（特定重大事故等対処施設） | 原子炉建屋への故意の大型航空機衝突などに備える施設。設置期限がある |
| 発注者 | 自ら工事を施工せず、計画・設計の条件を定めて工事を発注し、監理する立場。東電の建築部門の基本的な立場（S091） |
| 保全業務 | 建物と付帯設備の状態を把握し、管理・保守する業務。東電の建築技術者の基本業務（S091） |
| 持分法 | 関連会社の利益を、出資比率に応じて投資会社の損益に取り込む会計処理 |
| リクルーター制度 | 社員が学生と面談し、情報提供や選考に関わる制度。東電は「あり」と記載（S089） |
| レベニューキャップ | 一般送配電事業者の収入の上限を規制期間ごとに定める託送料金制度（第1規制期間は2023〜2027年度） |
| 容量市場 | 将来の供給力（kW）を確保するための市場 |
