# 13 企業の意思決定の逆算（第3段階で新設）

- 調査基準日：2026年11月1日
- 方法：各事例について、①当時の外部環境、②企業の制約、③取りえた選択肢、④実際の判断、⑤結果を時系列で再構成する。そのうえで、公式説明（【当事者の主張】）と競合する仮説を、独立した証拠（実際の資源配分や、後の行動）と照合する。
- 史実の確度：本リポジトリの一次資料で確認したものは資料ID、一般に知られているが原典と照合していないものは「公知・要照合」と表記する。

## 事例1：JERAの設立と火力の完全統合（東電・中部、2014〜2019年）

| 項目 | 内容 |
|---|---|
| 時系列 | 2014年に東電・中部が包括提携に合意（公知・要照合）→2015年4月にJERAを設立。2015年10月に燃料輸送・トレーディング、2016年7月に上流・調達・海外発電、2019年4月に国内の既存火力を統合（S047） |
| 外部環境 | 事故後の原発の全停止で、火力の燃料費が急増した。LNGの「ジャパン・プレミアム」が問題視された。全面自由化（2016年）を控えていた |
| 東電の制約 | 国有化（2012年）、資金不足。新・総特（2014年）が「アライアンスによる企業価値の向上」を求めた（S001の沿革） |
| 中部の制約 | 浜岡が停止。燃料の調達規模の不足 |
| 選択肢 | (a)各社単独で調達を続ける、(b)燃料の調達だけを共同化する、(c)火力まで含めて統合する、(d)他の電力・商社と組む |
| 判断 | 段階的に(c)へ進んだ |
| 結果 | 世界最大級のLNG取扱量。2026年3月期の純利益1,935億円、2026年度の予想は4,800億円（S047, S060）。東電の第五次総特は「JERA以降、包括的なアライアンスは実現できていない」と書く（S001） |

**競合仮説**
| 仮説 | 内容 | 証拠との整合 |
|---|---|---|
| J-a 規模の経済（公式説明に近い） | 燃料調達の交渉力と効率 | 設備投資の79%が燃料事業（S047）、JERAGMが平時も利益を出している（S060）。**支持** |
| J-b 東電の再建のための資金・価値の創出 | 国の再建計画が求めた提携の成果を示す | 新・総特と新々・総特が提携を求め、JERAが「唯一の成功例」として扱われている（S001）。**支持** |
| J-c 中部の防衛的な選択 | 浜岡の停止の下で、火力のリスクを分散する | 中部は2026年に「多角化から転換」し、JERAを報告セグメントの一つとする（S041）。**部分的に支持** |
| J-d 段階的な統合は、労使・技術者の移籍コストを抑えるため | 一度に統合しない設計 | 3段階の統合（S047）、JERAの平均勤続16.4年（S047）。**整合するが直接の証拠はない** |

**事後評価【分析】**：J-aとJ-bが主因で、J-cが中部側の動機と判断する。2026年の危機では、統合が両社のグループ内ヘッジとして機能した（05章§12）。これは当初の設計目的（調達の効率化）ではなく、**副産物**だった可能性が高い。

## 事例2：東電の持株会社化と分社（2016年）

| 項目 | 内容 |
|---|---|
| 外部環境 | 全面自由化（2016年4月）と送配電の法的分離（2020年）の予定 |
| 制約 | 国有化の下での経営改革。新・総特が事業別の自律を求めた |
| 選択肢 | (a)一体のまま運営する、(b)法的分離の期限（2020年）まで待つ、(c)前倒しで持株会社化する |
| 判断 | (c) 2016年4月にHD・FP・PG・EPへ分社（S030） |
| 結果 | 第五次総特（2026年）が、分社化後に「HDと事業主体の間の情報流通・連携が低下」し、ウクライナ危機後のリスクの予兆検知が遅れたと自己評価した（S001） |

**競合仮説**：(i)自由化に備えた事業ごとの説明責任の明確化（公式説明）、(ii)将来の事業別の提携・売却の準備（後のJERA統合、第五次総特のアライアンスの「共同事業体」の発想と整合）。**事後の行動（2019年のFPの事業のJERAへの移管、2026年の共同事業体の公募）は(ii)を支持する**。分社の弊害（情報の分断）は、第五次総特が自ら認めた【当事者の主張】。

## 事例3：柏崎刈羽の再稼働までの13年

| 年 | 出来事 | 出典 |
|---|---|---|
| 2013 | 6・7号機の審査を申請（公知・要照合） | — |
| 2017 | 設置変更許可（公知・要照合） | — |
| 2021 | 核物質防護の不適切事案。規制委の対応区分が引き上げられる | S001 |
| 2023 | 追加検査の結果を受けて区分が戻る | S001 |
| 2024.4 | 7号機に燃料を装荷 | S001 |
| 2025.2 | 7号機の特重の完了予定を2029年8月に変更（設置期限は2025年10月） | S001 |
| 2025.6 | 6号機の起動準備に集中すると判断 | S001 |
| 2025.10 | 1,000億円規模の地域貢献と、1・2号機の廃炉の検討を表明 | S001 |
| 2025.12 | 新潟県知事が了解 | S001 |
| 2026.1–4 | 6号機の再起動（1/21）と営業運転（4/16） | S006 |
| 2026.9 | 規則改正で6号機の特重の期限が2031年4月に延長 | S032 |

**逆算：なぜ「7号機ではなく6号機」で「1・2号機の廃炉」なのか**
- 制約：7号機は特重の期限を過ぎ（2025年10月）、運転できない。6号機は期限まで猶予があった。
- 選択肢：(a)7号機の特重の完成を待つ、(b)6号機を先に動かす、(c)両方を待つ。
- 判断：(b)。【分析】キャッシュの必要（1基で年約1,000億円）と、規制上の制約（特重の期限）の両方から、合理的に導かれる判断である。
- 1・2号機の廃炉の表明（2025年10月、県議会の連合委員会で）の競合仮説：
  - (i)経営資源（人員・施工力）の集中（公式説明）
  - (ii)地元との交渉の材料（再稼働の了解と引き換えに基数を減らす）
  - (iii)古い号機の安全投資の経済性が成り立たない

  表明の場が県議会で、時期が知事の判断の直前だったことは(ii)と整合する。他方、(i)と(iii)も否定できない。**三つの複合と判断する**（確信度：中）。

## 事例4：関西電力：火力を手放さず、原子力の早期再稼働と再投資

| 時期 | 出来事 |
|---|---|
| 2010年代後半 | 高浜・大飯・美浜3号機などが順次再稼働（公知・要照合） |
| 2019 | 金品受取問題（公知） |
| 2021.3 | 経営理念「Purpose & Values」（S040） |
| 2021→2025年度 | 自己資本比率19.2%→35.1%（S040） |
| 2025.7 | 美浜の後継機に向けた地質調査を表明（報道） |
| 2026.4 | 経営計画2026：DC事業を情報通信へ区分変更。南港・姫路第一のLNG更新、揚水の更新（S040） |

**競合仮説**（04章第2版 H-K2a〜c に加えて）
- H-K3 「関西は新設の判断を、制度が整うまで保留している（オプション保持）」：調査は2030年頃までとし、判断は「事業環境を踏まえる」とする（報道）。一方で、LNG火力の更新は着工の予定を明記している（S040）。**不確実性の高い原子力は「オプション」、確実性の高いLNGは「実行」という使い分け**と整合する。
- 反証の候補：2027年中に美浜の後継機の建設決定があれば、H-K3は弱まる（15章の指標 I-C3）。

| 時期 | 出来事 |
|---|---|

| 2014〜 | 4号機・3号機の審査を申請（公知・要照合） |
| 2018〜 | 基準地震動のデータの扱いが恣意的な手法へエスカレート（報道） |

|---|---|---|

| 項目 | 内容 |
|---|---|
| 判断 | 送配電への投資（2,173億円）が発電（1,846億円）を上回る。越後変電所の新設など（S042） |
| 逆算 | 財務は薄い（自己資本比率19.4%）が、送配電の投資はレベニューキャップで回収できる。発電への投資は回収が不確実なため絞る、という**回収の確実性による資本配分**と整合する |
| 競合仮説 | 国の広域系統のマスタープラン（S003）による外生的な投資の要請。どちらの比重が大きいかは、投資の決定過程の資料が必要 |

## 横断的な発見【分析】
1. **回収の確実性が資本配分を決める**：規制の回収（送配電）、制度の回収（長期脱炭素オークション）、市場の回収（小売・火力）の順に、投資が選好される（事例7・8・10）。
2. **不確実な大型案件は「オプション」として保持される**（美浜の後継機、大間、東通）。撤退は、減損・地元・国策の三つのコストが一度に顕在化するため、先送りされやすい。
3. **提携は危機と国家関与の産物**である（JERAは事故後、第五次総特のアライアンスはFCFの赤字の下）。平時の自発的な大型統合の事例は、日本の電力では乏しい。
4. 公式説明は**判断の一面（効率・安全）だけを示し、交渉上・財務上の動機は語られない**傾向がある（事例3の1・2号機、事例7の33.4%）。後者は、後の行動や数値の選び方から推定するしかない。
