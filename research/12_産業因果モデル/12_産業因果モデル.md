# 12 産業因果モデル：変数・経路・時間差・フィードバック（第3段階で新設）

- 調査基準日：2026年11月1日
- 目的：歴史、政策、地政学、技術、資本市場、電力需要、企業戦略、組織、人事、専門職の相互作用を、**「どの変数が変わると、どの経路で、どれだけの時間差で、どの変数に効くか」**として記述する。
- 方法：
  - ①変数を「遅い変数」（歴史・制度・人口構成）と「速い変数」（価格・需要・利益）に分ける。
  - ②経路ごとに、メカニズム、時間差、量的証拠（一次資料で確認できた大きさ）、確信度を示す。
  - ③経路が閉じて自己強化・自己抑制するフィードバックを特定する。
  - ④因果の同定上の注意（交絡・逆因果・同時性）を経路ごとに書く。

## 3. フィードバック・ループ

### R1 原子力の信頼・投資の好循環（関西型、自己強化）
`稼働 → 利益・財務余力↑ → 安全投資・地域投資↑ → 規制・地元の信頼↑ → 稼働の継続・新設の検討` 
証拠：関西の財務の回復と、美浜の後継機の調査（S040、報道）。弱点：不祥事（2019年の金品受取問題）が起きれば、ループは逆転しうる。

### R2 停止・圧力・不正の悪循環（自己強化。中部・東電の過去事例）
`停止の長期化 → 収益圧力↑ → 経営による再稼働の督促 → 現場の不正・手抜きの誘因 → 発覚 → 審査の厳格化・地元の不信 → 停止の長期化` 
証拠：浜岡（経営の叱責が不正の一因と報じられている）、柏崎刈羽の核物質防護の事案と安全対策工事の未完了（S001）。【分析】このループを断ち切る制度的な装置は、規制の独立性と内部通報だけでなく、**再稼働の時期を経営目標のKPIにしない**ことである。

### R3 人材の空洞化ループ（自己強化、遅い）
`採用凍結（2011〜） → 30代の層の欠落 → オーナー能力↓ → 外注への依存↑ → 社内に知見がたまらない → プロジェクトの遅延・費用増 → 財務の悪化 → 採用・処遇の抑制` 
証拠：S001（年齢構成の歪み、オーナー能力の不足）、S053（30代の層の薄さ）、S051（中途採用での補充）。現在の介入：中途採用（年俸制で520〜1,260万円）、処遇の柔軟化、生成AIによる形式知化（申請書の確認作業を約8割削減の見込み、S032）。

### B1 価格による需要抑制（自己抑制、速い）
`燃料価格↑ → 電気料金↑ → 需要↓ → 燃料の購入量↓` 
証拠：上期のエリア需要△6.3%（S032）。ただし、P4（政府の補助）がこのループを弱めている。

### B2 規制料金による費用の転嫁（自己抑制、遅い）
`送配電の費用↑（物価・金利・調整力） → 収入見通しの見直し → 託送料金↑ → 送配電の収支の回復` 
証拠：2,516億円の増額承認（S032）。このループは送配電の財務を安定させるが、需要家の負担を増やし、DCの立地競争力（電気料金）を弱める。

### R4 DC需要と系統投資（条件付きの自己強化）
`DC需要 → 系統の増強 → 接続の早期化 → DC立地の増加` 
ただし `託送料金↑ → 立地競争力↓`（B2と競合）。どちらが勝つかで、06章のS1かS3かが分かれる。

## 5. モデルの限界
- 経路の多くは**少数の事例（n=1〜10）**から導いている。統計的な推定ではない。
- 速い変数（価格・利益）と遅い変数（人口構成・制度）の相互作用は、時間差が長く、同時に多数の要因が動くため、因果の同定が難しい。
- P5（危機→規制の柔軟化）、P6（DC→託送料金）、P15（求人→重要度）は、相関を因果と取り違える危険が特に大きい。16章の反証表で個別に扱う。
