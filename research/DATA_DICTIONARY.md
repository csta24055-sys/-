# データ辞書 v0.1

## 主要データ

`app/data/papers.json` が初期書誌マスター。Electronアプリでは初回起動時にこの初期値をコピーし、変更後はOSの `userData/tajima-state.json` に保存する（原本は上書きしない）。ブラウザプレビューは `localStorage` に保存する。`app/data/seed.js` は初期JSONと同じ配列のブラウザ読込版。

各論文オブジェクトには次を持たせている。

| キー | 意味 |
|---|---|
| `id` | 安定した一意識別子 |
| `title`, `authors`, `year` | 論文書誌情報 |
| `venue`, `detail` | 掲載誌・巻号ページなど。未確認は埋めない |
| `collectionScope` | `lab`=研究室サイトの最近の論文、`faculty`=教授共著を含む業績、`user`=利用者登録 |
| `categoryIds` | 研究分野の複数タグ。仮分類であることを表示 |
| `sourceUrl` | 参照元公式サイトURL。個別論文PDFのURLとは限らない |
| `bibliographyVerified` | 公式の一覧に同名の書誌があるか |
| `fullTextVerified` | 全文を精査したか。初期値はすべて `false` |
| `pdfPath` | アプリが取り込んだPDFのローカル保存パス。初期値は空 |
| `summary` | 利用者が本文を確認して入力する項目（目的・手法・結果・結論・限界・根拠ページ） |
| `memo` | 読書ノート |
| `isUserAdded` | ユーザーが独自に追加したか |
| `pdfHash` | 取り込んだPDFのSHA-256（`userData/pdfs/<hash>.pdf`） |
| `pdfText` | 取り込んだPDFから端末内で抽出したページ別テキスト（全文検索用、1論文40万字まで）。シードには無い |
| `pdfPages`, `pdfTextTruncated` | PDFのページ数、本文テキストを上限で切り詰めたか |
| `pdfMeta` | 抽出日時・ファイル名・書誌**候補**（`candidates`: title/authors/year とそれぞれの根拠）。候補は利用者が確認して反映する |
| `summaryUpdatedAt` | 要約・ノートの最終保存日時 |

`fullTextVerified` は利用者がPDFを紐づけたうえで「本文PDFと照合して記入した」にチェックした場合のみ `true`（自己申告）。

## 保存とバックアップ（デスクトップ）

- `userData/tajima-state.json`：アトミック書き込み（一時ファイル→rename）。保存のたびに直前の内容を `tajima-state.bak.json` に退避。
- 読み込めない場合は `tajima-state.corrupt-<時刻>.json` に退避し、`.bak` から自動復旧。
- 新しい版で公開書誌が増えた場合、未登録IDの書誌だけを追加（利用者のメモ・PDF紐づけは上書きしない）。
- テストや持ち運び用に、環境変数 `TAJIMA_USER_DATA` で保存先フォルダを変更できる。

## 集計ルール

- 年度別件数は1論文1件。全年度合計は登録件数に一致。
- 分野別集計は**複数ラベル計数**。1論文に耐震・損傷・FEM等を重複付与するためカテゴリ件数の合計は52件を超えうる。
- `other` は施工研究等を含む関連・横断テーマ。
- 初期分類は**論文のタイトルをもとにした暫定的な編集分類**。学術的な正式カテゴリー、研究室側の分類ではない。
- 自作の推薦スコアは類似文字列・ジャンル一致のヒューリスティック。根拠の強さ・学術的な新規性・成功確率ではない。

## データの改良優先順位

1. DOI、各学会論文の直接リンク、巻号頁を追加（確認できる場合だけ）。
2. 論文種別（学会論文、査読誌、卒業論文、修士論文、会議録）を厳密化。
3. 登録済みの原文PDFをユーザー側で読み込ませ、引用ページと根拠を持つ要約を生成。
4. 研究室から卒論・修論の正式リストが提供されたら別コレクションで取り込む。公開権限を都度確認。

## 保存（スマートフォン / ブラウザ / ホーム画面のWebアプリ）

- IndexedDB データベース `tajima-research-navigator`：`kv` ストアに状態（`state`）と1世代前（`state-prev`）、`pdfs` ストアに取り込んだPDFのバイト列（キーはSHA-256）。
- `pdfPath` が `idb:<sha256>` の論文は、その端末（ブラウザ）内のIndexedDBにPDF本体がある。PCのファイルパスや別端末の `idb:` は、その端末では開けない（再度紐づける）。
- 旧版（localStorage）のデータは初回起動時にIndexedDBへ移行する。保存容量が不足した場合はPDF本文の検索用テキストを除いて保存する。
- iPhoneではSafariとホーム画面のWebアプリで保存領域が別になる。
