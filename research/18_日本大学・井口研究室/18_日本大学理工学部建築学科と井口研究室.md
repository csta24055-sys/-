## 1. 学科の教育体系【確認事実：S092】

| 区分 | 内容 |
|---|---|
| 科目の構成 | 全学共通教育、教養教育、基礎教育（英語・数学・物理・化学）、専門教育 |
| 専門教育の分野 | 基礎、設計、計画・法規、**環境工学・設備**（環境工学Ⅰ、建築設備Ⅰなど）、構造力学・構造設計、材料・構法・生産、実験（建築実験Ⅰ〜Ⅳ）、総合・実践（建築学キャリアデザイン、卒業研究・設計） |
| 学年の進行 | 1年：基礎（建築基礎実験、デザイン基礎で3DCADとプログラミングの基礎）／2年：専門分野の基礎／**3年後期：研究室に配属**、建築学キャリアデザイン、建築実験Ⅳ（実際の空調設備で風量・圧力を測定）／4年：卒業研究または卒業設計 |
| 大学院（博士前期課程） | 2年以上在学し、特別研究6単位を含む30単位以上を修得して修士（工学）。特色ある科目例：**建築設備計画演習**（空気調和設備・給排水衛生設備の設計の実務フロー）、サステナブルデザイン特論、建築構造設計演習など |
| 大学院の入試 | 学内推薦（5月下旬にWeb登録、6月上旬に出願、7月上旬に試験）、一般第1〜3期（S093） |
| 大学院の進学者数 | 2018〜2025年度に57〜88名（2025年度は85名、定員は50名）（S093） |

**学部卒業時に想定される技術的能力【分析】**：建築学の全領域（設計・計画・構造・環境・材料・施工・法規）の基礎、建築設備の測定実験の経験、卒業研究による一つのテーマの調査・実験・論述。**建築設備の実務的な設計フロー**は、大学院の科目（建築設備計画演習）で扱われる。学部だけでは体系的に学ぶ機会が限られる可能性がある【推論：学部の設備系の科目の詳細なシラバスは未確認】。

## 2. 就職と進路の傾向【確認事実：S093】
- 2024年度の就職率は95.1%。卒業生は3万人以上。
- 学科独自の支援：
  - 4月から月1回の「就職・進学ガイダンス」。
  - 10〜12月の「OBOGと学生との懇談会」。約300名が参加し、学部の就職希望者の**約4割が参加企業に内定**している。
  - 11月の「キャリア教育プログラム」（意匠・構造・設備・開発・研究などの専門職志望者向け）。
- 主な就職実績（2026年3月時点）：大手ゼネコン、ハウスメーカー、設備会社（ダイダン）、設計事務所、NTTファシリティーズ、東日本旅客鉄道、国土交通省、東京都など。**東京電力は、公開されている「主な就職実績」の一覧には記載がない**。
- ゼネコン大手5社＋大手設計事務所に就職した人数は、学部で10〜30名、大学院で10〜21名（2016〜2024年）。大学院修了者のほうが大手設計事務所への就職が多い傾向がある（大手設計事務所は学部0〜2名、大学院4〜12名）。

**推論の限界**：一覧に記載がないことは、東電への就職者がいないことを意味しない。学科単位の東電への就職者数は公開されていない【不明】。東電の建築部門の社員インタビューには、「研究室OBから東京電力に建築部門がある事を教えてもらい」興味を持ったという記述がある（S091、大学名は不明）。これは、**研究室のOB・OGの経路が情報の取得に機能しうる**ことを示す事例だが、日本大学の事例かどうかは分からない。

## 3. 井口研究室（建築環境・設備研究室の井口担当分）

### 3.1 指導教員の経歴【確認事実：S080】
- 井口雅登 准教授：博士（工学）、一級建築士、気象予報士。
- 日本大学理工学部建築学科を卒業し、同大学院の博士前期課程（建築学専攻）を修了。
- **2002〜2015年に東京電力株式会社に勤務**。2009〜2011年は東京大学大学院工学系研究科の受託研究員を兼務。
- 2015年から日本大学理工学部建築学科。日本女子大学の非常勤講師も兼務（2023〜2024年は同大学院）。

### 3.2 研究テーマ【確認事実：S082】
- 井口担当：全館空調住宅の温湿度とエネルギー消費、住宅内の空気質、室内の気流。
- 蜂巣教授との共同：大学施設の建物のエネルギー消費。
- 研究室全体：企業との共同研究や、遠隔地での実験がある。
- 公開論文（S082、C30）：
  1. マルコフ連鎖を適用したモンテカルロ法による**空冷ヒートポンプチラーの定期点検結果の分析**（空気調和・衛生工学会論文集、2022年、査読あり）
  2. **蓄熱システムの空調熱源機の保全記録**を用いた多層ニューラルネットワークによる識別モデル（同、2022年、査読あり）
  3. 住宅における床チャンバー空調の設計法の研究（その5：実戸建住宅の温熱シミュレーションと実測の比較、日本建築学会環境系論文集、2019年）
  4. 集合住宅の床チャンバー空調の室間温度差（日本建築学会技術報告集、2024年）
  5. 壁掛エアコンを用いた薄型床下空調の温熱環境（同、2024年、実寸モックアップでの暖房実験）
  6. 床チャンバーを用いた空調システムの設計手法（その1、2012年、東京大学の研究者らとの共著）
- 学外での役職（S082）：建築環境・省エネルギー機構の全館暖冷房委員会の委員長、日本サステナブル建築協会のヒートポンプ式セントラル空調システム評価基準策定TGの委員、日本建築学会の伝熱小委員会の幹事、YUCACOシステム研究会の会長など。

### 3.3 実際に行っている研究と、今後取り組み得る研究の区別
| 区分 | 内容 | 根拠 |
|---|---|---|
| 実施（確認） | 全館空調・床チャンバー空調の温熱環境（実測・実寸実験・シミュレーション）、住宅の空気質、室内気流、住宅・大学施設のエネルギー消費、空調熱源機の点検・保全記録の統計的分析・機械学習 | S082, C30 |
| 取り組み得る（推論） | 業務用建物の空調設備の運用データ分析（BEMS）、蓄熱・ヒートポンプによるDR（需要の調整）、保全計画の最適化（リスクに基づく保全）、CFDによる気流解析 | 既存のテーマの延長として技術的に自然。ただし、研究室の方針・設備・共同研究の条件に依存する【推論】 |

### 3.4 形成される能力【分析】
| 能力 | 形成の経路 | 確度 |
|---|---|---|
| 熱・空気の工学（伝熱、空調、換気、湿り空気） | 研究テーマそのもの | 高 |
| 実測（温湿度・気流・エネルギー）と実験計画 | 実戸建・実寸モックアップの実験 | 高（研究室の実施例） |
| シミュレーション（温熱・負荷計算） | 論文3・6 | 中（学生ごとに異なる） |
| データ分析・統計・機械学習 | 論文1・2（点検・保全記録の分析） | 中（担当テーマによる） |
| 共同研究・遠隔地実験での協働 | 企業との共同研究 | 中 |

## 5. 他の建築系研究室との比較での特徴（公開情報の範囲）【分析】
- 学科には19の研究室がある（S093）。環境系は、建築環境・設備研究室と環境・音響系の研究室などである（S083）。
- 井口研究室の特徴は、①**住宅の空調システムの設計法**（床チャンバー空調）を実測・実験・シミュレーションで扱うこと、②**設備の保全記録のデータ分析**（統計・機械学習）を扱うこと、③指導教員が**実務（電力会社）と学外の技術基準づくり**（評価基準のTG、委員会）の両方に関わっていることである。②と③は、他の研究室の公開情報では同様の記述が見られなかった。ただし、他の研究室のすべての研究内容を調べたわけではない。
